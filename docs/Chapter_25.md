# 25 否定（ひてい）・部分否定（ぶぶんひてい） (否定・部分否定)

ものごとを打（う）ち消（け）したり、全面的（ぜんめんてき）には否定（ひてい）せず一部（いちぶ）だけを認（みと）めたりするとき、どの表現（ひょうげん）を使（つか）えばよいでしょうか。（否定某事，或不作全面否定而只承认其中一部分时，应使用哪些表达？）

| 核心功能 | 句型 | 语感重点 |
| :--- | :--- | :--- |
| 根据常理判断“不可能” | 〜はずがない | 由客观根据、原有预期推导 |
| 断然认定“不可能” | 〜わけがない | 说话人的确信、反驳更强 |
| 正式地说“没有做……” | 〜ことなく | 书面语，相当于「〜ないで」 |
| 连……都不做 | 〜もしない | 常含惊讶、不满或责备 |
| 根本顾不上…… | 〜どころではない | 没有做该事的余力或条件 |
| 强烈反问“不可能／绝不” | 〜ものか | 感情色彩强，不宜用于郑重场合 |
| 没有……便…… | 〜なしに・〜ことなしに | 正式书面表达 |
| 没必要做到……地步 | 〜までもない | 认为不值得特意去做 |
| 承认前项但附加保留 | 〜ことは〜が | “是……倒是……，不过……” |
| 未必总是如此 | 〜とは限（かぎ）らない | 指出例外或相反可能性 |
| 并不是…… | 〜わけではない | 否定由语境产生的结论或误解 |
| 也不是不…… | 〜ないことはない | 双重否定，消极肯定 |
| 并非只要……就…… | 〜というものではない | 否定过度概括的原则、看法 |
| 倒也不是不…… | 〜ないものでもない等 | 更委婉、常带个人判断 |

## 学習前（がくしゅうまえ）の小（しょう）テスト (课前小测验)

### 知（し）っていますか

[ a. はずがない　b. とは限（かぎ）らない　c. ことなく　d. こともない　e. どころじゃない ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。

1. こんな不正確（ふせいかく）な仕事（しごと）のやり方（かた）では、課長（かちょう）のOKが出（で）る（ **a. はずがない** ）。
   - **中文理解**：工作方式这么不严谨，科长按理不可能批准。
2. 今週（こんしゅう）はカラオケに行（い）く約束（やくそく）だけど、忙（いそが）しくてカラオケ（ **e. どころじゃない** ）。
   - **中文理解**：虽然约好这周去唱卡拉 OK，但忙得根本顾不上。
3. 彼（かれ）らは途中（とちゅう）で休（やす）む（ **c. ことなく** ）、目的地（もくてきち）まで歩（ある）き続（つづ）けた。
   - **中文理解**：他们中途没有休息，一直走到了目的地。
4. 希望者（きぼうしゃ）が多（おお）いので、申（もう）し込（こ）んでもみんな参加（さんか）できる（ **b. とは限（かぎ）らない** ）。
   - **中文理解**：申请者很多，所以即使报名，也未必人人都能参加。
5. 「先日（せんじつ）の仕事（しごと）の話（はなし）、無理（むり）をすればやれない（ **d. こともない** ）んですが……」
   「そうですか。それではお願（ねが）いします」
   - **中文理解**：“前几天谈的那项工作，勉强一下倒也不是不能做……”“是吗？那就拜托了。”

### 使（つか）えますか

文脈（ぶんみゃく）に合（あ）う方（ほう）を選（えら）びなさい。

1. 大阪（おおさか）から3時間（さんじかん）はかかるから、{ **a. 2時（にじ）に着（つ）くわけがない。** ／ b. 2時（にじ）に着（つ）くどころじゃない。 }
   - **中文理解**：从大阪出发要三个小时，因此不可能两点到达。「どころではない」表示“顾不上做某事”，不适合单纯否定到达的可能性。
2. 昼食（ちゅうしょく）を食（た）べることは食（た）べましたが、{ **a. サンドイッチ1つ（ひとつ）だけなんです。** ／ b. まだおなかがいっぱいです。 }
   - **中文理解**：午饭吃倒是吃了，但只吃了一个三明治。后项应补充与前项相反或限制前项的信息。
3. 品物（しなもの）は、安（やす）ければ必（かなら）ず { a. 売（う）れるはずがない。／ **b. 売（う）れるというものではない。** }
   - **中文理解**：商品并非只要便宜就一定卖得出去；这里是在否定“便宜必然畅销”这一简单化看法。
4. 大学院（だいがくいん）に行（い）くことを決（き）めたことは決（き）めたんだけど、{ **a. 自信（じしん）がない。** ／ b. 自信（じしん）がある。 }
   - **中文理解**：决定读研究生倒是决定了，不过没有信心。
5. あんな映画（えいが）がおもしろいものか。ぼくは { a. 3回（さんかい）も見（み）た。／ **b. 途中（とちゅう）で見（み）るのをやめた。** }
   - **中文理解**：那种电影怎么会有意思？我看到一半就不看了。

## 25 Ⅰ 否定（ひてい）

### 25 Ⅰ・1 〜はずがない ★3

**【意味（いみ）】根拠（こんきょ）から考（かんが）えると、その可能性（かのうせい）はない (按道理不可能……)**

①「王（おう）さん、遅（おそ）いですね。どうしたんでしょう」
「王（おう）さんは来（こ）られる **はずがない** よ。今日（きょう）は大切（たいせつ）な会議（かいぎ）があると言（い）っていたから」
- **中文理解**：“小王还没来，真慢啊。怎么回事呢？”“小王按理不可能来。他说今天有重要会议。”

②「けさ、品川駅（しながわえき）で佐藤（さとう）さんを見（み）ましたよ」
「そんな **はずはありません** 。佐藤（さとう）さんは今（いま）アイルランドを旅行（りょこう）していますよ」
- **中文理解**：“今天早上我在品川站看到佐藤了。”“不可能有这种事。佐藤现在正在爱尔兰旅行。”

③チンさんは生（なま）の魚（さかな）は食（た）べないから、刺身（さしみ）が好（す）きだと言（い）う **はずがありません** 。
- **中文理解**：小陈不吃生鱼，所以按理不可能说自己喜欢生鱼片。

④「え、さっき見（み）た写真（しゃしん）がない？　そんな **はずない** 。机（つくえ）の上（うえ）に返（かえ）しておいたよ」
「あ、あった、あった。ごめんなさい」
- **中文理解**：“咦，刚才看的照片不见了？不可能啊，我放回桌上了。”“啊，找到了。对不起。”

**接続（せつぞく）** V・イA普通形（ふつうけい）／ナAな・ナAである／Nの・Nである ＋ はずがない

▶ 既知（きち）の事実（じじつ）、常識（じょうしき）或（ある）いは予定（よてい）から論理的（ろんりてき）に考（かんが）え、「そうなる見込（みこ）みはない」と判断（はんだん）します。話（はな）し言葉（ことば）では「はずない」と「が」を落（お）とすことがあります。（根据已知事实、常识或原定安排作逻辑判断，认为没有那种可能；口语中可省略「が」。）

**【辨析：はずがない vs. わけがない】**
「はずがない」更容易让人联想到客观根据和原有预期；「わけがない」则常是说话人断然排除某种可能，反驳和感情色彩更强。许多场合二者都可使用，但侧重点并不完全相同。

### 25 Ⅰ・2 〜わけがない ★3

**【意味（いみ）】理由（りゆう）・事情（じじょう）から考（かんが）えて、絶対（ぜったい）にあり得（え）ない (怎么可能……／绝不可能……)**

①昔（むかし）の日本（にほん）のことを聞（き）いても、外国人（がいこくじん）の彼（かれ）が知（し）っている **わけがない** じゃないか。
- **中文理解**：就算问从前日本的事情，身为外国人的他怎么可能知道呢？

②こんな小説（しょうせつ）をあの人（ひと）が読（よ）む **わけがない** 。あの人（ひと）は雑誌（ざっし）やマンガしか読（よ）まないんだから。
- **中文理解**：那个人怎么可能读这种小说？他只看杂志和漫画。

③こんなに気温（きおん）が低（ひく）くて雨（あめ）が多（おお）い夏（なつ）だから、秋（あき）においしい果物（くだもの）が採（と）れる **わけがない** 。
- **中文理解**：夏天气温这么低、雨又这么多，秋天不可能收获好吃的水果。

④「大山（おおやま）さん、暇（ひま）かな。テニスに誘（さそ）ってみようかな」
「彼女（かのじょ）は今（いま）、就職活動中（しゅうしょくかつどうちゅう）だから、暇（ひま）な **わけない** よ」
- **中文理解**：“大山有空吗？要不要约她打网球？”“她现在正忙着求职，怎么可能有空。”

**接続（せつぞく）** V・イA普通形（ふつうけい）／ナAな・ナAである／Nの・Nである ＋ わけがない

▶ 事情（じじょう）や話（はな）し手（て）の認識（にんしき）に照（て）らして「成立（せいりつ）する理由（りゆう）がない」と強（つよ）く断定（だんてい）します。「そんなわけがない」の形（かたち）もよく使（つか）います。口語（こうご）では「わけない」とも言（い）います。（依据情况或说话人的认知，断然认定不可能成立；「そんなわけがない」很常见，口语可说「わけない」。）

> **接续注意**：规范的教材接续通常是「ナAな＋わけがない」「Nの＋わけがない」，如「簡単（かんたん）なわけがない」「学生（がくせい）のわけがない」。现代口语中也能见到「犯人（はんにん）なわけがない」一类「Nな」形式，但学习和考试时宜先掌握「Nの」。

### 25 Ⅰ・3 〜ことなく ★2 [W]

**【意味（いみ）】〜しないで、そのまま次（つぎ）の動作（どうさ）・状態（じょうたい）が続（つづ）く (没有……就……／不曾……而一直……)**

①花子（はなこ）さんの部屋（へや）から芝居（しばい）の練習（れんしゅう）をする声（こえ）が、夕方（ゆうがた）まで途切（とぎ）れる **ことなく** 聞（き）こえていた。
- **中文理解**：从花子房间传出的排戏声一直持续到傍晚，没有中断。

②彼（かれ）は夏休（なつやす）みも帰国（きこく）する **ことなく** 、研究（けんきゅう）を続（つづ）けた。
- **中文理解**：他暑假也没有回国，继续进行研究。

③林（はやし）さんは誰（だれ）にも相談（そうだん）する **ことなく** 、学校（がっこう）を辞（や）めてしまった。
- **中文理解**：林没有和任何人商量便退学了。

④犯人（はんにん）は人（ひと）に怪（あや）しまれる **ことなく** 、その家（いえ）の庭（にわ）に入（はい）ることができた。
- **中文理解**：犯人没有引起别人怀疑，进入了那户人家的院子。

**接続（せつぞく）** V辞書形（じしょけい） ＋ ことなく

▶ 「〜ないで」的正式书面说法，常用于本来可能发生、通常会做或容易中断的事情实际上没有发生。它不表示单纯的先后顺序，而强调“在未做 A 的状态下继续 B”。

**【使用提醒】**
「今日（きょう）は砂糖（さとう）を入（い）れることなくコーヒーを飲（の）みたい」并非语法错误，但对日常小事显得过于郑重，通常说「砂糖（さとう）を入（い）れずに／入（い）れないで飲（の）みたい」。在书面描写或有意形成对比时，「ことなく」仍可成立。

### 25 Ⅰ・4 〜もしない ★2

**【意味（いみ）】〜さえしない／全（まった）く〜しない (连……都不……)**

①私（わたし）が出（だ）した手紙（てがみ）を、彼（かれ）は開（あ）け **もしないで** 捨（す）ててしまったそうだ。
- **中文理解**：听说他连我寄的信都没拆开便扔了。（原句是“连打开都没打开”，不是“看都没看”。）

②私（わたし）が作（つく）った音楽（おんがく）のCDを聞（き）き **もしないで** 、いろいろ言（い）わないでください。
- **中文理解**：请不要连我制作的音乐 CD 都没听，就说三道四。

③食事（しょくじ）の時間（じかん）だと声（こえ）を掛（か）けたが、兄（あに）は立（た）ち上（あ）がり **もしない** 。疲（つか）れているのだろう。
- **中文理解**：我叫哥哥吃饭，可他连站都没站起来。大概是累了吧。

④よく調（しら）べ **もしないで** 、簡単（かんたん）に結論（けつろん）を出（だ）さないでください。
- **中文理解**：请不要连认真调查都不做，便轻率地下结论。

**接続（せつぞく）** Vます形（けい）の語幹（ごかん） ＋ もしない

▶ 「最低限（さいていげん）それくらいはするだろう」という予想（よそう）に反（はん）して、実際（じっさい）にはそれさえしないことを強調（きょうちょう）します。驚（おどろ）き、不満（ふまん）、非難（ひなん）を伴（ともな）うことが多（おお）い表現（ひょうげん）です。（强调对方出乎预料地连最低限度的动作也没做，常含惊讶、不满或责备。）

### 25 Ⅰ・5 〜どころではなく・〜どころではない ★2

**【意味（いみ）】〜する時間（じかん）・余裕（よゆう）・状況（じょうきょう）ではない (根本顾不上……／哪里谈得上……)**

①初（はじ）めて九州（きゅうしゅう）へ来（き）たのに、見物（けんぶつ） **どころではなく** 、夜遅（よるおそ）くまで会議（かいぎ）だ。
- **中文理解**：虽然第一次来到九州，却根本顾不上游览，要开会到深夜。

②「高橋（たかはし）さん、来週（らいしゅう）の金曜日（きんようび）、サッカーの試合（しあい）のチケットがあるんだけど、行（い）きませんか」
「すみません。私（わたし）、今（いま）忙（いそが）しくてサッカーを見（み）に行（い）く **どころではない** んです」
- **中文理解**：“高桥，我有下周五足球赛的票，要去吗？”“抱歉，我现在太忙，根本顾不上看足球。”

③結婚（けっこん）した頃（ころ）はお金（かね）がなくて、お祝（いわ）いをする **どころじゃなかった** 。
- **中文理解**：刚结婚时没有钱，哪里还谈得上庆祝。

**接続（せつぞく）** V辞書形（じしょけい）／N ＋ どころではない・どころではなく

▶ 本来（ほんらい）ならしたいこと、普通（ふつう）ならできることについて、より重大（じゅうだい）・緊急（きんきゅう）な事情（じじょう）があり、その余裕（よゆう）が全（まった）くないと強（つよ）く否定（ひてい）します。「どころじゃない」は口語形（こうごけい）です。「どころではなく」は後（うし）ろの文（ぶん）へ続（つづ）けます。（因更重大、紧急的情况而完全顾不上某事；「どころじゃない」是口语，「どころではなく」用于连接后文。）

### 25 Ⅰ・6 〜ものか ★2 [S]

**【意味（いみ）】決（けっ）して〜ない／どうして〜だろうか、いや〜ない (绝不……／怎么可能……)**

①「展覧会（てんらんかい）、どうだった」
「あんな人（ひと）の多（おお）い所（ところ）へ二度（にど）と行（い）く **ものか** 。作品（さくひん）は全然（ぜんぜん）見（み）えなくて、人（ひと）の頭（あたま）ばかりだったよ」
- **中文理解**：“展览怎么样？”“那么挤的地方我绝不会再去。作品根本看不见，只看见一片人头。”

②寮（りょう）の食事（しょくじ）で初（はじ）めて納豆（なっとう）が出（で）た時（とき）には、「こんなものが食（た）べられる **ものか** 」と思（おも）った。
- **中文理解**：宿舍第一次供应纳豆时，我心想：“这种东西怎么可能吃得下？”

③「田中（たなか）さんって、正直（しょうじき）な人（ひと）ですね」
「田中（たなか）さんが正直（しょうじき）な **もんか** 。田中（たなか）さんの言（い）うことはうそばかりだ」
- **中文理解**：“田中是个诚实的人吧。”“他哪里诚实了？他说的尽是谎话。”

**接続（せつぞく）** V・イA普通形（ふつうけい）／ナAな／Nな ＋ ものか

▶ 反語（はんご）によって相手（あいて）の発言（はつげん）やある可能性（かのうせい）を強（つよ）く否定（ひてい）したり、「絶対（ぜったい）にしない」という決意（けつい）を表（あらわ）したりします。「もんか」はくだけた形（かたち）です。感情的（かんじょうてき）で強（つよ）いため、目上（めうえ）の人（ひと）への丁寧（ていねい）な応答（おうとう）には向（む）きません。（借反问强烈否定或表达“绝不做”的决心；语气较冲。）

### 25 Ⅰ・7 〜なしに・〜ことなしに ★1 [W]

**【意味（いみ）】〜しないで／〜がなければ (没有……便……／不经……就……)**

①2時（にじ）から4時（よじ）までは取材（しゅざい）ですから、事前（じぜん）の断（ことわ）り **なしに** 呼（よ）び出（だ）しをしないでください。
- **中文理解**：两点到四点是采访时间，请不要事先不打招呼便叫我出去。

②私（わたし）たちは3時間（さんじかん）、休憩（きゅうけい）する **ことなしに** 会議（かいぎ）を続（つづ）けた。
- **中文理解**：我们连续开了三个小时的会，中间没有休息。

③厚（あつ）い本（ほん）なのにあまりにおもしろくて、中断（ちゅうだん）する **ことなしに** 終（お）わりまで読（よ）んでしまった。
- **中文理解**：书虽厚，却太有趣了，我一口气读到最后，中途没有停下。

**接続（せつぞく）** N ＋ なしに　／　V辞書形（じしょけい） ＋ ことなしに

▶ 「〜ないで」的正式书面表达。动作性名词可直接接「なしに」，动词则接「ことなしに」。在「AことなしにBはできない」中，还可强调 A 是 B 成立不可缺少的条件，如「努力（どりょく）することなしに成功（せいこう）はない」（不努力便不可能成功）。日常会话通常用「〜なしで／〜ないで」。

### 25 Ⅰ・8 〜までもなく・〜までもない ★1

**【意味（いみ）】そこまでする必要（ひつよう）はない (没必要特意做到……地步)**

①簡単（かんたん）な計算（けいさん）だから、電卓（でんたく）を使（つか）う **までもない** 。
- **中文理解**：计算很简单，没必要动用计算器。

②詳（くわ）しい説明（せつめい）がここに書（か）いてあるから、わざわざ店員（てんいん）さんの話（はなし）を聞（き）く **までもなく** 、読（よ）めば分（わ）かる。
- **中文理解**：这里已经写有详细说明，不必特意去问店员，看一看就明白。

③中村（なかむら）さんはアメリカへ転勤（てんきん）になったそうだ。林（はやし）さんが本人（ほんにん）から直接（ちょくせつ）聞（き）いたのだから、確（たし）かめる **までもない** だろう。
- **中文理解**：听说中村调到美国了。既然林直接听本人说过，大概没必要再确认。

④熱（ねつ）もないんだから、わざわざ病院（びょういん）に行（い）く **までのこともない** 。一日（いちにち）休（やす）めば治（なお）るだろう。
- **中文理解**：又没发烧，不至于特意去医院。休息一天大概就好了。

**接続（せつぞく）** V辞書形（じしょけい） ＋ までもない・までもなく

▶ 做该动作并非完全不可以，而是说话人判断“事情很简单、结论很明显，不值得做到那个程度”。「言（い）うまでもなく」是固定说法，意为“不用说／不言而喻”。「〜ことはない」只是说没有必要；「〜までもない」还带有“没必要特意做到那一步”的尺度感。「〜までのこともない」意义相同。

## 25 Ⅱ 部分否定（ぶぶんひてい）

### 25 Ⅱ・1 〜ことは〜が ★3

**【意味（いみ）】一応（いちおう）〜という事実（じじつ）は認（みと）めるが、問題（もんだい）・制限（せいげん）がある (……是……，不过……)**

①この漢字（かんじ）は意味（いみ）が分（わ）かる **ことは分（わ）かるんですが** 、使（つか）い方（かた）がよく分（わ）からないんです。
- **中文理解**：这个汉字的意思懂倒是懂，不过不太会用。

②昨日（きのう）林（はやし）さんの家（うち）へ行（い）く **ことは行（い）ったが** 、留守（るす）で会（あ）えなかった。
- **中文理解**：昨天去林家倒是去了，可他不在，没见到。

③今（いま）の部屋（へや）は便利（べんり）な **ことは便利（べんり）だが** 、狭（せま）い。
- **中文理解**：现在的房间方便倒是方便，就是很小。

④西（にし）さんと同（おな）じ部屋（へや）だと、楽（たの）しい **ことは楽（たの）しいけど** 、勉強（べんきょう）ができないんです。
- **中文理解**：和西住一个房间，开心倒是开心，可没法学习。

**接続（せつぞく）** 同（おな）じ述語（じゅつご）を「XことはXが／けれど」の形（かたち）で繰（く）り返（かえ）す

▶ 前半（ぜんはん）で相手（あいて）の見方（みかた）や最低限（さいていげん）の事実（じじつ）を認（みと）め、後半（こうはん）で不満（ふまん）・例外（れいがい）・制限（せいげん）を付（つ）け加（くわ）えます。過去（かこ）の動作（どうさ）では例②（れいに）のように「行（い）くことは行（い）った」と、前後（ぜんご）の時制（じせい）が異（こと）なることがあります。（先让步承认，再补充限制；过去动作常出现「辞书形＋ことは＋过去形」。）

### 25 Ⅱ・2 〜とは限（かぎ）らない ★3

**【意味（いみ）】必（かなら）ずそうだとは言（い）えない；例外（れいがい）もある (未必……／不一定……)**

①テレビの天気予報（てんきよほう）がいつも当（あ）たる **とは限（かぎ）らない** 。
- **中文理解**：电视天气预报未必每次都准。

②話題（わだい）になっているからといって、その本（ほん）がおもしろい **とは限（かぎ）らない** 。
- **中文理解**：即使那本书很热门，也不一定有趣。

③テレビで報道（ほうどう）されることがいつも真実（しんじつ）だ **とは限（かぎ）らない** 。
- **中文理解**：电视报道的内容未必永远都是真相。

④事故（じこ）が起（お）きない **とは限（かぎ）らない** から、高（たか）い山（やま）に登（のぼ）るときはしっかり準備（じゅんび）をした方（ほう）がいい。
- **中文理解**：并非绝不会发生事故，也就是说事故仍有可能发生，所以登高山时最好充分准备。

**接続（せつぞく）** 普通形（ふつうけい） ＋ とは限（かぎ）らない（ナA・Nでは「だ」を入（い）れることがある）

▶ 一般（いっぱん）に正（ただ）しいと思（おも）われていることや、相手（あいて）が当然（とうぜん）だと考（かんが）えていることについて、例外（れいがい）・別（べつ）の可能性（かのうせい）を示（しめ）します。「いつも・全（すべ）て・誰（だれ）でも・必（かなら）ずしも」や「〜からといって」とよく一緒（いっしょ）に使（つか）います。（针对一般化判断指出例外，常与“总是、全部、未必、虽说……”等搭配。）

> **否定形注意**：「起（お）きないとは限（かぎ）らない」是否定“不会发生”，所以实际意思是“也可能发生”，不要按字面误译成“未必发生”。

### 25 Ⅱ・3 〜わけではない ★3

**【意味（いみ）】〜という結論（けつろん）・事情（じじょう）ではない (并不是……／并非意味着……)**

①鈴木（すずき）さんは高校生時代（こうこうせいじだい）に勉強（べんきょう）ばかりしていた **わけではない** 。よくクラブ活動（かつどう）もしていた。
- **中文理解**：铃木高中时并非只顾学习，他也经常参加社团活动。

②離婚（りこん）をしたいという、あなたの今（いま）の気持（きも）ちが分（わ）からない **わけではありません** 。
- **中文理解**：我并不是不理解你现在想离婚的心情。（即“能够理解一些”。）

③新聞（しんぶん）によると、インフルエンザの予防接種（よぼうせっしゅ）をみんなが受（う）けられる **わけではない** ようだ。
- **中文理解**：据报纸报道，似乎并不是所有人都能接种流感疫苗。

④今日（きょう）の会（かい）に出席（しゅっせき）したい **わけではない** んだけど、頼（たの）まれたから行（い）くんです。
- **中文理解**：我并不是自己想参加今天的聚会，只是受人所托才去。

**接続（せつぞく）** V・イA普通形（ふつうけい）／ナAな・ナAである／Nの・Nな・Nである ＋ わけではない

▶ 前（まえ）の事情（じじょう）から聞（き）き手（て）が導（みちび）きそうな結論（けつろん）や、既（すで）に出（で）た誤解（ごかい）を否定（ひてい）します。文脈（ぶんみゃく）によって全面否定（ぜんめんひてい）にも部分否定（ぶぶんひてい）にもなります。「〜ないわけではない」は二重否定（にじゅうひてい）で、「全（まった）く〜ないのではない」と控（ひか）えめに肯定（こうてい）します。（用于纠正由上下文得出的结论；双重否定表示有限度地肯定。）

**【辨析：とは限らない vs. わけではない】**
「とは限らない」着重“并非所有情况如此，存在例外”；「わけではない」着重“不能由眼前情况得出那个结论／实际情况并不是那样”。例如：「有名（ゆうめい）な店（みせ）が全部（ぜんぶ）おいしいとは限（かぎ）らない」是在指出例外；「行列（ぎょうれつ）しているが、特（とく）においしいわけではない」是在否定由“排队”产生的推断。

### 25 Ⅱ・4 〜ないことはない・〜ないこともない ★2

**【意味（いみ）】全（まった）く〜ないとは言（い）えない (也不是不……／并非完全不……)**

①「誰（だれ）か明日（あした）テニスをしないかなあ」
「うーん、林（はやし）さんならテニスが好（す）きだから、し **ないこともない** んじゃない」
- **中文理解**：“明天有没有人会打网球呢？”“嗯，林喜欢网球，也不是完全不会打吧。”

②今（いま）から走（はし）って行（い）けば9時20分（くじにじゅっぷん）の電車（でんしゃ）に間（ま）に合（あ）わ **ないこともない** 。
- **中文理解**：现在跑过去的话，倒也不是赶不上九点二十分的电车。

③「課長（かちょう）、今（いま）、お忙（いそが）しいですか」
「忙（いそが）しく **ないこともない** けど、どんな用事（ようじ）ですか」
- **中文理解**：“科长，您现在忙吗？”“也不能说不忙，不过是什么事？”

④祖父（そふ）は携帯電話（けいたいでんわ）が嫌（きら）いだと言（い）っていた。しかし、最近（さいきん）は「便利（べんり）で **ないこともない** な」と言（い）うようになった。
- **中文理解**：祖父以前说讨厌手机，不过最近开始说“倒也不能说不方便”。

**接続（せつぞく）** Vない／イAくない／ナA・Nでない ＋ ことはない・こともない

▶ 二重否定（にじゅうひてい）で可能性（かのうせい）や一面（いちめん）を控（ひか）えめに認（みと）め、断定（だんてい）を避（さ）けます。「ことはない」常带“确实有这一面，但……”的让步感；「こともない」通常更柔和，表示“也存在这种可能”。口语中「便利（べんり）じゃないこともない」比「便利（べんり）でないこともない」自然。

### 25 Ⅱ・5 〜というものではない・〜というものでもない ★2

**【意味（いみ）】単純（たんじゅん）に〜と言（い）い切（き）ることはできない (并非只要……就……／不能一概而论)**

①スポーツはただ練習（れんしゅう）すればできるようになる **というものではない** 。効果的（こうかてき）な練習（れんしゅう）のやり方（かた）が大切（たいせつ）だ。
- **中文理解**：运动并非只要练习就一定能掌握，有效的练习方法很重要。

②会議（かいぎ）では何（なに）を言（い）うかが大切（たいせつ）だ。ただ出席（しゅっせき）していれば済（す）む **というものではない** 。
- **中文理解**：开会时发言内容很重要，并不是到场便算完事。

③車（くるま）はスピードが出（で）ればいい **というものではない** 。何（なに）より安全（あんぜん）が大切（たいせつ）だ。
- **中文理解**：汽车并非速度越快越好，安全最重要。

④お客様（きゃくさま）に対（たい）する話（はな）し方（かた）は、丁寧（ていねい）であればいい **というものでもありません** 。
- **中文理解**：对客人说话也并非只要措辞礼貌就够了。

**接続（せつぞく）** 普通形（ふつうけい） ＋ というものではない・というものでもない

▶ 某种主张、规则或因果关系被说得过于简单、绝对时，用本句型指出还需要其他条件或评价标准。常用「〜ば／なら〜というものではない」和「ただ〜ばいいというものではない」。它不同于单纯否认个人事实的「わけではない」，更常针对一般性看法。

---

### 25 Ⅱ・6 〜ないものでもない・〜ないでもない・〜なくもない ★1

**【意味（いみ）】条件（じょうけん）や見方（みかた）によっては、〜する可能性（かのうせい）もある (倒也不是不……／也不能说完全不……)**

①「高橋先生（たかはしせんせい）、お酒（さけ）はお飲（の）みにならないんですか」
「いいえ、飲（の）ま **ないでもない** んですが、とても弱（よわ）いんです」
- **中文理解**：“高桥老师，您不喝酒吗？”“倒也不是不喝，只是酒量很小。”

②今度（こんど）の仕事（しごと）、うまくいきそうな気（き）がし **ないでもない** 。
- **中文理解**：这次的工作，我倒也并非完全没有会顺利的感觉。

③引退（いんたい）する選手（せんしゅ）「正直（しょうじき）に言（い）うと、今（いま）辞（や）めるのは残念（ざんねん）だ、という気持（きも）ちが **なくもない** んです」
- **中文理解**：即将退役的选手说：“老实说，也不是完全没有‘现在退役很遗憾’的心情。”

**接続（せつぞく）**

- Vない形（けい） ＋ ものでもない・でもない
- Vなく／イAくなく／ナA・Nでなく ＋ もない

▶ 都是双重否定，但常用于个人判断、感受、好恶或有条件的意愿。「〜ないものでもない」尤其常表示“若满足条件，也并非不能做”，如「条件（じょうけん）次第（しだい）では引（ひ）き受（う）けないものでもない」；「〜ないでもない／〜なくもない」则常表示隐约的感觉或有限度的承认。与「〜ないことはない」意思接近，但语气更迂回、书面。

## 25 否定（ひてい）・部分否定（ぶぶんひてい） 練習（れんしゅう）

### A 文型選択（ぶんけいせんたく）

[　　]の中（なか）の言葉（ことば）を使（つか）って、次（つぎ）の文（ぶん）を完成（かんせい）させなさい。一（ひと）つの言葉（ことば）は一回（いっかい）しか使（つか）いません。

[ a. わけがない　b. ことは　c. わけではない　d. とは限（かぎ）らない ]

夫（おっと）「この小説（しょうせつ）、読（よ）んだ（1. **b. ことは** ）読（よ）んだんだけど、よく理解（りかい）できなかったよ。あい子（こ）、この主人公（しゅじんこう）の気持（きも）ち、分（わ）かる？」

妻（つま）「私（わたし）に分（わ）かる（2. **a. わけがない** ）でしょ。主人公（しゅじんこう）は老人（ろうじん）よ」

夫（おっと）「でも、あい子（こ）はこの作家（さっか）が好（す）きなんだろう？　よく読（よ）んでいるよね」

妻（つま）「特（とく）に好（す）きな（3. **c. わけではない** ）のよ。それに、好（す）きだからって、必（かなら）ずしも主人公（しゅじんこう）の心理（しんり）が分（わ）かる（4. **d. とは限（かぎ）らない** ）でしょう」

- **中文理解**：丈夫说小说看倒是看了，却不太理解主人公；妻子说自己不可能仅凭这一点就懂老人，也并非特别喜欢该作家，而且喜欢作品也未必能理解主人公的心理。

[ a. ことなく　b. どころではない　c. ものか　d. ことはない　e. というものではない　f. までもない　g. ものでもない ]

先輩（せんぱい）「あれ、今年（ことし）は花見（はなみ）には行（い）かないのか」

後輩（こうはい）「ええ、実（じつ）は今（いま）、花見（はなみ）（5. **b. どころではない** ）んです。運送会社（うんそうがいしゃ）でアルバイトをしているんです」

先輩（せんぱい）「へえ。仕事（しごと）、きついだろう」

後輩（こうはい）「ええ、きつくない（6. **d. ことはない** ）んですが、まあ、アルバイト料（りょう）は高（たか）いですから。一日（いちにち）も休（やす）む（7. **a. ことなく** ）二週間（にしゅうかん）頑張（がんば）れば、かなりの額（がく）になるんですよ」

先輩（せんぱい）「去年（きょねん）、重（おも）い荷物（にもつ）を山（やま）に運（はこ）ぶアルバイトをしたんだけど、もう二度（にど）とあんなきつい仕事（しごと）はやる（8. **c. ものか** ）と思（おも）ったよ。でも、この仕事（しごと）なら僕（ぼく）にもやれない（9. **g. ものでもない** ）なあ」

後輩（こうはい）「でも、言（い）う（10. **f. までもない** ）ことですけど、ただ運（はこ）べばいい（11. **e. というものではない** ）んですよ。決（き）まった時間（じかん）までに確実（かくじつ）に届（とど）けることが大切（たいせつ）なんです」

- **中文理解**：后辈忙着在运输公司打工，根本顾不上赏花。工作不能说不辛苦，但连续两周不休息可赚到不少钱。前辈曾发誓绝不再做苦工，不过觉得这份工作倒也并非不能做；后辈提醒，运输并非只搬东西就够了，准时可靠地送达才重要。

### B 言（い）い換（か）え

[ a. はずがない　b. どころではない　c. 限（かぎ）らない　d. わけではない　e. までもない　f. ないものでもない ]

1. リーさんがマラソン大会（たいかい）で入賞（にゅうしょう）する可能性（かのうせい）はない。
   - **言い換え**：リーさんがマラソン大会（たいかい）で入賞（にゅうしょう）する（ **a. はずがない** ）。
2. タムさんとリーさん、どちらが速（はや）いか、わざわざタイムを計（はか）る必要（ひつよう）はない。はっきり分（わ）かっている。
   - **言い換え**：どちらが速（はや）いか、わざわざタイムを計（はか）る（ **e. までもない** ）。
3. といっても、タムさんが特（とく）に速（はや）いのではない。
   - **言い換え**：タムさんが特（とく）に速（はや）い（ **d. わけではない** ）。
4. 体調（たいちょう）がいつもいいとは言（い）えないからである。
   - **言い換え**：体調（たいちょう）がいつもいいとは（ **c. 限（かぎ）らない** ）からである。
5. 僕（ぼく）は今（いま）、忙（いそが）しいのでマラソンをする余裕（よゆう）はないが、いつか二人（ふたり）に強（つよ）く誘（さそ）われれば、マラソン大会（たいかい）に絶対（ぜったい）出（で）ないとは言（い）えない。
   - **言い換え**：僕（ぼく）は今（いま）、忙（いそが）しくてマラソン（ **b. どころではない** ）が、いつか二人（ふたり）に強（つよ）く誘（さそ）われれば、マラソン大会（たいかい）に出（で）（ **f. ないものでもない** ）。

## まとめ：迷（まよ）いやすい否定表現（ひていひょうげん）

| 想表达的意思 | 最自然的句型 | 例句 |
| :--- | :--- | :--- |
| 有根据地判断不可能 | 〜はずがない | 予定（よてい）から見（み）て、今日（きょう）届（とど）くはずがない。 |
| 断然反驳“不可能” | 〜わけがない | 彼（かれ）がそんなうそを信（しん）じるわけがない。 |
| 并非所有情况如此 | 〜とは限（かぎ）らない | 高価（こうか）な物（もの）が良（よ）いとは限（かぎ）らない。 |
| 否定某个推论或误解 | 〜わけではない | 高（たか）いから買（か）わないわけではない。 |
| 否定简单化的一般原则 | 〜というものではない | 謝（あやま）れば済（す）むというものではない。 |
| 委婉承认一部分 | 〜ないことはない | 食（た）べられないことはないが、好（す）きではない。 |
