# 29 主張（しゅちょう）・断定的評価（だんていてきひょうか）

自分（じぶん）の確信（かくしん）を込（こ）めて主張（しゅちょう）したり、ある事実（じじつ）を断定的（だんていてき）に評価（ひょうか）したりするとき、どのような表現（ひょうげん）を使（つか）えばよいでしょうか。（表达强烈主张，或对事实作出断定性评价时，可以使用哪些说法？）

| 核心功能 | 句型 | 语感重点 |
| :--- | :--- | :--- |
| 主观确信 | 〜に決（き）まっている | “肯定是”，口语中较强势 |
| 别无选择 | 〜しかない／〜ほかない | 排除其他办法，只能如此 |
| 否定意志 | 〜まい | 决意不做，偏书面、郑重 |
| 断定本质或原因 | 〜にほかならない | “正是／无非是”，正式书面 |
| 限定范围、程度 | 〜にすぎない | “不过是”，不超过该范围 |
| 给事实定性 | 〜というものだ | “这才叫／可谓”，带评价 |
| 认为某项最稳妥 | 〜に越（こ）したことはない | 并非必须，但这样最好 |
| 表示最后手段 | 〜までだ | “大不了……”，带决心 |
| 某条件会使一切失去意义 | 〜ばそれまでだ | “一旦……就全完了” |
| 评价某反应没有必要 | 〜に（は）当（あ）たらない | “不值得／用不着”，正式 |

## 29 主張（しゅちょう）・断定的評価（だんていてきひょうか）

### 29・1 〜に決（き）まっている ★3

**【意味（いみ）】きっと〜だ／当然（とうぜん）〜だ (一定……／肯定……)**

①妻（つま）「夕飯（ゆうはん）はゆり子（こ）が作（つく）ってくれるそうよ。大丈夫（だいじょうぶ）かな」
　夫（おっと）「料理（りょうり）が好（す）きなゆり子（こ）が作（つく）るんだから、おいしい **に決（き）まっている** よ。楽（たの）しみだね」
- **中文理解**：妻子：“听说晚饭由百合子来做，没问题吧？”丈夫：“她那么喜欢做饭，肯定好吃。真期待啊。”

②試合（しあい）ではAチームが勝（か）つ **に決（き）まっています** よ。日頃（ひごろ）の練習量（れんしゅうりょう）がすごいんですから。
- **中文理解**：比赛肯定是 A 队获胜，因为他们平时的训练量非常大。

③そんな暗（くら）い所（ところ）で本（ほん）を読（よ）んだら、目（め）に悪（わる）い **に決（き）まっている** 。
- **中文理解**：在那么暗的地方看书，肯定对眼睛不好。

④今週中（こんしゅうじゅう）に30枚（さんじゅうまい）のレポートを書（か）くなんて、無理（むり） **に決（き）まっています** 。
- **中文理解**：要在本周内写出 30 页报告，肯定办不到。

**接続（せつぞく）** 普通形（ふつうけい）＋ に決（き）まっている（ナA・Nの現在肯定形（げんざいこうていけい）は「だ」を付（つ）けない。ナA／N＋であるも可（か））

▶ 話（はな）し手（て）が根拠（こんきょ）を当然（とうぜん）だと考（かんが）え、「ほかの可能性（かのうせい）はない」と強（つよ）く断定（だんてい）する表現（ひょうげん）です。「〜に違（ちが）いない」より会話的（かいわてき）で、感情（かんじょう）や主張（しゅちょう）が前面（ぜんめん）に出（で）ます。（说话人认为结论理所当然，强烈断定没有其他可能。）

▶ 確信（かくしん）が強（つよ）いぶん、証拠（しょうこ）が不十分（ふじゅうぶん）な場面（ばめん）や相手（あいて）の判断（はんだん）を否定（ひてい）する場面（ばめん）では、独断的（どくだんてき）に響（ひび）くことがあります。「きっと〜と思（おも）う」はより柔（やわ）らかい言（い）い方（かた）です。

### 29・2 〜しかない・〜（より）ほか（は）ない・〜ほか（仕方（しかた）が）ない ★3

**【意味（いみ）】ほかに方法（ほうほう）・選択肢（せんたくし）がない (只能……／除此以外别无他法)**

①1度（いちど）決心（けっしん）したら、最後（さいご）までやる **しかない** 。
- **中文理解**：既然已经下定决心，就只能坚持到底。

②この事故（じこ）の責任（せきにん）はこちら側（がわ）にあるのだから、謝（あやま）る **しかない** と思（おも）う。
- **中文理解**：这次事故的责任在我方，我想只能道歉。

③私（わたし）の場合（ばあい）、生活費（せいかつひ）を抑（おさ）えるには、電話代（でんわだい）の節約（せつやく） **しかない** んですよ。
- **中文理解**：就我的情况而言，要压缩生活费，只能从电话费上节省。

④当時（とうじ）、私（わたし）は生活（せいかつ）に困（こま）っていたので、学校（がっこう）を辞（や）めて働（はたら）く **ほかなかった** 。
- **中文理解**：当时生活困难，我只好退学工作。

⑤この病気（びょうき）を治（なお）す方法（ほうほう）は手術（しゅじゅつ） **しかない** そうです。すぐに入院（にゅういん）する **よりほかはありません** 。
- **中文理解**：听说治疗这种病只有手术这一种办法，只能马上住院。

⑥これ以上（いじょう）赤字（あかじ）が続（つづ）いたら、営業（えいぎょう）を辞（や）める **ほか仕方（しかた）がない** でしょう。
- **中文理解**：如果亏损再持续下去，恐怕只能停止营业。

**接続（せつぞく）** V辞書形（じしょけい）／動作性名詞（どうさせいめいし）＋ しかない ／ V辞書形（じしょけい）＋（より）ほか（は）ない・ほか仕方（しかた）がない

▶ 複数（ふくすう）の可能性（かのうせい）を考（かんが）えた結果（けっか）、実行（じっこう）できる選択肢（せんたくし）が一（ひと）つしか残（のこ）っていないことを表（あらわ）します。諦（あきら）めや不本意（ふほんい）の気持（きも）ちを伴（ともな）うことが多（おお）いですが、必（かなら）ずしも悲観的（ひかんてき）とは限（かぎ）らず、決意（けつい）を示（しめ）すこともあります。（表示排除其他可能后只剩一种选择，常带无奈，也可表现果断。）

▶ 「〜しかない」は会話（かいわ）で最（もっと）も普通（ふつう）です。「〜ほかない」「〜よりほかはない」はやや硬（かた）く、「〜ほか仕方（しかた）がない」は諦（あきら）めや無念（むねん）の気持（きも）ちがさらに出（で）やすい形（かたち）です。

> **形（かたち）に注意（ちゅうい）**：「手術（しゅじゅつ）しかない」では「手術（しゅじゅつ）」そのものが唯一（ゆいいつ）の選択肢（せんたくし）です。「手術（しゅじゅつ）するしかない」では、「手術（しゅじゅつ）を行（おこな）う」という行動（こうどう）が唯一（ゆいいつ）の方法（ほうほう）です。（前者强调“手术”这一选项，后者强调“进行手术”这一行动。）

### 29・3 〜まい ★2 [W]

**【意味（いみ）】決（けっ）して〜しようとは思（おも）わない／〜するのはやめよう (决不……／不打算……)**

①私（わたし）の部屋（へや）には使（つか）わない物（もの）が多（おお）すぎる。もう無駄（むだ）な買（か）い物（もの）はする **まい** 。
- **中文理解**：我的房间里没用的东西太多了。我再也不买无用的东西了。

②1度（いちど）危（あぶ）ない経験（けいけん）をしたので、もう決（けっ）して冬山（ふゆやま）には登（のぼ）る **まい** と決心（けっしん）したが、やはりまた登（のぼ）りたくなる。
- **中文理解**：经历过一次危险后，我下定决心再也不登冬山，可还是又想去。

③考（かんが）え **まい** 、考（かんが）え **まい** とするけれど、やっぱり明日（あした）のことが気（き）になって眠（ねむ）れない。
- **中文理解**：虽然一再努力不去想，可还是惦记明天的事，无法入睡。

**接続（せつぞく）** V辞書形（じしょけい）＋ まい

- 一段動詞（いちだんどうし）は、辞書形（じしょけい）と語幹（ごかん）の両方（りょうほう）が使（つか）えます：食（た）べるまい／食（た）べまい。
- する → するまい／すまい。来（く）る → 来（く）るまい／来（こ）まい。

▶ 本節（ほんせつ）の「〜まい」は強（つよ）い否定（ひてい）の意志（いし）を表（あらわ）す、硬（かた）い書（か）き言葉（ことば）です。日常会話（にちじょうかいわ）では「もう〜しない」「〜するのはやめよう」の方（ほう）が自然（しぜん）です。（本节表示强烈的否定意志，偏书面；日常口语一般直接说“不再做”。）

▶ 独立（どくりつ）した文（ぶん）で話（はな）し手（て）の決意（けつい）を述（の）べる場合（ばあい）、主語（しゅご）は普通（ふつう）第一人称（だいいちにんしょう）です。ただし、「彼（かれ）は二度（にど）と戻（もど）るまいと決（き）めた」のように、引用節（いんようせつ）の中（なか）で第三者（だいさんしゃ）の決意（けつい）を報告（ほうこく）することはできます。したがって、「否定意志（ひていいし）の主語（しゅご）は常（つね）に第一人称（だいいちにんしょう）だ」とするのは厳密（げんみつ）ではありません。

▶ 「彼（かれ）は来（こ）ないだろう」の意味（いみ）を表（あらわ）す否定推量（ひていすいりょう）の「〜まい」もありますが、それは第（だい）26課（か）の用法（ようほう）です。そのため、独立（どくりつ）した「彼（かれ）は戻（もど）るまい」は普通（ふつう）「彼（かれ）は戻（もど）らないだろう」という推量（すいりょう）に解釈（かいしゃく）されます。第三者（だいさんしゃ）の決意（けつい）なら「戻（もど）るまいと決（き）めた」のように文脈（ぶんみゃく）を示（しめ）します。

### 29・4 〜にほかならない ★2 [W]

**【意味（いみ）】まさに〜だ／〜以外（いがい）のものではない (正是……／无非是……)**

①文化（ぶんか）とは、人々（ひとびと）の日々（ひび）の暮（く）らし方（かた） **にほかならない** 。
- **中文理解**：所谓文化，正是人们日常的生活方式。

②あまり利用（りよう）されない公共（こうきょう）の建物（たてもの）を建築（けんちく）するのは、税金（ぜいきん）の無駄遣（むだづか）い **にほかならない** 。
- **中文理解**：建造很少有人使用的公共建筑，无非是在浪费税款。

③彼（かれ）が子（こ）どもに厳（きび）しいのは、子（こ）どもの将来（しょうらい）を心配（しんぱい）するから **にほかならない** 。
- **中文理解**：他对孩子严格，正是因为担心孩子的将来。

**接続（せつぞく）** N＋ にほかならない ／ 普通形（ふつうけい）＋ からにほかならない

▶ ある事実（じじつ）の本質（ほんしつ）・正体（しょうたい）・唯一（ゆいいつ）の原因（げんいん）を「まさにこれだ」と限定（げんてい）し、強（つよ）く断定（だんてい）する表現（ひょうげん）です。論説文（ろんせつぶん）・演説（えんぜつ）などに多（おお）い硬（かた）い書（か）き言葉（ことば）です。（把某事的本质、性质或唯一原因断定为“正是这个”。）

> **「〜ほかない」との違（ちが）い**：「謝（あやま）るほかない」は、謝（あやま）る以外（いがい）に方法（ほうほう）がないという意味（いみ）です。「原因（げんいん）は私（わたし）の不注意（ふちゅうい）にほかならない」は、原因（げんいん）がまさに自分（じぶん）の不注意（ふちゅうい）だと断定（だんてい）しています。前者（ぜんしゃ）は行動（こうどう）の選択（せんたく）、後者（こうしゃ）は本質（ほんしつ）・原因（げんいん）の認定（にんてい）です。

### 29・5 〜にすぎない ★2

**【意味（いみ）】ただ〜だけだ／〜以上（いじょう）ではない (只不过是……／仅仅……)**

①「あなたはギリシャ語（ご）ができるそうですね」
　「いいえ、ただちょっとギリシャ文字（もじ）が読（よ）める **にすぎません** 」
- **中文理解**：“听说你会希腊语。”“不，我只不过能认一点希腊字母。”

②当時（とうじ）の私（わたし）の有給休暇（ゆうきゅうきゅうか）は、1年（いちねん）にわずか4日（よっか） **にすぎなかった** 。
- **中文理解**：当时我的带薪假一年仅有四天。

③私（わたし）は無名（むめい）の一市民（いちしみん） **にすぎません** が、この事件（じけん）について政府（せいふ）に強（つよ）く抗議（こうぎ）します。
- **中文理解**：我不过是一名无名市民，但我要就这一事件向政府提出强烈抗议。

④彼（かれ）は、ただ父親（ちちおや）が有名（ゆうめい）である **にすぎない** 。彼（かれ）自身（じしん）に実力（じつりょく）があるのではない。
- **中文理解**：他不过是父亲有名而已，并不是他本人有实力。

**接続（せつぞく）** N／普通形（ふつうけい）（ナA・Nは「である」）＋ にすぎない

▶ 数量（すうりょう）・程度（ていど）・身分（みぶん）・事実（じじつ）の範囲（はんい）を「それ以上（いじょう）ではない」と限定（げんてい）します。「ただ〜にすぎない」「ほんの〜にすぎない」「わずか〜にすぎない」とよく使（つか）います。（把数量、程度、身份或事实限制在某一范围内，表示“不超过这一点”。）

▶ 自分（じぶん）を謙遜（けんそん）したり、相手（あいて）や物事（ものごと）を低（ひく）く評価（ひょうか）したりすることが多（おお）いですが、文型（ぶんけい）の中心（ちゅうしん）は範囲（はんい）の限定（げんてい）であり、必（かなら）ずしも程度（ていど）の低（ひく）さを表（あらわ）すわけではありません。例（たと）えば「これは全体（ぜんたい）の一部（いちぶ）にすぎない」は、それが全部（ぜんぶ）ではないことを述（の）べています。（句型的核心是限定范围，并不必然含有贬低评价。）

### 29・6 〜というものだ ★2

**【意味（いみ）】本当（ほんとう）に〜だ／まさに〜と評価（ひょうか）できる (这才叫……／可谓……／真是……)**

①親（おや）が子（こ）どもの遊（あそ）びにまでうるさく口（くち）を出（だ）す……あれでは子（こ）どもがかわいそう **というものだ** 。
- **中文理解**：父母连孩子怎么玩都要不停干涉……那样的话，孩子可真够可怜的。

②料理（りょうり）をたくさん注文（ちゅうもん）して、結局（けっきょく）食（た）べきれずに残（のこ）す。そして捨（す）てる。本当（ほんとう）にもったいない **というものだ** 。
- **中文理解**：点了很多菜，最后吃不完，剩下又扔掉。这真叫浪费。

③つらいこともあれば、うれしいこともある。それが人生（じんせい） **というものだ** 。
- **中文理解**：有痛苦，也有快乐，这才是人生。

④長（なが）い間（あいだ）の研究（けんきゅう）がようやく認（みと）められた。努力（どりょく）の甲斐（かい）があった **というものだ** 。
- **中文理解**：长期研究终于得到认可，这才算努力没有白费。

**接続（せつぞく）** 普通形（ふつうけい）＋ というものだ（ナA・Nは「だ」を付（つ）けずに接続（せつぞく）することが多（おお）い）

▶ 目（め）の前（まえ）の事実（じじつ）や状況（じょうきょう）に対（たい）し、「普通（ふつう）に考（かんが）えれば、まさに〜と呼（よ）ぶべきだ」と話（はな）し手（て）が評価（ひょうか）・批判（ひはん）・感想（かんそう）を言（い）い切（き）る表現（ひょうげん）です。（对事实或状况作出“这正可称为……”的断定性评价。）

▶ 句末（くまつ）は通常（つうじょう）「というものだ」という定型（ていけい）で使（つか）いますが、その前（まえ）の内容（ないよう）は④の「甲斐（かい）があった」のように過去形（かこけい）にも、否定形（ひていけい）にもできます。「〜というものではない」は本（ほん）文型（ぶんけい）の単純（たんじゅん）な否定（ひてい）ではなく、普通（ふつう）は「必（かなら）ずしも〜ではない」という別（べつ）の文型（ぶんけい）です。

### 29・7 〜に越（こ）したことはない ★2

**【意味（いみ）】〜するのが一番（いちばん）よい／〜の方（ほう）が安心（あんしん）だ (最好……／……再好不过)**

①この山道（やまみち）は安全（あんぜん）だけれど、用心（ようじん）する **に越（こ）したことはない** でしょう。
- **中文理解**：这条山路虽然安全，但谨慎一点总是最好。

②けんかなどはしない **に越（こ）したことはない** が、我慢（がまん）できない場合（ばあい）もあるだろう。
- **中文理解**：当然最好不要吵架，不过有时也会忍无可忍。

③年（とし）を取（と）ってからも、足（あし）は丈夫（じょうぶ）である **に越（こ）したことはない** 。今日（きょう）から何（なに）か運動（うんどう）を始（はじ）めよう。
- **中文理解**：上了年纪后，腿脚当然是越健康越好。从今天开始做点运动吧。

④収入（しゅうにゅう）は多（おお）い **に越（こ）したことはない** が、働（はたら）きすぎて体（からだ）を壊（こわ）したら駄目（だめ）だ。
- **中文理解**：收入当然越多越好，但工作过度把身体累垮就不行了。

**接続（せつぞく）** V辞書形（じしょけい）・Vない形（けい）／イAい／ナA語幹（ごかん）・N（「である」を加（くわ）える形（かたち）も可（か））＋ に越（こ）したことはない

▶ 「絶対（ぜったい）にそうしなければならない」とまでは言（い）わないが、常識的（じょうしきてき）・安全面（あんぜんめん）・実用面（じつようめん）から見（み）て、その選択（せんたく）が最（もっと）も望（のぞ）ましいと評価（ひょうか）します。（并非说非如此不可，而是认为从常识、安全或实用角度看这样最好。）

▶ 「〜に越（こ）したことはないが／けれど」と後（あと）に条件（じょうけん）や現実的（げんじつてき）な限界（げんかい）を付（つ）け加（くわ）えることがよくあります。前（まえ）には原則（げんそく）として現在（げんざい）の非過去形（ひかこけい）を使（つか）います。

### 29・8 〜までだ・〜までのことだ ★1

**【意味（いみ）】ほかに方法（ほうほう）がなければ、最後（さいご）の手段（しゅだん）として〜する (大不了……／无非就……)**

①台風（たいふう）で家（いえ）までの交通機関（こうつうきかん）が止（と）まってしまったら、歩（ある）いて帰（かえ）る **までだ** 。
- **中文理解**：如果因台风回家的交通工具都停运，大不了走回去。

②この仕事（しごと）、手伝（てつだ）ってくれる人（ひと）がいないなら、私（わたし）1人（ひとり）でやる **までだ** 。
- **中文理解**：这项工作若没人帮忙，大不了我一个人做。

③彼女（かのじょ）がどうしてもお金（かね）を返（かえ）さないと言（い）うのなら、仕方（しかた）がない。法（ほう）に訴（うった）える **までのことだ** 。
- **中文理解**：如果她无论如何都不还钱，那也没办法，只能诉诸法律。

**接続（せつぞく）** V辞書形（じしょけい）＋ までだ・までのことだ

▶ 通常（つうじょう）の方法（ほうほう）が使（つか）えない条件（じょうけん）を受（う）け、「その場合（ばあい）は最後（さいご）にこの手段（しゅだん）を取（と）ればよい」と覚悟（かくご）・決意（けつい）を示（しめ）します。「〜しかない」に見（み）られる無力感（むりょくかん）だけでなく、「大（たい）したことではない。この方法（ほうほう）を取（と）ればよい」という強気（つよき）な響（ひび）きも出（で）ます。

> **第（だい）16課（か）の用法（ようほう）との違（ちが）い**：Vた形（けい）＋「までだ」は「ただ〜しただけだ」（例（れい）：聞（き）かれたから答（こた）えたまでだ）。本節（ほんせつ）の V辞書形（じしょけい）＋「までだ」は、今後（こんご）取（と）る最後（さいご）の手段（しゅだん）を表（あらわ）します。

### 29・9 〜ばそれまでだ ★1

**【意味（いみ）】そのような結果（けっか）になれば、それ以前（いぜん）の努力（どりょく）・価値（かち）は意味（いみ）を失（うしな）う (一旦……就全完了／……就前功尽弃)**

①高（たか）い車（くるま）を買（か）っても、事故（じこ）で壊（こわ）れてしまえ **ばそれまでだ** 。
- **中文理解**：即使买了昂贵的车，一旦因事故撞坏，也就全完了。

②一生懸命（いっしょうけんめい）働（はたら）いても、病気（びょうき）になれ **ばそれまでだ** 。無理（むり）をしない方（ほう）がいい。
- **中文理解**：即使拼命工作，一旦病倒，一切也就失去意义了。最好别太勉强。

③飛行機（ひこうき）は怖（こわ）い。落（お）ち **たらそれまでだ** 。新幹線（しんかんせん）で行（い）こう。
- **中文理解**：飞机很可怕，一旦坠落就全完了。还是坐新干线吧。

**接続（せつぞく）** Vば／Vたら ＋ それまでだ

▶ 前（まえ）に「いくら〜ても」「どんなに〜ても」などを置（お）き、積（つ）み上（あ）げた努力（どりょく）や得（え）た物（もの）も、ある条件（じょうけん）が起（お）これば無意味（むいみ）になると警告（けいこく）することが多（おお）いです。（常用于警告：无论此前做了多少努力，某一结果一旦发生便会失去意义。）

▶ 「そんなことを言（い）えばそれまでだ」のように、相手（あいて）の発言（はつげん）を受（う）けて、「そう言（い）われると、それ以上（いじょう）話（はな）し合（あ）えない」という意味（いみ）でもよく使（つか）います。命（いのち）や物（もの）が実際（じっさい）に終（お）わる場合（ばあい）だけではありません。

### 29・10 〜に（は）当（あ）たらない ★1

**【意味（いみ）】〜するほどのことではない／〜するのは適当（てきとう）ではない (不值得……／用不着……／不宜……)**

①彼（かれ）はいい結果（けっか）を出（だ）せなかったが、一生懸命（いっしょうけんめい）やったのだから、非難（ひなん）する **に当（あ）たらない** 。
- **中文理解**：他虽然没取得好结果，但已经尽了全力，不该因此责难他。

②普段（ふだん）目立（めだ）たない子（こ）どもが面白（おもしろ）い文（ぶん）を書（か）いたからといって、驚（おどろ）く **には当（あ）たらない** 。子（こ）どもは皆（みな）、何（なに）か隠（かく）れた力（ちから）を持（も）っているのだから。
- **中文理解**：平时不起眼的孩子写出有趣的文章，也不必惊讶；每个孩子都拥有某种潜在能力。

③山田（やまだ）さんの成功（せいこう）の裏（うら）には親（おや）の援助（えんじょ）があるのです。称賛（しょうさん） **には当（あ）たりません** 。
- **中文理解**：山田的成功背后有父母相助，因此还谈不上值得称赞。

**接続（せつぞく）** V辞書形（じしょけい）／動作性名詞（どうさせいめいし）＋ に（は）当（あ）たらない

▶ 「その事実（じじつ）は、驚（おどろ）く・非難（ひなん）する・称賛（しょうさん）するほどのものではない」と、ある反応（はんのう）や評価（ひょうか）が必要（ひつよう）ではない、または適切（てきせつ）ではないと判断（はんだん）する硬（かた）い表現（ひょうげん）です。「は」を入（い）れると、ほかの反応（はんのう）と対比（たいひ）する響（ひび）きが出（で）ます。

▶ 抽選（ちゅうせん）について「くじに当（あ）たらない」と言（い）う場合（ばあい）や、分類（ぶんるい）について「条件（じょうけん）に当（あ）たらない」と言（い）う場合（ばあい）は、ここで扱（あつか）う文型（ぶんけい）とは別（べつ）です。

## 練習（れんしゅう） (练习)

### A　★3・★2

枠（わく）の中（なか）の言葉（ことば）を使（つか）って、次（つぎ）の文（ぶん）を完成（かんせい）させなさい。1つの言葉（ことば）は1回（いっかい）しか使（つか）いません。

[ a. に決（き）まっている　b. しかない　c. まい　d. にほかならない　e. にすぎなかった　f. というものだ　g. それまでだ ]

息子（むすこ）の太郎（たろう）はバイクの腕（うで）がいい。しかし、1度（いちど）大（おお）けがをしてからは、もうバイクには乗（の）る（1. **c. まい** ）と決心（けっしん）したようだった。でも、それは一時的（いちじてき）な決心（けっしん）（2. **e. にすぎなかった** ）。夫（おっと）はあの事故（じこ）の後（あと）、彼（かれ）からバイクを取（と）り上（あ）げてしまった。「いいバイクを持（も）っていても、命（いのち）を失（うしな）ったら（3. **g. それまでだ** ）」と夫（おっと）は言（い）う。もちろん太郎（たろう）のことを心配（しんぱい）するから（4. **d. にほかならない** ）。しかし、あれでは太郎（たろう）がかわいそう（5. **f. というものだ** ）。太郎（たろう）も間（ま）もなく20歳（はたち）。バイクが危険（きけん）なことは分（わ）かっている（6. **a. に決（き）まっている** ）。分（わ）かっていて乗（の）るのだ。私（わたし）は、今（いま）はもうあの子（こ）の好（す）きなようにさせる（7. **b. しかない** ）と思（おも）っている。

- **中文理解**：太郎骑摩托车的技术很好。可自从受过一次重伤后，他似乎曾下定决心不再骑；但那不过是一时的决心。丈夫在事故后没收了他的摩托车，说“车再好，丢了命就全完了”。这当然正是因为担心太郎。不过那样做，太郎实在可怜。太郎也快 20 岁了，他肯定知道摩托车危险，是明知危险仍要骑。我想现在也只能让他按自己的意愿去做。

### B　★2・★1

枠（わく）の中（なか）の言葉（ことば）を使（つか）って、次（つぎ）の文（ぶん）を完成（かんせい）させなさい。1つの言葉（ことば）は1回（いっかい）しか使（つか）いません。

[ a. まい　b. にほかならない　c. にすぎない　d. というものだ　e. に越（こ）したことはない　f. には当（あ）たらない　g. までのことだ　h. それまでだ ]

1. 親（おや）が私（わたし）の気持（きも）ちを分（わ）かってくれないのなら、家（いえ）を出（で）る（ **g. までのことだ** ）。
   - **中文理解**：如果父母不理解我的心情，大不了离家而已。
2. この論文（ろんぶん）は大作（たいさく）ではあるけれど、データが少（すこ）し古（ふる）いですね。優秀作（ゆうしゅうさく）として掲載（けいさい）する（ **f. には当（あ）たらない** ）と思（おも）います。
   - **中文理解**：这篇论文虽是大作，但数据有些陈旧，我认为还不宜作为优秀作品刊登。
3. 日本（にほん）が資源問題（しげんもんだい）に関心（かんしん）を持（も）ってきた理由（りゆう）は、日本（にほん）が資源（しげん）に乏（とぼ）しい国（くに）だから（ **b. にほかならない** ）。
   - **中文理解**：日本一直关注资源问题，正是因为日本是一个资源匮乏的国家。
4. 自由（じゆう）を諦（あきら）めるくらいなら、私（わたし）は一生（いっしょう）結婚（けっこん）する（ **a. まい** ）。
   - **中文理解**：如果结婚意味着放弃自由，我宁可一辈子不结婚。
5. この質問（しつもん）の意味（いみ）が理解（りかい）できる人（ひと）は、ごく少数（しょうすう）（ **c. にすぎない** ）。
   - **中文理解**：能理解这个问题含义的人不过是极少数。
6. やりたくないからやらないなんて、君（きみ）、それはわがまま（ **d. というものだ** ）。
   - **中文理解**：只因不想做就不做，你这可真叫任性。
7. 普段（ふだん）は健康（けんこう）でも、無理（むり）をしない生活（せいかつ）を心掛（こころが）ける（ **e. に越（こ）したことはない** ）。
   - **中文理解**：即使平时身体健康，最好也注意保持不过度勉强的生活方式。
8. どんなに練習（れんしゅう）しても、けがをして試合（しあい）に出（で）られなくなったら（ **h. それまでだ** ）。
   - **中文理解**：无论怎样练习，一旦受伤而无法参赛，就前功尽弃了。

## まとめ：似（に）ている表現（ひょうげん）の焦点（しょうてん）

| 句型 | 焦点 | 例句含义 |
| :--- | :--- | :--- |
| 〜しかない | 选择只剩一个 | 只能道歉 |
| 〜にほかならない | 本质或原因只有一个 | 原因正是疏忽 |
| 〜にすぎない | 范围不超过某一点 | 不过是一部分 |
| 〜までだ | 已准备采取最后手段 | 大不了重新做 |
| 〜ばそれまでだ | 某结果会使此前一切失去意义 | 失败便前功尽弃 |

尤其要分清「ほかない」和「にほかならない」：前者回答“还能怎么做”，后者回答“本质或原因究竟是什么”。
