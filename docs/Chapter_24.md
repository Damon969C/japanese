# 24 経過（けいか）・結末（けつまつ） (过程・结局)

どのような過程（かてい）を経（へ）て現在（げんざい）の状態（じょうたい）になったか、また最終的（さいしゅうてき）にどのような結果（けっか）になったかを述（の）べる時（とき）、どの表現（ひょうげん）を使（つか）えばよいでしょうか。（说明经过怎样的过程形成当前状态，或最终得到何种结果时，应使用哪些表达？）

| 核心功能 | 句型 | 语感重点 |
| :--- | :--- | :--- |
| 做后发现某结果 | 〜たところ | 后项是新发现、非意志结果 |
| 反复折腾后的坏结果 | 〜あげく（に） | 过程长，结果多为负面 |
| 长时间过程后的结果 | 〜末（すえ）（に） | 结果可好可坏 |
| 做过一次后状态延续 | 〜たきり | 预期的后续没有发生 |
| 到了严重阶段才…… | 〜に至（いた）って | “到了这个地步” |
| 从事实自然得出结论 | 〜わけだ | 难怪、自然就是…… |
| 完全做完／达到极点 | 〜きる・〜きれる | 完成、极度、能否全部完成 |
| 推导出某种结果 | 〜ことになる | 按条件计算或发展便会…… |
| 换言、归纳结论 | 〜ということだ | 也就是说…… |
| 已有规则或安排 | 〜ことになっている | 非个人临时决定 |
| 克服困难坚持到底 | 〜ぬく | 过程中的意志和坚持 |
| 差一点成为某结果 | 〜ところだった | 实际未发生 |
| 放任不管／一直持续 | 〜っぱなし | 常带负面评价 |
| 到最后仍没做成 | 〜ずじまい | 常含遗憾、失望 |
| 正式说明事情原委 | 〜次第（しだい）だ | “情况就是如此” |
| 最终发展到某阶段 | 〜に至（いた）る | 正式、书面 |
| 落到更坏的结局 | 〜始末（しまつ）だ | 强烈负面评价 |

---

## 学習前（がくしゅうまえ）の小（しょう）テスト (课前小测验)

### 知（し）っていますか

[ a. ということだ　b. ということになる　c. きり　d. あげく　e. ところだった ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。

1. 会社（かいしゃ）を辞（や）めるかどうか、いろいろ迷（まよ）った（ **d. あげく** ）、やはり辞（や）めることにした。
   - **中文理解**：关于是否辞职，我反复犹豫了很久，最后还是决定辞职。
2. 先週（せんしゅう）の火曜（かよう）から外食（がいしょく）しているから、今日（きょう）でもう一週間（いっしゅうかん）も外食（がいしょく）している（ **a. ということだ** ）。
   - **中文理解**：从上周二起一直在外面吃饭，也就是说到今天已经整整一周了。
3. 「高校（こうこう）サッカーの決勝戦（けっしょうせん）は引（ひ）き分（わ）けらしいよ」
   「ということは、つまり両校（りょうこう）優勝（ゆうしょう）（ **b. ということになる** ）ね」
   - **中文理解**：“高中足球决赛好像打成平局。”“那也就是说，两所学校并列冠军了。”
4. 前（まえ）のバスが行（い）った（ **c. きり** ）、三十分（さんじゅっぷん）もたつのに、まだ次（つぎ）のバスが来（こ）ない。
   - **中文理解**：上一班公交车开走后，已经过了三十分钟，下一班仍没来。
5. 駐車（ちゅうしゃ）する時（とき）、慌（あわ）てていたので、もう少（すこ）しで隣（となり）の車（くるま）にぶつける（ **e. ところだった** ）。
   - **中文理解**：停车时太慌张，差点撞上旁边的车。

### 使（つか）えますか

文脈（ぶんみゃく）に最（もっと）も自然（しぜん）な方（ほう）を選（えら）びなさい。

1. 就職（しゅうしょく）について両親（りょうしん）に相談（そうだん）したところ、{ a. 大阪（おおさか）の会社（かいしゃ）に決（き）めた。／ **b. 自分（じぶん）で決（き）めろと言（い）われた。** }
   - **中文理解**：我就求职问题请教父母，结果他们让我自己决定。
2. 私（わたし）たちは { a. 三時（さんじ）に出発（しゅっぱつ）したいことになっている。／ **b. 三時（さんじ）に出発（しゅっぱつ）することになっている。** }
   - **中文理解**：我们定于三点出发。
3. { **a. 何（なん）でも最後（さいご）までやり抜（ぬ）くことが大切（たいせつ）だ。** ／ b. この靴（くつ）は履（は）き抜（ぬ）いたから、新（あたら）しいのを買（か）おう。 }
   - **中文理解**：无论做什么，坚持到底都很重要。
4. { a. 一生懸命（いっしょうけんめい）頑張（がんば）ったので、後（あと）で満足（まんぞく）するところでした。／ **b. 一生懸命（いっしょうけんめい）頑張（がんば）らなければ、必（かなら）ず後（あと）で後悔（こうかい）することになりますよ。** }
   - **中文理解**：如果不拼命努力，之后一定会后悔。
5. { **a. 何度（なんど）も教員（きょういん）採用試験（さいようしけん）を受（う）けた末（すえ）に、ついに合格（ごうかく）した。** ／ b. 今年（ことし）の教員（きょういん）採用試験（さいようしけん）を一度（いちど）受（う）けた末（すえ）に、幸運（こううん）にも合格（ごうかく）した。 }
   - **中文理解**：多次参加教师录用考试后，终于合格了。

> **判断要点**：「〜たところ」后接实际发现的结果，不接说话人随后主动做出的决定。「〜末（すえ）に」需要能感受到较长或反复的过程；只做一次便顺利成功时通常不用。「履（は）き抜（ぬ）く」不表示“把鞋穿坏”，应说「履（は）き潰（つぶ）す」。

## 24 Ⅰ 経過（けいか）

### 24 Ⅰ・1 〜たところ ★3

**【意味（いみ）】〜してみたら、その結果（けっか）・事実（じじつ）が分（わ）かった (做了……后，发现……)**

①レポートのテーマについて先輩（せんぱい）に相談（そうだん）してみ **たところ** 、先輩（せんぱい）はいろいろアドバイスをくれた。
- **中文理解**：我试着就报告主题请教学长，结果他给了我很多建议。

②久（ひさ）しぶりに先生（せんせい）のお宅（たく）をお訪（たず）ねし **たところ** 、先生（せんせい）はお留守（るす）だった。
- **中文理解**：我久违地去老师家拜访，结果老师不在家。

③明日（あした）はハイキングなので、天気（てんき）はどうかと思（おも）ってパソコンで調（しら）べてみ **たところ** 、一日中（いちにちじゅう）晴（は）れのようだった。
- **中文理解**：明天要去远足，我用电脑查了天气，结果显示似乎全天晴朗。

④田中（たなか）さんなら分（わ）かるだろうと思（おも）って聞（き）いてみ **たところが** 、彼（かれ）にも分（わ）からないということだった。
- **中文理解**：我以为田中会知道，便问了他，没想到他也不知道。

**接続（せつぞく）** Vた ＋ ところ

▶ ある行為（こうい）を実際（じっさい）に行（おこな）った後（あと）で、初（はじ）めて分（わ）かった事実（じじつ）や、自然（しぜん）に生（しょう）じた結果（けっか）を報告（ほうこく）します。後項（こうこう）には、話（はな）し手（て）の命令（めいれい）・勧誘（かんゆう）・意志的（いしてき）決定（けってい）は普通（ふつう）来（き）ません。（表示实施某动作后发现的新事实或自然产生的结果，后项通常不是说话人的命令、邀请或主动决定。）

**【扩展说明】**
「両親（りょうしん）に相談（そうだん）したところ、留学（りゅうがく）に賛成（さんせい）してくれた」自然；「相談（そうだん）したところ、留学（りゅうがく）を決（き）めた」若表示自己作决定则不合本用法，可说「相談（そうだん）した後（あと）、決（き）めた」。不过结果不一定“偶然”，核心是后项为做后所得的发现。「〜たところが」还带有结果出乎预期、常令人失望的转折语气。另要区分「今（いま）帰（かえ）ってきたところだ」（刚刚回来）这一时间阶段用法。

### 24 Ⅰ・2 〜あげく（に）・〜あげくの ★2

**【意味（いみ）】長（なが）い間（あいだ）いろいろ〜した後（あと）、結局（けっきょく）好（この）ましくない結果（けっか）になった (折腾许久后，最终落得不好的结果)**

①人気（にんき）バンドのCDを買（か）おうと三時間（さんじかん）も並（なら）んだ **あげく** 、結局（けっきょく）買（か）えなかった。
- **中文理解**：为了买人气乐队的 CD 排了三个小时，结果还是没买到。

②太郎（たろう）はお金（かね）のことや友人（ゆうじん）の問題（もんだい）で、散々（さんざん）親（おや）に心配（しんぱい）を掛（か）けた **あげく** 、とうとう家（いえ）を出（で）てしまった。
- **中文理解**：太郎因金钱和朋友问题让父母操尽了心，最后竟离家出走了。

③この問題（もんだい）については、長時間（ちょうじかん）にわたる議論（ぎろん）の **あげく** 、とうとう結論（けつろん）は出（で）なかった。
- **中文理解**：关于这个问题，经过长时间讨论，最终仍未得出结论。

④あの時（とき）は山（やま）で散々（さんざん）道（みち）に迷（まよ）った **あげくの果（は）てに** 、大雨（おおあめ）にも降（ふ）られて、本当（ほんとう）に怖（こわ）かった。
- **中文理解**：那次在山里迷路折腾了很久，最后又遭遇大雨，实在可怕。

**接続（せつぞく）** Vた／動作性名詞（どうさせいめいし）のNの ＋ あげく（に）・あげくの

▶ 試行錯誤（しこうさくご）・苦労（くろう）・迷（まよ）いなどが長（なが）く続（つづ）いたのに、最後（さいご）は残念（ざんねん）な結果（けっか）になったことを表（あらわ）します。「散々（さんざん）・いろいろ・長（なが）い間（あいだ）」などとよく一緒（いっしょ）に使（つか）います。（表示长期反复、费尽周折后却得到令人遗憾的结果。）

**【扩展说明】**
一次、短暂或轻微的动作通常不足以构成这一“漫长过程”。例如单纯说「社長（しゃちょう）と一度（いちど）けんかしたあげく、会社（かいしゃ）を辞（や）めた」较生硬；若争执长期升级，则可以成立。结果通常为负面；中性或正面结果宜优先使用「〜末（すえ）に」。「あげくの果（は）てに」是进一步加强“到头来”的惯用形式。

### 24 Ⅰ・3 〜末（すえ）（に）・〜末（すえ）の ★2

**【意味（いみ）】長（なが）い間（あいだ）いろいろ〜した後（あと）、最終的（さいしゅうてき）に (经过长期过程后，最终……)**

①帰国（きこく）するというのは、散々（さんざん）迷（まよ）った **末（すえ）に** 決（き）めたことです。
- **中文理解**：回国是我反复犹豫后最终作出的决定。

②家族（かぞく）が父（ちち）の任地（にんち）である大阪（おおさか）へ移（うつ）らないというのは、家族（かぞく）でよく話（はな）し合（あ）った **末（すえ）の** 結論（けつろん）です。
- **中文理解**：全家不搬去父亲任职地大阪，是家人充分商量后得出的结论。

③試合（しあい）はAチームとBチームの激（はげ）しい戦（たたか）いの **末（すえ）** 、Aチームが勝（か）った。
- **中文理解**：A 队与 B 队经过激战，最终 A 队获胜。

④委員会（いいんかい）は五時間（ごじかん）に及（およ）ぶ討議（とうぎ）の **末（すえ）に** 、来年度（らいねんど）の主（おも）な活動計画（かつどうけいかく）を取（と）り決（き）めた。
- **中文理解**：委员会经过长达五小时的讨论，最终确定了下一年度的主要活动计划。

**接続（せつぞく）** Vた／Nの ＋ 末（すえ）（に）・末（すえ）の

▶ 長（なが）い時間（じかん）や複数（ふくすう）の段階（だんかい）を経（へ）て、最終的（さいしゅうてき）な判断（はんだん）・結果（けっか）に達（たっ）したことを表（あらわ）します。結果（けっか）はよい場合（ばあい）にも悪（わる）い場合（ばあい）にも使（つか）えます。（表示经历长期或多个阶段后得出最终判断或结果，结果可好可坏。）

**【扩展说明】**
「あげく」着重“折腾后却落得不良结果”，含说话人的负面评价；「末（すえ）に」较中性、正式，更着重过程的终点。若没有足够长的过程，如“今年第一次考试便幸运通过”，一般只说「試験（しけん）を受（う）けて合格（ごうかく）した」。

### 24 Ⅰ・4 〜きり・〜きりだ ★2

**【意味（いみ）】〜してから、そのまま次（つぎ）の変化（へんか）がない (做了……之后就一直没有后续变化)**

①子（こ）どもが昼（ひる）に出掛（でか）けた **きり** 、夜（よる）の八時（はちじ）になっても帰（かえ）ってこないので心配（しんぱい）です。
- **中文理解**：孩子中午出门后，到了晚上八点还没回来，我很担心。

②佐藤（さとう）さんは十年前（じゅうねんまえ）にスイスへ行（い）った **きり** 、そのままスイスに定住（ていじゅう）してしまったらしい。
- **中文理解**：听说佐藤十年前去了瑞士，此后便一直在那里定居。

③「課長（かちょう）は？」
「具合（ぐあい）がよくないから病院（びょういん）へ行（い）くと言（い）って出（で）た **きりなんです** 。心配（しんぱい）ですね」
- **中文理解**：“科长呢？”“他说身体不舒服要去医院，出去后就一直没回来。真让人担心。”

**接続（せつぞく）** Vた ＋ きり（だ）

▶ ある動作（どうさ）が最後（さいご）に一度（いちど）起（お）きた後（あと）、本来（ほんらい）予想（よそう）される次（つぎ）の動作（どうさ）や変化（へんか）が起（お）こらず、その状態（じょうたい）が続（つづ）いていることを表（あらわ）します。後項（こうこう）は「〜ない」が多（おお）いですが、例②（れいに）のような継続状態（けいぞくじょうたい）も可能（かのう）です。（表示最后一次动作之后，预期的后续没有发生，状态持续至今；后项常是否定，但也可直接描述持续状态。）

**【扩展说明】**
口语中常说「〜たっきり」。「一回（いっかい）きり」「二人（ふたり）きり」也含“仅限于”的意义，但属于「きり＝だけ」的另一用法，不要与本节“做后一直……”混淆。

### 24 Ⅰ・5 〜に至（いた）って（は） ★1 [W]

**【意味（いみ）】〜という重大（じゅうだい）・極端（きょくたん）な段階（だんかい）になって (直到事态发展到……地步)**

①39度（さんじゅうきゅうど）の熱（ねつ）が三日（みっか）も続（つづ）くという事態（じたい） **に至（いた）って** 、彼（かれ）はやっと医者（いしゃ）へ行（い）く気（き）になった。
- **中文理解**：直到三十九度高烧持续三天，他才终于愿意去看医生。

②関係者（かんけいしゃ）は、子（こ）どもが自殺（じさつ）する **に至（いた）って** 初（はじ）めて事（こと）の重大（じゅうだい）さを知（し）った。
- **中文理解**：直到孩子自杀，相关人员才第一次认识到事情的严重性。

③学校（がっこう）へほとんど行（い）かずにアルバイトばかりしていた彼（かれ）だが、いよいよ留年（りゅうねん）という状況（じょうきょう） **に至（いた）っては** 、親（おや）に本当（ほんとう）のことを言（い）わざるを得（え）なかった。
- **中文理解**：他几乎不去学校，只顾打工；事到将要留级的地步，便不得不向父母说出实情。

**接続（せつぞく）** V辞書形（じしょけい）／N ＋ に至（いた）って（は）

▶ 事態（じたい）が深刻（しんこく）な段階（だんかい）まで進（すす）んだ後（あと）で、ようやく認識（にんしき）・行動（こうどう）が生（しょう）じたことを表（あらわ）します。「やっと・ようやく・初（はじ）めて」などとよく一緒（いっしょ）に使（つか）います。（表示事态发展到严重阶段后，才终于出现某种认识或行动。）

**【扩展说明】**
「に至（いた）っては」的「は」会进一步突出该极端阶段。根据语境，它还可表示“说到最极端的某人／某事”，如「弟（おとうと）に至（いた）っては、連絡（れんらく）さえしない」，这时不一定是时间上的“到了……之后”。

## 24 Ⅱ 結末（けつまつ）

### 24 Ⅱ・1 〜わけだ ★3

**【意味（いみ）】事情（じじょう）から考（かんが）えると、当然（とうぜん）〜という結論（けつろん）になる (根据情况，自然可得出……的结论)**

①30ページの宿題（しゅくだい）だから、一日（いちにち）に3ページずつやれば十日（とおか）で終（お）わる **わけです** 。
- **中文理解**：作业共三十页，每天做三页，自然十天就能完成。

②夜型（よるがた）の人間（にんげん）が増（ふ）えてきたために、コンビニエンスストアがこれほど広（ひろ）がった **わけです** 。
- **中文理解**：正因为夜间活动的人越来越多，便利店才会普及到这种程度。

③このスケジュール表（ひょう）を見（み）ると、東京（とうきょう）に帰（かえ）って来（く）るのは水曜日（すいようび）の午前中（ごぜんちゅう） **というわけだ** 。
- **中文理解**：看这张日程表，也就是说会在星期三上午回到东京。

④「昨日（きのう）の会（かい）、来（こ）なかったんですね」
「会（かい）があると知（し）らなかったから行（い）かなかった **わけで** 、知（し）っていたらもちろん行（い）きましたよ」
- **中文理解**：“昨天的聚会你没来啊。”“我是因为不知道有聚会才没去；要是知道，当然会去。”

**接続（せつぞく）** V・イA普通形（ふつうけい）／ナAな・ナAである／Nな・Nである・Nという ＋ わけだ

▶ 前（まえ）に示（しめ）された事実（じじつ）・理由（りゆう）・計算（けいさん）から、当然（とうぜん）導（みちび）かれる結論（けつろん）を述（の）べたり、今（いま）まで分（わ）からなかった事情（じじょう）を理解（りかい）して「なるほど」と納得（なっとく）したりする時（とき）に使（つか）います。（用于说明由事实、理由或计算自然得出的结论，也可表示终于明白缘由后的“难怪如此”。）

**【扩展说明】**
原句「午前中（ごぜんちゅう）のわけだ」不自然，名词结论可说「午前中（ごぜんちゅう）なわけだ」或更清楚地说「午前中（ごぜんちゅう）というわけだ」。注意「わけではない」表示“并非……”，「わけがない」表示“不可能……”，意义与本节不同。

### 24 Ⅱ・2 〜きる・〜きれる ★3

**【意味（いみ）】全部（ぜんぶ）・最後（さいご）まで〜する／全部（ぜんぶ）〜できる (全部做完；能全部做完)**

①5巻（ごかん）もある長（なが）い小説（しょうせつ）を、夏休（なつやす）み中（ちゅう）に全部（ぜんぶ）読（よ）み **きった** 。
- **中文理解**：我在暑假期间读完了足有五卷的长篇小说。

②慎重（しんちょう）な彼（かれ）が「絶対（ぜったい）にやれる」と言（い）い **きった** のだから、相当（そうとう）の自信（じしん）があるのだろう。
- **中文理解**：一向谨慎的他断言“绝对能做到”，想必相当有自信。

③井上（いのうえ）さんは年（とし）を取（と）った両親（りょうしん）と入院中（にゅういんちゅう）の奥（おく）さんを抱（かか）え、困（こま）り **きって** いるらしい。
- **中文理解**：井上既要照顾年迈父母，又要照顾住院的妻子，似乎已苦恼到了极点。

④あの商品（しょうひん）は人気（にんき）があるらしく、発売（はつばい）と同時（どうじ）に売（う）り **きれて** しまった。
- **中文理解**：那件商品似乎很受欢迎，一上市便售罄了。

⑤わたしが休（やす）みに家（いえ）へ帰（かえ）ると、母（はは）はいつも食（た）べ **きれない** ほどのごちそうを作（つく）ってくれる。
- **中文理解**：每逢我放假回家，母亲总会做多得吃不完的饭菜。

⑥あの子（こ）の複雑（ふくざつ）な思（おも）いは、きっと親（おや）でも理解（りかい）し **きれない** だろう。
- **中文理解**：那个孩子复杂的心情，恐怕连父母也无法完全理解。

**接続（せつぞく）** Vます形（けい）の語幹（ごかん）＋ きる／きれる／きれない

▶ 「Vきる」は動作（どうさ）を最後（さいご）まで完全（かんぜん）に行（おこな）うこと、断定（だんてい）を強（つよ）く言（い）うこと、または状態（じょうたい）が極限（きょくげん）に達（たっ）することを表（あらわ）します。「Vきれる／きれない」は、全量（ぜんりょう）・完全（かんぜん）な実行（じっこう）が可能（かのう）かどうかを表（あらわ）します。（「Vきる」表示彻底完成、强烈断定或达到极限；「Vきれる／きれない」表示能否全部、完全做到。）

**【扩展说明】**
「読（よ）みきる」着重“读完整部”，「読（よ）み抜（ぬ）く」则更突出克服困难坚持读到底。「売（う）り切（き）れる」已是常用复合动词，表示全部售完；「困（こま）りきる・疲（つか）れきる」表示状态达到极点，不是“完成一个动作”。

### 24 Ⅱ・3 〜ことになる ★3

**【意味（いみ）】条件（じょうけん）・事情（じじょう）から考（かんが）えると、結果（けっか）として〜になる (按条件或情况推导，结果会是……)**

①この事故（じこ）による負傷者（ふしょうしゃ）は、女性（じょせい）三人（さんにん）、男性（だんせい）四人（よにん）の合（あ）わせて七人（ななにん）という **ことになる** 。
- **中文理解**：这起事故的伤者为三名女性和四名男性，也就是共七人。

②十一時（じゅういちじ）の新幹線（しんかんせん）だと、十三時（じゅうさんじ）からの大阪（おおさか）の会議（かいぎ）に間（ま）に合（あ）わない **ことになる** 。ここから大阪（おおさか）まで三時間（さんじかん）は掛（か）かるから。
- **中文理解**：若乘十一点的新干线，就会赶不上十三点在大阪召开的会议，因为从这里到大阪至少要三小时。

③今（いま）、遊（あそ）んでばかりいると、試験（しけん）の前（まえ）になって悔（く）やむ **ことになる** よ。
- **中文理解**：现在如果只顾玩，到考试前就会后悔。

④あの人（ひと）にお金（かね）を貸（か）すと、結局（けっきょく）返（かえ）してもらえない **ことになる** ので、貸（か）したくない。
- **中文理解**：把钱借给那个人，结果终究会收不回来，所以我不想借。

**接続（せつぞく）** V辞書形（じしょけい）・Vない形（けい）＋ ことになる　；　N・ナA ＋ ということになる

▶ ある条件（じょうけん）を計算（けいさん）・推論（すいろん）した結果（けっか）、論理的（ろんりてき）にその結論（けつろん）になること、または現在（げんざい）の行動（こうどう）が将来（しょうらい）の結果（けっか）を招（まね）くことを表（あらわ）します。（表示通过计算、推论得出的逻辑结果，或当前行为将招致的未来结果。）

**【扩展说明】**
「ことになる」还可表示由组织、他人或环境作出的决定，如「来月（らいげつ）転勤（てんきん）することになった」；「ことにする」则表示本人决定。这里的①②接近「わけだ」，但「ことになる」更突出推演后“会形成这一结果”。③④常用于提醒或警告不良后果。

### 24 Ⅱ・4 〜ということだ ★3

**【意味（いみ）】前（まえ）の内容（ないよう）をまとめると、つまり〜だ (归纳前文，也就是说……)**

①山田（やまだ）さんはまだ来（き）ていませんか。つまり、また遅刻（ちこく） **ということですね** 。
- **中文理解**：山田还没来吗？也就是说，他又迟到了。

②チケットは全（すべ）て当日券（とうじつけん）です。つまり、早（はや）めに来（き）ていただいた方（ほう）がいい **ということです** 。
- **中文理解**：门票全部当天出售，也就是说，各位最好早点来。

③係（かかり）の人（ひと）「明日（あした）は特別（とくべつ）な行事（ぎょうじ）のため、この駐車場（ちゅうしゃじょう）は臨時（りんじ）に駐車禁止（ちゅうしゃきんし）になります」
客（きゃく）「ということは、つまり車（くるま）では来（く）るな **ということですね** 」
- **中文理解**：工作人员：“明天因举办特别活动，本停车场临时禁停。”顾客：“也就是说，不要开车来，对吧？”

**接続（せつぞく）** 普通形（ふつうけい）／N ＋ ということだ

▶ 前（まえ）の発言（はつげん）・事実（じじつ）を受（う）け、それを別（べつ）の言（い）い方（かた）で要約（ようやく）したり、そこから引（ひ）き出（だ）した意味（いみ）を相手（あいて）に確認（かくにん）したりします。「つまり・ということは」とよく一緒（いっしょ）に使（つか）います。（承接前文，以另一种说法概括，或确认由此推导出的含义。）

**【扩展说明】**
「〜ということだ」还有“听说……”的传闻用法，如「明日（あした）は休（やす）みだということだ」。本节是结论、换言用法，必须结合「つまり」「ということは」等上下文判断。与「わけだ」相比，它更像对信息进行改述；「わけだ」更带“原来如此、自然如此”的理解。

### 24 Ⅱ・5 〜ことになっている・〜こととなっている ★3

**【意味（いみ）】規則（きそく）・予定（よてい）・取（と）り決（き）めとして〜と決（き）まっている (按规定、计划或安排应当……)**

①会社（かいしゃ）では、社員（しゃいん）は一年（いちねん）に一回（いっかい）健康診断（けんこうしんだん）を受（う）ける **ことになっています** 。
- **中文理解**：公司规定员工每年接受一次健康检查。

②うちの子（こ）の小学校（しょうがっこう）では、親（おや）の住所録（じゅうしょろく）を学校外（がっこうがい）に持（も）ち出（だ）さない **ことになっている** 。
- **中文理解**：我孩子就读的小学规定，不得把家长通讯录带出校外。

③午後（ごご）の分科会（ぶんかかい）は二時（にじ）から **ということとなっております** ので、一時五十分（いちじごじゅっぷん）までにお集（あつ）まりください。
- **中文理解**：下午的分组讨论会定于两点开始，请于一点五十分前集合。

④うちの会社（かいしゃ）では、お客様（きゃくさま）に会（あ）う時（とき）以外（いがい）は、スーツを着（き）なくてもいい **ことになっている** 。
- **中文理解**：我们公司规定，除会见客户时以外，可以不穿西装。

**接続（せつぞく）** V辞書形（じしょけい）・Vない形（けい）＋ ことになっている　；　N ＋ ということになっている

▶ 個人（こじん）がその場（ば）で決（き）めたことではなく、組織（そしき）の規則（きそく）、既定（きてい）の予定（よてい）、社会的（しゃかいてき）習慣（しゅうかん）などとして成立（せいりつ）していることを表（あらわ）します。「こととなっている」はさらに改（あらた）まった言（い）い方（かた）です。（表示并非个人临时决定，而是作为组织规则、既定安排或社会习惯已经成立；「こととなっている」更郑重。）

**【扩展说明】**
个人主动维持的习惯用「毎朝（まいあさ）走（はし）ることにしている」，外部规则或共同安排用「毎朝（まいあさ）走（はし）ることになっている」。规定内容中常出现「〜てもいい・〜てはいけない・〜なければならない」。

### 24 Ⅱ・6 〜抜（ぬ）く ★2

**【意味（いみ）】困難（こんなん）を越（こ）えて、最後（さいご）まで完全（かんぜん）に〜する (克服困难，坚持到底)**

①マラソンの精神（せいしん）というのは、優勝（ゆうしょう）できなくても最後（さいご）まで走（はし）り **抜（ぬ）く** ことだ。
- **中文理解**：马拉松精神就是即使不能夺冠，也要坚持跑到最后。

②彼（かれ）は十年間（じゅうねんかん）も続（つづ）いた内戦（ないせん）の時代（じだい）を何（なん）とか生（い）き **抜（ぬ）いて** 、今（いま）は幸（しあわ）せに暮（く）らしている。
- **中文理解**：他设法熬过了持续十年的内战时期，如今生活幸福。

③わたしは親（おや）として、あの子（こ）の長所（ちょうしょ）も欠点（けってん）も知（し）り **抜（ぬ）いている** つもりです。
- **中文理解**：作为父母，我自认为完全了解那个孩子的优点和缺点。

④田舎（いなか）での一人暮（ひとりぐ）らしを望（のぞ）む祖母（そぼ）を残（のこ）して東京（とうきょう）に来（き）たのは、家族（かぞく）で考（かんが）え **抜（ぬ）いて** 出（だ）した結論（けつろん）です。
- **中文理解**：把希望独居乡下的祖母留下而来到东京，是全家深思熟虑后作出的决定。

**接続（せつぞく）** Vます形（けい）の語幹（ごかん）＋ 抜（ぬ）く

▶ 苦労（くろう）・困難（こんなん）・長（なが）い時間（じかん）を乗（の）り越（こ）えて最後（さいご）まで行為（こうい）を続（つづ）けること、または考（かんが）え・知識（ちしき）などを徹底（てってい）させることを表（あらわ）します。（表示克服困难坚持到底，或把思考、认识贯彻到彻底程度。）

**【扩展说明】**
「〜きる」主要关注完成、全量或极限；「〜抜（ぬ）く」主要关注过程中的困难、毅力和坚持。因此「食（た）べきる」是“全部吃完”，而「苦（くる）しくても走（はし）り抜（ぬ）く」是“即使艰难也坚持跑到底”。并非所有动词都能自由接「抜（ぬ）く」，常见搭配应整体记忆。

### 24 Ⅱ・7 〜ところだった ★2

**【意味（いみ）】もう少（すこ）しで〜という結果（けっか）になりそうだったが、実際（じっさい）にはならなかった (差一点就……，但实际没有发生)**

①考（かんが）え事（ごと）をしながら歩（ある）いていたので、横道（よこみち）から出（で）て来（き）た自転車（じてんしゃ）に危（あぶ）なくぶつかる **ところだった** 。
- **中文理解**：我边走边想事情，差点撞上从岔路出来的自行车。

②切符（きっぷ）売（う）り場（ば）に来（く）るのがもう少（すこ）し遅（おそ）かったら、映画（えいが）の予約券（よやくけん）が買（か）えない **ところだった** 。
- **中文理解**：如果再晚一点到售票处，就差点买不到电影预售票了。（实际买到了。）

③二百（にひゃく）メートル平泳（ひらおよ）ぎの競泳（きょうえい）で、もう少（すこ）しで一位（いちい）になる **ところだった** のに、タッチの差（さ）で二位（にい）だった。
- **中文理解**：二百米蛙泳比赛中本来差一点就能得第一，却以极小差距位居第二。

**接続（せつぞく）** V辞書形（じしょけい）・Vない形（けい）＋ ところだった

▶ ある結果（けっか）が実現（じつげん）する直前（ちょくぜん）まで行（い）ったものの、最終的（さいしゅうてき）には実現（じつげん）しなかったことを表（あらわ）します。悪（わる）い結果（けっか）を免（まぬか）れた場合（ばあい）にも、よい結果（けっか）を逃（のが）して残念（ざんねん）な場合（ばあい）にも使（つか）えます。（表示某结果几乎实现但最终没有发生，可指幸免坏事，也可指错失好结果。）

**【扩展说明】**
坏结果常与「もう少（すこ）しで・危（あぶ）なく・危（あや）うく」搭配。整个句型固定回顾“当时差点发生”，所以句末是过去式「だった」。例②中的否定「買（か）えないところだった」表示“险些陷入买不到的结果”，实际成功买到。

### 24 Ⅱ・8 〜っぱなし ★2 [S]

**【意味（いみ）】〜したまま放置（ほうち）する／同（おな）じ状態（じょうたい）がずっと続（つづ）く (做完后放着不管；一直处于某状态)**

①道具（どうぐ）が出（だ）し **っぱなし** だよ。使（つか）ったら片付（かたづ）けなさい。
- **中文理解**：工具拿出来后一直没收，用完要整理好。

②あのメーカーは売（う）り **っぱなし** ではなく、アフターケアがしっかりしている。
- **中文理解**：那家厂商并非卖完就不管，售后服务很完善。

③この仕事（しごと）は立（た）ち **っぱなし** のことが多（おお）いので、疲（つか）れる。
- **中文理解**：这份工作经常要一直站着，所以很累。

④「また負（ま）けたね」
「あのチームはシーズンが始（はじ）まってから負（ま）け **っぱなし** だね」
- **中文理解**：“又输了啊。”“那支队从赛季开始后一直在输。”

**接続（せつぞく）** Vます形（けい）の語幹（ごかん）＋ っぱなし

▶ 一（ひと）つ目（め）の用法（ようほう）は、動作（どうさ）をした後（あと）、本来（ほんらい）するべき処理（しょり）をせず、その状態（じょうたい）を放置（ほうち）することです。二（ふた）つ目（め）は、立（た）つ・負（ま）けるなど同（おな）じ動作（どうさ）・状態（じょうたい）が長（なが）く続（つづ）くことです。どちらも不満（ふまん）・負担（ふたん）などの否定的（ひていてき）評価（ひょうか）を伴（ともな）うことが多（おお）いです。（一是做后不作应有处理，二是同一动作或状态长时间持续，两者常带负面评价。）

**【扩展说明】**
原说明中的「後（あと）の当然（とうぜん）しなければならないことをしないである」应改为「しないでいる」。典型对比如「窓（まど）を開（あ）けっぱなしにする」（开着不关）和「一日中（いちにちじゅう）働（はたら）きっぱなしだ」（持续工作一整天）。

### 24 Ⅱ・9 〜ずじまい ★2

**【意味（いみ）】結局（けっきょく）〜しないまま終（お）わる (最终仍没做成……)**

①あの本（ほん）はいろいろな友達（ともだち）に勧（すす）められたんですが、何（なん）となく気（き）が進（すす）まず、結局（けっきょく）読（よ）ま **ずじまいでした** 。
- **中文理解**：许多朋友都推荐过那本书，可我不知为何一直提不起兴趣，最后还是没读。

②そろそろ昼食（ちゅうしょく）を、と思（おも）っていたら来客（らいきゃく）があり、そのうちにミーティングが始（はじ）まり、結局（けっきょく）昼食（ちゅうしょく）は取（と）ら **ずじまいだった** 。
- **中文理解**：正打算吃午饭时来了客人，随后会议又开始了，结果午饭也没吃成。

③その件（けん）については、いろいろな人（ひと）に聞（き）いて回（まわ）ったが、結局（けっきょく）真相（しんそう）は分（わ）から **ずじまいだった** 。
- **中文理解**：关于那件事，我四处询问了许多人，最终仍没弄清真相。

④あの映画（えいが）も終（お）わってしまいました。見（み）たいと思（おも）っても、忙（いそが）しくて見（み） **ずじまいのこと** が多（おお）いんですよ。
- **中文理解**：那部电影也下映了。很多时候虽想看，却因为忙而最终没看成。

**接続（せつぞく）** Vない形（けい）から「ない」を取（と）る ＋ ずじまい　※する → せずじまい、来（く）る → 来（こ）ずじまい

▶ したい、またはする予定（よてい）だった行為（こうい）が、心理的（しんりてき）・時間的（じかんてき）・物理的（ぶつりてき）理由（りゆう）で実現（じつげん）しないまま機会（きかい）が終（お）わったことを表（あらわ）します。「結局（けっきょく）・とうとう」とよく一緒（いっしょ）に使（つか）い、残念（ざんねん）・心残（こころのこ）りの気持（きも）ちを伴（ともな）うことが多（おお）いです。（表示原想做或计划做的事因各种原因直至机会结束仍未实现，常带遗憾。）

**【扩展说明】**

### 24 Ⅱ・10 〜次第（しだい）だ ★2 [F]

**【意味（いみ）】事情（じじょう）・理由（りゆう）は以上（いじょう）のとおりだ／そのため〜した (事情原委就是如此；因此才……)**

**接続（せつぞく）** V辞書形（じしょけい）＋ 始末（しまつ）だ　；　この／その／あの ＋ 始末（しまつ）だ

**【扩展说明】**

## 本章（ほんしょう）の使（つか）い分（わ）け

- **过程后得到结果**：负面且费尽周折用「あげく」，中性且可好可坏用「末（すえ）に」。
- **完成到底**：关注完成量用「きる」，关注克服困难和意志用「抜（ぬ）く」。
- **从信息得结论**：「わけだ」表示“原来自然如此”，「ということだ」表示“换言之”，「ことになる」表示“推演后会形成该结果”。
- **未实现**：「ところだった」是差点发生但没发生；「ずじまい」是直到机会结束仍没做成。
- **坏结果持续升级**：「始末（しまつ）だ」带强烈责备；「に至（いた）る」本身只表示到达终点，结果不一定负面。
