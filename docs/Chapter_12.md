# 12 基準（きじゅん） (基准)

何（なに）かを基準（きじゅん）にして動作（どうさ）が行（おこな）われると言（い）いたいときは、どんな言い方（いいかた）がありますか。 (想要表达以某事物为基准进行动作时，有什么样的表达方式呢？)

| 分类 | 句型 | 核心功能 |
| :--- | :--- | :--- |
| 样态・一致 | 〜ように、〜とおり（に） | 大致照某种样态，或忠实依照内容 |
| 素材・依据 | 〜をもとに、〜に基（もと）づいて、〜を踏（ふ）まえて | 以素材创作、以依据判断、把既有事实纳入考虑 |
| 方针・现实标准 | 〜に沿（そ）って、〜に即（そく）して | 不偏离方针，或紧贴现实与规范 |
| 环境・支配关系 | 〜のもとで、〜のもとに | 在某人的指导、某种制度或条件之下 |

---

### 12・1 〜ように・〜ような ★3

**【意味（いみ）】〜とだいたい同（おな）じに (和……大致相同/像……那样)**

①大（おお）けがをした後（あと）、体（からだ）が思（おも）う（ **ように** ）動（うご）かなくなってしまった。
- **中文理解**：受了重伤之后，身体变得不能如自己所愿地活动了。

②人間（にんげん）に感情（かんじょう）がある（ **ように** ）、人間（にんげん）以外（いがい）の動物（どうぶつ）にも感情（かんじょう）があるはずだ。
- **中文理解**：就像人类有感情一样，人类以外的动物也应该有感情。

③ご存じ（ごぞんじ）の（ **ように** ）、この町（まち）には「山下（やました）」という姓（せい）が多（おお）いです。
- **中文理解**：如您所知，这个镇上姓“山下”的人很多。

④この実験（じっけん）では、わたしが期待（きたい）していた（ **ような** ）データは得（え）られなかった。
- **中文理解**：在这个实验中，没能得到我所期待的那种数据。

**接続（せつぞく）** V普通形（ふつうけい） / Nの ＋ ように・ような（名词、ナ形容词也可用「Nである／ナAである＋ように」）
▶ ある内容（ないよう）・様子（ようす）とだいたい同（おな）じであること、またはそれを例（れい）として示（しめ）すことを表（あらわ）す。文書（ぶんしょ）では「次（つぎ）のように」などで後（あと）の内容（ないよう）を予告（よこく）することも多（おお）い。（表示与某内容、样态大致相同，或将其作为例子提示。公文中也常用「次のように」预告后文内容。）
→ 2課（にか）I・1「〜ように」

**【扩展说明】**
「ように」强调样态或整体上的相似，不要求每个细节完全一致。例①的固定搭配「思うように」是“如愿、按自己的意图”，不是“像想象的那样”。修饰动词用「ように」，修饰名词用「ような」。本节不要与表示目的的「忘れないようにメモする」混淆。

### 12・2 〜とおり（に）・〜とおりの・〜どおりだ ★3

**【意味（いみ）】〜と同（おな）じに (和……一样/正如……)**

①わたしの言（い）った（ **とおりに** ）やってみてください。
- **中文理解**：请照我说的试着做一下。

②ものごとは自分（じぶん）の考（かんが）え（ **どおりに** ）はいかないものだ。
- **中文理解**：事情往往不能如自己所愿那样发展。

③試合（しあい）の結果（けっか）はわたしが思（おも）っていた（ **とおりだった** ）。
- **中文理解**：比赛的结果和我预想的一样。

④この本（ほん）の作者（さくしゃ）に初（はじ）めて直接（ちょくせつ）会（あ）うことができた。前（まえ）から想像（そうぞう）していた（ **とおりの** ）人（ひと）だった。
- **中文理解**：第一次直接见到了这本书的作者。是和我以前想象的一样的人。

⑤この本（ほん）に書（か）いてある（ **とおり** ）、インターネットにはいろいろな問題（もんだい）点（てん）があるのです。
- **中文理解**：正如这本书里写的那样，互联网存在着各种各样的问题。

**接続（せつぞく）** Vる・Vた／Nの ＋ とおり（に）　　N ＋ どおり（に）
▶ 一致（いっち）する内容（ないよう）であることを表（あらわ）す。1「〜ように」と意味（いみ）・使い方（つかいかた）が同（おな）じだが、「まったく同（おな）じに」という感（かん）じが強（つよ）い。（表示内容一致。与1「〜ように」的意思、用法相同，但“完全一样”的感觉更强。）

**【扩展说明】**
「〜とおり」强调结果或做法忠实地与说明、计划、预想等一致。动词后用「とおり」，名词后可用「Nのとおり」或复合形式「Nどおり」。例如「説明書どおり」正确，而「説明書のとおり」也可以；「説明書とおり」则错误。

### 12・3 〜をもとに（して）・〜をもとにする・〜をもとにした ★3

**【意味（いみ）】〜を素材（そざい）にして／〜からヒントを得（え）て (以……为素材/从……得到启发)**

①このドレスは、日本（にほん）の着物（きもの）の形（かたち）を（ **もとに** ）新（あたら）しくデザインしたものです。
- **中文理解**：这件礼服是以日本和服的形状为基础重新设计的。

②この映画（えいが）は歴史（れきし）的（てき）な事実（じじつ）を（ **もとにして** ）作（つく）られたものである。
- **中文理解**：这部电影是以历史事实为基础制作的。

③若（わか）いころ体験（たいけん）したことを（ **もとにして** ）、小説（しょうせつ）を書（か）いてみようと思（おも）っています。
- **中文理解**：我想把年轻时体验过的事情作为素材，试着写部小说。

④流行（りゅうこう）歌（か）の中（なか）には有名（ゆうめい）なクラシックの曲（きょく）の一部（いちぶ）を（ **もとにした** ）ものがある。
- **中文理解**：流行歌曲中，有一些是以著名古典乐曲的一部分为原型的。

**接続（せつぞく）** N ＋ をもとに（して）
▶ 1）あるものが生（う）み出（だ）されるときの素材（そざい）を表（あらわ）す。「その素材（そざい）を生（い）かしながら何（なに）かをする」と言（い）いたいときに使（つか）われ、後（あと）には、書（か）く・話（はな）す・作（つく）る・創作（そうさく）する、などの意味（いみ）を持（も）つ文（ぶん）が来（く）る。（表示某事物产生时的素材。在想要表达“一边利用那个素材一边做某事”时使用，后面接具有写、说、制作、创作等意义的句子。）
2）6「〜に基（もと）づいて」と意味（いみ）が似（に）ているが、「〜をもとにして」は、もとの素材（そざい）や情報（じょうほう）を利用（りよう）し、そこから新（あたら）しいものを作（つく）ることに重点（じゅうてん）がある。（与6「〜に基づいて」意思相近，但「〜をもとにして」侧重利用原始素材或信息，由此制作出新的事物。）

**【扩展说明】**
后项常是「書く・作る・デザインする・編集する」等创造行为，成品可以在原素材上进行改编。表示法律、数据、理论是判断的根据时，一般用「〜に基づいて」。

### 12・4 〜を〜に（して）・〜を〜として・〜を〜にする・〜を〜とする・〜を〜にした・〜を〜とした ★3

**【意味（いみ）】N1をN2という役割（やくわり）・基準（きじゅん）・区切（くぎ）りに定（さだ）めて (把N1定为N2这一角色、基准或界限)**

①祖父（そふ）は今日（きょう）も孫（まご）のヒロシを話し相手（はなしあいて）（ **にして** ）散歩（さんぽ）に出（で）かけた。
- **中文理解**：祖父今天也把孙子宏当作聊天的对象，出门散步去了。

②今回（こんかい）のキャンプを最後（さいご）（ **に** ）、わたしたちのグループは解散（かいさん）することになった。
- **中文理解**：以这次露营为最后一次，我们的群体决定解散了。

③卒業（そつぎょう）を1つの区切（くぎ）り（ **として** ）、これからは自立（じりつ）して生（い）きていきたい。
- **中文理解**：把毕业作为一个节点，从今以后我想自立地生活下去。

④この大会（たいかい）に参加（さんか）できるのは社会（しゃかい）奉仕（ほうし）を目的（もくてき）（ **とする** ）団体（だんたい）だけです。
- **中文理解**：能参加这个大会的，只有以社会服务为目的的团体。

⑤この研究（けんきゅう）会（かい）では環境（かんきょう）問題（もんだい）を中心（ちゅうしん）（ **とした** ）さまざまな問題（もんだい）を話（はな）し合（あ）いたいと思（おも）う。
- **中文理解**：我想在这个研究会上讨论以环境问题为中心的各种问题。

**接続（せつぞく）** N1 ＋ を ＋ N2 ＋ に（して）/ として / にする / とする
▶ ある行動（こうどう）や場面（ばめん）で、N1にN2という役割（やくわり）・位置（いち）づけ・目的（もくてき）・区切（くぎ）りを与（あた）える表現（ひょうげん）。（表示在某一行动或场景中，赋予N1以N2这一角色、定位、目的或界限。）

**【扩展说明】**
「〜にする」较口语、具体，带有选择或改变状态的感觉；「〜とする」较正式，常用于规定、定义、目的。修饰名词时用「〜にした／〜とした＋N」。固定说法「〜を最後に」表示以某次事件为最后界限，此后不再继续。

### 12・5 〜に沿（そ）って・〜に沿（そ）う・〜に沿（そ）った ★2

**【意味（いみ）】〜に合（あ）うように／〜に従って（にしたがって） (为了符合……/沿着……/按照……)**

①この学習（がくしゅう）計画（けいかく）表（ひょう）（ **に沿（そ）って** ）、毎日（まいにち）少（すこ）しずつ単語（たんご）の勉強（べんきょう）を進（すす）めていくつもりです。
- **中文理解**：我打算按照这个学习计划表，每天一点点地推进单词的学习。

②ただ今（ただいま）のご質問（しつもん）に対して（にたいして）お答え（おこたえ）します。ご期待（きたい）（ **に沿（そ）う** ）回答（かいとう）ができるかどうか自信（じしん）がありませんが……。
- **中文理解**：现在就您的问题进行回答。我没有把握能否做出符合您期待的回答，但是……。

③製品（せいひん）の説明（せつめい）をするときは、マニュアル（ **に沿（そ）った** ）やり方（やりかた）で進（すす）めれば失敗（しっぱい）はないだろう。
- **中文理解**：在说明产品的时候，只要按照手册上的做法进行，就不会失败吧。

**接続（せつぞく）** N ＋ に沿（そ）って
▶ 「〜から離（はな）れないで・〜からずれないで」という意味（いみ）を表（あらわ）す。期待（きたい）・希望（きぼう）・方針（ほうしん）・マニュアルなどの語（ご）につくことが多（おお）い。（表示“不偏离……・不背离……”的意思。多接在期待、希望、方针、手册等词语后面。）

**【扩展说明】**
既可表示沿着道路、河流等实际路线移动，也可表示不偏离计划、方针、要求等抽象路线。动作过程受到该路线或方针持续引导，是此句型的重点。

### 12・6 〜に基（もと）づいて・〜に基（もと）づく・〜に基（もと）づいた ★2

**【意味（いみ）】〜を基本（きほん）にして (以……为基础)**

①わたしは自分（じぶん）の経験（けいけん）（ **に基（もと）づいて** ）、意見（いけん）を述（の）べたいと思（おも）います。
- **中文理解**：我想基于我自己的经验来发表意见。

②この小説（しょうせつ）は歴史（れきし）的（てき）事実（じじつ）（ **に基（もと）づいて** ）書（か）かれたものです。
- **中文理解**：这部小说是基于历史事实写的。

③わたしは、彼（かれ）の人道（じんどう）主義（しゅぎ）（ **に基（もと）づく** ）考え方（かんがえかた）に同感（どうかん）した。
- **中文理解**：我很赞同他基于人道主义的想法。

④これはただの推測（すいそく）ではなく、たくさんの実験（じっけん）データ（ **に基（もと）づいた** ）科学（かがく）的（てき）事実（じじつ）である。
- **中文理解**：这不只是推测，而是基于许多实验数据的科学事实。

**接続（せつぞく）** N ＋ に基（もと）づいて
▶ 「〜を判断（はんだん）・行動（こうどう）・制度（せいど）などの根拠（こんきょ）や土台（どだい）として、あることをする」と言（い）いたいときに使（つか）う。（表示“把……作为判断、行动或制度等的根据或基础来做某事”。）

**【扩展说明】**
常接「事実・データ・法律・理論・経験」等可靠依据，语气较正式。重点是结论或行动有根据，并不表示“精神上不背离”。创造作品时若强调取得素材，优先用「〜をもとに」；若强调史实是可靠依据，可用「史実に基づく」。

### 12・7 〜のもとで・〜のもとに ★2

**【意味（いみ）】〜の影響（えいきょう）・管理（かんり）・条件（じょうけん）の下（もと）で (在……的影响、管理或条件之下)**

①わたしは、いい環境（かんきょう）といい理解（りかい）者（しゃ）の（ **もとで** ）、恵（めぐ）まれた生活（せいかつ）を送（おく）ることができた。
- **中文理解**：我在良好的环境和善解人意者的支持下，过上了条件优越的生活。

②ぼくは今（いま）、作曲（さっきょく）家（か）の小林（こばやし）先生（せんせい）の（ **もとで** ）作曲（さっきょく）を勉強（べんきょう）しています。
- **中文理解**：我现在正在作曲家小林老师的指导下学习作曲。

③当社（とうしゃ）の薬品（やくひん）は厳（きび）しい管理（かんり）の（ **もとに** ）保存（ほぞん）されています。
- **中文理解**：本公司的药品在严格的管理下被保存着。

④新（あたら）しいリーダーの（ **もとに** ）、人々（ひとびと）は協力（きょうりょく）を約束（やくそく）し合（あ）った。
- **中文理解**：在新的领导者的带领下，人们互相约定要合作。

**接続（せつぞく）** N ＋ のもとで
▶ 「〜の影響（えいきょう）の下（もと）で・〜の影響（えいきょう）を受（う）けながら」という意味（いみ）。（“在……的影响下・一边受……的影响”的意思。）

**【扩展说明】**
「〜のもとで」常强调在某人指导、管理或具体环境中进行动作，如「先生のもとで学ぶ」；「〜のもとに」更常见于制度、方针、名义等抽象支配关系，或表示人们聚集到某中心之下。两者有时可以互换，但搭配倾向不同。

### 12・8 〜に即（そく）して・〜に即（そく）した ★1

**【意味（いみ）】〜に従って（にしたがって） (根据……/符合……)**

①規則（きそく）は、その時々（ときどき）の実情（じつじょう）（ **に即（そく）して** ）変（か）えることがあってもいいのではないでしょうか。
- **中文理解**：规则根据各个时期的实际情况进行更改，不也是可以的吗？

②現行（げんこう）の法律（ほうりつ）（ **に即（そく）して** ）ものごとの可否（かひ）を判断（はんだん）しなければならない。
- **中文理解**：必须根据现行法律来判断事物的可否。

③非常（ひじょう）事態（じたい）でも、人道（じんどう）（ **に即（そく）した** ）行動（こうどう）がとれるようになりたい。
- **中文理解**：希望即使在紧急状态下，也能采取符合人道的行动。

**接続（せつぞく）** N ＋ に即（そく）して
▶ そのことが基準（きじゅん）になるという意味（いみ）。事実（じじつ）・規範（きはん）を表（あらわ）す名詞（めいし）につく。（表示该事物成为基准的意思。接在表示事实、规范的名词后面。）

**【扩展说明】**
正式书面语，强调紧贴实际情况、事实或规范作出判断与处理。与「〜に沿って」相比，「〜に即して」更重视现实或规范作为判断标准，而不是沿着一个既定流程逐步行动。

---

### 12・9 〜を踏（ふ）まえて・〜を踏（ふ）まえた ★1

**【意味（いみ）】〜を土台（どだい）や前提（ぜんてい）にし、それを考慮（こうりょ）に入（い）れて (以……为基础或前提，并将其纳入考虑)**

①本日（ほんじつ）は前回（ぜんかい）の中間（ちゅうかん）報告（ほうこく）（ **を踏（ふ）まえて** ）、活発（かっぱつ）な討論（とうろん）を進（すす）めていきたいと思（おも）います。
- **中文理解**：今天我想在上次中期报告的基础上，推进活跃的讨论。

②わが社（しゃ）は今回（こんかい）の事業（じぎょう）の失敗（しっぱい）という事実（じじつ）（ **を踏（ふ）まえて** ）、次（つぎ）の事業（じぎょう）計画（けいかく）を立（た）てなければならない。
- **中文理解**：我们公司必须立足于这次事业失败这一事实，来制定下一个事业计划。

③子育（こそだ）て支援（しえん）については、現実（げんじつ）（ **を踏（ふ）まえた** ）柔軟（じゅうなん）な対応（たいおう）が必要（ひつよう）だろう。
- **中文理解**：关于育儿支援，需要立足于现实的灵活应对吧。

**接続（せつぞく）** N ＋ を踏（ふ）まえて
▶ 「あることを土台（どだい）や前提（ぜんてい）にした上（うえ）で、考（かんが）えや行動（こうどう）を進（すす）める」と言（い）いたいときに使（つか）う。（想要表达“在把某事作为基础或前提之上，推进想法或行动”时使用。）

**【扩展说明】**
不仅把前项当作依据，还含有“吸取、考虑前项后再采取下一步”的意思，常接「結果・反省・経験・現状・意見」。此处的「踏まえて」是抽象用法，中文不译成字面的“踩着”。

## 練習（れんしゅう） (练习)

**A**
**[ ]の中（なか）の言葉（ことば）を使（つか）って、次（つぎ）の文（ぶん）を完成（かんせい）させなさい。1つの言葉（ことば）はI、IIそれぞれで、1回（いっかい）ずつしか使（つか）いません。**
（使用方框中的词语完成下面的句子。每个词语在I和II中分别只能使用一次。）
