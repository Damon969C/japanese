# 21 逆接（ぎゃくせつ）仮定（かてい）条件（じょうけん） (逆接假定条件)

ある状況（じょうきょう）を仮（かり）に認（みと）めても、それに左右（さゆう）されず同（おな）じ判断（はんだん）・結果（けっか）が成立（せいりつ）すると述（の）べる時（とき）、どんな言（い）い方（かた）がありますか。 (即使暂且承认某种情况，判断或结果仍不受其影响时，可以使用哪些表达方式呢？)

| 功能 | 句型 | 核心语感 |
| :--- | :--- | :--- |
| 提出极端让步条件 | たとえ〜ても | 即使……也…… |
| 暂且假设后仍不改变结论 | 〜としても | 就算假定……也…… |
| 承认某情况或覆盖任意选择 | 〜にしても／にしろ／にせよ | 即便……；无论…… |
| 判断做了也无济于事 | 〜たところで | 即使做……也没用 |
| 正式表示不论何者 | 〜であれ／〜であろうと | 无论是…… |
| 强硬表示不受任何情况影响 | 〜ようが／〜ようと（も） | 不管……也…… |
| 正反两种情况都不影响结果 | 〜ようが〜まいが | 无论做不做…… |

## 学習前（がくしゅうまえ）の小（しょう）テスト (课前小测验)

### 知（し）っていますか

正（ただ）しいものを選（えら）びなさい。

1. たとえ大（おお）きい地震（じしん）が（a. 起（お）きたら／ **b. 起（お）きても** ／ c. 起（お）きると）、このビルは大丈夫（だいじょうぶ）だろう。
   - **中文理解**：即使发生大地震，这栋大楼大概也没事。
2. どんな会社（かいしゃ）を始（はじ）める（a. としたら／ **b. としても** ／ c. とすれば）、お金（かね）が必要（ひつよう）だ。
   - **中文理解**：无论创办什么样的公司，都需要资金。
3. あなたがどちらの進路（しんろ）を選（えら）ぶ（a. として／ b. としろ／ **c. にせよ** ）、わたしはあなたを応援（おうえん）し続（つづ）けます。
   - **中文理解**：无论你选择哪一条道路，我都会继续支持你。
4. 結婚（けっこん）するにしろ、しない（a. とせよ／ **b. にしろ** ／ c. にせよ）、早（はや）く自分（じぶん）の家（いえ）を持（も）ちたい。
   - **中文理解**：无论结不结婚，我都想早点拥有自己的房子。
5. 今（いま）からどんなに（ **a. 頑張（がんば）ったとしても** ／ b. 頑張（がんば）ったら／ c. 頑張（がんば）れば）、もうどうにもならない。
   - **中文理解**：事到如今，无论再怎么努力，也已经无济于事。

### 使（つか）えますか

正（ただ）しい方（ほう）を選（えら）びなさい。

1. （a. たとえ1日（いちにち）が24時間（にじゅうよじかん）でも／ **b. たとえ1日（いちにち）が30時間（さんじゅうじかん）でも** ）、わたしはやっぱり忙（いそが）しい。
   - **中文理解**：即使一天有三十个小时，我也还是很忙。
2. どんなに急（いそ）いだとしても、（a. 8時（はちじ）の新幹線（しんかんせん）に乗（の）れるだろう。／ **b. 8時（はちじ）の新幹線（しんかんせん）には乗（の）れないだろう。** ）
   - **中文理解**：无论怎么赶，大概都赶不上八点的新干线。
3. （a. 誰（だれ）か訪（たず）ねてくるとしても／ **b. 誰（だれ）も訪（たず）ねてこないとしても** ）、いつも部屋（へや）をきれいにしておきなさい。
   - **中文理解**：即使没有任何人来访，也要始终把房间收拾干净。
4. どんなに高（たか）い本（ほん）であるにせよ、（ **a. 彼（かれ）なら買（か）えるだろう。** ／ b. わたしには買（か）えないだろう。）
   - **中文理解**：书无论多贵，如果是他，大概都买得起。
5. （ **a. どこへ行（い）くにしろ** ／ b. わたしの妹（いもうと）は5歳（ごさい）にしろ）、妹（いもうと）はわたしと一緒（いっしょ）に行（い）きたがる。
   - **中文理解**：无论去哪里，妹妹都想和我一起去。

### 21・1 たとえ〜ても ★3

**【意味（いみ）】もし極端（きょくたん）な〜という状況（じょうきょう）になっても (即使……也……)**

①（ **たとえ** ）大雪（おおゆき）が降（ふ）っ（ **ても** ）、仕事（しごと）は休（やす）めません。
- **中文理解**：即使下大雪，也不能请假不上班。

②（ **たとえ** ）お金（かね）がなく（ **ても** ）、幸（しあわ）せに暮（く）らせる方法（ほうほう）はあるだろう。
- **中文理解**：即使没有钱，大概也有幸福生活的方法。

③（ **たとえ** ）彼（かれ）の友人（ゆうじん）たちがどんなに反対（はんたい）し（ **ても** ）、彼（かれ）はこの町（まち）を出（で）ていくだろう。
- **中文理解**：即使朋友们再怎么反对，他大概仍会离开这座城镇。

④（ **たとえ** ）夫（おっと）の病気（びょうき）がどんなに心配（しんぱい）（ **でも** ）、子（こ）どもたちに話（はな）すことはできない。
- **中文理解**：即使再担心丈夫的病情，也不能告诉孩子们。

**接続（せつぞく）** たとえ ＋ Vても／イAくても／ナAでも／Nでも
▶ 普通（ふつう）なら後項（こうこう）に影響（えいきょう）しそうな条件（じょうけん）を極端（きょくたん）な例（れい）として挙（あ）げ、「その場合（ばあい）でも結論（けつろん）は変（か）わらない」と強調（きょうちょう）する。（举出通常足以影响后项的、甚至极端的条件，强调即便如此结论仍不改变。）

**【扩展说明】**
「たとえ」是强调副词，可以省略；真正承担让步条件的是「ても／でも」。常与「どんなに・誰が・何が」等搭配。「たとえ雨が降ると」不成立，因为后项必须用逆接条件形式。

### 21・2 〜としても・〜としたって ★3

**【意味（いみ）】〜と仮定（かてい）しても (即使假定……)**

①新（あたら）しい仕事（しごと）を探（さが）す（ **としても** ）、この町（まち）を離（はな）れたくない。
- **中文理解**：即使要找新工作，我也不想离开这座城镇。

②オーストラリアに行（い）く（ **としても** ）、予定（よてい）がいっぱいなので今年（ことし）は無理（むり）です。
- **中文理解**：就算要去澳大利亚，由于日程已满，今年也去不了。

③もし、あの時（とき）彼（かれ）が求婚（きゅうこん）しなかった（ **としても** ）、わたしの方（ほう）から結婚（けっこん）の話（はなし）をしていただろう。
- **中文理解**：即使当时他没有求婚，我大概也会主动提出结婚。

④マンションを買（か）う（ **としたって** ）、駅（えき）の近（ちか）くは無理（むり）だね。
- **中文理解**：就算买公寓，车站附近的也买不起吧。

**接続（せつぞく）** 普通形（ふつうけい）＋ としても
▶ ある内容（ないよう）が事実（じじつ）か、実現（じつげん）するか分（わ）からない段階（だんかい）で、それを仮（かり）に認（みと）めても後項（こうこう）の判断（はんだん）は変（か）わらないと述（の）べる。（在某事是否为事实、是否会实现尚不明确时，暂且承认它，仍表示后项判断不变。）

**【扩展说明】**
「にしても」也可表示让步，但「としても」更突出人为设定的假设，常与「もし・たとえ・仮に」连用。例③是假设与事实相反的过去情况。随意会话中的「としたって」语气更口语，有时带不满或反驳。

### 21・3 〜にしても・〜にしろ・〜にせよ ★2

**【意味（いみ）】仮（かり）に〜であっても／どれを選（えら）んでも (即使……；无论……)**

①もしこの仕事（しごと）をする（ **にしても** ）、あまり長（なが）くは続（つづ）けたくない。
- **中文理解**：即使做这份工作，我也不想做得太久。

②どんな会社（かいしゃ）の試験（しけん）を受（う）ける（ **にしろ** ）、面接（めんせつ）に行（い）く時（とき）には身（み）なりだけはきちんとしなさい。
- **中文理解**：无论参加哪家公司的考试，去面试时至少要衣着整洁。

③いつ出発（しゅっぱつ）する（ **にしろ** ）、準備（じゅんび）だけはしておいた方（ほう）がいい。
- **中文理解**：无论什么时候出发，至少应事先做好准备。

④たとえ僅（わず）かな額（がく）（ **にせよ** ）、予算（よさん）を使（つか）う場合（ばあい）は委員会（いいんかい）の承認（しょうにん）を得（え）なければならない。
- **中文理解**：即使金额很少，动用预算时也必须获得委员会批准。

⑤もし少年（しょうねん）が家出（いえで）をした（ **にせよ** ）、まだそんなに遠（とお）くへは行（い）っていないだろう。
- **中文理解**：即使那名少年离家出走了，大概也还没走太远。

**接続（せつぞく）** N／普通形（ふつうけい）（ナA・Nは「〜である」も可（か））＋ にしても・にしろ・にせよ
▶ 前項（ぜんこう）を一応（いちおう）認（みと）めても後項（こうこう）の主張（しゅちょう）・評価（ひょうか）は変（か）わらないこと、または疑問詞（ぎもんし）が表（あらわ）すどの選択肢（せんたくし）でも同（おな）じ結論（けつろん）になることを表（あらわ）す。（表示即便暂且承认前项，后项主张或评价仍不改变；与疑问词搭配时，则表示无论选择哪一种，结论都相同。）

**【扩展说明】**
「にしても」较中性、会话中常见；「にしろ」更直接有力；「にせよ」最正式、书面色彩最强。三者还可成对列举两种情况，如「行くにせよ、行かないにせよ」。与第 18 章的用法相比，本章更突出“假设条件不影响结论”。

### 21・4 〜たところで ★1

**【意味（いみ）】仮（かり）に〜しても、期待（きたい）する結果（けっか）は得（え）られない (即使做……也没用)**

①今（いま）から車（くるま）を飛（と）ばして行（い）っ（ **たところで** ）、間（ま）に合（あ）わない。
- **中文理解**：现在即使飞车赶去也来不及。

②周（まわ）りの人（ひと）がどんなに止（と）め（ **たところで** ）、彼女（かのじょ）はこの会（かい）を辞（や）めるだろう。
- **中文理解**：周围的人无论怎样劝阻，她大概还是会退出这个组织。

③10時間（じゅうじかん）話（はな）し合（あ）っ（ **たところで** ）、いい解決策（かいけつさく）はないだろう。
- **中文理解**：即使商量十个小时，大概也找不到好的解决办法。

④わたしはいくら練習（れんしゅう）し（ **たところで** ）、選手（せんしゅ）になれないことは分（わ）かっている。
- **中文理解**：我知道自己无论怎么练习也当不了运动员。

**接続（せつぞく）** Vた ＋ ところで
▶ まだ起（お）きていない行為（こうい）を仮定（かてい）し、「実行（じっこう）しても期待（きたい）する効果（こうか）はなく、無駄（むだ）・不十分（ふじゅうぶん）だ」と話（はな）し手（て）が判断（はんだん）する。（假设一个尚未发生的行为，表示说话人判断即使实施也得不到预期效果，徒劳或结果不足。）

**【扩展说明】**
前面的「た」是固定接续，不表示该行为已经发生。后项常为否定、低评价或「無駄だ」等。原说明“句末不能用过去式”过于绝对；在过去反事实推测中可以说「相談したところで、何も変わらなかっただろう」。但若只是在叙述实际发生过的结果，就不属于本节用法。

### 21・5 〜であれ・〜であろうと ★1 [W]

**【意味（いみ）】どんな〜であっても (无论是……)**

①たとえ命令（めいれい）されたことが何（なん）（ **であれ** ）、上司（じょうし）の言葉（ことば）には逆（さか）らえない。
- **中文理解**：无论被命令做什么，都不能违抗上司的话。

②相手（あいて）が教授（きょうじゅ）（ **であれ** ）、上級生（じょうきゅうせい）（ **であれ** ）、自分（じぶん）の意見（いけん）をはっきり言（い）うべきだ。
- **中文理解**：无论对方是教授还是高年级学生，都应该明确表达自己的意见。

③転勤（てんきん）する先（さき）がどんな所（ところ）（ **であれ** ）、わたしは一生懸命（いっしょうけんめい）に勤（つと）めるつもりだ。
- **中文理解**：无论被调到什么地方，我都打算努力工作。

④いかなる国（くに）（ **であろうと** ）、若（わか）い人（ひと）を大切（たいせつ）にしない国（くに）に将来（しょうらい）はない。
- **中文理解**：无论哪个国家，不重视年轻人就没有未来。

**接続（せつぞく）** N ＋ であれ・であろうと
▶ 身分（みぶん）・種類（しゅるい）・選択肢（せんたくし）が何（なん）であっても、それと無関係（むかんけい）に後項（こうこう）の判断（はんだん）が成立（せいりつ）すると述（の）べる硬（かた）い表現（ひょうげん）。（正式地表示不论身份、种类或选项是什么，后项判断均不受影响。）

**【扩展说明】**
常与「たとえ・何・誰・どんな・いかなる」连用，也可用「N1であれN2であれ」列举。主要接名词；动词、形容词内容应使用「〜ようが／〜ようと」或先名词化。书面语、演讲和郑重主张中较常见。

### 21・6 〜ようが・〜ようと（も） ★1

**【意味（いみ）】どんな状況（じょうきょう）になっても (无论……也……)**

①ほかの人（ひと）からどんなに悪（わる）く言（い）われ（ **ようが** ）、あの人（ひと）は平気（へいき）だ。
- **中文理解**：无论别人把他说得多难听，他都毫不在意。

②雨（あめ）が降（ふ）ろ（ **うが** ）、槍（やり）が降（ふ）ろ（ **うが** ）、彼（かれ）は行（い）くだろう。
- **中文理解**：哪怕天上下雨、下长矛，他大概都会去。

③たとえ、誰（だれ）が何（なん）と言（い）お（ **うとも** ）、彼（かれ）は決心（けっしん）を曲（ま）げないだろう。
- **中文理解**：无论谁说什么，他大概都不会改变决心。

④たとえ相手（あいて）が世界（せかい）チャンピオンだろ（ **うと** ）、俺（おれ）は闘（たたか）うぞ。
- **中文理解**：即使对手是世界冠军，我也要战斗。

⑤ロシアがどんなに寒（さむ）かろ（ **うとも** ）、このコートと帽子（ぼうし）があれば大丈夫（だいじょうぶ）だ。
- **中文理解**：俄罗斯无论多冷，只要有这件大衣和帽子就没问题。

⑥嵐（あらし）だろ（ **うと** ）、地震（じしん）だろ（ **うと** ）、この建物（たてもの）にいれば安全（あんぜん）だ。
- **中文理解**：无论是暴风雨还是地震，只要待在这栋建筑里就安全。

**接続（せつぞく）** V意向形（いこうけい）／イA（「〜い」→「〜かろう」）／ナA・Nだろう ＋ が・と（も）
▶ どれほど極端（きょくたん）な行為（こうい）・状態（じょうたい）を仮定（かてい）しても、後項（こうこう）は影響（えいきょう）を受（う）けず成立（せいりつ）すると、強（つよ）い意志（いし）・判断（はんだん）を表（あらわ）す。（假设再极端的行为或状态，后项仍不受影响，常表达坚定意志或强烈判断。）

**【扩展说明】**
原接续「イAいかろう」有误，应把词尾「い」变为「かろう」，如「寒い→寒かろう」「高い→高かろう」。这里的动词意向形也不表示打算。例②是惯用夸张说法「雨が降ろうが槍が降ろうが」，“槍”是长矛，不是冰雹，意为“不管发生什么都……”。

### 21・7 〜ようが〜まいが・〜ようと〜まいと ★1

**【意味（いみ）】〜しても、しなくても (无论做还是不做……)**

①夏休（なつやす）みに帰国（きこく）し（ **ようが** ）、する（ **まいが** ）、論文（ろんぶん）は8月末（はちがつまつ）までに完成（かんせい）させなければならない。
- **中文理解**：无论暑假回不回国，论文都必须在八月底前完成。

②会（かい）に出席（しゅっせき）し（ **ようが** ）、出席（しゅっせき）する（ **まいが** ）、年会費（ねんかいひ）は払（はら）わなければならない。
- **中文理解**：无论是否出席会议，都必须缴纳年费。

③雨（あめ）が降（ふ）ろ（ **うと** ）、降（ふ）る（ **まいと** ）、この行事（ぎょうじ）は毎年（まいとし）必（かなら）ず同（おな）じ日（ひ）に行（おこな）われます。
- **中文理解**：无论下不下雨，这项活动每年都一定在同一天举行。

④あの人（ひと）が来（こ）（ **ようと** ）、来（く）る（ **まいと** ）、わたしには関係（かんけい）がないことだ。
- **中文理解**：那个人来不来都与我无关。

**接続（せつぞく）** V意向形（いこうけい）＋ が／と ＋ 同（おな）じVの辞書形（じしょけい）＋ まい ＋ が／と
▶ 同（おな）じ行為（こうい）が起（お）きる場合（ばあい）と起（お）きない場合（ばあい）の両方（りょうほう）を挙（あ）げ、どちらでも後項（こうこう）の結論（けつろん）は変（か）わらないと表（あらわ）す。（并列同一行为发生与不发生两种情况，表示无论哪一种，后项结论都不改变。）

**【扩展说明】**
「まい」是否定意志或否定推量的较正式形式。五段动词一般用辞书形＋まい；一段动词也可用词干＋まい，如「食べまい」；「する」还可说「すまい」。现代会话中用「〜ても〜なくても」更自然，本句型多见于书面语或有力的主张。

#### 逆接假定表达对比

| 句型 | 主要焦点 | 语体／限制 |
| :--- | :--- | :--- |
| たとえ〜ても | 举出极端条件仍不影响结果 | 通用、最基础 |
| 〜としても | 把未确定内容暂设为事实 | 假设意味强 |
