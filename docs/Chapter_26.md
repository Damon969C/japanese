# 26 伝聞（でんぶん）・推量（すいりょう） (传闻・推测)

聞（き）いたり読（よ）んだりした情報（じょうほう）を伝（つた）えるとき、また、確実（かくじつ）ではないことについて根拠（こんきょ）を示（しめ）しながら判断（はんだん）するとき、どの表現（ひょうげん）を使（つか）えばよいでしょうか。（转述听来、读来的信息，或根据线索判断不确定之事时，应使用哪些表达？）

| 核心功能 | 句型 | 语感重点 |
| :--- | :--- | :--- |
| 正式转述消息 | 〜ということだ・〜とのことだ | 「とのこと」尤常见于书信、通知 |
| 不很确定地转述 | 〜とか | “听说……来着”，较口语、留有余地 |
| 正式警告负面风险 | 〜おそれがある | 新闻、公告常用，只接不良结果 |
| 有把握地推断 | 〜に違（ちが）いない | 说话人确信“一定……” |
| 由眼前迹象判断 | 〜とみえて・〜とみえる | 推断与观察依据通常同句出现 |
| 正式地推测“不会” | 〜まい | 书面、演讲语体；本章讲否定推量 |
| 委婉提出推断 | 〜ではあるまいか | “恐怕是……吧／难道不是……吗” |
| 警告可能出现坏结果 | 〜かねない | 常指某行为可能酿成后果 |
| 郑重断言“一定” | 〜に相違（そうい）ない | 比「に違いない」更正式、书面 |

---

## 学習前（がくしゅうまえ）の小（しょう）テスト (课前小测验)

### 知（し）っていますか

[ a. ということだ　b. とみえる　c. ではあるまいか　d. かねない　e. まい ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。

1. 準備体操（じゅんびたいそう）をせずに激（はげ）しいスポーツをしたら、けがをし（ **d. かねない** ）。
   - **中文理解**：不做热身便进行剧烈运动，可能会受伤。
2. これ以上（いじょう）森林（しんりん）の木（き）を切（き）り続（つづ）けると、地球上（ちきゅうじょう）から多（おお）くの動物（どうぶつ）がいなくなってしまうの（ **c. ではあるまいか** ）。
   - **中文理解**：如果继续砍伐森林，地球上许多动物恐怕会消失吧。
3. 石井君（いしいくん）は最近（さいきん）、元気（げんき）だね。今回（こんかい）の成功（せいこう）でだいぶ自信（じしん）をつけた（ **b. とみえる** ）。
   - **中文理解**：石井最近很有精神，看来这次成功让他增添了不少信心。
4. テレビの長期予報（ちょうきよほう）によると、今年（ことし）の冬（ふゆ）は平年（へいねん）より暖（あたた）かい（ **a. ということだ** ）。
   - **中文理解**：据电视的长期预报说，今年冬天会比常年暖和。
5. 選手（せんしゅ）の強化（きょうか）を図（はか）らないと、オリンピック出場（しゅつじょう）などとても期待（きたい）でき（ **e. まい** ）。
   - **中文理解**：若不设法提升选手实力，恐怕根本无法期待参加奥运会。

### 使（つか）えますか

文脈（ぶんみゃく）と文体（ぶんたい）に合（あ）う方（ほう）を選（えら）びなさい。

1. そちらでは地震（じしん）の被害（ひがい）は { **a. ほとんどなかったとのこと、よかったですね。** ／ b. ほとんどなかったそうです。よかったですね。 }
   - **中文理解**：听说您那里几乎没有遭受地震损失，真是太好了。「とのこと、〜」适合面对当事人的正式书信；「そうです」在此像是在把第三方消息告诉当事人，语境不自然。
2. { a. 今日（きょう）は水曜日（すいようび）に違（ちが）いないから、／ **b. 今日（きょう）は水曜日（すいようび）だから、** } ごみを出（だ）そう。
   - **中文理解**：今天就是星期三，所以去倒垃圾吧。已能由日历确认的普通事实无须用推量。
3. { a. 彼（かれ）はにこにこしているとみえて、何（なに）かいいことがあったらしい。／ **b. 彼（かれ）は何（なに）かいいことがあったとみえて、にこにこしている。** }
   - **中文理解**：看来他遇到了什么好事，一直笑眯眯的。「Aとみえて、B」中 A 是推断，B 是推断依据。
4. 娘（むすめ）「この不景気（ふけいき）だから、{ a. お姉（ねえ）さんの就職（しゅうしょく）は難（むずか）しいのではあるまいか。／ **b. お姉（ねえ）さんの就職（しゅうしょく）は難（むずか）しいんじゃないかしら。** }」
   母（はは）「そうねえ。難（むずか）しいかもしれないわねえ」
   - **中文理解**：女儿：“现在这么不景气，姐姐找工作会不会很难？”母亲：“是啊，可能很难。”家庭会话宜用口语；「ではあるまいか」过于正式。
5. この薬（くすり）を飲（の）むと、{ **a. 運転中（うんてんちゅう）に眠（ねむ）くなりかねない。** ／ b. 病気（びょうき）が治（なお）りかねない。 }
   - **中文理解**：服药后开车可能会犯困。「かねない」通常预告坏结果，康复是好事，不合其基本语感。

## 26 Ⅰ 伝聞（でんぶん）

### 26 Ⅰ・1 〜ということだ・〜とのことだ ★3

**【意味（いみ）】〜そうだ／〜と聞（き）いている (听说……／据说……)**

①家（うち）の近（ちか）くの空（あ）き地（ち）に何（なに）ができるのかと思（おも）っていたら、大（おお）きなスポーツセンターができる **ということだ** 。
- **中文理解**：我一直在想家附近的空地要建什么，听说会建一座大型体育中心。

②新聞（しんぶん）によると、インフルエンザの患者（かんじゃ）はこれからも増（ふ）えるだろう **とのことです** 。
- **中文理解**：据报纸报道，流感患者今后可能还会增加。

③大統領（だいとうりょう）の来日（らいにち）は来月（らいげつ）10日（とおか） **とのことだが** 、夫人（ふじん）は来日（らいにち）されないそうだ。
- **中文理解**：听说总统定于下月十日访日，不过夫人不会同行。

④お手紙（てがみ）によると、太郎君（たろうくん）も来年（らいねん）はいよいよ社会人（しゃかいじん）になられる **とのこと** 、ご活躍（かつやく）を心（こころ）から祈（いの）っています。（手紙（てがみ））
- **中文理解**：来信得知太郎明年终于也要步入社会，衷心祝愿他大展身手。（书信）

⑤妹（いもうと）「お母（かあ）さんが、荷物（にもつ）が多（おお）いから駅（えき）まで迎（むか）えに来（き）てくれ **って** 」
兄（あに）「うん、分（わ）かった」
- **中文理解**：妹妹：“妈妈说行李很多，让你到车站接她。”“嗯，知道了。”

⑥「あらあら、『本日（ほんじつ）の事務（じむ）取（と）り扱（あつか）いは終了（しゅうりょう）しました』 **だって** 。5分（ごふん）遅（おそ）かったね」
- **中文理解**：“哎呀，上面写着‘今天的业务办理已经结束’。我们晚了五分钟。”

**接続（せつぞく）**

- 普通形（ふつうけい）・引用（いんよう）する文（ぶん） ＋ ということだ
- 普通形（ふつうけい）・N ＋ とのことだ
- 引用（いんよう）する文（ぶん） ＋ って／だって（口語（こうご））

▶ 他人（たにん）の発言（はつげん）、新聞（しんぶん）、手紙（てがみ）などから得（え）た情報（じょうほう）を伝（つた）えます。「ということだ」は引用性（いんようせい）が強（つよ）く、普通形（ふつうけい）だけでなく「〜だろう」「〜てくれ」など、元（もと）の発言（はつげん）の形（かたち）も取（と）り込（こ）めます。「とのことだ」は簡潔（かんけつ）で正式（せいしき）なため、報告（ほうこく）・通知（つうち）・書信（しょしん）でよく使（つか）われます。（二者都转述消息；前者更像引用，后者更简洁正式。）

▶ ナ形容詞（けいようし）・名詞（めいし）では、「元気（げんき）だとのことだ」のように原文（げんぶん）の「だ」を残（のこ）す形（かたち）と、「元気（げんき）とのことだ」のように省（はぶ）く形（かたち）がどちらも見（み）られます。手紙（てがみ）では例④（れいよん）のように「とのこと、〜」と後文（こうぶん）へ続（つづ）けることもできます。

▶ 「って」是口语引用助词，相当于「と（言っている／書いてある）」。例⑥的「だって」是句末引用，不能与表示“但是”的接续助词「だって」混淆。

**【同形辨析】**
「ということだ」还可表示根据前文得出的结论“也就是说……”，如第 24 章的用法。本章例句有「新聞（しんぶん）によると」「話（はなし）では」等信息来源，因此是传闻。

### 26 Ⅰ・2 〜とか ★2

**【意味（いみ）】〜そうだが／〜と聞（き）いたが (听说……来着／好像听说……)**

①「テレビで見（み）たんだけど、北海道（ほっかいどう）は昨日（きのう）大雪（おおゆき）だった **とか** 」
「そうですか。いよいよ冬（ふゆ）ですねえ」
- **中文理解**：“我从电视上看到，听说北海道昨天下了大雪。”“是吗，冬天终于来了。”

②課長（かちょう）の話（はなし）では、打（う）ち合（あ）わせの資料（しりょう）を2時前（にじまえ）には用意（ようい）してくれ **とか** 。間（ま）に合（あ）うかなあ。
- **中文理解**：听科长说，好像是让我们在两点前备好会议资料。来得及吗？

③来年（らいねん）は妹（いもうと）さんが日本（にほん）へ留学（りゅうがく）のご予定（よてい）だ **とか** 。楽（たの）しみに待（ま）っています。（手紙（てがみ））
- **中文理解**：听说令妹明年计划来日本留学，我很期待。（书信）

**接続（せつぞく）** 普通形（ふつうけい）・引用（いんよう）する文（ぶん） ＋ とか

▶ 记忆不十分确定、不愿断言，或轻描淡写地提及听来的消息时使用。比「そうだ」「ということだ」更留有余地，语气也较随意。它可保留原话中的命令、请求等形式，如例②。这里是句末传闻用法，不是「本（ほん）とか雑誌（ざっし）」（书、杂志之类）中列举事物的「とか」。

## 26 Ⅱ 推量（すいりょう）

### 26 Ⅱ・1 〜おそれがある ★3 [W]

**【意味（いみ）】悪（わる）いことが起（お）こる可能性（かのうせい）がある (恐怕会……／有……的风险)**

①この薬（くすり）は副作用（ふくさよう）の **おそれがある** ので、医者（いしゃ）の指示（しじ）に従（したが）って飲（の）んでください。
- **中文理解**：这种药可能有副作用，请遵照医生指示服用。

②昼頃（ひるごろ）、風雨（ふうう）が強（つよ）まる **おそれがあります** ので、外出（がいしゅつ）するときはお気（き）を付（つ）けください。
- **中文理解**：中午前后风雨可能增强，外出时请注意安全。

③この地震（じしん）による津波（つなみ）の **おそれはありません** 。
- **中文理解**：此次地震没有引发海啸的危险。

④喫煙（きつえん）は、心臓（しんぞう）の病気（びょうき）の危険性（きけんせい）を高（たか）める **おそれがあります** 。
- **中文理解**：吸烟可能提高患心脏病的风险。

**接続（せつぞく）** V普通形（ふつうけい）／Nの ＋ おそれがある

▶ 「恐（おそ）れ」本来表示担忧。本句型只用于不良结果或风险，不用于值得期待的好事。新闻、天气预报、产品说明和官方通知中很常见，语气客观、正式。「可能性（かのうせい）がある」可用于好坏两面，范围更广。

### 26 Ⅱ・2 〜に違（ちが）いない ★3

**【意味（いみ）】根拠（こんきょ）から考（かんが）えて、きっと〜だと思（おも）う (一定……／肯定……)**

①何度（なんど）電話（でんわ）してもいない。リンさんは旅行（りょこう）にでも行（い）っている **に違（ちが）いない** 。
- **中文理解**：打了好几次电话都没人接。林一定是去旅行之类的地方了。

②駅（えき）の前（まえ）にあんなに人（ひと）が集（あつ）まっているよ。何（なに）か事件（じけん）があった **に違（ちが）いない** 。
- **中文理解**：车站前聚了那么多人，肯定发生了什么事情。

③課（か）のみんなが知（し）らないということは、田中（たなか）さんがきちんと報告（ほうこく）しなかった **に違（ちが）いない** 。
- **中文理解**：科里所有人都不知道，田中肯定没有好好汇报。

④あそこに止（と）まっているのは青山（あおやま）さんの車（くるま） **に違（ちが）いない** 。青（あお）い新車（しんしゃ）だって言（い）っていたから。
- **中文理解**：停在那里的肯定是青山的汽车，因为他说过自己买的是蓝色新车。（原译“电车”有误。）

**接続（せつぞく）** V・イA普通形（ふつうけい）／ナA語幹（ごかん）／N ＋ に違（ちが）いない

▶ 观察到的线索使说话人高度确信某个结论，强于「たぶん〜だろう」。它仍是推测，事实可能与推测不同。「〜はずだ」侧重由规则、计划或逻辑得出的合理预期；「〜に違いない」更直接表达说话人的确信。

### 26 Ⅱ・3 〜とみえて・〜とみえる ★3

**【意味（いみ）】見（み）える事実（じじつ）から判断（はんだん）すると、〜らしい (看来……／从迹象看……)**

①夜遅（よるおそ）く雨（あめ）が降（ふ）った **とみえて** 、庭（にわ）がぬれている。
- **中文理解**：看来深夜下过雨，院子是湿的。

②伊藤君（いとうくん）は社長（しゃちょう）に話（はなし）がある **とみえて** 、さっきから社長室（しゃちょうしつ）の前（まえ）を行（い）ったり来（き）たりしている。
- **中文理解**：伊藤看来有话要对社长说，从刚才起一直在社长室门口来回走。

③この子（こ）は絵（え）が好（す）きだ **とみえて** 、暇（ひま）さえあれば絵（え）を描（か）いている。
- **中文理解**：这孩子看来很喜欢画画，一有空便画。

④彼（かれ）の話（はなし）を聞（き）いたところでは、彼（かれ）はこの計画（けいかく）に相当（そうとう）意欲（いよく）を持（も）っている **とみえる** 。
- **中文理解**：从他所说的话来看，他似乎对这项计划很有热情。

**接続（せつぞく）** 普通形（ふつうけい）（ナA・Nでは「だ」を残（のこ）す） ＋ とみえて・とみえる

▶ 基本结构为「推断 A＋とみえて、观察依据 B」。例①的“院子湿了”、例②的“来回走”才是说话人实际看到的根据，不要把两部分颠倒。也可像例④那样先说根据，再以「〜とみえる」作结。比「ようだ／らしい」更明确地把推断与可观察的迹象联系起来，常用于第三者的状态。

### 26 Ⅱ・4 〜まい ★2 [W]

**【意味（いみ）】おそらく〜ないだろう (大概不会……／恐怕不能……)**

①この事件（じけん）は複雑（ふくざつ）だから、そう簡単（かんたん）には解決（かいけつ）する **まい** 。
- **中文理解**：这起事件很复杂，恐怕不会那么容易解决。

②この不況（ふきょう）は深刻（しんこく）だから、安易（あんい）な対策（たいさく）では景気（けいき）の早期回復（そうきかいふく）は望（のぞ）め **まい** 。
- **中文理解**：经济衰退很严重，仅靠草率的对策，恐怕无法期待景气迅速复苏。

③それが唯一（ゆいいつ）の解決策（かいけつさく）ではある **まい** 。もっと別（べつ）の観点（かんてん）から見（み）たらどうか。
- **中文理解**：那恐怕不是唯一的解决办法，何不换个角度看看？

④この様子（ようす）では雨（あめ）は降（ふ）る **まい** と思（おも）うけれど、一応（いちおう）傘（かさ）を持（も）っていったらどうですか。
- **中文理解**：看样子大概不会下雨，不过还是带把伞怎么样？

**接続（せつぞく）**

- 五段動詞（ごだんどうし）：V辞書形（じしょけい） ＋ まい
- 一段動詞（いちだんどうし）：V辞書形（じしょけい）／Vない形（けい）から「ない」を除（のぞ）いた形（かたち） ＋ まい（食（た）べるまい／食（た）べまい）
- する → するまい・すまい　／　来（く）る → 来（く）るまい・来（こ）まい
- イAくは／ナA・Nでは ＋ あるまい

▶ 「〜ないだろう」に相当（そうとう）する硬（かた）い否定推量（ひていすいりょう）で、文章（ぶんしょう）、演説（えんぜつ）や独（ひと）り言（ごと）に現（あらわ）れます。日常会話（にちじょうかいわ）では普通（ふつう）「〜ないだろう」を使（つか）います。動詞（どうし）につく「まい」には「絶対（ぜったい）に〜しないつもりだ」という否定意志（ひていいし）もありますが、それは別用法（べつようほう）です。

### 26 Ⅱ・5 〜ではあるまいか ★2 [W]

**【意味（いみ）】〜ではないだろうか (恐怕是……吧／难道不是……吗)**

①田中（たなか）さんはそう言（い）うけれども、必（かなら）ずしもそうとは言（い）い切（き）れないの **ではあるまいか** 。
- **中文理解**：田中虽那样说，但恐怕不能断定事情一定如此吧。

②水不足（みずぶそく）が続（つづ）くと、今年（ことし）も米（こめ）の生産（せいさん）に影響（えいきょう）が出（で）るの **ではあるまいか** と心配（しんぱい）だ。
- **中文理解**：我担心如果持续缺水，今年的稻米生产恐怕也会受影响。

③不況（ふきょう）、不況（ふきょう）というが、これが普通（ふつう）の状態（じょうたい）なの **ではあるまいか** 。
- **中文理解**：大家总说不景气，但这会不会才是常态呢？

④部長（ぶちょう）が会社（かいしゃ）を辞（や）めたのは、重要（じゅうよう）な点（てん）で社長（しゃちょう）と意見（いけん）が合（あ）わなかったため **ではあるまいか** 。
- **中文理解**：部长离职，恐怕是因为在重要问题上与社长意见不合吧。

**接続（せつぞく）** V・イA普通形（ふつうけい）＋の／ナA・N＋なの ＋ ではあるまいか

▶ 「のではないだろうか」的正式、书面形式。表面上是疑问，实际上常用于作者谨慎地提出自己的推断或主张，并非真的要求听者回答。名词也可直接接「Nではあるまいか」，如「原因（げんいん）は疲労（ひろう）ではあるまいか」。日常会话一般用「〜んじゃないか」「〜のではないでしょうか」。

### 26 Ⅱ・6 〜かねない ★2

**【意味（いみ）】悪（わる）い結果（けっか）になる可能性（かのうせい）がある (很可能会……／搞不好会……)**

①そんな乱暴（らんぼう）な運転（うんてん）をしたら、事故（じこ）を起（お）こし **かねない** よ。
- **中文理解**：那样粗暴驾驶，很可能会引发事故。

②食事（しょくじ）と睡眠（すいみん）だけはきちんと取（と）らないと、体（からだ）を壊（こわ）し **かねません** 。
- **中文理解**：如果连饮食和睡眠都不能保证，很可能会把身体弄垮。

③最近（さいきん）のマスコミの過剰（かじょう）な報道（ほうどう）は、無関係（むかんけい）な人（ひと）を傷（きず）つけることにもなり **かねない** 。
- **中文理解**：最近媒体的过度报道，甚至可能伤害无关的人。

④インフルエンザという病気（びょうき）は分（わ）からないことが多（おお）いので、政府（せいふ）が対策（たいさく）を誤（あやま）ると大流行（だいりゅうこう）し **かねない** 。
- **中文理解**：流感还有许多未知之处，政府若应对失误，可能造成大流行。

**接続（せつぞく）** Vます形（けい）の語幹（ごかん） ＋ かねない

▶ 说话人根据某人的行为、性格或事态发展，警告可能出现自己不希望看到的结果。只用于负面结果。「おそれがある」更客观正式，常见于公告和报道；「かねない」更常带说话人的警惕、批评，尤其适合“这样做会酿成……”的语境。

> **形似注意**：「Vます形＋かねる」表示“难以／不能做”，如「お答（こた）えしかねます」；它的礼貌否定「かねません」若放在「Vます形＋かねない」中，却表示“可能会做”。要结合前接动词和语境判断。

### 26 Ⅱ・7 〜に相違（そうい）ない ★2 [W]

**【意味（いみ）】間違（まちが）いなく〜だと思（おも）う (一定……／毫无疑问……)**

①不合格品（ふごうかくひん）がそれほど出（で）たとは、製品（せいひん）の検査（けんさ）が相当（そうとう）厳（きび）しい **に相違（そうい）ない** 。
- **中文理解**：竟然查出那么多不合格品，产品检验一定相当严格。

②彼（かれ）の言（い）ったことは事実（じじつ） **に相違（そうい）ない** だろうとは思（おも）うが、一応（いちおう）調（しら）べてみる必要（ひつよう）がある。
- **中文理解**：我想他说的应该确实是事实，不过仍有必要查证一下。

③反対（はんたい）されてすぐ自分（じぶん）の意見（いけん）を引（ひ）っ込（こ）めたところを見（み）ると、彼女（かのじょ）は初（はじ）めから自分（じぶん）の意見（いけん）に自信（じしん）がなかった **に相違（そうい）ない** 。
- **中文理解**：从她一遭反对便立即收回意见来看，她起初一定就对自己的意见没有信心。

**接続（せつぞく）** V・イA普通形（ふつうけい）／ナA語幹（ごかん）／N ＋ に相違（そうい）ない

▶ 意思与「に違（ちが）いない」基本相同，但更郑重、更书面，常见于论说、正式陈述。「相違（そうい）」本义是差异；「契約書（けいやくしょ）の内容（ないよう）に相違（そうい）ありません」还可按字面表示“与合同内容没有出入”，要与本节的推量句型区别。

## 26 伝聞（でんぶん）・推量（すいりょう） 練習（れんしゅう）

### A 文型選択（ぶんけいせんたく）

文脈（ぶんみゃく）に合（あ）う方（ほう）を選（えら）びなさい。

1. 「リンさんは今週末（こんしゅうまつ）には帰国（きこく）したい { **a. ということでしたが、** ／ b. そうでしたが、 } 切符（きっぷ）が取（と）れず、帰国（きこく）を延期（えんき）したそうですよ」
   - **中文理解**：听说林原本说想在本周末回国，但没买到票，已经推迟了。这里是在回顾对方先前说过的愿望，适合用能保留原话形式的「ということでした」。传闻助动词「そうだ」本身通常不以「そうでした」来标记消息取得于过去；时间关系应放在被转述内容或「ということだった」上。
2. 最近（さいきん）お体（からだ）の調子（ちょうし）があまりよくない { **a. とのこと、** ／ b. そうで、 } どうぞご自愛（じあい）ください。
   - **中文理解**：听说您最近身体不太好，请多保重。教材预期答案是正式书信式的「とのこと、」；「よくないそうで、どうぞ……」在语法上也能成立，但语体没有 a 那么郑重、凝练，因此不能简单判成绝对错误。
3. 社長（しゃちょう）、お電話（でんわ）によると、井上（いのうえ）さんは3時（さんじ）には見（み）える { a. に違（ちが）いありません。／ **b. とのことです。** }
   - **中文理解**：社长，来电说井上三点前会到。「見える」在这里是「来る」的尊敬语，不是“看得见”。
4. お母（かあ）さん、明日（あした）は10センチぐらい雪（ゆき）が { **a. 積（つ）もるそうだって。** ／ b. 積（つ）もりそうだって。 } うれしいな。友達（ともだち）と雪（ゆき）で遊（あそ）べるね。
   - **中文理解**：妈妈，听说说明天会积大约十厘米的雪。精确数值来自预报，是传闻「積もるそうだ」；「積もりそうだ」表示根据眼前样子判断“看起来要积雪”。
5. 明日（あした）もいい天気（てんき）だ { **a. とみえて、** ／ b. とのことで、 } 西（にし）の空（そら）が赤（あか）い。
   - **中文理解**：西边天空泛红，看来明天也会是好天气。后项是推断的观察依据。
6. 最近（さいきん）の木村（きむら）さんの暗（くら）い顔（かお）を見（み）ると、何（なに）か大（おお）きな問題（もんだい）を抱（かか）えているのでは { a. あるまい／ **b. あるまいか** } と気（き）になる。
   - **中文理解**：看到木村最近阴沉的脸，我不禁担心他是不是遇到了大问题。
7. 今朝（けさ）、また電車（でんしゃ）の信号機（しんごうき）のトラブルが { **a. あったとか。** ／ b. ありかねない。 } 最近（さいきん）、多（おお）いね。
   - **中文理解**：听说今早铁路信号又出故障了，最近真多。这里是转述已经发生的消息。
8. 「佐々木君（ささきくん）、このところ練習（れんしゅう）に来（こ）ないね」
   「佐々木（ささき）？　彼（かれ）はもうこのチームには { **a. 戻（もど）らないんじゃない？** ／ b. 戻（もど）らないのではあるまいか。 }」
   - **中文理解**：“佐佐木最近没来训练。”“他是不是不会回队了？”两项语法上都可表示推测，但朋友间对话应选口语 a。
9. 「店長（てんちょう）、店員（てんいん）にそんな厳（きび）しいことを言（い）ったら、すぐ { a. 辞（や）めかねますよ。／ **b. 辞（や）めかねませんよ。** }」
   「駄目（だめ）なことは駄目（だめ）だよ」
   - **中文理解**：“店长，对店员说得那么严厉，他可能马上辞职。”“不对的事就是不对。”「辞めかねません」是「辞めかねない」的礼貌形；「辞めかねます」通常会被理解为“难以辞职”。

### B 文脈完成（ぶんみゃくかんせい）

[ a. とみえて　b. とのこと　c. かねない　d. に違（ちが）いない　e. ということだ ]

4月（しがつ）は新（あたら）しいことが始（はじ）まる月（つき）だ。部長（ぶちょう）の話（はなし）では、我（わ）が社（しゃ）も20人（にじゅうにん）の新入社員（しんにゅうしゃいん）を迎（むか）える（1. **e. ということだ** ）。しばらくは落（お）ち着（つ）かない日（ひ）が続（つづ）くだろう。古（ふる）い社員（しゃいん）たちも、それなりに緊張（きんちょう）している（2. **a. とみえて** ）、いつもとは違（ちが）った表情（ひょうじょう）だ。誰（だれ）もが新（あたら）しい年度（ねんど）がスタートする緊張感（きんちょうかん）と新鮮（しんせん）さを感（かん）じている（3. **d. に違（ちが）いない** ）。話（はなし）によると、会社（かいしゃ）も近々（ちかぢか）、新（あたら）しいシステムを入（い）れる（4. **b. とのこと** ）だ。僕（ぼく）ものんびりしていると、若（わか）いパワーに追（お）い越（こ）され（5. **c. かねない** ）から、頑張（がんば）ろう。

- **中文理解**：四月是新事物开始的月份。部长说公司将迎来二十名新员工，因此一阵子内大概都安定不下来。老员工看来也相当紧张，表情与平日不同。每个人一定都感受到新年度开始的紧张与新鲜。据说公司近期还要引入新系统。我若继续悠闲下去，搞不好会被年轻人的力量赶超，所以得加油。
- **标点修正**：原文第 1 空后用逗号会把「ということ」悬空；这里补成完整句「ということだ。」。第 4 空则保留句外的「だ」，构成「とのことだ」。

## まとめ：情報源（じょうほうげん）と確信度（かくしんど）

| 表达 | 信息从哪里来 | 确信／语体 |
| :--- | :--- | :--- |
| 〜ということだ | 他人、媒体、文件 | 中性，引用感较强 |
| 〜とのことだ | 他人、媒体、书信 | 正式、简洁 |
| 〜とか | 模糊记忆或听闻 | 不很确定、较随意 |
| 〜とみえる | 眼前迹象 | 明示观察依据 |
| 〜に違（ちが）いない | 说话人的判断 | 确信度高，日常也可用 |
| 〜に相違（そうい）ない | 说话人的判断 | 确信度高，正式书面 |
| 〜おそれがある | 客观风险资料 | 正式警告负面可能 |
| 〜かねない | 行为、性格、事态走势 | 带警惕或批评的负面可能 |
