# 28 誘（さそ）い・勧（すす）め・注意（ちゅうい）・禁止（きんし）

相手（あいて）を誘（さそ）ったり、行動（こうどう）を勧（すす）めたり、指示（しじ）・注意（ちゅうい）・禁止（きんし）を伝（つた）えたりするとき、どのような表現（ひょうげん）を使（つか）えばよいでしょうか。（邀请、劝告、下达指示或表达禁止时，可以使用哪些说法？）

| 核心功能 | 句型 | 语感重点 |
| :--- | :--- | :--- |
| 书面指示、规则 | 〜こと | 简洁、正式；句末省略了命令表达 |
| 劝对方不必做 | 〜ことはない | “没有必要”，用于安慰或忠告 |
| 提出规范性主张 | 〜べきだ／〜べきではない | 基于责任、常识或立场作判断 |
| 诉诸社会常识 | 〜ものだ／〜ものではない | 常带训诫、说教语气 |
| 郑重号召共同做 | 〜ようではないか | 演说、提案中常见，号召力较强 |
| 正式表示无妨 | 〜ても差（さ）し支（つか）えない | 客观上不会造成妨碍 |
| 给出直接忠告 | 〜ことだ | 把某做法当作解决办法提出 |
| 古典式禁止 | 〜べからず／〜べからざる | 告示、格言或固定书面表达 |

## 学習前（がくしゅうまえ）の小（しょう）テスト (课前小测验)

### 知（し）っていますか

[ a. こと　b. ことはない　c. べきだ　d. ものではない　e. ことだ ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。

1. 集合時間（しゅうごうじかん）：午前（ごぜん）8時（はちじ）30分（さんじゅっぷん）。遅（おく）れない（ **a. こと** ）。（お知（し）らせ）
   - **中文理解**：集合时间为上午 8 点 30 分。不得迟到。（通知）
2. 電車（でんしゃ）の中（なか）で騒（さわ）いでいる子（こ）どもがいたら、ちょっと注意（ちゅうい）する（ **c. べきだ** ）と思（おも）う。
   - **中文理解**：如果有孩子在电车里吵闹，我觉得应该适当提醒一下。
3. ほかの人（ひと）が何（なに）を言（い）っても気（き）にしない（ **e. ことだ** ）よ。
   - **中文理解**：不管别人说什么，最好都别放在心上。
4. ほかの人（ひと）のいる前（まえ）で携帯電話（けいたいでんわ）で大（おお）きな声（こえ）で話（はな）す（ **d. ものではない** ）。
   - **中文理解**：不应该当着别人的面大声打电话。
5. このプリントは1部（いちぶ）あれば十分（じゅうぶん）だ。コピーを取（と）る（ **b. ことはない** ）。
   - **中文理解**：这份资料有一份就够了，没有必要复印。

### 使（つか）えますか

文脈（ぶんみゃく）に合（あ）う方（ほう）を選（えら）びなさい。

1. 先生（せんせい）、この言葉（ことば）について { **a. もう1度（いちど）説明（せつめい）していただきたいのですが。** ／ b. もう1度（いちど）説明（せつめい）することですよ。 }
   - **中文理解**：老师，关于这个词，想请您再讲解一次。对老师提出请求，要用礼貌的请求表达；「〜ことだ」会显得像在教训对方。
2. 年上（としうえ）の人（ひと）には丁寧（ていねい）な言葉（ことば）を { a. 使（つか）わないものではない。／ **b. 使（つか）うものだ。** }
   - **中文理解**：对年长者理应使用礼貌用语。「Vないものではない」并不是本课的规范表达，而且会被理解成双重否定。
3. 大型（おおがた）バイクに乗（の）るには、{ a. 免許（めんきょ）を取（と）るべきだ。／ **b. 免許（めんきょ）を取（と）らなければならない。** }
   - **中文理解**：骑大型摩托车必须取得相应驾照。这里是在陈述法定条件，因此 b 更准确；若是在表达“人应当守法”这一规范性意见，仍可以使用「べきだ」。
4. 何（なに）もそんな小（ちい）さいことで { **a. 泣（な）くことはないでしょう。** ／ b. 泣（な）くことではないでしょう。 }
   - **中文理解**：没必要为那么一点小事哭吧。「Vることはない」表示没有必要；「Vることではない」不是这一句型。
5. さあ、みんな、この案（あん）をすぐに { **a. 実行（じっこう）しようではないか。** ／ b. 実行（じっこう）するのではないか。 }
   - **中文理解**：来，大家马上实行这个方案吧。a 是号召共同采取行动，b 则像是在询问或推断“不是要实行吗”。

## 28 誘（さそ）い・勧（すす）め・注意（ちゅうい）・禁止（きんし）

### 28・1 〜こと ★3 [W]

**【意味（いみ）】〜しなさい／〜してはいけない (须……／不得……)**

①宿題（しゅくだい）の作文（さくぶん）は5日（いつか）までに木村先生（きむらせんせい）に出（だ）す **こと** 。
- **中文理解**：作业作文须在 5 日之前交给木村老师。

②図書室（としょしつ）の本（ほん）は必（かなら）ず返（かえ）す **こと** 。
- **中文理解**：图书室的书必须归还。

③試験（しけん）の日（ひ）は消（け）しゴムを忘（わす）れない **こと** 。
- **中文理解**：考试当天不得忘带橡皮。

④11月（じゅういちがつ）17日（じゅうしちにち）（火（か））12時（じゅうにじ）にJR田町駅（たまちえき）の改札口前（かいさつぐちまえ）に集合（しゅうごう）の **こと** 。
- **中文理解**：11 月 17 日（星期二）12 点在 JR 田町站检票口前集合。

**接続（せつぞく）** V辞書形（じしょけい）・Vない形（けい）／動作性名詞（どうさせいめいし）＋ の ＋ こと

▶ 学校（がっこう）・会社（かいしゃ）・団体（だんたい）などが、規則（きそく）や指示（しじ）を簡潔（かんけつ）に伝（つた）える表現（ひょうげん）です。掲示（けいじ）、配布物（はいふぶつ）、試験（しけん）の注意書（ちゅういが）きなどでよく使（つか）われます。先生（せんせい）や責任者（せきにんしゃ）が口頭（こうとう）で伝（つた）えることもあります。（用于学校、公司或团体简洁地传达规则、指示，常见于告示、讲义和考试须知；负责人也可口头使用。）

▶ 肯定形（こうていけい）は「〜しなさい」、否定形（ひていけい）は「〜してはいけない」に相当（そうとう）します。文末（ぶんまつ）の「こと」は命令（めいれい）・規定（きてい）を表（あらわ）す定型（ていけい）で、名詞化（めいしか）の「こと」とは働（はたら）きが違（ちが）います。

### 28・2 〜ことはない ★3

**【意味（いみ）】〜する必要（ひつよう）はない (没有必要……／不必……)**

①天気予報（てんきよほう）は晴（は）れだから、今日（きょう）は傘（かさ）を持（も）っていく **ことはない** な。
- **中文理解**：天气预报说是晴天，所以今天没必要带伞。

②試験（しけん）は簡単（かんたん）な質問（しつもん）だけだから、心配（しんぱい）する **ことはありません** 。
- **中文理解**：考试只有简单的问题，所以不必担心。

③たった1回（いっかい）試合（しあい）に負（ま）けただけで、何（なに）もテニス部（ぶ）を辞（や）める **ことはありません** よ。
- **中文理解**：只不过输了一场比赛，完全没有必要退出网球部。

④インターネットでレストランの地図（ちず）や行（い）き方（かた）を調（しら）べることもできるんだから、わざわざ地図（ちず）を郵便（ゆうびん）で送（おく）る **ことはない** よ。
- **中文理解**：网上也能查餐厅地图和路线，所以不必特意把地图寄过来。

**接続（せつぞく）** V辞書形（じしょけい）＋ ことはない

▶ 相手（あいて）が考（かんが）えている行動（こうどう）について、「そうする必要（ひつよう）はない」と助言（じょげん）したり、安心（あんしん）させたりする言（い）い方（かた）です。「何（なに）も〜ことはない」「わざわざ〜ことはない」とよく組（く）み合（あ）わせます。（对对方考虑采取的行动表示“不必那样做”，常用于劝告或安慰。）

> **注意（ちゅうい）**：「日本（にほん）へ行（い）ったことはない」は経験（けいけん）を表（あらわ）す文型（ぶんけい）で、「日本（にほん）へ行（い）った経験（けいけん）がない」という意味（いみ）です。「こと」の前（まえ）は Vた形（けい）です。本節（ほんせつ）の「行（い）くことはない」は V辞書形（じしょけい）に続（つづ）き、「行（い）く必要（ひつよう）がない」という意味（いみ）です。（前者是“没去过”，后者是“没必要去”。）

### 28・3 〜べきだ・〜べきではない ★3

**【意味（いみ）】責任（せきにん）・常識（じょうしき）・目的（もくてき）から考（かんが）えて、〜するのが適切（てきせつ）だ／適切（てきせつ）ではない (应该……／不应该……)**

①私（わたし）は彼女（かのじょ）に言（い）う **べき** ことを全部（ぜんぶ）言（い）った。
- **中文理解**：我把该对她说的话全都说了。

②みんなで決（き）めた約束（やくそく）は、みんなで守（まも）る **べきだ** 。
- **中文理解**：大家共同定下的约定，理应由大家共同遵守。

③だまされてお金（かね）を取（と）られたんですか。それは、すぐに警察（けいさつ）に届（とど）ける **べきです** よ。
- **中文理解**：被骗走钱了吗？那应该马上报警。

④お年寄（としよ）りに対（たい）して、子（こ）どもに話（はな）すような言葉（ことば）で話（はな）す **べきではない** 。
- **中文理解**：不应该用哄小孩似的说话方式对待老人。

**接続（せつぞく）** V辞書形（じしょけい）＋ べきだ（する → するべきだ／すべきだ）

▶ 話（はな）し手（て）が、道徳（どうとく）・責任（せきにん）・常識（じょうしき）・目的（もくてき）などを基準（きじゅん）に「それが望（のぞ）ましい、正（ただ）しい」と強（つよ）く判断（はんだん）する表現（ひょうげん）です。単（たん）なる好（この）みより強（つよ）く、「〜た方（ほう）がいい」より規範的（きはんてき）です。（依据道德、责任、常识或目的作出较强的规范性判断。）

▶ 法律（ほうりつ）や規則（きそく）で決（き）まった義務（ぎむ）を客観的（きゃっかんてき）に説明（せつめい）するときは、普通（ふつう）「〜なければならない」を使（つか）います。ただし、「人（ひと）は法律（ほうりつ）を守（まも）るべきだ」のように、法律（ほうりつ）について話（はな）し手（て）の規範的（きはんてき）な主張（しゅちょう）を述（の）べることはできます。したがって、「法律（ほうりつ）の話（はなし）には使（つか）えない」という絶対的（ぜったいてき）な規則（きそく）ではありません。

▶ 「〜べきだった」は、本来（ほんらい）する必要（ひつよう）があったのにしなかったことを表（あらわ）します。「〜べきではなかった」は、本来（ほんらい）してはいけなかったのにしたことを表（あらわ）します。どちらも後悔（こうかい）や批判（ひはん）を伴（ともな）うことがあります。（分别相当于“本来应该做却没做”和“本来不该做却做了”。）

### 28・4 〜ものだ・〜ものではない ★2

**【意味（いみ）】社会的（しゃかいてき）な常識（じょうしき）として、〜するのが当然（とうぜん）だ／〜しないのが当然（とうぜん）だ (按常理应当……／不该……)**

①会社（かいしゃ）や会（かい）への手紙（てがみ）の宛名（あてな）には、「様（さま）」ではなく「御中（おんちゅう）」と書（か）く **ものだ** 。
- **中文理解**：写给公司或团体的信，收件方名称后通常不用「様」，而用「御中」。

②良識（りょうしき）のある人（ひと）は、通勤電車（つうきんでんしゃ）の中（なか）で化粧（けしょう）などしない **ものだ** 。
- **中文理解**：按说有公德心的人不会在通勤电车里化妆。此句表达的是说话人的社会评价，并非客观事实。

③もう9時（くじ）だ。早（はや）く起（お）きなさい。休（やす）みの日（ひ）でも9時（くじ）までには起（お）きる **もんだ** 。
- **中文理解**：已经 9 点了，快起床。就算休息日，按说也该在 9 点前起床。

④エレベーターの中（なか）で人（ひと）の悪口（わるくち）など言（い）う **ものではない** 。
- **中文理解**：不应该在电梯里说别人的坏话。

⑤年下（としした）の人（ひと）や弱（よわ）い人（ひと）のことをからかう **もんじゃない** よ。
- **中文理解**：不该取笑比自己年幼或弱小的人。

**接続（せつぞく）** V辞書形（じしょけい）・Vない形（けい）＋ ものだ ／ V辞書形（じしょけい）＋ ものではない

▶ 個人的（こじんてき）な提案（ていあん）というより、道徳（どうとく）・習慣（しゅうかん）・社会常識（しゃかいじょうしき）を一般論（いっぱんろん）のように示（しめ）す表現（ひょうげん）です。相手（あいて）に直接（ちょくせつ）言（い）うと、説教（せっきょう）する響（ひび）きが出（で）やすいです。（把道德、习惯或社会常识当作一般原则来说；直接对人使用容易带训诫口吻。）

> **語彙（ごい）メモ**：「御中（おんちゅう）」は会社（かいしゃ）・部署（ぶしょ）・団体（だんたい）そのものを宛先（あてさき）にするときに使（つか）います。個人名（こじんめい）まで書（か）く場合（ばあい）は、その人（ひと）に「様（さま）」を付（つ）け、「御中（おんちゅう）」とは併用（へいよう）しません。（写到具体个人姓名时用「様」，不要与「御中」同时使用。）

▶ 会話（かいわ）では「〜もんだ」「〜もんじゃない」となることがあります。「ものではない」は法律上（ほうりつじょう）の禁止（きんし）そのものではなく、「常識的（じょうしきてき）・道徳的（どうとくてき）に考（かんが）えて、するべきではない」という戒（いまし）めです。（表示“按常理或道德不该做”，不等同于法律上的禁止。）

→ 30課（か）3「〜ものだ（回想（かいそう））」／30課（か）4「〜ものだ（感嘆（かんたん））」

### 28・5 〜ようではないか ★2

**【意味（いみ）】一緒（いっしょ）に〜しよう (让我们……吧／何不一起……)**

①成功（せいこう）するか分（わ）からないが、とにかくやってみ **ようではないか** 。
- **中文理解**：虽然不知道能否成功，但总之让我们试一试吧。

②携帯電話（けいたいでんわ）に使（つか）う時間（じかん）を減（へ）らして、もっと本（ほん）を読（よ）もう **ではないか** 。
- **中文理解**：减少花在手机上的时间，多读些书吧。

③おやつ代（だい）をみんなで出（だ）し合（あ）うというのは、いい考（かんが）えですね。早速（さっそく）、今月（こんげつ）から始（はじ）め **ようではありませんか** 。
- **中文理解**：大家一起凑零食钱是个好主意。我们就从这个月开始吧。

④新（あたら）しい車（くるま）を買（か）う前（まえ）に、まず家（うち）には車（くるま）が本当（ほんとう）に必要（ひつよう）かどうか話（はな）し合（あ） **おうじゃないか** 。
- **中文理解**：买新车之前，先讨论一下家里是否真的需要车吧。

**接続（せつぞく）** V意向形（いこうけい）＋ ではないか

▶ 聞（き）き手（て）を含（ふく）む人々（ひとびと）に共同（きょうどう）の行動（こうどう）を力強（ちからづよ）く呼（よ）びかける表現（ひょうげん）です。日常（にちじょう）の軽（かる）い誘（さそ）いより、演説（えんぜつ）・会議（かいぎ）の提案（ていあん）・文章（ぶんしょう）での呼（よ）びかけに向（む）いています。（郑重而有号召力地邀请听者共同采取行动。）

▶ 「〜ようではありませんか」は丁寧（ていねい）、「〜ようじゃないか」は会話的（かいわてき）です。伝統的（でんとうてき）な教材（きょうざい）では「〜ようではないか」を男性的（だんせいてき）な表現（ひょうげん）と説明（せつめい）することがありますが、現代（げんだい）の使（つか）い方（かた）を性別（せいべつ）だけで分（わ）けることはできません。実際（じっさい）の語感（ごかん）は、丁寧（ていねい）さ、場面（ばめん）、文末（ぶんまつ）の形（かたち）に左右（さゆう）されます。「じゃないか」は文脈（ぶんみゃく）によって、やや荒（あら）っぽく響（ひび）くことがあります。

▶ 文脈（ぶんみゃく）によっては、共同（きょうどう）の誘（さそ）いではなく、強（つよ）い意志（いし）や挑発（ちょうはつ）を表（あらわ）します。例（れい）：「そこまで言（い）うなら、君（きみ）の実力（じつりょく）を見（み）せてもらおうではないか。」（既然说到这个份上，那就让我见识一下你的实力吧。）

### 28・6 〜ても差（さ）し支（つか）えない ★2

**【意味（いみ）】〜ても問題（もんだい）・支障（ししょう）がない (即使……也不碍事／……也无妨)**

①「明日（あした）の朝（あさ）、用（よう）があるんですが、9時（くじ）までに来（こ）なく **ても差（さ）し支（つか）えない** でしょうか」
　「ええ、いいですよ」
- **中文理解**：“明早我有点事，9 点前不到也不会有影响吗？”“嗯，可以。”

②看護師（かんごし）（予防注射（よぼうちゅうしゃ）の後（あと））「今晩（こんばん）、お風呂（ふろ）に入（はい）っ **ても差（さ）し支（つか）えない** ですよ」
- **中文理解**：护士（打完预防针后）：“今晚洗澡也无妨。”

③推薦書（すいせんしょ）は入学願書（にゅうがくがんしょ）の締切日（しめきりび）より2、3日（に、さんにち）遅（おく）れ **ても差（さ）し支（つか）えありません** 。
- **中文理解**：推荐信比入学申请的截止日期晚两三天也没有问题。

④履歴書（りれきしょ）はコピー **でも差（さ）し支（つか）えありません** 。
- **中文理解**：简历使用复印件也无妨。

**接続（せつぞく）** Vても／イAくても／ナAでも／Nでも ＋ 差（さ）し支（つか）えない

▶ その条件（じょうけん）でも、予定（よてい）・規則（きそく）・安全（あんぜん）・手続（てつづ）きなどに具体的（ぐたいてき）な支障（ししょう）がないことを表（あらわ）します。「〜てもいい」「〜ても構（かま）わない」より改（あらた）まった、事務的（じむてき）な表現（ひょうげん）です。（表示从日程、规则、安全或手续等方面看不会造成实际妨碍，语气正式、客观。）

▶ 許可（きょか）を求（もと）めたり与（あた）えたりするときにも使（つか）いますが、中心（ちゅうしん）の意味（いみ）は積極的（せっきょくてき）な賛成（さんせい）ではなく、「支障（ししょう）がない」という判断（はんだん）です。漢字（かんじ）では通常（つうじょう）「差（さ）し支（つか）えない」と書（か）き、全部（ぜんぶ）を平仮名（ひらがな）で「さしつかえない」と書（か）くこともあります。（核心并非积极赞成，而是判断客观上不会造成妨碍。）

### 28・7 〜ことだ ★2

**【意味（いみ）】〜するのが一番（いちばん）よい／〜した方（ほう）がよい (最好……／应当……)**

①何事（なにごと）も失敗（しっぱい）を恐（おそ）れずにやってみる **ことだ** 。
- **中文理解**：无论做什么，最好都不要害怕失败，先试一试。

②車（くるま）を運転（うんてん）するときは、絶対（ぜったい）にお酒（さけ）を飲（の）んではいけません。誘（さそ）われても飲（の）まな **いことです** 。
- **中文理解**：开车时绝对不能喝酒；即使有人劝酒，也不要喝。

③書（か）く力（ちから）をつけたいのなら、毎日（まいにち）、日記（にっき）をつける **ことだ** 。
- **中文理解**：如果想提高写作能力，最好每天写日记。

**接続（せつぞく）** V辞書形（じしょけい）・Vない形（けい）＋ ことだ

▶ ある目的（もくてき）を達成（たっせい）する方法（ほうほう）や、問題（もんだい）への対処法（たいしょほう）として、話（はな）し手（て）が強（つよ）めの忠告（ちゅうこく）を与（あた）える表現（ひょうげん）です。一般的（いっぱんてき）な心得（こころえ）を述（の）べることもあります。（把某种做法作为达到目的或解决问题的办法，给出较直接的忠告。）

▶ 「上（うえ）の立場（たちば）の人（ひと）だけが下（した）の人（ひと）に使（つか）う」という厳密（げんみつ）な文法条件（ぶんぽうじょうけん）はありません。ただし、断定的（だんていてき）なため、上司（じょうし）や年長者（ねんちょうしゃ）に直接（ちょくせつ）使（つか）うと、上（うえ）から目線（めせん）に聞（き）こえやすいです。その場合（ばあい）は「〜た方（ほう）がよろしいかと思（おも）います」などの婉曲的（えんきょくてき）な表現（ひょうげん）が適（てき）しています。

> **「〜こと」との違（ちが）い**：文末（ぶんまつ）の「提出（ていしゅつ）すること」は規則（きそく）・通知（つうち）です。「上達（じょうたつ）したければ毎日（まいにち）練習（れんしゅう）することだ」は話（はな）し手（て）の助言（じょげん）です。

→ 30課（か）6「〜ことだ（感嘆（かんたん））」

### 28・8 〜べからず・〜べからざる ★1 [W]

**【意味（いみ）】〜してはいけない／〜することができない (禁止……／不可……)**

①昔（むかし）はここに「ここで泳（およ）ぐ **べからず** 」と書（か）いた立（た）て札（ふだ）があった。
- **中文理解**：以前这里有一块写着“禁止在此游泳”的告示牌。

②「用（よう）のない者（もの）、この部屋（へや）に入（はい）る **べからず** 」（張（は）り紙（がみ））
- **中文理解**：“无关人员不得进入本室。”（告示）

③前田（まえだ）さんのようなバランス感覚（かんかく）のある人（ひと）は、この会（かい）にとって欠（か）く **べからざる** 存在（そんざい）だ。
- **中文理解**：像前田这样有平衡判断力的人，是这个团体不可或缺的人物。

**接続（せつぞく）** V辞書形（じしょけい）＋ べからず ／ V辞書形（じしょけい）＋ べからざる ＋ N

▶ 古典語（こてんご）の助動詞（じょどうし）「べし」の否定形（ひていけい）に由来（ゆらい）する硬（かた）い書（か）き言葉（ことば）です。「〜べからず」は告示（こくじ）・標語（ひょうご）・格言（かくげん）などで禁止（きんし）を表（あらわ）します。現代（げんだい）の日常会話（にちじょうかいわ）では、普通（ふつう）「〜てはいけない」を使（つか）います。

▶ 「〜べからざる＋N」は「〜することができないN／〜してはいけないN」を表（あらわ）します。「欠（か）くべからざる」は「欠（か）くことができない」、つまり「不可欠（ふかけつ）な」という意味（いみ）です。「許（ゆる）すべからざる行為（こうい）」は「許（ゆる）してはいけない行為（こうい）」です。（分别如“不可或缺的”和“不可原谅的”。）

## まとめ：強（つよ）さと根拠（こんきょ）の違（ちが）い

| 想表达的内容 | 最合适的句型 | 判断依据 |
| :--- | :--- | :--- |
| 组织明文要求 | 〜こと | 规则、通知、指示 |
| 对方无须采取行动 | 〜ことはない | 必要性不存在 |
| 说话人认为理应如此 | 〜べきだ | 责任、目的、规范判断 |
| 社会常识本来如此 | 〜ものだ | 道德、习惯、一般常识 |
| 解决问题最好这样做 | 〜ことだ | 说话人的忠告 |
| 客观上不会造成妨碍 | 〜ても差（さ）し支（つか）えない | 手续、安全、日程等条件 |

「〜べきだ」「〜ものだ」「〜ことだ」都可译作“应该”，但语用不同：分别侧重规范性判断、社会常识和解决问题的直接建议。选择时不要只看中文译词。
