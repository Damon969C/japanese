# 日语自动词与他动词学习资料（一）

> 依据 [1.txt](../../1.txt) 的顺序校订。校订日期：2026-07-15。
> 日语例句为本稿重新编写；词条、日语例句和日语搭配中的汉字词均以“词语（假名）”标注读音。中文说明中的汉字不属于注音对象。

## 使用说明

- “标准自他对应”表示两词在某个核心义项上可形成状态与致使状态的对照，但不代表所有义项都一一对应。
- 自动词常以「が」标示发生变化的主体；他动词常以「を」标示受作用的对象。移动路径、离开点等也可用「を」，不能仅凭助词判断词性。
- 原始词表中的误写、非严格配对、较旧形式和常用写法差异，均在“辨析”中明确说明。

## 第 1 组（1—10）

### 1. 始まる（はじまる）／始める（はじめる）

- **关系：** 标准自他对应：前项说明状态、变化或动作本身，后项说明主体对对象施加作用。
- **始まる（はじまる）〔自动词〕：** 某事开始；基本句型是「名词＋が＋始まる（はじまる）」。
- **始める（はじめる）〔他动词〕：** 某人开始某事；基本句型是「名词＋を＋始める（はじめる）」。
- **例句：**
  - 会議（かいぎ）が九時（くじ）に始まった（はじまった）。——会议九点开始了。
  - 司会者（しかいしゃ）が会議（かいぎ）を始めた（はじめた）。——主持人开始了会议。

---

### 2. 集まる（あつまる）／集める（あつめる）

- **关系：** 标准自他对应：前项说明状态、变化或动作本身，后项说明主体对对象施加作用。
- **集まる（あつまる）〔自动词〕：** 人、物、注意等聚集到一处，常用「名词＋が／に＋集まる（あつまる）」。
- **集める（あつめる）〔他动词〕：** 收集或召集人、物、信息等，常用「名词＋を＋集める（あつめる）」。
- **例句：**
  - 駅前（えきまえ）に人（ひと）が集まった（あつまった）。——人们聚集到了车站前。
  - 彼（かれ）は古い切手（ふるいきって）を集めて（あつめて）いる。——他在收集旧邮票。

### 3. 決まる（きまる）／決める（きめる）

- **关系：** 标准自他对应：前项说明状态、变化或动作本身，后项说明主体对对象施加作用。
- **決まる（きまる）〔自动词〕：** 方案、日期、结果等被确定，或自然形成定局。
- **決める（きめる）〔他动词〕：** 主体作出决定、选定内容。
- **例句：**
  - 出張（しゅっちょう）の日程（にってい）が決まった（きまった）。——出差日程定下来了。
  - 担当者（たんとうしゃ）が日程（にってい）を決めた（きめた）。——负责人确定了日程。

### 4. 閉まる（しまる）／閉める（しめる）

- **关系：** 标准自他对应：前项说明状态、变化或动作本身，后项说明主体对对象施加作用。
- **閉まる（しまる）〔自动词〕：** 门、窗、店铺等处于关闭或停止营业的状态。
- **閉める（しめる）〔他动词〕：** 把门、窗、容器或店铺关上。
- **例句：**
  - 風（かぜ）で窓（まど）が閉まった（しまった）。——窗户被风吹关了。
  - 寒い（さむい）ので窓（まど）を閉めた（しめた）。——因为冷，所以关上了窗户。

### 5. 早まる（はやまる）／早める（はやめる）

- **关系：** 大体构成自他对应，但至少一项是多义词，具体格助词和译法要随义项判断。
- **早まる（はやまる）〔自动词〕：** 时间提前、速度加快；也可表示“轻率行事”。
- **早める（はやめる）〔他动词〕：** 把时间提前或把速度加快。
- **例句：**
  - 出発（しゅっぱつ）が一日（いちにち）早まった（はやまった）。——出发提前了一天。
  - 出発（しゅっぱつ）を一日（いちにち）早めた（はやめた）。——把出发提前了一天。
- **辨析：** 「早まる（はやまる）」的“轻率”义没有可直接对应的「早める（はやめる）」用法。

- **例句：**

  - 友人（ゆうじん）を私（わたし）の家（いえ）に泊めた（とめた）。——我让朋友住在了家里。

### 12. 溜まる（たまる）／溜める（ためる）

- **关系：** 大体构成自他对应，但至少一项是多义词，具体格助词和译法要随义项判断。
- **溜まる（たまる）〔自动词〕：** 水、垃圾、工作、疲劳等堆积或积压。
- **溜める（ためる）〔他动词〕：** 让某物积存，或把工作、压力等攒下来。
- **例句：**
  - 洗濯物（せんたくもの）が溜まって（たまって）いる。——待洗的衣物堆起来了。
  - 疲れ（つかれ）を溜めない（ためない）ように休む（やすむ）。——注意休息，不让疲劳积累。
- **辨析：** 汉字“貯”偏向储蓄金钱等有价值之物；汉字“溜”偏向一般积聚，常含积压意味。

### 13. 固まる（かたまる）／固める（かためる）

- **例句：**

### 14. 収まる（おさまる）／収める（おさめる）

- **关系：** 大体构成自他对应，但至少一项是多义词，具体格助词和译法要随义项判断。
- **収まる（おさまる）〔自动词〕：** 物品恰好容纳于范围内，或事态平息。
- **収める（おさめる）〔他动词〕：** 把物品放入一定范围，也可指取得成果、拍入画面等。
- **例句：**
  - 荷物（にもつ）が箱（はこ）に収まった（おさまった）。——行李正好装进了箱子。
  - 全員（ぜんいん）を写真（しゃしん）に収めた（おさめた）。——把所有人都拍进了照片。
- **辨析：** 「収まる（おさまる）／収める（おさめる）」义项很多，需结合「箱（はこ）に」「写真（しゃしん）に」「成果（せいか）を」等搭配理解。

### 15. 納まる（おさまる）／納める（おさめる）

- **关系：** 大体构成自他对应，但至少一项是多义词，具体格助词和译法要随义项判断。
- **納まる（おさまる）〔自动词〕：** 物品被放到应在的位置，或被妥善交付。
- **納める（おさめる）〔他动词〕：** 缴纳金钱、交付物品，或把物品放妥。
- **例句：**
  - 道具（どうぐ）が棚（たな）に納まった（おさまった）。——工具放到了架子上的合适位置。
  - 税金（ぜいきん）を期限内（きげんない）に納める（おさめる）。——在期限内缴税。
- **辨析：** 汉字“納”强调交纳、交付或归入应在之处；不能与“収”和“治”随意换写。

### 16. 治まる（おさまる）／治める（おさめる）

- **关系：** 词汇上有关联，但两个词的常用义并非完全对称；不能只靠「が／を」机械替换。
- **治まる（おさまる）〔自动词〕：** 混乱、疼痛、风浪等平息，恢复安定。
- **治める（おさめる）〔他动词〕：** 治理国家、地区或组织。
- **例句：**
  - 薬（くすり）を飲む（のむ）と痛み（いたみ）が治まった（おさまった）。——吃药后疼痛平息了。
  - 賢い王（かしこいおう）が国（くに）を治めた（おさめた）。——贤明的国王治理了国家。
- **辨析：** 两词都含“使之有秩序”的概念，但现代常用义并非简单的状态—致使对应。

### 24. はまる（はまる）／はめる（はめる）

- **关系：** 大体构成自他对应，但至少一项是多义词，具体格助词和译法要随义项判断。
- **はまる（はまる）〔自动词〕：** 物体严丝合缝地嵌入，也可指陷入或沉迷。
- **はめる（はめる）〔他动词〕：** 把物体嵌入，或戴上戒指、手套等。

  - 大雨（おおあめ）で川（かわ）が溢れた（あふれた）。——河水因暴雨漫了出来。
  - コップから水（みず）がこぼれた。／子供（こども）が水（みず）をこぼした。——水从杯中洒出／孩子把水洒了。
- **辨析：** 原词表把「溢れる（あふれる）」直接配给「こぼす」，并不严谨。真正形态对应的是「こぼれる／こぼす」；「溢れる（あふれる）」要表达致使通常说「溢れさせる（あふれさせる）」。

### 50. 乱れる（みだれる）／乱す（みだす）

- **关系：** 标准自他对应：前项说明状态、变化或动作本身，后项说明主体对对象施加作用。
- **乱れる（みだれる）〔自动词〕：** 秩序、队列、头发、呼吸等变乱。
- **乱す（みだす）〔他动词〕：** 扰乱秩序、节奏、心情或弄乱外观。
- **例句：**
  - 強風（きょうふう）で列（れつ）が乱れた（みだれた）。——队列被强风扰乱了。
  - 風（かぜ）が彼女（かのじょ）の髪（かみ）を乱した（みだした）。——风吹乱了她的头发。

## 第 6 组（51—52）

### 51. 離れる（はなれる）／離す（はなす）

- **关系：** 标准自他对应：前项说明状态、变化或动作本身，后项说明主体对对象施加作用。
- **離れる（はなれる）〔自动词〕：** 人与物相互分离，或离开某处；起点常用「から」或表示离脱的「を」。
- **離す（はなす）〔他动词〕：** 把相连或靠近的人、物分开，或放开手。
- **例句：**
  - 船（ふね）が岸（きし）を離れた（はなれた）。——船离开了岸边。
  - 母親（ははおや）が子供（こども）の手（て）を離した（はなした）。——母亲松开了孩子的手。
- **辨析：** 原词表的「話す（はなす）」是错字；它表示“说话”，正确对应词是「離す（はなす）」。

### 52. 流れる（ながれる）／流す（ながす）

- **关系：** 大体构成自他对应，但至少一项是多义词，具体格助词和译法要随义项判断。
- **流れる（ながれる）〔自动词〕：** 水、空气、声音、时间或信息沿一定方向移动。
- **流す（ながす）〔他动词〕：** 使液体等流动、冲走，也可播放音乐或传播信息。
- **例句：**
  - 雪解け水（ゆきどけみず）が川（かわ）を流れる（ながれる）。——融雪水流过河道。
  - 係員（かかりいん）が水（みず）を流して（ながして）床（ゆか）を洗った（あらった）。——工作人员放水冲洗了地板。
- **辨析：** 自动词句「川（かわ）を流れる（ながれる）」中的「を」表示经过的路径，不是他动词宾语。
