# 20 仮定（かてい）条件（じょうけん）・確定（かくてい）条件（じょうけん） (假定条件・确定条件)

ある状況（じょうきょう）を仮（かり）に想定（そうてい）した時（とき）、または成立（せいりつ）した状況（じょうきょう）を前提（ぜんてい）にして、その結果（けっか）や判断（はんだん）を述（の）べる時（とき）、どんな言（い）い方（かた）がありますか。 (假设某种情况，或把已经成立的情况作为前提来说明结果、判断时，可以使用哪些表达方式呢？)

| 功能 | 句型 | 核心语感 |
| :--- | :--- | :--- |
| 提出最低充分条件 | 〜さえ〜ば | 只要……就…… |
| 暂时设定某种情况 | 〜としたら／とすれば／とすると | 假如……的话 |
| 表示与事实相反的条件 | 〜ば〜のに、〜たら〜だろう | 要是……本来就…… |
| 提出不可缺的必要条件 | 〜ないことには、〜ない限（かぎ）り | 如果不……就……；除非…… |
| 假设难以实现的愿望 | 〜ものなら | 如果真能…… |
| 排除不得的关键因素 | 〜を抜（ぬ）きにしては、〜なくしては | 没有……就无法…… |
| 警告严重后果 | 〜ようものなら、〜たら最後（さいご） | 万一……；一旦……就完了 |
| 根据新情况考虑后果 | 〜となると | 如果／既然变成那样…… |
| 为特殊对象愿意破例 | 〜とあれば | 如果是为了／如果是…… |

---

## 学習前（がくしゅうまえ）の小（しょう）テスト (课前小测验)

### 知（し）っていますか

[ a. さえあれば　b. としたら　c. ないことには　d. を抜（ぬ）きにしては　e. ようものなら ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。

1. 結婚（けっこん）するかどうか分（わ）からないが、もし、する（ **b. としたら** ）、30歳（さんじゅっさい）になる前（まえ）がいい。
   - **中文理解**：虽然还不知道是否结婚，但假如要结，最好在三十岁以前。
2. みんなの協力（きょうりょく）（ **d. を抜（ぬ）きにしては** ）、この仕事（しごと）は成功（せいこう）しなかっただろう。
   - **中文理解**：若没有大家的协助，这项工作大概不可能成功。
3. 家族（かぞく）が病気（びょうき）になると、健康（けんこう）で（ **a. さえあれば** ）、ほかに何（なに）も要（い）らないと思（おも）う。
   - **中文理解**：家人生病时，就会觉得只要健康，其他什么都不需要。
4. 佐藤（さとう）さんという人（ひと）がうちの仕事（しごと）に合（あ）うかどうか、会（あ）ってみ（ **c. ないことには** ）、分（わ）からない。
   - **中文理解**：佐藤这个人是否适合我们的工作，不亲自见见就无法判断。
5. 兄（あに）はカメラをとても大切（たいせつ）にしている。黙（だま）って借（か）り（ **e. ようものなら** ）、後（あと）で大変（たいへん）なことになる。
   - **中文理解**：哥哥非常爱惜相机；要是敢不说一声就借走，之后可就麻烦了。

### 使（つか）えますか

正（ただ）しい方（ほう）を選（えら）びなさい。

1. この仕事（しごと）は時間（じかん）さえ（a. なければできない。／ **b. あればできる。** ）
   - **中文理解**：这项工作只要有时间就能完成。
2. お金（かね）で解決（かいけつ）できるものなら、（ **a. そうしたい。** ／ b. お金（かね）が必要（ひつよう）だ。）
   - **中文理解**：如果真能用钱解决，我愿意那样做。

### 20・1 〜さえ〜ば ★3

**【意味（いみ）】その条件（じょうけん）だけ満（み）たされれば (只要……就……)**

①うちの子（こ）は暇（ひま）（ **さえ** ）あれ（ **ば** ）、本（ほん）を読（よ）んでいます。
- **中文理解**：我家孩子只要有空就在看书。

②湿度（しつど）（ **さえ** ）低（ひく）けれ（ **ば** ）、東京（とうきょう）の夏（なつ）は暮（く）らしやすいのではないか。
- **中文理解**：只要湿度低一些，东京的夏天或许就容易熬过了。

③これは薬（くすり）を飲（の）み（ **さえ** ）すれ（ **ば** ）治（なお）るという病気（びょうき）ではありません。
- **中文理解**：这不是只要吃药就能治好的病。

④課長（かちょう）に（ **さえ** ）ちゃんと断（ことわ）っておけ（ **ば** ）、今日（きょう）の会議（かいぎ）に欠席（けっせき）しても大丈夫（だいじょうぶ）だよ。
- **中文理解**：只要事先好好向科长说明，今天不参加会议也没关系。

⑤この机（つくえ）、もう1サイズ小（ちい）さく（ **さえ** ）あれ（ **ば** ）、わたしの部屋（へや）にちょうどいいのですが。
- **中文理解**：这张桌子只要再小一号，就正好适合我的房间了。

⑥子（こ）どもたちの体（からだ）（ **さえ** ）健康（けんこう）（ **なら** ）、親（おや）はそれだけで満足（まんぞく）だ。
- **中文理解**：只要孩子们身体健康，父母便心满意足了。

**接続（せつぞく）** N（＋助詞（じょし））＋ さえ ＋ 条件形（じょうけんけい）　／　Vます形（けい）の語幹（ごかん）＋ さえすれば　／　イAく・ナAで ＋ さえあれば
▶ 話（はな）し手（て）が「その条件（じょうけん）が成立（せいりつ）すれば十分（じゅうぶん）で、ほかは問題（もんだい）ではない」と考（かんが）えていることを表（あらわ）す。（表示说话人认为只需满足这一最低条件便已足够，其他条件都不成问题。）

**【扩展说明】**
这不一定是客观上唯一的必要条件，而是说话人把它突出为“最低限度就够”。「が／を」通常被「さえ」替代，如「時間さえあれば」「薬さえ飲めば」；「に／で／と」等往往保留，如「課長にさえ言えば」。还可说「約束を守ってさえいれば」。

### 20・2 〜としたら・〜とすれば・〜とすると ★3

**【意味（いみ）】〜と仮定（かてい）した場合（ばあい） (假如……的话)**

①もし、ここに100万円（ひゃくまんえん）あった（ **としたら** ）、何（なに）に使（つか）いますか。
- **中文理解**：假如这里有一百万日元，你会怎么花？

②この参加者（さんかしゃ）名簿（めいぼ）が正（ただ）しい（ **としたら** ）、まだ来（き）ていない人（ひと）が2人（ふたり）いる。
- **中文理解**：假如这份参加者名单准确，就还有两个人没来。

③わたしの言葉（ことば）が彼（かれ）の気分（きぶん）を悪（わる）くしたのだ（ **としたら** ）、本当（ほんとう）に申（もう）し訳（わけ）ないことをしたと思（おも）う。
- **中文理解**：如果我的话让他不快，那我真是做了很对不起他的事。

④時給（じきゅう）800円（はっぴゃくえん）で1日（いちにち）4時間（よじかん）、1週間（いっしゅうかん）に5日（いつか）働（はたら）く（ **とすれば** ）、1週間（いっしゅうかん）で1万（いちまん）6,000円（ろくせんえん）になる。
- **中文理解**：假设时薪八百日元，每天工作四小时、每周五天，那么一周收入为一万六千日元。

⑤報告書（ほうこくしょ）の数字（すうじ）が間違（まちが）っている（ **とすれば** ）、結論（けつろん）は全（まった）く違（ちが）うものになるだろう。
- **中文理解**：如果报告中的数字有误，结论大概会完全不同。

⑥運転（うんてん）免許証（めんきょしょう）を取（と）るのに30万円（さんじゅうまんえん）以上（いじょう）もかかる（ **とすると** ）、今（いま）のわたしには無理（むり）だ。
- **中文理解**：如果考取驾照要花三十万日元以上，现在的我负担不起。

⑦車（くるま）を持（も）っている彼（かれ）が来（こ）ない（ **とすると** ）、誰（だれ）が荷物（にもつ）を運（はこ）んでくれるのだろうか。
- **中文理解**：假如有车的他不来，那谁来帮我们搬行李呢？

**接続（せつぞく）** 普通形（ふつうけい）＋ としたら・とすれば・とすると
▶ まだ事実（じじつ）と決（き）まっていない内容（ないよう）を一時的（いちじてき）に事実（じじつ）として置（お）き、その場合（ばあい）の結果（けっか）・判断（はんだん）を考（かんが）える。（把尚未确定的内容暂时当作事实，推导这种情况下的结果或判断。）

**【扩展说明】**
三者基本可互换，但有常见倾向：「としたら」最容易表现想象、选择和说话人的反应；「とすれば」常用于以某项信息为前提作逻辑推论；「とすると」常把思考推进到“那么接下来会怎样”。这些是语感倾向，不是绝对规则。名词、ナ形容词通常保留「だ」，如「学生だとしたら」「静かだとすれば」。

### 20・3 〜ば〜（のに）・〜たら〜（だろう） ★3

**【意味（いみ）】事実（じじつ）とは違（ちが）う条件（じょうけん）を考（かんが）える (要是……本来就……)**

①きのうのミーティングに君（きみ）も来（く）れ（ **ば** ）よかった（ **のに** ）。とても大切（たいせつ）なことを話（はな）したよ。
- **中文理解**：昨天的会议你也来就好了；会上谈了非常重要的事。

②もう少（すこ）し暇（ひま）（ **なら** ）、お手伝（てつだ）いできた（ **のに** ）。すみません。
- **中文理解**：要是再有空一点，本来就能帮忙了。对不起。

③店（みせ）できれいなセーターを見（み）たの。もっと安（やす）けれ（ **ば** ）買（か）ったんだ（ **けれど** ）……。
- **中文理解**：我在店里看到一件漂亮毛衣；要是再便宜些，本来就买了，可惜……

④若（わか）いうちにもっと外国語（がいこくご）を勉強（べんきょう）してい（ **たら** ）、好（す）きな旅行（りょこう）の仕事（しごと）ができた（ **だろう** ）。
- **中文理解**：如果年轻时多学些外语，大概就能从事自己喜欢的旅游工作了。

**接続（せつぞく）** Vば／イAければ／ナA・Nなら（ば）＋ 結果（けっか）　／　Vたら ＋ 結果（けっか）
▶ 現実（げんじつ）には成立（せいりつ）しなかった条件（じょうけん）を仮定（かてい）し、その場合（ばあい）なら可能（かのう）だった結果（けっか）や、残念（ざんねん）・後悔（こうかい）を述（の）べる。（假设现实中并未成立的条件，说明在该条件下本可实现的结果，常表达遗憾或后悔。）

**【扩展说明】**
要分清两类结构：①「Vばよかった（のに）」本身表示“要是做了就好了／本该做”；②③是“条件 + 本可出现的结果”。过去反事实常用「〜ていたら、〜ただろう／〜たのに」。句末「のに／けれど」可省略未说出口的遗憾，不表示普通的事实转折。

### 20・4 〜ないことには ★2

**【意味（いみ）】まず〜しなければ、次（つぎ）が成立（せいりつ）しない (如果不先……就无法……)**

①ある商品（しょうひん）が売（う）れるかどうかは、市場（しじょう）調査（ちょうさ）をしてみ（ **ないことには** ）、分（わ）からない。
- **中文理解**：某件商品卖不卖得动，不先做市场调查就无法判断。

②山田（やまだ）さんが資料（しりょう）を持（も）っているんだから、彼（かれ）が来（こ）（ **ないことには** ）、会議（かいぎ）が始（はじ）まりません。
- **中文理解**：资料在山田手里，他不来，会议就开不了。

③体（からだ）が健康（けんこう）で（ **ないことには** ）、いい仕事（しごと）はできないだろう。
- **中文理解**：身体不健康，大概就做不好工作。

④誠（まこと）に申（もう）し訳（わけ）ありませんが、ご本人様（ほんにんさま）であることを証明（しょうめい）するものが（ **ないことには** ）、お支払（しはら）いすることができません。
- **中文理解**：非常抱歉，如果没有能证明您身份的证件，我们无法付款。

**接続（せつぞく）** Vない／イAくない／ナAでない／Nでない ＋ ことには
▶ 前項（ぜんこう）が後項（こうこう）の必要（ひつよう）条件（じょうけん）で、「まずそれが成立（せいりつ）しなければ、判断（はんだん）も行動（こうどう）も先（さき）へ進（すす）めない」と表（あらわ）す。後項（こうこう）は「分（わ）からない・できない・始（はじ）まらない」など否定的（ひていてき）な内容（ないよう）になる。（前项是后项的必要条件，表示若不先满足它，判断或行动便无法继续；后项通常是否定或困难内容。）

**【扩展说明】**
原说明所说的“多表示消极心情”并非必要条件；核心是客观或主观上的先决条件。「ない限り」强调条件边界和持续状态，而「ないことには」更像“第一步不完成，下一步无从谈起”，会话感也较强。

### 20・5 〜ものなら ★2

**【意味（いみ）】実現（じつげん）は難（むずか）しいが、もし本当（ほんとう）にできるなら (如果真能……的话)**

①できる（ **ものなら** ）、鳥（とり）になって国（くに）へ帰（かえ）りたい。
- **中文理解**：如果真能做到，我想变成鸟飞回祖国。

②この仕事（しごと）、辞（や）められる（ **ものなら** ）、今（いま）すぐにでも辞（や）めたい。でも家族（かぞく）がいるからなあ。
- **中文理解**：这份工作要是真能辞，我恨不得立刻辞掉；可我还有家人要养。

③スケジュールが自由（じゆう）になる（ **ものなら** ）、広島（ひろしま）に1泊（いっぱく）したいのだが、そうもいかない。
- **中文理解**：如果日程真能自由安排，我想在广岛住一晚，可现实不允许。

④治（なお）る（ **ものなら** ）、どんな手術（しゅじゅつ）でも受（う）けます。
- **中文理解**：如果真能治好，无论什么手术我都接受。

**接続（せつぞく）** 可能形（かのうけい）など、可能（かのう）の意味（いみ）を含（ふく）むVる ＋ ものなら
▶ 実現（じつげん）の可能性（かのうせい）が非常（ひじょう）に低（ひく）いことを承知（しょうち）しながら、「それでも可能（かのう）なら」と願望（がんぼう）・意志（いし）・挑発（ちょうはつ）を述（の）べる。（明知实现可能性很低，仍假设“如果真能做到”，以表达愿望、意志，有时也用于挑衅。）

**【扩展说明】**
比普通「なら」更强烈地暗示难以实现。常见「戻れるものなら戻りたい」「やれるものならやってみろ」。只有普通事实条件时不能使用，如「田中さんが来るものなら始めよう」不自然。注意与 20・7「意向形＋ものなら」在接续和意义上完全不同。

### 20・6 〜を抜（ぬ）きにしては ★2

**【意味（いみ）】〜を除外（じょがい）したら成立（せいりつ）しない (没有／撇开……就无法……)**

①料理（りょうり）の上手（じょうず）な山田（やまだ）さん（ **を抜（ぬ）きにしては** ）、パーティーは開（ひら）けません。
- **中文理解**：没有擅长做菜的山田，聚会办不起来。

②悪条件（あくじょうけん）の中（なか）の登山（とざん）は、隊長（たいちょう）の強（つよ）いリーダーシップ（ **を抜（ぬ）きにしては** ）成功（せいこう）しない。
- **中文理解**：在恶劣条件下登山，若没有队长强有力的领导便不会成功。

③この国（くに）の将来（しょうらい）は、観光（かんこう）事業（じぎょう）の発展（はってん）（ **を抜（ぬ）きにしては** ）あり得（え）ない。
- **中文理解**：不考虑旅游业的发展，就谈不上这个国家的未来。

**接続（せつぞく）** N ＋ を抜（ぬ）きにしては
▶ ある人（ひと）・要素（ようそ）が欠（か）かせず、それを参加者（さんかしゃ）・考慮（こうりょ）の対象（たいしょう）から外（はず）すと、後項（こうこう）が実現（じつげん）できないと述（の）べる。（某人或某因素不可或缺；若把它排除在参与者或考虑范围之外，后项便无法实现。）

**【扩展说明】**
前接内容不必都是说话人“高度评价的事物”；关键在于语境中不可缺少。单用「Nを抜きにして」只表示“省去／不考虑 N”，后项不一定否定，如「挨拶を抜きにして本題に入る」。加「は」后常形成“若没有 N 就不行”的条件判断。

### 20・7 〜ようものなら ★2

**【意味（いみ）】万一（まんいち）〜するようなことがあれば (要是胆敢／万一……)**

①この学校（がっこう）は規則（きそく）が厳（きび）しいから、断（ことわ）らずに休（やす）も（ **うものなら** ）、大変（たいへん）だ。
- **中文理解**：这所学校校规很严，要是胆敢不请假就缺席，可就麻烦了。

②彼（かれ）のような責任感（せきにんかん）のない人（ひと）が委員長（いいんちょう）になろ（ **うものなら** ）、この委員会（いいんかい）の活動（かつどう）はめちゃくちゃになる。わたしは反対（はんたい）だ。
- **中文理解**：要是让他那种没有责任感的人当上委员长，委员会的活动会乱成一团；我反对。

③彼女（かのじょ）はこの仕事（しごと）に全（すべ）てを懸（か）けている。もし失敗（しっぱい）し（ **ようものなら** ）、二度（にど）と立（た）ち直（なお）れないのではないか。
- **中文理解**：她把一切都押在这份工作上；万一失败，恐怕再也振作不起来。

**接続（せつぞく）** V意向形（いこうけい）＋ ものなら
▶ 好（この）ましくない事態（じたい）が万一（まんいち）起（お）きた場合（ばあい）を誇張（こちょう）して仮定（かてい）し、その後（あと）に重大（じゅうだい）・深刻（しんこく）な結果（けっか）が来（く）ると警告（けいこく）する。（夸张地假设某个不希望发生的情况万一出现，并警告随后会有严重后果。）

**【扩展说明】**
这里的意向形不表示主语的“打算”，而是固定接续。常用于警告、威胁或担忧，如「秘密を漏らそうものなら、ただでは済まない」。与「可能形＋ものなら」的“如果真能做到”必须严格区分。

### 20・8 〜ない限（かぎ）り ★2

**【意味（いみ）】〜しなければ／〜しない間（あいだ）は (除非……；只要不……)**

①この建物（たてもの）は許可（きょか）が（ **ない限（かぎ）り** ）、見学（けんがく）できません。
- **中文理解**：这栋建筑没有许可就不能参观。

**【扩展说明】**

### 20・12 〜とあれば ★1

**【意味（いみ）】特別（とくべつ）な〜なら、喜（よろこ）んで／仕方（しかた）なく (如果是……；如果为了……)**

①子（こ）どもの教育費（きょういくひ）（ **とあれば** ）、多少（たしょう）の出費（しゅっぴ）も仕方（しかた）がない。
- **中文理解**：如果是孩子的教育费用，多花一些钱也没办法。

②彼（かれ）は人柄（ひとがら）がいいから、彼（かれ）のため（ **とあれば** ）、協力（きょうりょく）を惜（お）しまない人（ひと）が多（おお）いだろう。
- **中文理解**：他人品很好；如果是为了他，大概有很多人会不惜提供帮助。

**接続（せつぞく）** N／普通形（ふつうけい）＋ とあれば
▶ 特別（とくべつ）な事情（じじょう）・目的（もくてき）・相手（あいて）を条件（じょうけん）として、「その場合（ばあい）なら例外的（れいがいてき）に受（う）け入（い）れる、進（すす）んで行動（こうどう）する」と述（の）べる。（以特殊情况、目的或对象为条件，表示若是那种情况，便愿意破例接受或主动行动。）

**【扩展说明】**
原文只列「N＋とあれば」，范围过窄；也可以接普通形，如「君が困っているとあれば、助けないわけにはいかない」。它是假定条件，与第 19 章说明已出现特殊场面的原因「とあって」不同。

#### 必要条件表达对比

| 句型 | 关注点 | 后项特点 |
| :--- | :--- | :--- |
| 〜さえ〜ば | 这个最低条件满足便足够 | 常为肯定、可能 |
| 〜ないことには | 前一步不完成，下一步无从开始 | 多为「分からない／できない」 |
| 〜ない限（かぎ）り | 该条件是改变现状的界线；也可表示默认规则 | 可否定，也可肯定 |
| 〜を抜（ぬ）きにしては | 某人或因素不可排除 | 多为不成立、困难 |
| 〜なくしては | 抽象要素不可或缺，语气庄重 | 强烈否定、反问 |
