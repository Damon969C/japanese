# 第4章 時点（じてん）・場面（ばめん）

**核心提示**：ものごとが行（おこな）われるときや場面（ばめん）を示（しめ）したいときは、どんな言（い）い方（かた）がありますか。（当想表达事情发生的时间点或场合时，有哪些表达方式？）

---

## 0. 導入（どうにゅう） (引入)

### 知（し）っていますか (你知道吗？)
**[ ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。**
（使用方框中的词语，完成句子。1个词语只能使用1次。）
【选项：a. うちに b. ところに c. 最中（さいちゅう）に d. 折（おり）に e. に際（さい）して】

1. コーヒーショップで話（はなし）をしている[ **a. うちに** ]、大切（たいせつ）な用事（ようじ）を忘（わす）れてしまった。
   - **中文理解**：在咖啡店聊着聊着，不知不觉就把重要的事情给忘了。

2. 留学（りゅうがく）[ **e. に際（さい）して** ]、わたしはいろいろな人（ひと）のお世話（おせわ）になった。
   - **中文理解**：在留学之际，我得到了很多人的帮助与照顾。

3. 閉会（へいかい）のあいさつが終（お）わった[ **b. ところに** ]、中川（なかがわ）さんが入（はい）ってきた。
   - **中文理解**：闭幕致辞刚结束的时候，中川先生进来了。

4. 先日（せんじつ）京都（きょうと）へ旅行（りょこう）した[ **d. 折（おり）に** ]、京都大学（きょうとだいがく）の山田（やまだ）教授（きょうじゅ）を訪（たず）ねた。
   - **中文理解**：前几天去京都旅行的时候，拜访了京都大学的山田教授。

5. 面接試験（めんせつしけん）の[ **c. 最中（さいちゅう）に** ]、急（きゅう）におなかが痛（いた）くなった。
   - **中文理解**：正当面试考试进行时，肚子突然疼了起来。

### 使（つか）えますか (你会用吗？)
**どちらが正（ただ）しいですか。正（ただ）しい方（ほう）を選（えら）びなさい。**
（哪一个是正确的？请选择正确的一方。）

1. ｛ **a. 音楽（おんがく）を聴（き）いているうちに、** b. 音楽（おんがく）を聴（き）いているところで、｝眠（ねむ）くなってきた。
   - **中文理解**：听着音乐，不知不觉就困了。（表示在持续听音乐的过程中发生了变化。）

2. 「会議（かいぎ）をしている真（ま）っただ中（なか）でも眠（ねむ）る」という意味（いみ）になるのはどちらですか。｛a. わたしはにぎやかな最中（さいちゅう）でも、 **b. わたしは会議（かいぎ）の最中（さいちゅう）でも、**｝眠（ねむ）ることがある。
   - **中文理解**：若要表达“即使正在开会，有时也会睡着”，应选「会議（かいぎ）の最中（さいちゅう）」。（「にぎやかな最中（さいちゅう）」若有充分上下文并非绝对不能成立，但没有说明是什么活动。）

3. みち子（みちこ）は本（ほん）を読（よ）みかけたが、｛ **a. 途中（とちゅう）ですぐに眠（ねむ）ってしまった。** b. まだ本（ほん）を開（ひら）いてもいなかった。｝
   - **中文理解**：道子开始读书，但读到一半就睡着了。（「読（よ）みかけた」说明已经开始却未完成；b 的“还完全没翻开”与此前提矛盾。）

4. 緊急時（きんきゅうじ）の操作（そうさ）を示（しめ）す告知（こくち）として自然（しぜん）なのはどちらですか。｛a. 非常（ひじょう）の折（おり）には、 **b. 非常（ひじょう）の際（さい）には、**｝この出口（でぐち）から出（で）てください。
   - **中文理解**：作为紧急情况的操作告示，应选「非常（ひじょう）の際（さい）」。（「折（おり）」并非只能用于正面事件；这里的区别是固定搭配和告示语体。）

5. 研究発表（けんきゅうはっぴょう）に向（む）けた意図的（いとてき）な準備（じゅんび）を述（の）べるなら、研究発表（けんきゅうはっぴょう）をするにあたって、｛a. 病気（びょうき）になってしまった。 **b. いろいろ準備（じゅんび）をした。**｝
   - **中文理解**：若要叙述为研究发表而进行的主动准备，应选“做了各种准备”。（「にあたって」后典型地接准备、说明、请求等，不适合单纯交代偶然插曲。）

## 本章（ほんしょう）の見取（みと）り図（ず）

| 表現（ひょうげん） | 关注点 | 语体与限制 |
|---|---|---|
| ～際（さい）（に） | 某事发生时 | 正式、客观；通知和操作说明中常见 |
| ～ところ | 动作即将开始、正在进行或刚结束的阶段 | `Vる／Vている／Vた` 的形态决定阶段 |
| ～かける | 已开始但未完成，或变化接近实现 | 常见「読（よ）みかけ・消（き）えかけ」 |
| ～うちに | 状态持续期间发生变化，或趁状态未变行动 | 强调“过程中的变化／机会窗口” |
| ～最中（さいちゅう）（に） | 正处于活动最集中的时候 | 常带“中途发生别的事”的语感 |
| ～において | 地点、领域、场合 | 「で」的正式书面表达；修饰名词用「における」 |
| ～折（おり）（に） | 某次机会、某个时节 | 郑重，常见于书信和寒暄；不限于好事 |
| ～に際（さい）して | 面临某个重要、正式场合 | 比「際（さい）に」更突出“值此之际” |
| ～にあたって | 面对重要事项而准备、致辞、表明态度 | 行动者的主动准备色彩较强 |
| ～にあって | 身处特殊时代、环境或处境 | 正式书面语，不是普通地点助词 |

## 4 Ⅰ 時点（じてん）・動作（どうさ）の途中（とちゅう）

### 4 Ⅰ・1 〜際（さい）（に）・〜際（さい）の
【接続（せつぞく）】Vる・Vた / Nの ＋ 際（さい）（に）
【意味（いみ）】〜ときに（……的时候 / ……之际）
▶ 特別（とくべつ）な時（とき）や改（あらた）まった場面（ばめん）で「〜するとき」と言（い）いたいときに使（つか）う、硬（かた）い表現（ひょうげん）。（用于正式或郑重场合表达“……的时候”。）

#### 例文（れいぶん） (例句)

1. お帰（かえ）りの **際（さい）は** お足元（あしもと）にお気（き）をつけください。
   - **中文理解**：回去的时候请注意脚下。

2. 先月（せんげつ）モンゴルを訪問（ほうもん）した **際（さい）に**、現地（げんち）の子（こ）どもたちと親（した）しく交流（こうりゅう）することができた。
   - **中文理解**：上个月访问蒙古的时候，能够和当地孩子们亲切交流。

3. 申（もう）し込（こ）み用紙（ようし）は3月（さんがつ）1日（ついたち）までにお送（おく）りください。その **際（さい）**、返信用封筒（へんしんようふうとう）を忘（わす）れずに同封（どうふう）してください。
   - **中文理解**：申请表请在3月1日前寄出。届时，请不要忘记附上回邮信封。

4. 昨年（さくねん）、ボランティアのためのセミナーを行（おこな）った **際（さい）の** 記録（きろく）をお見（み）せいたします。
   - **中文理解**：我给您看看去年举办志愿者研讨会时的记录。

**【拡張説明】(扩展说明)**
「際」比「とき」郑重，常用于通知、说明、书面文件或正式发言。日常小事一般不用「際」。

### 4 Ⅰ・2 〜ところ
【接続（せつぞく）】Vる・Vている・Vた ＋ ところ
【意味（いみ）】動作（どうさ）の直前（ちょくぜん）・最中（さいちゅう）・直後（ちょくご）（正要…… / 正在…… / 刚……）
▶ 動作（どうさ）がどの段階（だんかい）にあるかを表（あらわ）す。（表示动作处于哪个阶段。）

#### 例文（れいぶん） (例句)

1. いい夢（ゆめ）を見（み）ていたのに、ごちそうを食（た）べる **ところで** 目（め）が覚（さ）めてしまった。
   - **中文理解**：明明在做美梦，却在正要吃大餐的时候醒了。

2. 日曜日（にちようび）のお楽（たの）しみ番組（ばんぐみ）が始（はじ）まった **ところに** 電話（でんわ）がかかってきた。
   - **中文理解**：星期天的娱乐节目刚开始的时候，电话打来了。

3. ご飯（はん）を食（た）べている **ところへ** 友（とも）だちが訪（たず）ねてきた。
   - **中文理解**：正吃饭的时候朋友来访了。

4. 家（いえ）を出（で）る **ところを** 母（はは）に呼（よ）び止（と）められ、いろいろ用事（ようじ）を頼（たの）まれた。
   - **中文理解**：正要出门的时候被母亲叫住，嘱咐了各种事情。

**【拡張説明】(扩展说明)**
- 「Vるところ」：正要做，还没开始。
- 「Vているところ」：正在做。
- 「Vたところ」：刚做完。
- 后面的助词会根据句意变为「ところで・ところに・ところへ・ところを」。其中「ところを」常和「見（み）る・見（み）つかる・捕（つか）まえる・呼（よ）び止（と）める」等搭配，表示某个状态被看到、被抓住或被打断。
- 表示阶段的「Vたところ」常和「今（いま）・たった今（いま）・ちょうど」等搭配。另有「やってみたところ、うまくいった」这种“试着做后发现……”的结果用法，不属于本节的阶段表达。

### 4 Ⅰ・3 〜かける・〜かけの・〜かけだ
【接続（せつぞく）】Vます形（けい）去（さ）ます ＋ かける
【意味（いみ）】〜し始（はじ）めたが未完了（みかんりょう）だ／変化（へんか）が起（お）こりそうだ（做到一半尚未完成 / 正接近某种变化）
▶ 動作（どうさ）が始（はじ）まったまま完了（かんりょう）していないこと、または変化（へんか）が起（お）こり始（はじ）めていることを表（あらわ）す。（表示动作已经开始但尚未完成，或某种变化已经显现、接近实现。）

#### 例文（れいぶん） (例句)

1. かぜは治（なお）り **かけた** が、またひどくなってしまった。
   - **中文理解**：感冒快好了，却又变得严重了。

2. わたしは雑誌（ざっし）を読（よ）み **かけて**、そのまま眠（ねむ）ってしまった。
   - **中文理解**：我杂志看到一半，就那样睡着了。

3. こんなところに食（た）べ **かけの** りんごを置（お）いて、あの子（こ）はどこへ行（い）ったのだろう。
   - **中文理解**：把吃了一半的苹果放在这种地方，那孩子去哪儿了呢。

4. 一郎（いちろう）の宿題（しゅくだい）はまだやり **かけだ**。
   - **中文理解**：一郎的作业还只做到一半。

**【拡張説明】(扩展说明)**
「〜かける」可表示“刚开始／做到一半”，也可表示变化接近实现。「読（よ）みかけの本（ほん）」是读到一半的书；「消（き）えかけた火（ひ）」是快要熄灭、已经开始变弱的火。它不表示单纯“刚做完”。

### 4 Ⅰ・4 〜うちに・〜ないうちに
【接続（せつぞく）】Vる・Vている・Vない / イAい / ナAな / Nの ＋ うちに
【意味（いみ）】〜している間（あいだ）に／〜の状態（じょうたい）が変（か）わる前（まえ）に（在……期间 / 趁着……）
▶ ある状態（じょうたい）が続（つづ）いている間（あいだ）に、変化（へんか）が起（お）こる、またはその状態（じょうたい）が変（か）わる前（まえ）に何（なに）かをすることを表（あらわ）す。（表示在某状态持续期间发生变化，或趁状态改变前做某事。）

#### 例文（れいぶん） (例句)

1. 今（いま）は上手（じょうず）に話（はな）せなくても練習（れんしゅう）を重（かさ）ねる **うちに** 上手（じょうず）になります。
   - **中文理解**：即使现在说得不好，在不断练习的过程中也会变得熟练。

2. 友（とも）だちに誘（さそ）われて何回（なんかい）か山登（やまのぼ）りをしている **うちに**、わたしもすっかり山（やま）が好（す）きになった。
   - **中文理解**：被朋友邀请去爬了几次山，在这期间我也完全喜欢上了爬山。

3. ふと外（そと）を見（み）ると、気（き）がつかない **うちに** 雨（あめ）が降（ふ）り出（だ）していた。
   - **中文理解**：不经意间向外望去，没察觉的时候已经下起雨来了。

4. 5日間（いつかかん）、外国出張（がいこくしゅっちょう）をしている **うちに**、近（ちか）くの公園（こうえん）の桜（さくら）が全部（ぜんぶ）散（ち）ってしまった。
   - **中文理解**：出国出差的五天里，不知不觉附近公园的樱花全落光了。

**【拡張説明】(扩展说明)**
本章的「うちに」重点有两种：一是“在持续过程中不知不觉发生变化”，二是“趁状态还没改变前做某事”。「ないうちに」表示“在还没有……之前”。

- 「間（あいだ）に」只把前项当作时间范围；「うちに」更容易带出“不知不觉的变化”或“状态改变前要抓住机会”的语感。

### 4 Ⅰ・5 〜最中（さいちゅう）（に）・〜最中（さいちゅう）だ
【接続（せつぞく）】Vている / Nの ＋ 最中（さいちゅう）（に）
【意味（いみ）】ちょうど〜しているときに（正当……的时候）
▶ 動作（どうさ）がまさに進行中（しんこうちゅう）であることを表（あらわ）す。（表示动作正处于进行中。）

#### 例文（れいぶん） (例句)

1. 会議（かいぎ）の **最中（さいちゅう）**、だれかの携帯（けいたい）が鳴（な）った。
   - **中文理解**：正开会的时候，不知谁的手机响了。

2. シャワーを浴（あ）びている **最中（さいちゅう）に**、玄関（げんかん）にだれか人（ひと）が来（き）た。
   - **中文理解**：正洗澡的时候，玄关有人来了。

3. 来年度（らいねんど）の行事予定（ぎょうじよてい）については、今（いま）話（はな）し合（あ）いをしている **最中（さいちゅう）です**。
   - **中文理解**：关于明年的活动计划，现在正在商讨中。

**【拡張説明】(扩展说明)**
「最中」主要接正在进行的活动或事件，后半句常出现突然插入、打断该活动的事情。它并非绝对不能接状态，例如「お忙（いそが）しい最中（さいちゅう）」「混乱（こんらん）の最中（さいちゅう）」都可成立；但普通、静态的性质一般不说成「最中」。

## 4 Ⅱ 場面（ばめん）・状況（じょうきょう）

### 4 Ⅱ・1 〜において・〜における
【接続（せつぞく）】N ＋ において / におけるN
【意味（いみ）】〜で／〜に（在……）
▶ 場所（ばしょ）・場面（ばめん）・状況（じょうきょう）・領域（りょういき）を表（あらわ）す硬（かた）い表現（ひょうげん）。（表示地点、场面、状况、领域的正式书面表达。）

#### 例文（れいぶん） (例句)

1. 卒業式（そつぎょうしき）はA会館（エーかいかん） **において** 行（おこな）われる予定（よてい）です。
   - **中文理解**：毕业典礼预计在 A 会馆举行。

2. 最近（さいきん）、環境（かんきょう）への関心（かんしん）が高（たか）まったためか、人々（ひとびと）の暮（く）らし方（かた） **においても** ある変化（へんか）が見（み）られる。
   - **中文理解**：也许是因为最近对环境的关注度提高了，在人们的生活方式上也能看到某些变化。

3. マスコミはある意味（いみ） **において**、人（ひと）を傷（きず）つける武器（ぶき）にもなる。
   - **中文理解**：媒体在某种意义上也可能成为伤人的武器。

4. 経済界（けいざいかい） **における** 彼（かれ）の地位（ちい）は高（たか）くはないが、彼（かれ）の主張（しゅちょう）は注目（ちゅうもく）されている。
   - **中文理解**：他在经济界的地位虽然不高，但他的主张备受关注。

**【拡張説明】(扩展说明)**
「において」与「で」意思相近，但更正式。日常生活中的普通动作一般不用它。

- (△) わたしは毎日（まいにち）図書館（としょかん）において勉強（べんきょう）します。
- (〇) わたしは毎日（まいにち）図書館（としょかん）で勉強（べんきょう）します。

### 4 Ⅱ・2 〜折（おり）（に）・〜折（おり）の
【接続（せつぞく）】Vる・Vた / Nの ＋ 折（おり）（に）
【意味（いみ）】〜機会（きかい）に（在……的时候 / 借……的机会）
▶ ある機会（きかい）を表（あらわ）す、書（か）き言葉（ことば）的（てき）で丁寧（ていねい）な表現（ひょうげん）。（表示某个机会的郑重书面表达。）

#### 例文（れいぶん） (例句)

1. このことは今度（こんど）お目（め）にかかった **折（おり）に** 詳（くわ）しくお話（はな）しいたします。
   - **中文理解**：这件事下次见到您时再详细跟您说。

2. 先月（せんげつ）上海（シャンハイ）に行（い）った **折（おり）**、日本語学校時代（にほんごがっこうじだい）の友（とも）だちの家（いえ）を訪（たず）ねました。
   - **中文理解**：上个月去上海的时候，拜访了日语学校时代的朋友家。

3. 何（なに）かの **折（おり）に** わたしのことを思（おも）い出（だ）したら手紙（てがみ）をくださいね。
   - **中文理解**：如果有什么机会想起我的话，请给我写信。

4. これは、昨年（さくねん）イタリアを旅行（りょこう）した **折（おり）の** 写真（しゃしん）です。
   - **中文理解**：这是去年去意大利旅行时拍的照片。（修饰名词时用「折（おり）のN」。）

**【拡張説明】(扩展说明)**
「折」多用于书信、寒暄等郑重表达，语感上偏“某个时点、某次机会”。它并不限于正面场合，「入院（にゅういん）した折（おり）」「病気療養中（びょうきりょうようちゅう）の折（おり）」也可以成立。操作说明、条件提示或紧急告知则通常用「際」，如「非常（ひじょう）の際（さい）は、この出口（でぐち）を使（つか）ってください」。

### 4 Ⅱ・3 〜に際（さい）して・〜に際（さい）し
【接続（せつぞく）】V辞書形（じしょけい）／N ＋ に際（さい）して
【意味（いみ）】〜をするときに／〜の機会（きかい）に（在做……的时候 / 当……之际）
▶ 何（なに）か特別（とくべつ）なことを始（はじ）める時（とき）や、その場面（ばめん）で言（い）う硬（かた）い表現（ひょうげん）。（在开始某件重要事情或处于某正式场面时使用。）

#### 例文（れいぶん） (例句)

1. お2人（ふたり）の人生（じんせい）の門出（かどで） **に際（さい）して**、ひとことお祝（いわ）いの言葉（ことば）を申（もう）し上（あ）げます。
   - **中文理解**：在两位开启人生新篇章之际，请允许我献上一句祝福。

2. 田中（たなか）氏（し）は今回（こんかい）の会議参加（かいぎさんか） **に際（さい）して**、前（まえ）もってしっかりと議案（ぎあん）の検討（けんとう）を行（おこな）った。
   - **中文理解**：田中先生在参加本次会议之际，事先认真研究了议案。

3. このたびの私（わたし）の転職（てんしょく） **に際（さい）しましては**、たいへんお世話（せわ）になりました。
   - **中文理解**：这次我换工作时，承蒙您多方关照。

4. 建設工事（けんせつこうじ）を始（はじ）める **に際（さい）し**、これまでの経過（けいか）をまとめて報告書（ほうこくしょ）を作成（さくせい）した。
   - **中文理解**：在开始建设工程之际，总结了迄今为止的经过并制作了报告。

**【拡張説明】(扩展说明)**
「に際（さい）して」比「ときに」正式，前项多是留学（りゅうがく）、転職（てんしょく）、会議参加（かいぎさんか）、工事開始（こうじかいし）等较重要的事情，不用于日常小动作。

- 「際（さい）に」可以只是正式地标示时间或条件；「に際（さい）して」更常把前项视为一个重要场合，后项叙述相应的准备、致辞、感谢或注意事项。

### 4 Ⅱ・4 〜にあたって・〜にあたり
【接続（せつぞく）】V辞書形（じしょけい）／N ＋ にあたって
【意味（いみ）】〜をするときに／〜の前（まえ）に（在……之际 / 当……之前）
▶ 重要（じゅうよう）な行動（こうどう）や行事（ぎょうじ）の前（まえ）に、準備（じゅんび）・挨拶（あいさつ）・依頼（いらい）などをすることを表（あらわ）す。（表示在重要行动或活动之前进行准备、致辞、请求等。）

#### 例文（れいぶん） (例句)

1. 新（あたら）しい年（とし）のはじめ **にあたって**、ひとことごあいさつ申（もう）し上（あ）げます。
   - **中文理解**：在新年伊始之际，请允许我致以问候。

2. この店（みせ）を開店（かいてん）する **にあたって**、周囲（しゅうい）の人（ひと）の協力（きょうりょく）を求（もと）め、しっかり準備（じゅんび）をしました。
   - **中文理解**：在这家店开业之际，我寻求周围人的协助，做了充分准备。

3. この計画（けいかく）を実行（じっこう）する **にあたり**、できるだけの資料（しりょう）を集（あつ）める必要（ひつよう）がある。
   - **中文理解**：在实施这项计划之前，有必要尽可能多地收集资料。

4. コンサートの開会（かいかい） **にあたりまして**、皆様（みなさま）にお願（ねが）いがございます。
   - **中文理解**：在音乐会开幕之际，有件事想拜托大家。

**【拡張説明】(扩展说明)**
「にあたって」后面通常接积极准备、说明、请求、致辞等，不接偶然发生的消极事情。

「に際（さい）して」与「にあたって」有较大重叠。前者更中性地说“值此场合”，后者更强调行动者“面对、着手”重要事项时所作的准备或所持的态度。因此「開始（かいし）にあたって方針（ほうしん）を説明（せつめい）する」比描述偶然插曲更典型。

### 4 Ⅱ・5 〜にあって
【接続（せつぞく）】N ＋ にあって
【意味（いみ）】〜に／〜で／〜という状況（じょうきょう）で（处于……状况下）
▶ 特別（とくべつ）な時代（じだい）・状況（じょうきょう）・立場（たちば）の中（なか）にいることを表（あらわ）す硬（かた）い表現（ひょうげん）。（表示处于某种特殊时代、状况或立场之中。）

#### 例文（れいぶん） (例句)

1. 今（いま）、わが国（くに）は社会（しゃかい）の転換期（てんかんき） **にあって**、人々（ひとびと）の価値観（かちかん）も揺（ゆ）れている。
   - **中文理解**：现在，我国正处于社会转型期，人们的价值观也在动摇。

2. 現在（げんざい）のような高度情報社会（こうどじょうほうしゃかい） **にあって**、個人情報（こじんじょうほう）を守（まも）ることの重要性（じゅうようせい）が叫（さけ）ばれている。
   - **中文理解**：在如今这样的高度信息社会中，保护个人信息的重要性正被强调。

3. この非常時（ひじょうじ） **にあって**、あなたはどうしてそんなに平気（へいき）でいられるのですか。
   - **中文理解**：在这种非常时期，你怎么还能这么若无其事呢？

**【拡張説明】(扩展说明)**
「にあって」不用于普通地点，而用于“时代、社会状况、非常时期”等抽象且特殊的状况。`Nにあっても` 可明确表示“即使处于 N”，`Nにあってこそ` 则强调“正因为处于 N”；单独的 `Nにあって` 通常只是交代所处背景。

## 4 練習（れんしゅう） (练习题)

### A. （ ）に「で・に・へ・を」を入（い）れなさい。何（なに）も入（い）れない場合（ばあい）もあります。

### B. [ ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。1つ（ひとつ）の言葉（ことば）は1回（いっかい）しか使（つか）いません。

年（とし）のはじめにひとことごあいさつ申（もう）し上（あ）げます。昨年（さくねん）は厳（きび）しい年（とし）でした。契約交渉（けいやくこうしょう）の（ **1. d. 最中（さいちゅう）に** ）地震（じしん）が起（お）こったり、ようやく工事（こうじ）が始（はじ）まった（ **2. b. ところに** ）台風（たいふう）が来（き）たりしました。やり（ **3. f. かけて** ）中断（ちゅうだん）された作業（さぎょう）もいろいろあります。しかし、厳（きび）しいということはある意味（いみ）（ **4. e. において** ）いいことです。困難（こんなん）なときにあれこれ考（かんが）えている（ **5. c. うちに** ）新（あたら）しい計画（けいかく）が生（う）まれてくるのです。今後（こんご）も何（なに）か困（こま）ったことが起（お）こった（ **6. a. 際（さい）** ）は、みんなで助（たす）け合（あ）っていきたいと思（おも）います。

### C. どちらが正（ただ）しいですか。正（ただ）しい方（ほう）を選（えら）びなさい。（哪一个是正确的？请选择正确的一方。）

1. 「東京（とうきょう）へ行（い）った機会（きかい）に先生（せんせい）に会（あ）った」という意味（いみ）を表（あらわ）すなら、（**a. 上京（じょうきょう）した** b. 入浴（にゅうよく）した）折（おり）に高校時代（こうこうじだい）の先生（せんせい）に会（あ）った。
   - **中文理解**：若要表达去东京时见到了高中老师，应选「上京（じょうきょう）した」。（「入浴（にゅうよく）した折（おり）」也能在特殊场景中组成句子；这里不是用事件的正面、负面来判断。）

2. 海外転勤（かいがいてんきん）という重要（じゅうよう）な機会（きかい）の準備（じゅんび）を尋（たず）ねるなら、（a. 入浴（にゅうよく）する **b. 海外（かいがい）に転勤（てんきん）する**）に際（さい）して、どのようなものが必要（ひつよう）でしょうか。
   - **中文理解**：若询问海外调职这一重要场合需要准备什么，应选 b。（日常洗澡一般不用如此郑重的「に際（さい）して」；护理规程等特殊正式语境另当别论。）

3. スポーツ大会（スポーツたいかい）を開催（かいさい）するにあたって、｛ **a. 実行委員（じっこういいん）がごあいさつを申（もう）し上（あ）げます。** b. 突然（とつぜん）雨（あめ）が降（ふ）り出（だ）しました。｝
   - **中文理解**：在举办运动会之际，请允许执行委员致辞。（「にあたって」典型地接准备、致辞、方针等有意行为，不用于单纯交代偶然发生的插曲。）

4. 現代社会（げんだいしゃかい）の特殊（とくしゅ）な状況（じょうきょう）を背景（はいけい）として述（の）べるなら、現代（げんだい）の（a. 老人（ろうじん）ホーム **b. 高齢化社会（こうれいかしゃかい）**）にあって、介護（かいご）の質（しつ）が問（と）われている。
   - **中文理解**：若要把现代社会的特殊处境作为背景，应选“老龄化社会”。（本句型典型地接时代、社会状况；具体设施中的地点通常用「で」。）
