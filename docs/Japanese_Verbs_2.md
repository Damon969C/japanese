# 日语自动词与他动词学习资料（二）

> 依据 [2.txt](../../2.txt) 的顺序校订。校订日期：2026-07-15。

## 使用说明

- “标准自他对应”表示两词在某个核心义项上可形成状态与致使状态的对照，但不代表所有义项都一一对应。
- 自动词常以「が」标示发生变化的主体；他动词常以「を」标示受作用的对象。移动路径、离开点等也可用「を」，不能仅凭助词判断词性。
- 原始词表中的误写、非严格配对、较旧形式和常用写法差异，均在“辨析”中明确说明。

## 第 1 组（1—10）

### 1. 慣れる（なれる）／慣らす（ならす）

- **关系：** 标准自他对应：前项说明状态、变化或动作本身，后项说明主体对对象施加作用。
- **慣れる（なれる）〔自动词〕：** 适应环境、工作或某种状态；对象通常用「に」。
- **慣らす（ならす）〔他动词〕：** 使人或动物逐渐习惯，也可磨合新器具。
- **例句：**
  - 一週間（いっしゅうかん）で新しい職場（あたらしいしょくば）に慣れた（なれた）。——一周后适应了新职场。
  - 少しずつ（すこしずつ）子供（こども）を集団生活（しゅうだんせいかつ）に慣らした（ならした）。——逐渐让孩子适应集体生活。

- **枯れる（かれる）〔自动词〕：** 植物失去水分和生机，也可指声音沙哑、才能老练。

### 4. 遅れる（おくれる）／遅らせる（おくらせる）

- **关系：** 标准自他对应：前项说明状态、变化或动作本身，后项说明主体对对象施加作用。
- **遅れる（おくれる）〔自动词〕：** 到达、开始或进度晚于预定时间；对象常用「に」。
- **遅らせる（おくらせる）〔他动词〕：** 把时间推后，或使进度变慢。
- **例句：**
  - 事故（じこ）で電車（でんしゃ）が十分（じゅっぷん）遅れた（おくれた）。——电车因事故晚了十分钟。

- **辨析：** 原词表的「遅らす（おくらす）」可以见到，但现代中性的常用形式是「遅らせる（おくらせる）」。

### 7. 晴れる（はれる）／晴らす（はらす）

- **关系：** 词汇上有关联，但两个词的常用义并非完全对称；不能只靠「が／を」机械替换。
- **晴れる（はれる）〔自动词〕：** 天气转晴；也可指疑惑、心情等消散。
- **晴らす（はらす）〔他动词〕：** 消除疑念、郁闷、怨恨等。现代日常语通常不表示“使天气转晴”。
- **例句：**
  - 昼（ひる）には雨（あめ）がやんで空（そら）が晴れた（はれた）。——中午雨停天晴了。
  - 休日（きゅうじつ）に運動（うんどう）して気分（きぶん）を晴らした（はらした）。——休息日通过运动舒展了心情。
- **辨析：** 不要把「晴らす（はらす）」解释成日常意义上的“让天空放晴”；其常见宾语是「疑い（うたがい）」「鬱憤（うっぷん）」「恨み（うらみ）」等。
- **词典核对：** [查看词典条目](https://kotobank.jp/word/%E6%99%B4%E3%82%89%E3%81%99-604958)

### 12. 踊る（おどる）／踊らせる（おどらせる）

- **关系：** 使役性关联：后项带有“使其……”的意思，但现代日语往往另有更中性的使役形式。
- **踊る（おどる）〔自动词〕：** 人随节奏跳舞；也可比喻受人操纵。
- **踊らせる（おどらせる）〔使役形式〕：** 让某人跳舞；也可比喻操纵某人。
- **例句：**
  - 子供（こども）たちが音楽（おんがく）に合わせて（あわせて）踊った（おどった）。——孩子们随着音乐跳舞。
  - 先生（せんせい）が子供（こども）たちを舞台（ぶたい）で踊らせた（おどらせた）。——老师让孩子们在舞台上跳舞。
- **辨析：** 原词表的「踊らす（おどらす）」是存在的词，常含“使其跳舞、任意操纵”之意；一般使役表达优先用「踊らせる（おどらせる）」。
- **词典核对：** [查看词典条目](https://kotobank.jp/word/%E8%B8%8A%E3%82%89%E3%81%99-453530)

### 13. 怒る（おこる）／怒らせる（おこらせる）

- **关系：** 使役性关联：后项带有“使其……”的意思，但现代日语往往另有更中性的使役形式。
- **怒る（おこる）〔自动词〕：** 生气、发怒；生气的对象通常用「に」。
- **怒らせる（おこらせる）〔使役形式〕：** 惹某人生气。
- **例句：**

### 16. 凝る（こる）／凝らす（こらす）

- **关系：** 词汇上有关联，但两个词的常用义并非完全对称；不能只靠「が／を」机械替换。
- **凝る（こる）〔自动词〕：** 肌肉僵硬；也可指热衷于某事或设计讲究。

- **例句：**
  - 長時間（ちょうじかん）の作業（さぎょう）で肩（かた）が凝った（こった）。——长时间工作使肩膀僵硬了。
  - 職人（しょくにん）が細部（さいぶ）に工夫（くふう）を凝らした（こらした）。——工匠在细节上费尽心思。
- **辨析：** 常用义不是“肩膀僵硬／使肩膀僵硬”的直接对应；应分别记住「肩（かた）が凝る（こる）」和「工夫（くふう）を凝らす（こらす）」。
