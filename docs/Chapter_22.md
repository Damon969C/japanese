# 22 不可能（ふかのう）・可能（かのう）・困難（こんなん）・容易（ようい） (不可能・可能・困难・容易)

ある事情（じじょう）によって、ある行為（こうい）ができない・できる・難（むずか）しい・する価値（かち）があると述（の）べる時（とき）、どの表現（ひょうげん）を使（つか）えばよいでしょうか。（说明某种行为因具体情况而不能做、可能发生、难以做到或值得去做时，应使用哪些表达？）

| 核心功能 | 句型 | 语感重点 |
| :--- | :--- | :--- |
| 因立场、责任而不能做 | 〜わけにはいかない | 不是能力不足，而是“不能那么做” |
| 完全没有办法 | 〜ようがない／〜ようもない | 缺少手段、方法 |
| 心理或性质上难以做到 | 〜がたい | 正式、书面色彩较强 |
| 委婉表示不能或难以 | 〜かねる | 商务、正式场合常用 |
| 存在／不存在客观可能性 | 〜得（う）る／〜得（え）ない | 不表示个人技能 |
| 想做却受阻 | 〜ようにも〜ない | 意愿与现实障碍相冲突 |
| 值得、足以 | 〜に足（た）る | 对人或事物作正面评价 |
| 经得起／不忍看听 | 〜に堪（た）える／〜に堪（た）えない | 两种意义须结合搭配判断 |

## 学習前（がくしゅうまえ）の小（しょう）テスト (课前小测验)

### 知（し）っていますか

[ a. ようがない　b. わけにはいかない　c. かねる　d. 得（え）ない　e. がたい ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。

1. テレビの修理屋（しゅうりや）が今日（きょう）来（く）ると言（い）っていたから、留守（るす）にする（ **b. わけにはいかない** ）。
   - **中文理解**：修电视的人说今天会来，所以我不能不在家。
2. 彼（かれ）はその晩（ばん）わたしの家（いえ）にいたのだから、事件（じけん）の現場（げんば）にいたなどということはあり（ **d. 得（え）ない** ）。
   - **中文理解**：那天晚上他在我家，所以他不可能出现在案发现场。
3. 彼（かれ）が最近（さいきん）言（い）ったり書（か）いたりしていることは、理解（りかい）し（ **e. がたい** ）。
   - **中文理解**：他最近所说、所写的内容很难理解。
4. 彼（かれ）からは国（くに）を出（で）てから何（なん）の連絡（れんらく）もないので、手紙（てがみ）の出（だ）し（ **a. ようがない** ）。
   - **中文理解**：他离开这个国家后一直杳无音信，所以连信也无从寄出。
5. 入（はい）ったばかりの会社（かいしゃ）を辞（や）めてしまったなどとは、両親（りょうしん）には言（い）い出（だ）し（ **c. かねる** ）。
   - **中文理解**：刚进公司就辞职，这件事实在难以向父母开口。

### 使（つか）えますか

文脈（ぶんみゃく）に最（もっと）も自然（しぜん）な方（ほう）を選（えら）びなさい。

1. { **a. 材料（ざいりょう）が何（なに）もないのだから、おいしい料理（りょうり）など作（つく）りようがない。** ／ b. 今日（きょう）は疲（つか）れているから、食事（しょくじ）など作（つく）りようがない。 }
   - **中文理解**：什么材料都没有，因此根本没办法做出美味的饭菜。
2. { a. ここから富士山（ふじさん）が見（み）え得（え）ますか。／ **b. 考（かんが）え得（う）る方法（ほうほう）は、もうみんな試（ため）してみたのだが……。** }
   - **中文理解**：能想到的方法都试过了，可是……
3. { a. 法律（ほうりつ）では未成年者（みせいねんしゃ）はたばこを吸（す）うわけにはいかないことになっている。／ **b. 彼女（かのじょ）からのせっかくのプレゼントだから、大（おお）きすぎるなどと言（い）うわけにはいかない。** }
   - **中文理解**：这是她特意送的礼物，因此不好说“太大了”之类的话。
4. { a. わたしの仕事（しごと）は夜（よる）の仕事（しごと）なので、朝早（あさはや）くは起（お）きがたい。／ **b. 労働条件（ろうどうじょうけん）についての会社側（かいしゃがわ）のこの提案（ていあん）は受（う）け入（い）れがたい。** }
   - **中文理解**：公司方面关于劳动条件的这项提案难以接受。
5. { **a. それについてはすぐにはお答（こた）えしかねます。** ／ b. 新（あたら）しいパソコンを買（か）いたかったのだが、お金（かね）が足（た）りなくて買（か）いかねた。 }
   - **中文理解**：关于那件事，我目前很难立即答复。

> **判断要点**：「作（つく）りようがない」要求“没有做法或手段”；单纯疲劳应说「作（つく）れない」。「〜得（う）る」表示客观可能性，不表示眼睛能否看见或个人会不会做。「〜かねる」也不用于单纯缺钱等客观能力不足。

## 22・1 〜わけにはいかない ★3

**【意味（いみ）】立場（たちば）・責任（せきにん）・常識（じょうしき）などを考（かんが）えると、〜できない (考虑到立场、责任或常识，不能……)**

①明日（あした）は試験（しけん）があるから、今日（きょう）は遊（あそ）んでいる **わけにはいかない** 。
- **中文理解**：明天有考试，所以今天不能一直玩。

②これは亡（な）くなった友人（ゆうじん）がくれた大切（たいせつ）なもので、あげる **わけにはいかない** んです。
- **中文理解**：这是已故朋友送给我的重要物品，不能送给别人。

③「そろそろ帰（かえ）りませんか」
「大事（だいじ）な話（はなし）があって課長（かちょう）を待（ま）っているので、帰（かえ）る **わけにはいかない** んですよ」
- **中文理解**：“差不多该回去了吧？”“我有重要的事要和科长谈，正在等他，所以不能回去。”

④明日（あした）は会社（かいしゃ）の面接試験（めんせつしけん）だ。絶対（ぜったい）に遅刻（ちこく）する **わけにはいかない** 。
- **中文理解**：明天是公司的面试，绝对不能迟到。

**接続（せつぞく）** V辞書形（じしょけい）＋ わけにはいかない

▶ 物理的（ぶつりてき）・能力的（のうりょくてき）に不可能（ふかのう）なのではなく、「本当（ほんとう）はそうする可能性（かのうせい）があっても、社会的（しゃかいてき）事情（じじょう）や心理的（しんりてき）抵抗（ていこう）のため、そうする選択（せんたく）はできない」と表（あらわ）します。（并非物理上或能力上做不到，而是由于社会责任、道德、承诺、立场或心理顾虑，不能选择那样做。）

**【扩展说明】**
规则也可以成为说话人“不能那样做”的理由，如「法律（ほうりつ）で禁止（きんし）されているから、吸（す）うわけにはいかない」。但若只是客观说明规则本身，通常用「吸（す）ってはいけないことになっている」，不说「わけにはいかないことになっている」。否定式「Vないわけにはいかない」表示“不能不做”，即“必须做”：例「約束（やくそく）したから、行（い）かないわけにはいかない」。

## 22・2 〜ようがない・〜ようもない ★3

**【意味（いみ）】手段（しゅだん）・方法（ほうほう）がなく、どうしても〜できない (无从……；根本没有办法……)**

①あの人（ひと）の住所（じゅうしょ）も電話番号（でんわばんごう）も分（わ）からないのですから、連絡（れんらく）のし **ようがありません** 。
- **中文理解**：既不知道那个人的住址，也不知道电话号码，所以无从联系。

②この時計（とけい）は古（ふる）くてもう部品（ぶひん）がないから、直（なお）し **ようがない** 。
- **中文理解**：这块表太旧，零件已经没有了，所以没法修。

③森田（もりた）さんの山（やま）の家（いえ）は、バスも通（とお）っていないから、車（くるま）がないと行（い）き **ようがない** らしい。
- **中文理解**：听说森田在山里的房子不通公交，没有车就根本去不了。

④社員（しゃいん）はやる気（き）があるのだが、会社（かいしゃ）の方針（ほうしん）が変（か）わらないのだから、どうし **ようもない** 。
- **中文理解**：员工虽然有干劲，但公司的方针不改变，也就无可奈何。

**接続（せつぞく）** Vます形（けい）の語幹（ごかん）＋ ようがない／ようもない

▶ 「〜したくても、そのための方法（ほうほう）・根拠（こんきょ）・手掛（てが）かりがない」、または「どんな方法（ほうほう）を使（つか）っても無理（むり）だ」と述（の）べます。ここでの「よう」は漢字（かんじ）では「様（よう）」で、“方法”を表（あらわ）します。（表示想做却没有方法、依据或线索，或无论如何都办不到。）

**【扩展说明】**
「〜ようもない」语气比「〜ようがない」稍强。「言（い）いようがない」还可表示“不知如何形容”，如「言葉（ことば）では言（い）いようがない美（うつく）しさ」。不要把它当作普通可能形：因疲劳而做不了饭是「疲（つか）れていて作（つく）れない」，只有没有材料、工具或方法时才适合说「作（つく）りようがない」。

## 22・3 〜がたい ★2

**【意味（いみ）】心理的（しんりてき）・本質的（ほんしつてき）に〜するのが非常（ひじょう）に難（むずか）しい (在心理上或性质上难以……)**

①あの元気（げんき）なひろしが病気（びょうき）になるなんて、信（しん）じ **がたい** ことです。
- **中文理解**：那么健康的宏竟然会生病，实在令人难以置信。

②弱（よわ）い者（もの）をいじめるとは、許（ゆる）し **がたい** 行為（こうい）だ。
- **中文理解**：欺凌弱者是不可原谅的行为。

③南（みなみ）の国（くに）から来（き）たポンさんは、初（はじ）めての日本（にほん）の冬（ふゆ）が耐（た）え **がたかった** らしく、国（くに）へ帰（かえ）ってしまった。
- **中文理解**：来自南方国家的庞似乎难以忍受第一次经历的日本冬天，便回国了。

**接続（せつぞく）** Vます形（けい）の語幹（ごかん）＋ がたい

▶ 「信（しん）じる・許（ゆる）す・理解（りかい）する・想像（そうぞう）する・受（う）け入（い）れる・耐（た）える」など、認識（にんしき）・評価（ひょうか）・心理（しんり）に関係（かんけい）する動詞（どうし）とよく使（つか）います。正式（せいしき）で書（か）き言葉（ことば）的（てき）な表現（ひょうげん）です。（常与认知、评价和心理活动相关的动词搭配，语气正式、偏书面。）

**【扩展说明】**
「難（むずか）しい」不一定等于「〜がたい」。电脑不会用、伤未痊愈而走不远等个人能力或身体条件，应说「使（つか）えない」「歩（ある）けない」，不用「使（つか）いがたい」「歩（ある）きがたい」。但评价对象本身令人难以接近、难以忘却时，「近寄（ちかよ）りがたい雰囲気（ふんいき）」「忘（わす）れがたい思（おも）い出（で）」则很自然。

## 22・4 〜かねる ★2

**【意味（いみ）】事情（じじょう）や心理的（しんりてき）抵抗（ていこう）があって、〜することが難（むずか）しい／できない (碍于情况或心理顾虑，难以……)**

①課長（かちょう）に残業（ざんぎょう）を頼（たの）まれて、断（ことわ）り **かねて** 10時（じゅうじ）まで働（はたら）いた。
- **中文理解**：科长让我加班，我不好意思拒绝，便一直工作到十点。

②そろそろ就職活動（しゅうしょくかつどう）を始（はじ）めるんですが、IT関係（かんけい）の会社（かいしゃ）にするか、マスコミ関係（かんけい）の会社（かいしゃ）にするか、決（き）め **かねて** います。
- **中文理解**：差不多该开始求职了，但我还难以决定去 IT 公司还是传媒公司。

③客（きゃく）「ホンコン行（い）きの飛行機（ひこうき）は何時（なんじ）に出（で）ますか」
係（かかり）「ここでは分（わ）かり **かねます** ので、あちらのカウンターでお聞（き）きください」
- **中文理解**：顾客：“飞往香港的航班几点起飞？”工作人员：“这里无法确认，请到那边的柜台询问。”

④ただ今（いま）のご説明（せつめい）では、私（わたくし）どもとしては納得（なっとく）し **かねます** 。
- **中文理解**：仅凭刚才的说明，我方难以接受。

**接続（せつぞく）** Vます形（けい）の語幹（ごかん）＋ かねる

▶ 直接（ちょくせつ）「できません」と言（い）うのを避（さ）け、相手（あいて）の依頼（いらい）を丁寧（ていねい）に断（ことわ）る時（とき）や、正式（せいしき）な場面（ばめん）で判断（はんだん）・決定（けってい）が難（むずか）しいと述（の）べる時（とき）に多（おお）く使（つか）います。（用于委婉拒绝、或正式说明难以判断和决定。）

**【扩展说明】**
「〜かねる」带有说话人的立场和顾虑，不能代替所有的「〜できない」。因钱不够而没买成，应说「お金（かね）が足（た）りなくて買（か）えなかった」。还要特别注意「〜かねない」并不是其普通否定，而表示“有可能发生某种不良结果”：例「このままでは事故（じこ）が起（お）こりかねない」。

## 22・5 〜得（う）る・〜得（え）ない ★2

**【意味（いみ）】〜する可能性（かのうせい）がある／ない (有／没有……的客观可能性)**

①これは仕事（しごと）を成功（せいこう）させるために考（かんが）え **得（う）る** 最上（さいじょう）の方法（ほうほう）です。
- **中文理解**：这是为了使工作成功所能想到的最佳方法。

②この事故（じこ）はいつでも起（お）こり **得（う）る** こととして、十分（じゅうぶん）な注意（ちゅうい）が必要（ひつよう）だ。
- **中文理解**：这种事故随时都可能发生，因此必须充分注意。

③この事故（じこ）は全（まった）く予測（よそく）し **得（え）ぬ** ことであった。
- **中文理解**：这起事故是完全无法预料的。

④親友（しんゆう）を失（うしな）った悲（かな）しみは、言葉（ことば）では表（あらわ）し **得（え）ない** 。
- **中文理解**：失去挚友的悲痛无法用语言表达。

⑤「彼（かれ）は一人（ひとり）でロンドンへ行（い）くんですか」
「そんなことは、彼（かれ）の場合（ばあい）、あり **得（え）ません** よ。家族第一（かぞくだいいち）だから」
- **中文理解**：“他要一个人去伦敦吗？”“对他来说不可能，他把家庭放在第一位。”

**接続（せつぞく）** Vます形（けい）の語幹（ごかん）＋ 得（う）る／得（え）ない

▶ 客観的（きゃっかんてき）に見（み）て、その事態（じたい）が起（お）こる可能性（かのうせい）があるか、論理的（ろんりてき）に可能（かのう）かを述（の）べる硬（かた）い表現（ひょうげん）です。個人（こじん）の技能（ぎのう）としての「できる／できない」には普通（ふつう）使（つか）いません。（用于客观可能性或逻辑上的可能，通常不表示个人技能。）

**【扩展说明】**
辞書形（じしょけい）の「得（え）る」は「える」と「うる」の両方（りょうほう）が可能（かのう）ですが，这一语法中书面语常读「うる」，如「起（お）こり得（う）る」。活用（かつよう）后的形式一般读「え」：得（え）ない、得（え）た、得（え）ます。固定搭配「あり得（え）る／あり得（え）ない」在现代口语中多读「える／えない」。不能说「難（むずか）しい漢字（かんじ）は書（か）き得（え）ません」来表示个人不会写，应说「書（か）けません」。

## 22・6 〜ようにも〜ない ★1

**【意味（いみ）】〜しようと思（おも）っても、妨（さまた）げがあってできない (即使想……，也因受阻而不能……)**

①大切（たいせつ）な電話（でんわ）が来（く）ることになっているので、出掛（でか）け **ようにも** 出掛（でか）けられ **ません** 。
- **中文理解**：有一通重要电话要打来，所以即使想出门也走不开。

②言葉（ことば）が全（まった）く通（つう）じないので、道（みち）を聞（き）こ **うにも** 聞（き）けな **くて** 困（こま）った。
- **中文理解**：语言完全不通，想问路也问不了，十分为难。

③お金（かね）に困（こま）っている後輩（こうはい）から借金（しゃっきん）を頼（たの）まれて、断（ことわ）ろ **うにも** 断（ことわ）れ **なかった** 。
- **中文理解**：经济困难的后辈向我借钱，我想拒绝也没能拒绝。

④うっかり携帯電話（けいたいでんわ）を充電（じゅうでん）するのを忘（わす）れていたので、すぐ連絡（れんらく）し **ようにも** でき **なかった** んです。
- **中文理解**：我不小心忘了给手机充电，所以即使想马上联系也做不到。

**接続（せつぞく）** V意向形（いこうけい）＋ にも ＋ V可能形（かのうけい）の否定（ひてい）／できない

▶ 行為（こうい）をする意志（いし）はあるのに、外的（がいてき）事情（じじょう）や心理的（しんりてき）事情（じじょう）が妨（さまた）げになって実行（じっこう）できないことを強調（きょうちょう）します。（强调明明有意愿，却受现实条件阻碍而无法实施。）

**【扩展说明】**
前后重复同一动词最典型，如「帰（かえ）ろうにも帰（かえ）れない」，但并非绝对要求；后项也可以直接说明障碍，如「買（か）おうにもお金（かね）がない」。这一句型往往带有无奈或解释自身处境的语气。

## 22・7 〜に足（た）る ★1 [W]

**【意味（いみ）】〜するだけの価値（かち）・資格（しかく）が十分（じゅうぶん）にある (值得……；足以……)**

①彼（かれ）は今度（こんど）の数学（すうがく）オリンピックで、十分（じゅうぶん）満足（まんぞく）する **に足（た）る** 成績（せいせき）を収（おさ）めるだろう。
- **中文理解**：他在这次数学奥林匹克竞赛中，大概能取得足以令人满意的成绩。

②これはわざわざ議論（ぎろん）する **に足（た）る** 問題（もんだい）だろうか。
- **中文理解**：这是一个值得专门讨论的问题吗？

③彼女（かのじょ）は責任感（せきにんかん）が強（つよ）く、信頼（しんらい） **に足（た）る** 人物（じんぶつ）だ。
- **中文理解**：她责任心很强，是一个值得信赖的人。

**接続（せつぞく）** V辞書形（じしょけい）／動作性名詞（どうさせいめいし）＋ に足（た）る ＋ N

▶ 人（ひと）や物事（ものごと）が、ある評価（ひょうか）・行為（こうい）の対象（たいしょう）となるだけの価値（かち）や資格（しかく）を備（そな）えていることを表（あらわ）す書（か）き言葉（ことば）です。（表示某人或某事具备足够的价值或资格，偏书面。）

**【扩展说明】**
常见搭配有「信頼（しんらい）に足（た）る人物（じんぶつ）」「尊敬（そんけい）するに足（た）る人（ひと）」「注目（ちゅうもく）に足（た）る成果（せいか）」。否定可说「取（と）るに足（た）らない」或「取（と）るに足（た）りない」，表示“不值一提”。「〜に足（た）る」重点是价值评价，不是普通的“能够”。

## 22・8 〜に堪（た）える・〜に堪（た）えない ★1

**【意味（いみ）】〜する価値（かち）がある・〜に耐（た）えられる／不快（ふかい）で〜していられない (经得起、值得……／不忍……)**

①あの映画（えいが）は子（こ）ども向（む）けですが、大人（おとな）の鑑賞（かんしょう） **にも十分（じゅうぶん）堪（た）えます** 。
- **中文理解**：那部电影虽面向儿童，但也完全经得起成年人欣赏。

②彼（かれ）の小説（しょうせつ）はまだ、小説（しょうせつ）好（ず）きの読者（どくしゃ）が読（よ）む **に堪（た）える** 本（ほん）ではない。
- **中文理解**：他的小说还没有达到值得小说爱好者阅读的水准。

③事故現場（じこげんば）は全（まった）く見（み）る **に堪（た）えない** ありさまだ。
- **中文理解**：事故现场惨不忍睹。

④あの人（ひと）の話（はなし）はいつも人（ひと）の悪口（わるぐち）ばかりで、聞（き）く **に堪（た）えない** 。
- **中文理解**：那个人说的总是别人的坏话，实在不堪入耳。

**接続（せつぞく）** V辞書形（じしょけい）／動作性名詞（どうさせいめいし）＋ に堪（た）える・に堪（た）えない

▶ 肯定（こうてい）の「〜に堪（た）える」は、鑑賞（かんしょう）・使用（しよう）・批評（ひひょう）などに耐（た）えられる品質（ひんしつ）があり、それだけの価値（かち）があることを表（あらわ）します。否定（ひてい）の「見（み）るに堪（た）えない・聞（き）くに堪（た）えない」は、不快（ふかい）さや悲惨（ひさん）さのため、見続（みつづ）けたり聞（き）き続（つづ）けたりできないという評価（ひょうか）です。（肯定表示质量经得起某种行为；否定常表示因不快或悲惨而不忍看、不堪听。）

**【扩展说明】**
「読（よ）むに堪（た）えない」は“不忍卒读／质量差得读不下去”，而「読（よ）むに堪（た）える本（ほん）ではない」是“尚未达到值得一读的水准”，角度略有不同。另有正式套语「感謝（かんしゃ）に堪（た）えない」「喜（よろこ）びに堪（た）えない」，表示某种感情强烈至极，并不是“不值得感谢／喜悦”。

## 22 練習（れんしゅう） (练习)

### A　★3・★2

[ a. わけにはいかない　b. かねる　c. ようがない ] と、（　）の中（なか）の言葉（ことば）を一緒（いっしょ）に使（つか）って、文（ぶん）を完成（かんせい）させなさい。必要（ひつよう）なら形（かたち）を変（か）えなさい。

1. 「このCDプレーヤー、もう少（すこ）し安（やす）くなりませんか」
   「申（もう）し訳（わけ）ございませんが、これ以上（いじょう）お安（やす）くは **（いたす）＿＿＿＿** 」
   - **中文理解**：“这台 CD 播放器不能再便宜一点吗？”“非常抱歉，无法再为您降价。”
2. 申（もう）し訳（わけ）ありません。この掃除機（そうじき）は型（かた）が古（ふる）いため部品（ぶひん）がなく、 **（直（なお）す）＿＿＿＿** んです。
   - **中文理解**：非常抱歉，这台吸尘器型号太旧且没有零件，已经没法修了。
3. わたしの仕事（しごと）の遅（おく）れで同僚（どうりょう）には何回（なんかい）も迷惑（めいわく）を掛（か）けているので、今回（こんかい）の仕事（しごと）では **（遅（おく）れる）＿＿＿＿** んです。
   - **中文理解**：我已多次因工作拖延给同事添麻烦，这次绝不能再迟了。
4. 田中課長（たなかかちょう）は今（いま）、休暇（きゅうか）を取（と）って旅行中（りょこうちゅう）なので、この二日間（ふつかかん）は連絡（れんらく）の **（取（と）る）＿＿＿＿** ということです。
   - **中文理解**：田中科长正在休假旅行，据说这两天无从取得联系。
5. 先週（せんしゅう）もアルバイトを休（やす）んだから、今週（こんしゅう）は **（休（やす）む）＿＿＿＿** だろうな。
   - **中文理解**：上周已经请过假，这周恐怕不能再请了。
6. 友人（ゆうじん）にお金（かね）を借（か）りに行（い）ったのですが、やはり **（言（い）い出（だ）す）＿＿＿＿** 、そのまま帰（かえ）ってきてしまいました。
   - **中文理解**：我去向朋友借钱，但果然还是难以开口，就那样回来了。

### B　★2・★1

[ a. に堪（た）えない　b. に足（た）る　c. がたい　d. 得（え）ない　e. ようにも〜ない ] と、（　）の中（なか）の言葉（ことば）を一緒（いっしょ）に使（つか）って、文（ぶん）を完成（かんせい）させなさい。一（ひと）つの表現（ひょうげん）は一回（いっかい）しか使（つか）いません。

山下（やました）さんが会社（かいしゃ）のお金（かね）を不正（ふせい）に使（つか）ってしまったんですって。山下（やました）さんという人（ひと）をよく知（し）っているわたしとしては、とても **1.（信（しん）じる）＿＿＿＿** ことです。そんなことは絶対（ぜったい）に **2.（ある）＿＿＿＿** と思（おも）います。だって、彼（かれ）ほど **3.（信頼（しんらい））＿＿＿＿** 人（ひと）はいないと、いつも思（おも）っていたんですもの。もし事実（じじつ）だとしたら、今頃（いまごろ）は後悔（こうかい）して、どんなに苦（くる）しんでいるか……。上田（うえだ）さんなんか、 **4.（聞（き）く）＿＿＿＿** ひどいことを言（い）っているんですよ。もし、このことが原因（げんいん）で会社（かいしゃ）を辞（や）めることにでもなったら、わたしは **5.（慰（なぐさ）める）＿＿＿＿** 。わたしに何（なに）かしてあげられることはないかしら。早（はや）く事実（じじつ）を知（し）らなければ……。

- **中文理解**：听说山下挪用了公司的钱。作为很了解他的人，我实在难以相信。我认为这种事绝不可能发生，因为我一直觉得没有比他更值得信赖的人。如果这是真的，他现在该多么后悔、痛苦啊……上田甚至说了些不堪入耳的话。要是山下因此辞职，我即使想安慰他，恐怕也无从安慰。我能不能为他做些什么呢？必须尽快弄清事实……

## 本章（ほんしょう）の使（つか）い分（わ）け

- **客观上没有方法**：連絡（れんらく）のしようがない。
- **客观上可能发生**：事故（じこ）は起（お）こり得（う）る。
- **有能力但碍于责任不能做**：約束（やくそく）を破（やぶ）るわけにはいかない。
- **正式、委婉地说不能**：ご希望（きぼう）には応（おう）じかねます。
- **心理或评价上难以接受**：受（う）け入（い）れがたい提案（ていあん）だ。
- **想做却被障碍阻止**：帰（かえ）ろうにも帰（かえ）れない。
- **评价是否值得**：信頼（しんらい）に足（た）る／鑑賞（かんしょう）に堪（た）える。
