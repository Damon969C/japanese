# 17 話題（わだい） (话题)

ある事柄（ことがら）を話題（わだい）として取（と）り上（あ）げるときは、どんな言（い）い方（かた）がありますか。 (把某件事作为话题时，可以使用哪些表达方式呢？)

| 功能 | 句型 | 核心语感 |
| :--- | :--- | :--- |
| 解释词义、下定义 | 〜というのは、〜とは | 所谓……是指…… |
| 限定擅长领域 | 〜にかけては | 在……方面尤其出色 |
| 谈一般本质或推出结论 | 〜というものは、〜ということは | ……这种事物；既然如此，也就是说…… |
| 由联想转换话题 | 〜といえば、〜というと A | 说到……便想到…… |
| 确认对方所指 | 〜というと B | 你说的……是指……吗 |
| 对比地提出一方 | 〜はというと | 至于……则…… |
| 带感情强调程度 | 〜といったら | 要说……，那可真是…… |
| 遇到特定话题便改变态度 | 〜のこととなると | 一谈到……就…… |
| 带不满提出身边对象 | 〜ときたら | 说起……可真是…… |

---

### 17・1 〜というのは ★3

**【意味（いみ）】〜とは〜のことだ (所谓……，是指……)**

①「致（いた）し方（かた）がない」（ **というのは** ）、どういう意味（いみ）ですか。
- **中文理解**：「致し方がない」（无可奈何、没有办法）是什么意思？

②パソコンで「上書（うわが）き保存（ほぞん）」（ **というのは** ）、文書（ぶんしょ）を訂正（ていせい）して保存（ほぞん）するという意味（いみ）です。
- **中文理解**：电脑中的“覆盖保存”，是指修改文档后覆盖原文件进行保存。

③「多年草（たねんそう）」（ **っていうのは** ）、2年（にねん）以上（いじょう）にわたって生育（せいいく）する草本（そうほん）植物（しょくぶつ）のことだよ。冬（ふゆ）に地上部（ちじょうぶ）が枯（か）れても、地下部（ちかぶ）が生（い）き残（のこ）って春（はる）にまた芽（め）を出（だ）すものも多（おお）いんだ。
- **中文理解**：所谓多年生草本，是指能生长两年以上的草本植物。其中很多即使冬天地上部分枯萎，地下部分仍会存活并在春天重新发芽。

④ねえ、「オゾン」（ **って** ）何（なに）？
- **中文理解**：喂，“臭氧”是什么？

⑤赤字（あかじ）（ **とは** ）、収入（しゅうにゅう）より支出（ししゅつ）が多（おお）いことです。
- **中文理解**：所谓赤字，是指支出多于收入。

⑥水蒸気（すいじょうき）（ **とは** ）、気体（きたい）の状態（じょうたい）に変（か）わった水（みず）のことである。
- **中文理解**：所谓水蒸气，是指变成气态的水。

⑦温室（おんしつ）効果（こうか）ガス（ **とは** ）、二酸化（にさんか）炭素（たんそ）（CO2）・メタン・フロンなど、大気中（たいきちゅう）に熱（ねつ）をとどめ、地球（ちきゅう）の気温（きおん）上昇（じょうしょう）に関（かか）わる気体（きたい）のことである。
- **中文理解**：所谓温室气体，是指二氧化碳、甲烷、氟利昂等会把热量留在大气中、与全球升温有关的气体。

**接続（せつぞく）** N ＋ というのは・とは
▶ ある言葉（ことば）・名称（めいしょう）を話題（わだい）にし、その意味（いみ）・定義（ていぎ）・内容（ないよう）を説明（せつめい）する。「Nというのは／Nとは、〜ことだ・〜ものだ・〜という意味だ」の形（かたち）が多（おお）い。（把词语或名称作为话题，说明其含义、定义或内容；后项常用「〜ことだ／ものだ／という意味だ」。）

**【扩展说明】**
「というのは」会话和一般说明中都可使用；「とは」更简洁、偏书面，常见于词典式定义。随意会话中「というのは」缩约为「っていうのは」，还可进一步缩成「って」。例④的「って」同时承担引用和提示话题的作用。

### 17・2 〜にかけては ★3

**【意味（いみ）】〜の分野（ぶんや）では特（とく）に (在……方面；论……的话)**

①田中（たなか）さんは事務（じむ）の仕事（しごと）（ **にかけては** ）、素晴（すば）らしい能力（のうりょく）を持（も）っています。
- **中文理解**：田中在事务工作方面能力出众。

②父（ちち）は釣（つ）りが得意（とくい）だ。川釣（かわづ）り（ **にかけては** ）、この村（むら）で父（ちち）より上手（じょうず）な人（ひと）はいないと思（おも）う。
- **中文理解**：父亲擅长钓鱼。论溪河垂钓，我想村里没人比他更高明。

③わたしは足（あし）の速（はや）さ（ **にかけては** ）自信（じしん）があったのですが、若（わか）い人（ひと）にはもう勝（か）てません。
- **中文理解**：我过去对自己的跑步速度很有信心，但现在已经赢不了年轻人了。

**接続（せつぞく）** N ＋ にかけては
▶ 能力（のうりょく）・技術（ぎじゅつ）・知識（ちしき）などの分野（ぶんや）を限定（げんてい）し、その分野（ぶんや）では自信（じしん）がある、またはほかより優（すぐ）れていると述（の）べる。（限定能力、技术或知识等领域，表示在该方面有自信或胜过别人。）

**【扩展说明】**
它不是中性的“关于……”。后项通常带突出、比较或最高程度，如「右に出る者はいない」「自信がある」。也可带讽刺地评价缺点，如「忘れ物の多さにかけては彼が一番だ」，此时“出色”是反话。

### 17・3 〜とは ★2

**【意味（いみ）】〜というのは (所谓……；至于……)**

▶ 本節（ほんせつ）の「Nとは」は17・1の「Nというのは」とほぼ同（おな）じで、言葉（ことば）の意味（いみ）や一般的（いっぱんてき）な内容（ないよう）を説明（せつめい）するときに使（つか）う。書（か）き言葉（ことば）的（てき）で、簡潔（かんけつ）な形（かたち）である。（本节的「Nとは」与17・1的「Nというのは」基本相同，用来说明词义或一般内容，简洁且偏书面。）

**【扩展说明】**
另有「彼が辞めるとは驚いた」这种「普通形＋とは」：它把某个事实作为感叹对象，意为“竟然……”，并不是下定义。第30章的「〜とは」主要属于后一种用法，两者应根据前接形式和后项内容区分。

### 17・4 〜というものは・〜ということは ★2

**【意味（いみ）】〜は／その事実（じじつ）から考（かんが）えると (……这种事物；既然如此，也就是说……)**

①音楽（おんがく）（ **というものは** ）素晴（すば）らしいものだなあ。
- **中文理解**：音乐这种东西真美妙啊。

②個人（こじん）競技（きょうぎ）の試合（しあい）に出（で）る前（まえ）の緊張感（きんちょうかん）（ **というものは** ）、経験（けいけん）しないと分（わ）からないだろう。
- **中文理解**：参加个人项目比赛前的那种紧张感，不亲身经历大概无法体会。

③故郷（ふるさと）（ **というものは** ）、遠（とお）く離（はな）れるといっそう懐（なつ）かしくなる。
- **中文理解**：故乡这种存在，离得越远越令人怀念。

④体（からだ）が丈夫（じょうぶ）だ（ **ということは** ）、ありがたいことだと思（おも）っています。
- **中文理解**：我觉得身体健康是一件值得庆幸的事。

⑤長（なが）い間（あいだ）の習慣（しゅうかん）を変（か）える（ **ってことは** ）大変（たいへん）だ。
- **中文理解**：要改变长期形成的习惯，可不是件容易的事。

⑥自由（じゆう）時間（じかん）が十分（じゅうぶん）にある（ **ということは** ）、いろいろなことをやれる機会（きかい）があるということだ。
- **中文理解**：有充足的自由时间，也就是说有机会做各种事情。

⑦田中（たなか）さん、「明日（あした）からもう来（こ）ない」（ **ってことは** ）、つまり、この会社（かいしゃ）を辞（や）めるということですか。
- **中文理解**：田中，你说“从明天起不再来了”，也就是说要离开这家公司吗？

**接続（せつぞく）** N ＋ というものは ／ 普通形（ふつうけい）＋ ということは
▶ 「Nというものは」は、Nの本質（ほんしつ）・普遍的（ふへんてき）な性質（せいしつ）について感想（かんそう）や評価（ひょうか）を述（の）べる。「普通形＋ということは」は、文（ぶん）で表（あらわ）された事実（じじつ）を話題（わだい）にしたり、そこから導（みちび）かれる結論（けつろん）を述（の）べたりする。（前者谈论名词所指事物的本质或普遍性质；后者把一个事实作为话题，或由此推出结论。）

**【扩展说明】**
「というものは」常带概括和感慨，容易形成“所谓N这种东西……”的语气；不适合只描述某个偶然、一次性的个体。「ということは」的推论用法常与「つまり」「では」呼应。口语形式是「ってことは」。第16章「この3週間というもの」表示时间持续，结构和意义都不同。

### 17・5 〜といえば ★2

**【意味（いみ）】〜を話題（わだい）にすると (说到……；提起……)**

①今年（ことし）もまた紅葉（こうよう）の季節（きせつ）になった。紅葉（こうよう）（ **といえば** ）、5年（ごねん）前（まえ）に行（い）ったカナダの紅葉（こうよう）の美（うつく）しさが忘（わす）れられない。
- **中文理解**：今年又到了红叶季。说到红叶，我忘不了五年前在加拿大看到的美景。

②今年（ことし）こそ一緒（いっしょ）にスキーに行（い）きましょうね。スキー（ **といえば** ）、今度（こんど）の冬季（とうき）オリンピック、楽（たの）しみですね。
- **中文理解**：今年一定一起去滑雪吧。说到滑雪，下一届冬奥会真让人期待。

③「昨日（きのう）の台風（たいふう）はすごかったねえ。記録的（きろくてき）な大雨（おおあめ）だったようだよ」
「記録的（きろくてき）（ **っていえば** ）、今年（ことし）の暑（あつ）さも相当（そうとう）でしたね」
- **中文理解**：“昨天的台风真厉害，好像降下了破纪录的大雨。”“说到破纪录，今年的炎热程度也相当惊人。”

**接続（せつぞく）** 取（と）り上（あ）げる語（ご）・句（く）＋ といえば
▶ 相手（あいて）が言（い）ったこと、または自分（じぶん）の頭（あたま）に浮（う）かんだことを手掛（てが）かりに、関連（かんれん）する新（あたら）しい話題（わだい）を出（だ）す。（以对方提到的内容或自己想到的内容为线索，引出相关的新话题。）

**【扩展说明】**
随意会话中说「っていえば」。新话题通常与原词有联想关系，但不必是严格的逻辑结论。另有「便利といえば便利だ」这种承认一方面、随后加以保留的用法，意为“要说方便倒也方便”，不属于本节的话题联想。

### 17・6 A 〜というと ★2

**【意味（いみ）】〜という言葉（ことば）から思（おも）い浮（う）かぶのは (一说到……就会想到……)**

①古都（こと）（ **というと** ）、まず頭（あたま）に浮（う）かぶのは京都（きょうと）や鎌倉（かまくら）ですよね。
- **中文理解**：说到古都，首先浮现在脑海中的就是京都和镰仓吧。

②これは子（こ）どものための童話（どうわ）です。童話（どうわ）（ **というと** ）、どんな種類（しゅるい）の本（ほん）を想像（そうぞう）しますか。
- **中文理解**：这是写给儿童的童话。提到童话，你会想到哪类书？

③わたしは草花（くさばな）研究会（けんきゅうかい）で野草（やそう）の研究（けんきゅう）をしています。研究（けんきゅう）している（ **というと** ）、難（むずか）しいことをしているような印象（いんしょう）を持（も）つでしょうが、野山（のやま）を歩（ある）いて植物（しょくぶつ）を観察（かんさつ）しているんです。
- **中文理解**：我在花草研究会研究野生植物。一说“做研究”，大家也许会以为在做很难的事，其实我只是走进山野观察植物。

**接続（せつぞく）** N／普通形（ふつうけい）＋ というと
▶ ある言葉（ことば）を聞（き）いたとき、典型的（てんけいてき）な例（れい）・印象（いんしょう）・連想（れんそう）としてすぐ頭（あたま）に浮（う）かぶものを述（の）べる。（说出听到某个词时，作为典型例子、印象或联想立即想到的内容。）

**【扩展说明】**
口语可说「っていうと」。注意，例②实际使用的是完整形式「というと」，不能把它当作口语缩约的例子；判断语体应看形式本身，不应只看它是否出现在对话中。

### 17・6 B 〜というと ★2

**【意味（いみ）】あなたが今（いま）言（い）った〜は、つまり (你刚说的……是指……；这么说……)**

①「じゃあ、今度（こんど）の会（かい）はアマゾンでやることにしようよ」
「アマゾン（ **というと** ）、駅前（えきまえ）のコーヒーショップのことですか」
- **中文理解**：“那么，下次聚会就在‘亚马逊’办吧。”“你说的‘亚马逊’，是指车站前那家咖啡店吗？”

②「リーさんは荷物（にもつ）を整理（せいり）して、もう国（くに）へ帰（かえ）りましたよ」
「帰（かえ）った（ **っていうと** ）、もう日本（にほん）には戻（もど）らないということでしょうか」
- **中文理解**：“小李收拾好行李，已经回国了。”“你说‘回去了’，是指以后不回日本了吗？”

③「ヤンさんの家族（かぞく）は今（いま）3人（さんにん）ですよ」
「（ **というと** ）、赤（あか）ちゃんが生（う）まれたのですね」
- **中文理解**：“小杨家现在有三口人了。”“这么说，是宝宝出生了吧。”

**接続（せつぞく）** 相手（あいて）が使（つか）った語（ご）・句（く）＋ というと ／ 文頭（ぶんとう）で「というと」
▶ 相手（あいて）の発言（はつげん）を受（う）け、その指（さ）す内容（ないよう）を確認（かくにん）したり、そこから推測（すいそく）した結論（けつろん）を確（たし）かめたりする。（承接对方的话，确认其所指内容，或确认由此推断出的结论。）

**【扩展说明】**
A用法是自由联想，B用法则紧接对方刚说的话，并带确认语气。像例③一样省略前面的复述内容时，「というと」相当于“这么说来”。

### 17・7 〜はというと ★2

**【意味（いみ）】一方（いっぽう）、〜はどうかというと (至于……；而……呢)**

①わたしは文科系（ぶんかけい）の科目（かもく）は好（す）きだし得意（とくい）なのですが、理科系（りかけい）の科目（かもく）（ **はというと** ）、まったくだめなんです。
- **中文理解**：我喜欢也擅长文科类科目；至于理科类科目，就完全不行了。

②周（まわ）りの友（とも）だちはみんな結婚（けっこん）して、子育（こそだ）てに忙（いそが）しそうです。わたし（ **はというと** ）、仕事（しごと）がおもしろくて、結婚（けっこん）のことを考（かんが）える暇（ひま）がありません。
- **中文理解**：身边的朋友都结了婚，似乎正忙着育儿。至于我，工作很有意思，根本没空考虑结婚。

③ここ10年間（じゅうねんかん）で保育所（ほいくしょ）の数（かず）は大幅（おおはば）に増（ふ）えたようだ。しかし、わたしの地域（ちいき）（ **はというと** ）、まったく増（ふ）えていない。
- **中文理解**：近十年托儿所数量似乎大幅增加了；可说到我所在的地区，却完全没有增加。

**接続（せつぞく）** N（＋助詞（じょし））＋ はというと
▶ すでに述（の）べた人（ひと）・物（もの）・状況（じょうきょう）と比（くら）べながら、別（べつ）の一方（いっぽう）を話題（わだい）として取（と）り上（あ）げる。（一边与已经提到的人、物或情况作比较，一边把另一方作为话题提出。）

**【扩展说明】**
后项经常与前项形成鲜明对比，但不必是逻辑上的完全对立。它比普通的「Nは」更有“把镜头转到N看看”的感觉，也常用于自嘲或叙事转换。

### 17・8 〜といったら ★2

**【意味（いみ）】〜の程度（ていど）は本当（ほんとう）に (要说……，那可真是……)**

①この施設（しせつ）のスタッフたちの懸命（けんめい）な働（はたら）きぶり（ **といったら** ）、本当（ほんとう）に頭（あたま）が下（さ）がる。
- **中文理解**：要说这家设施的员工们工作有多拼命，真让人由衷敬佩。

②彼（かれ）はこの犬（いぬ）をとてもかわいがっている。そのかわいがり方（かた）（ **といったら** ）、あきれるほどだ。
- **中文理解**：他非常宠爱这条狗；那种宠法，简直到了让人看不下去的程度。

③山（やま）の中（なか）の一軒家（いっけんや）に、たった1人（ひとり）で泊（と）まったんです。あのときの怖（こわ）さ（ **といったら** ）、今（いま）思（おも）い出（だ）してもぞっとします。
- **中文理解**：我独自住在深山的一栋孤屋里。那时有多可怕，现在想起来还毛骨悚然。

**接続（せつぞく）** N ＋ といったら
▶ 驚（おどろ）き・感動（かんどう）・あきれ・恐怖（きょうふ）などの感情（かんじょう）を込（こ）め、Nの程度（ていど）が非常（ひじょう）に高（たか）いことを話題（わだい）にする。（带着惊讶、感动、无奈或恐惧等感情，强调N的程度非常高。）

**【扩展说明】**
后项常是评价或感叹，也可省略，让听者体会其程度，如「あの暑さといったら……」。常见加强形式「〜といったらない／ありはしない」表示“无比……”。不要与单纯转换话题的「といえば」混淆。

### 17・9 〜のこととなると ★2

**【意味（いみ）】〜の話題（わだい）・問題（もんだい）になると (一谈到……；一遇到……的问题)**

①川上（かわかみ）君（くん）は仕事（しごと）にはあまり熱心（ねっしん）ではないが、車（くるま）（ **のこととなると** ）目（め）が輝（かがや）く。
- **中文理解**：川上工作不太积极，但一谈到汽车，眼睛就亮了。

②自分（じぶん）の子（こ）ども（ **のこととなると** ）、自己（じこ）中心的（ちゅうしんてき）になってしまう母親（ははおや）が多（おお）い。
- **中文理解**：很多母亲一遇到与自己孩子有关的事，就会变得只顾自己一方。

- **中文理解**：山田会长平时很严厉，可一谈到孙辈，表情就温柔得像变了个人。

**接続（せつぞく）** N ＋ のこととなると
▶ 特定（とくてい）の人（ひと）・物（もの）に関（かん）する話題（わだい）や問題（もんだい）になると、普段（ふだん）とは違（ちが）う強（つよ）い関心（かんしん）・態度（たいど）・反応（はんのう）が現（あらわ）れることを表（あらわ）す。（表示一涉及特定人或事物的话题，就显露出不同于平常的强烈兴趣、态度或反应。）

**【扩展说明】**
重点不是“开始谈论”这个动作本身，而是特定领域触发了人物的特殊反应。更一般的「Nとなると」还可表示“一旦到了N这种条件／阶段”，如「試験となると緊張する」；「Nのこととなると」更明确地指“关于N的事情”。

### 17・10 〜ときたら ★1

**【意味（いみ）】〜は本当（ほんとう）に困（こま）ったものだ (说起……可真是……)**

①うちの子（こ）（ **ときたら** ）、朝（あさ）から晩（ばん）までいたずらばかりしているんですよ。
- **中文理解**：说起我家那孩子，从早到晚尽在恶作剧。

②周（まわ）りの家（いえ）はみんなきれいなのに、我が家（わがや）（ **ときたら** ）、草（くさ）がいっぱい生（は）えている。
- **中文理解**：周围的人家都收拾得很漂亮，可我家倒好，院里长满了草。

③田中（たなか）君（くん）（ **ときたら** ）、毎日（まいにち）インスタントラーメンを食（た）べているんだよ。体（からだ）によくないよね。
- **中文理解**：说起田中，他每天都吃方便面，对身体不好吧。

**接続（せつぞく）** N ＋ ときたら
▶ 身近（みぢか）な人（ひと）・物（もの）を話題（わだい）にし、その困（こま）った性質（せいしつ）や行動（こうどう）に対（たい）する非難（ひなん）・不満（ふまん）・あきれを表（あらわ）す。（把身边的人或事物作为话题，表达对其令人头疼的性格或行为的责备、不满或无奈。）

**【扩展说明】**
