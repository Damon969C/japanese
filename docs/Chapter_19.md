# 19 原因（げんいん）・理由（りゆう） (原因・理由)

物事（ものごと）がそのようになった原因（げんいん）、あるいは感（かん）じ方（かた）・考（かんが）え・判断（はんだん）の理由（りゆう）や根拠（こんきょ）を述（の）べるとき、どんな言（い）い方（かた）がありますか。 (说明事情形成的原因，或感觉、想法、判断的理由与根据时，可以使用哪些表达方式呢？)

| 功能 | 句型 | 核心语感 |
| :--- | :--- | :--- |
| 客观说明原因 | 〜によって／〜による、〜から、〜ことから | 由于……；由……引起 |
| 表示受益或归咎 | 〜おかげで、〜せいで | 多亏……；都怪…… |
| 辩解或强调唯一原因 | 〜ものだから、〜ばかりに | 因为嘛……；偏偏只因…… |
| 告示中的正式理由 | 〜につき | 因……（公告用语） |
| 以前提引出责任、判断 | 〜からには、〜以上（いじょう）（は）、〜上（うえ）は | 既然……就…… |
| 强调真正原因 | 〜からこそ、〜ばこそ | 正因为……才…… |
| 根据人物或迹象推断 | 〜のことだから、〜ところを見（み）ると | 以其性格／眼前迹象来看 |
| 原因与结果程度相称 | 〜だけに | 正因为……，所以更…… |
| 程度过强而产生结果 | 〜あまり（に） | 过于……以至于…… |
| 特殊情形引发自然结果 | 〜とあって | 因正值／因为是…… |
| 否定某身份并提出判断 | 〜ではあるまいし | 又不是…… |
| 顾及立场、情面 | 〜手前（てまえ） | 因已经……，碍于情面…… |

## 学習前（がくしゅうまえ）の小（しょう）テスト (课前小测验)

### 知（し）っていますか

[ a. おかげで　b. による　c. 以上（いじょう）は　d. のことだから　e. につき ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。

①全国（ぜんこく）の小学校（しょうがっこう）で、インフルエンザ（ **b. による** ）休校（きゅうこう）が増（ふ）えている。
- **中文理解**：全国各地的小学中，因流感而停课的情况正在增加。

②先輩（せんぱい）が親切（しんせつ）に教（おし）えてくれた（ **a. おかげで** ）、新入（しんにゅう）社員（しゃいん）のわたしも会社（かいしゃ）に早（はや）く慣（な）れることができた。
- **中文理解**：多亏前辈耐心指导，作为新员工的我也很快适应了公司。

③あのまじめな林（はやし）さん（ **d. のことだから** ）、約束（やくそく）を守（まも）らないということはないだろう。
- **中文理解**：林一向那么认真，应该不会不守约。

④みんなの前（まえ）でわたしが「やる」と言（い）った（ **c. 以上（いじょう）は** ）、何（なに）があっても最後（さいご）までやります。
- **中文理解**：既然我当着大家的面说了要做，无论发生什么都会坚持到底。

⑤録音中（ろくおんちゅう）（ **e. につき** ）、ノックをしないでください。
- **中文理解**：正在录音，请勿敲门。

### 使（つか）えますか

正（ただ）しい方（ほう）を選（えら）びなさい。

①これだけのお金（かね）を使（つか）ったからには、（ **a. 失敗（しっぱい）は許（ゆる）されない。** ）
- **中文理解**：既然花了这么多钱，就不能失败。

②子（こ）どものころに重（おも）い病気（びょうき）をしたせいで、（ **b. わたしは今（いま）でも体（からだ）が弱（よわ）い。** ）
- **中文理解**：因为小时候得过重病，我现在身体仍然很弱。

③リンさんは漫画家（まんがか）だけあって、（ **a. 人（ひと）の表情（ひょうじょう）を描（か）くのがうまい。** ）
- **中文理解**：林不愧是漫画家，很会画人物表情。

④部屋（へや）の電気（でんき）が消（き）えているところを見（み）ると、（ **a. 田中（たなか）さんは留守（るす）なのだろう。** ）
- **中文理解**：看房间的灯关着，田中大概不在家。

⑤初（はじ）めに水（みず）を1cc（いちシーシー）加（くわ）えなかったばかりに、（ **a. 実験（じっけん）は失敗（しっぱい）してしまった。** ）
- **中文理解**：只因一开始没有加入 1 cc 的水，实验失败了。

## 19Ⅰ　直接的（ちょくせつてき）な原因（げんいん）・理由（りゆう）

### 19Ⅰ・1 〜によって・〜による ★3

**【意味（いみ）】〜が原因（げんいん）で (由于……；由……造成)**

①この地方（ちほう）は津波（つなみ）（ **によって** ）、大（おお）きな被害（ひがい）が出（で）た。
- **中文理解**：这一地区因海啸遭受了严重损失。

②ABC店（エービーシーてん）は売（う）り上（あ）げが落（お）ちたこと（ **によって** ）、ついに店（みせ）を閉（し）めることとなった。
- **中文理解**：ABC 店由于营业额下降，最终走到了关门的地步。

③酒（さけ）を飲（の）んで運転（うんてん）をしてはいけないのだが、実際（じっさい）には、飲酒（いんしゅ）運転（うんてん）（ **による** ）事故（じこ）が多（おお）い。
- **中文理解**：酒后不得驾车，但现实中由酒驾引发的事故很多。

**接続（せつぞく）** N ＋ によって　／　N ＋ による ＋ N
▶ 原因（げんいん）と、その結果（けっか）として生（しょう）じた出来事（できごと）・変化（へんか）を比較的（ひかくてき）客観的（きゃっかんてき）に述（の）べる。受身（うけみ）の動作主（どうさしゅ）や手段（しゅだん）を示（しめ）す「によって」とは、文脈（ぶんみゃく）で区別（くべつ）する。（较客观、偏书面地说明原因及其结果。还可表示被动句的施事者或手段，需结合语境辨别。）

**【扩展说明】**
修饰名词时用「NによるN」，不用「NによってのN」。例③是“由酒驾引发的事故”；「インターネットによる注文」则通常表示“通过互联网下的订单”，属于手段用法，并非原因。

### 19Ⅰ・2 〜から・〜ことから・〜ところから ★3

**【意味（いみ）】〜が原因（げんいん）・根拠（こんきょ）で (由……；根据……)**

①栄養（えいよう）の不足（ふそく）（ **から** ）、病気（びょうき）になる子（こ）どもがいる。
- **中文理解**：有些孩子因营养不足而患病。

②子（こ）どもの火遊（ひあそ）び（ **から** ）、火事（かじ）になった。
- **中文理解**：孩子玩火引发了火灾。

③この辺（あた）りは富士山（ふじさん）がよく見（み）える（ **ことから** ）、富士見町（ふじみちょう）と呼（よ）ばれるようになった。
- **中文理解**：这一带因为能清楚看见富士山，后来被称为“富士见町”。

④彼女（かのじょ）はスペイン語（ご）ができるという（ **ことから** ）、旅行団（りょこうだん）の通訳（つうやく）に選（えら）ばれた。
- **中文理解**：鉴于她会西班牙语，她被选为旅行团的口译员。

⑤犯人（はんにん）たちの食（た）べ残（のこ）した食事（しょくじ）がまだ温（あたた）かい（ **ところから** ）、犯人（はんにん）はまだ遠（とお）くへは行（い）っていないと思（おも）われた。
- **中文理解**：根据犯人吃剩的饭菜仍有余温这一迹象，推断他们还没有走远。

**接続（せつぞく）** N ＋ から　／　普通形（ふつうけい）（ナAは「〜な／〜である」、Nは「〜である」）＋ ことから・ところから
▶ 「Nから」は原因（げんいん）・起点（きてん）を簡潔（かんけつ）に示（しめ）す。「〜ことから」は名称（めいしょう）の由来（ゆらい）や判断（はんだん）の根拠（こんきょ）を示（しめ）し、「〜ところから」は目（め）に見（み）える具体的（ぐたいてき）な点（てん）・様子（ようす）を手（て）がかりにする、やや硬（かた）い言（い）い方（かた）である。（「Nから」简洁表示原因或起点；「ことから」常说明命名由来或判断依据；「ところから」多把可观察到的具体迹象作为线索，语气较正式。）

**【扩展说明】**
「ことから」不是普通口语「から」的机械替换。它把前项作为可说明、可引用的“事实依据”，因此常见于命名、选定、推断和客观说明。「ところから」在现代日语中使用范围较窄，许多场合改用「ところを見ると」更自然。

### 19Ⅰ・3 〜おかげで・〜おかげか・〜おかげだ ★3

**【意味（いみ）】〜の影響（えいきょう）で、望（のぞ）ましい結果（けっか）になって (多亏……；托……的福)**

①田中（たなか）さんが紹介（しょうかい）してくださった（ **おかげで** ）、店（みせ）にいい人（ひと）が来（き）てくれることになりました。
- **中文理解**：多亏田中介绍，店里将有一位优秀的人来帮忙了。

②あなたがこの手紙（てがみ）を訳（やく）してくださった（ **おかげで** ）、この手紙（てがみ）の意味（いみ）が分（わ）かりました。
- **中文理解**：多亏您帮我翻译这封信，我才明白信的内容。

③道路（どうろ）工事（こうじ）が終（お）わって静（しず）かになった（ **おかげか** ）、昨夜（さくや）はよく眠（ねむ）れた。
- **中文理解**：也许是道路施工结束、周围安静下来的缘故，昨晚睡得很好。

④楽（たの）しく旅行（りょこう）ができたのは、清水（しみず）さんといういいガイドさん（ **のおかげだ** ）。
- **中文理解**：这次旅行能如此愉快，全靠清水这位好导游。

⑤「ご卒業（そつぎょう）おめでとうございます」
「先生（せんせい）、（ **おかげさまで** ）。ありがとうございます」
- **中文理解**：“祝贺你毕业。”“老师，多亏您的关照。谢谢您。”

**接続（せつぞく）** 普通形（ふつうけい）（ナAな／Nの）＋ おかげで・おかげか・おかげだ
▶ 人（ひと）の助（たす）けだけでなく、出来事（できごと）・状態（じょうたい）の好（よ）い影響（えいきょう）によって望（のぞ）ましい結果（けっか）が得（え）られた、と感謝（かんしゃ）や評価（ひょうか）を込（こ）めて述（の）べる。「おかげか」は原因（げんいん）を断定（だんてい）せず、「おかげだ」は「〜のは〜おかげだ」の形（かたち）でよく使（つか）う。（不仅用于人的帮助，也可表示某件事或状态带来了有利影响。「おかげか」是不完全确定原因；「おかげだ」常用于「〜のは〜おかげだ」。）

**【扩展说明】**
「おかげで」的核心是“把结果归功于前项”，并不要求前项有意帮助。也可反讽地说「君のおかげで電車に乗り遅れた」，此时表面用“多亏”，实际是在责怪对方；普通负面原因宜用「せいで」。

### 19Ⅰ・4 〜せいで・〜せいか・〜せいだ ★3

**【意味（いみ）】〜が原因（げんいん）で、好（この）ましくない結果（けっか）になって (因为……；都怪……)**

①きのうまで休（やす）みが3日（みっか）続（つづ）いた（ **せいで** ）、今日（きょう）は道（みち）がとても込（こ）んでいる。
- **中文理解**：可能因截至昨天连休三天，今天路上非常拥堵。

②祖父（そふ）は年（とし）（ **のせいで** ）、物忘（ものわす）れがひどくなった。
- **中文理解**：祖父因为上了年纪，健忘得更厉害了。

③昨夜（さくや）、遅（おそ）くまで飲（の）みすぎた（ **せいか** ）、頭（あたま）が痛（いた）い。
- **中文理解**：也许是昨晚喝酒喝得太多、又喝到很晚，今天头疼。

④兄（あに）が太（ふと）りすぎているのは、運動（うんどう）をしない（ **せいだ** ）と思（おも）う。
- **中文理解**：我觉得哥哥过胖是因为不运动。

**接続（せつぞく）** 普通形（ふつうけい）（ナAな／Nの）＋ せいで・せいか・せいだ
▶ 前（まえ）の事柄（ことがら）に好（この）ましくない結果（けっか）の責任（せきにん）を負（お）わせる言（い）い方（かた）。「せいか」は原因（げんいん）を断定（だんてい）せず、「せいだ」は「〜のは〜せいだ」の形（かたち）でよく使（つか）う。（把不理想结果归咎于前项，常带责怪或消极评价。「せいか」表示不确定，「せいだ」常见于判断句。）

**【扩展说明】**
「年のせい」「気のせい」等固定搭配未必是在责怪某个人，但仍带“原因造成了不理想现象”的视角。正面结果原则上用「おかげで」，不要机械地把所有“因为”都译成「せいで」。

### 19Ⅰ・5 〜ものだから・〜もので・〜もの／〜もん ★2

**【意味（いみ）】〜ので、仕方（しかた）がなかった (因为……嘛；是因为……)**

①「昨夜（さくや）の地震（じしん）、気（き）がつかなかったんですか」
「ええ、よく寝（ね）ていた（ **ものですから** ）」
- **中文理解**：“昨晚的地震，你没察觉吗？”“嗯，因为当时睡得很熟。”

②先週（せんしゅう）は忙（いそが）しかった（ **ものだから** ）、お返事（へんじ）するのが遅（おそ）くなりました。
- **中文理解**：因为上周实在太忙，回信晚了。

③明日（あした）の夜（よる）は友（とも）だちが泊（と）まりに来（く）る（ **もので** ）、飲（の）み会（かい）には出（で）られません。
- **中文理解**：因为明晚有朋友来住，我不能参加聚餐。

④「今日（きょう）の授業（じゅぎょう）にいなかったね」
「うん、あの授業（じゅぎょう）、面白（おもしろ）くない（ **もの** ）」
- **中文理解**：“你今天没来上课啊。”“嗯，因为那门课没意思嘛。”

⑤「え、そんなにたくさん食（た）べるの」
「だって、これ、おいしいんだ（ **もん** ）」
- **中文理解**：“咦，要吃那么多吗？”“因为这个好吃嘛。”

**接続（せつぞく）** 普通形（ふつうけい）（ナA・Nは「〜な」）＋ ものだから・もので　／　普通形（ふつうけい）＋ もの・もん
▶ 「ものだから／もので」は事情（じじょう）を説明（せつめい）し、「だから仕方（しかた）がなかった」という弁解（べんかい）・弁明（べんめい）の気持（きも）ちを添（そ）える。そのため、後（あと）に命令（めいれい）・依頼（いらい）・勧誘（かんゆう）などの働（はたら）きかけは来（き）にくい。（说明情况并暗示“所以也是没办法”，常用于辩解；后项通常不接命令、请求、劝诱等对听者的要求。）

**【扩展说明】**
礼貌说明用「ものですから」，较正式的书面说明可用「もので」。句末「もの／もん」直接给出理由，语气带撒娇、申辩或不服；「もん」更随意，成人会话中也能用，但正式场合应避免。它与表示常理的「ものだ」不是同一用法。

### 19Ⅰ・6 〜ばかりに ★2

**【意味（いみ）】ただ〜だけが原因（げんいん）で (偏偏只因为……；就因为……)**

①本当（ほんとう）のことを言（い）った（ **ばかりに** ）、みんなから仲間外（なかまはず）れにされてしまった。
- **中文理解**：只因说了实话，结果被大家排挤了。

②わたしが部屋（へや）の番号（ばんごう）を間違（まちが）えて書（か）いた（ **ばかりに** ）、大切（たいせつ）な郵便物（ゆうびんぶつ）が相手（あいて）に届（とど）かなかった。
- **中文理解**：就因为我写错了房间号码，重要邮件没能送到对方手中。

③外国（がいこく）に行（い）きたい（ **ばかりに** ）、荷物（にもつ）の中（なか）に隠（かく）れて船（ふね）に乗（の）る人（ひと）がいるそうだ。
- **中文理解**：听说有人一心只想出国，甚至藏进行李中上船。

④身長（しんちょう）が162cm（ひゃくろくじゅうにセンチ）ない（ **ばかりに** ）、航空（こうくう）会社（がいしゃ）の客室（きゃくしつ）乗務員（じょうむいん）になれなかった。
- **中文理解**：只因身高不到 162 厘米，没能成为航空公司的客舱乘务员。

**接続（せつぞく）** 普通形（ふつうけい）（ナAは「〜な／〜である」、Nは「〜である」）＋ ばかりに
▶ その一（ひと）つの原因（げんいん）のために、予想外（よそうがい）で好（この）ましくない結果（けっか）が起（お）きた、と後悔（こうかい）・非難（ひなん）・残念（ざんねん）な気持（きも）ちを込（こ）めて述（の）べる。（强调偏偏就是这一原因导致了意外或不理想的结果，常带后悔、责怪或遗憾。）

**【扩展说明】**
「〜たいばかりに」表示愿望强烈到把它当成唯一目标，后项常是极端、不妥或不惜代价的行动；重点不是“做了自己不想做的事”。「薬を飲んだばかりに治った」若只是正面结果通常不自然，但在讽刺或“反而造成麻烦”的语境中可以成立。

### 19Ⅰ・7 〜につき ★2

**【意味（いみ）】〜のため (因……；由于……)**

①改装中（かいそうちゅう）（ **につき** ）、10月（じゅうがつ）31日（さんじゅういちにち）まで休（やす）ませていただきます。（店（みせ）の張（は）り紙（がみ））
- **中文理解**：因店内装修，歇业至 10 月 31 日。（店面告示）

②11月（じゅういちがつ）3日（みっか）は祭日（さいじつ）（ **につき** ）、休業（きゅうぎょう）します。（事務所（じむしょ）の張（は）り紙（がみ））
- **中文理解**：11 月 3 日为节假日，故暂停营业。（事务所告示）

③会議中（かいぎちゅう）（ **につき** ）、103号室（ひゃくさんごうしつ）は4時（よじ）まで使用（しよう）できません。（注意書（ちゅういが）き）
- **中文理解**：因正在开会，103 室在 4 点前不能使用。（注意事项）

**接続（せつぞく）** N ＋ につき
▶ お知（し）らせ・掲示（けいじ）・張（は）り紙（がみ）・改（あらた）まった通知文（つうちぶん）で、理由（りゆう）を簡潔（かんけつ）に示（しめ）す硬（かた）い定型（ていけい）表現（ひょうげん）。日常（にちじょう）会話（かいわ）の個人的（こじんてき）な理由（りゆう）には普通（ふつう）使（つか）わない。（公告、告示和正式通知中简洁说明理由的固定书面语，通常不用于日常会话中的个人理由。）

**【扩展说明】**
「一人につき二枚」中的「につき」表示“每……”，与本节的原因用法不同，应根据后项是通知理由还是数量分配来判断。

## 19Ⅱ　前提（ぜんてい）・根拠（こんきょ）・強調（きょうちょう）された理由（りゆう）

### 19Ⅱ・1 〜からには・〜からは ★3

**【意味（いみ）】〜のだから、当然（とうぜん） (既然……就……)**

①県（けん）の代表（だいひょう）になって全国（ぜんこく）大会（たいかい）に出（で）る（ **からには** ）、勝（か）ってメダルを持（も）って帰（かえ）りたい。
- **中文理解**：既然作为县代表参加全国大赛，就想取胜并带奖牌回来。

②タイに住（す）む（ **からには** ）、タイ語（ご）が少（すこ）し話（はな）せた方（ほう）がいいだろう。
- **中文理解**：既然要住在泰国，最好会说一点泰语吧。

③子（こ）どもがいじめられているのを見（み）た（ **からには** ）、黙（だま）って見（み）ていることはできない。
- **中文理解**：既然看见孩子正在受欺负，就不能默不作声地旁观。

④こちらからお願（ねが）いする（ **からは** ）、わたしたちもできるだけのことをいたします。
- **中文理解**：既然是我们主动拜托您，我们也会尽己所能。

**接続（せつぞく）** 普通形（ふつうけい）（ナA・Nは「〜である」）＋ からには・からは
▶ 前（まえ）の事実（じじつ）・選択（せんたく）を受（う）けて、「そうである以上（いじょう）、後（あと）の判断（はんだん）・決意（けつい）・義務（ぎむ）は当然（とうぜん）だ」と強（つよ）く述（の）べる。後項（こうこう）には意志（いし）・義務（ぎむ）・勧告（かんこく）・禁止（きんし）・確信（かくしん）などが来（く）る。（以前项已成立的事实或选择为前提，强调后项的决心、义务、劝告、禁止或确信是理所当然的。）

**【扩展说明】**
「からには」重心在后项，即“既然如此，接下来就该怎样”。「からこそ」则把焦点放在前项，强调“真正的原因正是这个”。「からは」较少见，语气稍显郑重。原说明把「はずだ／に違いない」也统称为“意志”并不准确；它们表达的是说话人的判断或确信。

### 19Ⅱ・2 〜からこそ ★3

**【意味（いみ）】ほかでもなく〜が理由（りゆう）で (正因为……才……)**

①ジムはほかの人（ひと）の2倍（にばい）も勉強（べんきょう）した（ **からこそ** ）、大学（だいがく）に合格（ごうかく）できたのです。
- **中文理解**：吉姆正因为付出了别人两倍的学习量，才考上大学。

②佐藤（さとう）先生（せんせい）に診（み）ていただいた（ **からこそ** ）、この病気（びょうき）が見（み）つかったのです。
- **中文理解**：正因为请佐藤医生诊察，才发现了这种病。

③教師（きょうし）「皆（みな）さんのことが好（す）きだ（ **からこそ** ）、こんな小（ちい）さいことも注意（ちゅうい）するんです」
- **中文理解**：老师：“正因为喜欢大家，我才连这种小事也会提醒。”

④暑（あつ）い時（とき）だ（ **からこそ** ）、熱（あつ）いシャワーを浴（あ）びたい。
- **中文理解**：正因为天气炎热，反而想洗个热水澡。

**接続（せつぞく）** 普通形（ふつうけい）＋ からこそ
▶ 数（かず）ある理由（りゆう）の中（なか）で、前項（ぜんこう）こそが本当（ほんとう）に重要（じゅうよう）な理由（りゆう）だと強調（きょうちょう）する。「〜からこそ、〜のだ」の形（かたち）が多（おお）い。（从多个可能原因中突出前项才是真正、关键的原因，常与后项「のだ」呼应。）

**【扩展说明】**
前项本身可以是负面事实，如「失敗したからこそ分かった」；关键是说话人把它重新评价为产生后项的重要契机。它常用于正面意义、辩护或反常识的主张，但不能绝对解释成“几乎不用负面内容”。

### 19Ⅱ・3 〜ことだし ★2

**【意味（いみ）】〜という事情（じじょう）もあるので (也因为……；考虑到……)**

①雪（ゆき）も降（ふ）ってきた（ **ことだし** ）、今日（きょう）の山登（やまのぼ）りはやめにしよう。
- **中文理解**：雪也下起来了，今天就别爬山了吧。

②12月（じゅうにがつ）30日（さんじゅうにち）の新幹線（しんかんせん）の切符（きっぷ）も買（か）った（ **ことだし** ）、後（あと）は故郷（こきょう）へ帰（かえ）るだけだ。友人（ゆうじん）たちに会（あ）うのが楽（たの）しみだ。
- **中文理解**：12 月 30 日的新干线车票也买好了，接下来只等回故乡了。我很期待见到朋友们。

③夏（なつ）の（ **ことだし** ）、パーティーは庭（にわ）でやりますから、気楽（きらく）にカジュアルな服装（ふくそう）で来（き）てください。
- **中文理解**：考虑到正值夏天，聚会又在院子里举行，请轻松地穿休闲服来吧。

**接続（せつぞく）** 普通形（ふつうけい）（ナAな／Nの）＋ ことだし
▶ 判断（はんだん）・決定（けってい）・提案（ていあん）の理由（りゆう）を一（ひと）つ挙（あ）げるが、ほかにも理由（りゆう）があることを含（ふく）ませる。「〜し」より少（すこ）し改（あらた）まった言（い）い方（かた）。（列举判断、决定或提议的一个理由，同时暗示还有别的理由；比单用「し」略郑重。）

**【扩展说明】**
它不只是“较轻的理由”，更重要的是前项被当作当前决定的一个现成依据。例③「夏のことだし」可视作常见搭配；不能把所有「Nだから」都机械换成「Nのことだし」。

### 19Ⅱ・4 〜以上（いじょう）（は） ★2

**【意味（いみ）】〜のだから、その責任（せきにん）として (既然……就……)**

①オリンピックに出場（しゅつじょう）する（ **以上（いじょう）** ）、メダルを取（と）りたい。
- **中文理解**：既然要参加奥运会，就想拿到奖牌。

②この学校（がっこう）の生徒（せいと）である（ **以上（いじょう）は** ）、学校（がっこう）の規則（きそく）は守（まも）らなければならない。
- **中文理解**：既然是这所学校的学生，就必须遵守校规。

③お金（かね）を払（はら）ってこの博物館（はくぶつかん）に入場（にゅうじょう）した（ **以上（いじょう）** ）、閉館（へいかん）の時間（じかん）まで見（み）ていたい。
- **中文理解**：既然花钱进了这家博物馆，就想一直看到闭馆。

**接続（せつぞく）** 普通形（ふつうけい）（ナA・Nは「〜である」）＋ 以上（いじょう）（は）
▶ 成立（せいりつ）した事実（じじつ）を前提（ぜんてい）に、それに伴（ともな）う責任（せきにん）・覚悟（かくご）・判断（はんだん）を述（の）べる。後項（こうこう）には義務（ぎむ）・決意（けつい）・勧（すす）め・禁止（きんし）・確信（かくしん）などが多（おお）い。（以已成立的事实为前提，说明随之而来的责任、觉悟或判断，语体比「からには」正式。）

**【扩展说明】**
此处「以上」不表示数量上的“以上”。「以上（は）」偏书面、逻辑性强；「からには」更常见于会话，也更直接表现说话人的态度。前项通常不是纯粹未知的假设，而是已经成立或被说话人接受的前提。

### 19Ⅱ・5 〜上（うえ）は ★2

**【意味（いみ）】〜したのだから、覚悟（かくご）を持（も）って (既然已经……就……)**

①大学（だいがく）に進学（しんがく）すると決（き）めた（ **上（うえ）は** ）、しっかり勉強（べんきょう）しなければならない。
- **中文理解**：既然决定升入大学，就必须认真学习。

②マラソン大会（たいかい）を開（ひら）く（ **上（うえ）は** ）、十分（じゅうぶん）な準備（じゅんび）が必要（ひつよう）だ。
- **中文理解**：既然要举办马拉松比赛，就必须做好充分准备。

③会議（かいぎ）でやると決（き）まった（ **上（うえ）は** ）、この企画（きかく）をやりたくなくてもやるしかない。
- **中文理解**：既然会议已经决定实施这个企划，即使不想做也只能去做。

**接続（せつぞく）** Vる・Vた ＋ 上（うえ）は
▶ 決定（けってい）・選択（せんたく）・既成（きせい）の事実（じじつ）を受（う）け、責任（せきにん）・覚悟（かくご）を伴（ともな）う行動（こうどう）が必要（ひつよう）だと述（の）べる、硬（かた）い表現（ひょうげん）。（承接已经作出的决定、选择或既成事实，强调必须以责任和觉悟采取行动，语气正式而坚定。）

**【扩展说明】**
「上は」比「以上は」更容易让人联想到“事情已经走到这一步”。常与「決めた・引き受けた・約束した・始めた」等不可轻易反悔的行为搭配。不要与时间先后的「Vた上で（做完……之后）」混淆。

#### 「からには・以上（いじょう）（は）・上（うえ）は」对比

| 句型 | 语体与焦点 | 典型前项 |
| :--- | :--- | :--- |
| 〜からには | 会话中常见，突出说话人的决意或要求 | 既定事实、自己的选择 |
| 〜以上（いじょう）（は） | 较正式、逻辑性强，突出理应承担的责任 | 已成立或被承认的事实 |
| 〜上（うえ）は | 最郑重、觉悟感最强，强调事已至此不可反悔 | 决定、承诺、开始承担 |

### 19Ⅱ・6 〜のことだから・〜のことだ ★2

**【意味（いみ）】よく知（し）っている〜なのだから (以……的一贯性格来看)**

①あのまじめな佐藤（さとう）さん（ **のことだから** ）、言（い）ったことはきちんとやりますよ。
- **中文理解**：佐藤一向认真，说过的事一定会好好做到。

②「よし子（こ）、遅（おそ）いですね」
「買（か）い物（もの）の好（す）きなよし子（こ）（ **のことだ** ）。また、閉店（へいてん）まで買（か）い物（もの）をしているんだろう」
- **中文理解**：“良子真慢啊。”“她那么爱购物，大概又一直逛到商店关门吧。”

③「ケンタから聞（き）いたんですが、イチローがまり子（こ）と結婚（けっこん）するんだって」
「ケンタ（ **のことだ** ）。また、冗談（じょうだん）で言（い）っているんだろう」
- **中文理解**：“听健太说，一郎要和真理子结婚。”“健太那个人嘛，大概又是在开玩笑。”

**接続（せつぞく）** N ＋ のことだから・のことだ
▶ 話（はな）し手（て）と聞（き）き手（て）が知（し）っている人物（じんぶつ）の性格（せいかく）・習慣（しゅうかん）・事情（じじょう）を根拠（こんきょ）に、その人（ひと）の行動（こうどう）を推量（すいりょう）する。多（おお）くは人（ひと）を表（あらわ）す名詞（めいし）に付（つ）く。（根据双方都了解的某人的性格、习惯或情况，推测此人的行为；通常接表示人的名词。）

**【扩展说明】**
这不是直接的因果连接，而是“依据对这个人的了解作判断”。性格说明可明说，如「まじめな佐藤さんのことだから」，也可像例③那样省略。后项常用「だろう・はずだ・に違いない」。

### 19Ⅱ・7 〜ところを見（み）ると ★2

**【意味（いみ）】目（め）に見（み）える様子（ようす）から判断（はんだん）すると (从……迹象来看)**

①兄（あに）が急（きゅう）に掃除（そうじ）を始（はじ）めた（ **ところを見（み）ると** ）、友（とも）だちが遊（あそ）びに来（く）るんだと思（おも）う。
- **中文理解**：看哥哥突然开始打扫，应该是有朋友要来玩。

②雨（あめ）なのに朝（あさ）から大勢（おおぜい）の若（わか）い人（ひと）が集（あつ）まっている（ **ところを見（み）ると** ）、あの歌手（かしゅ）はよほど人気（にんき）があるのだろう。
- **中文理解**：下着雨却从早上起就聚集了许多年轻人，由此看来那位歌手一定非常受欢迎。

③発売前（はつばいまえ）からインターネットによる注文（ちゅうもん）が多（おお）くて話題（わだい）になっている（ **ところを見（み）ると** ）、あの本（ほん）はベストセラーになるかもしれない。
- **中文理解**：从尚未发售就有大量网络订单并已成为话题来看，那本书可能会成为畅销书。

**接続（せつぞく）** 普通形（ふつうけい）（ナAな／Nの）＋ ところを見（み）ると
▶ 実際（じっさい）に観察（かんさつ）できる行動（こうどう）・状態（じょうたい）を証拠（しょうこ）として、別（べつ）の事柄（ことがら）を推量（すいりょう）する。後項（こうこう）には「〜だろう・〜ようだ・〜かもしれない」などが多（おお）い。（把实际观察到的行为或状态当作证据，进而推测另一件事；后项常见推量表达。）

**【扩展说明】**
这里的「ところ」把前面的整个状态名词化，不是地点。与「ことから」相比，「ところを見ると」更强调说话人面对某个可观察迹象后作出现场式判断，通常不用于单纯说明名称由来。

### 19Ⅱ・8 〜だけに A ★2

**【意味（いみ）】〜なので、それにふさわしく (正因为……，所以相应地……)**

①伊藤（いとう）さんは実力（じつりょく）がある（ **だけに** ）、彼女（かのじょ）の発言（はつげん）は人（ひと）を引（ひ）き付（つ）ける。
- **中文理解**：伊藤正因为有实力，她的发言很有感染力。

②年末（ねんまつ）（ **だけに** ）、飛行機（ひこうき）も列車（れっしゃ）も帰省客（きせいきゃく）や旅行客（りょこうきゃく）で込（こ）んでいる。
- **中文理解**：正值年末，飞机和列车都挤满了返乡及旅行的乘客。

③桜井（さくらい）さんは若（わか）い（ **だけに** ）、理解（りかい）が早（はや）く、仕事（しごと）も手早（てばや）い。
- **中文理解**：樱井正因为年轻，理解得快，做事也麻利。

④今日（きょう）は37度（さんじゅうななど）以上（いじょう）あるそうだ。暑（あつ）さが暑（あつ）さ（ **だけに** ）、少（すこ）し歩（ある）くと大汗（おおあせ）をかく。
- **中文理解**：听说今天超过 37 度。因为热得非同寻常，稍微走几步就会大汗淋漓。

⑤デザインのいいセーターがあったが、2万円（にまんえん）という値段（ねだん）が値段（ねだん）（ **だけに** ）、買（か）わなかった。
- **中文理解**：有件设计不错的毛衣，但毕竟价格高达两万日元，我没有买。

**接続（せつぞく）** N／普通形（ふつうけい）（ナAは「〜な／〜である」、Nは「〜である」）＋ だけに
▶ 前項（ぜんこう）の性質（せいしつ）・程度（ていど）・立場（たちば）から見（み）て、後項（こうこう）の結果（けっか）や評価（ひょうか）が特（とく）に納得（なっとく）できる、または普通（ふつう）以上（いじょう）に強（つよ）く現（あらわ）れると述（の）べる。（表示后项结果或评价与前项性质、程度、身份相称，或正因前项而表现得格外明显。）

**【扩展说明】**
「NがNだけに」重复同一名词，表示该事物的程度、性质或分量非同一般，如「問題が問題だけに慎重に扱う」。例④⑤不是简单重复，而是提示“正因为这个热度／这个价格很特殊”。

### 19Ⅱ・8 〜だけに B ★2

**【意味（いみ）】〜だからこそ、予想（よそう）との差（さ）が大（おお）きく (正因为……，反而更……)**

①勝（か）てると思（おも）っていた（ **だけに** ）、負（ま）けた時（とき）のショックは大（おお）きかった。
- **中文理解**：正因为原以为能赢，落败时受到的打击才格外大。

②ケンタは家（いえ）が近（ちか）い（ **だけに** ）、かえって遅刻（ちこく）が多（おお）い。
- **中文理解**：健太正因为家近，反而经常迟到。

③今村（いまむら）さんは若（わか）い（ **だけに** ）、地味（じみ）なセーターがかえって彼女（かのじょ）の美（うつく）しさを引（ひ）き立（た）てている。
- **中文理解**：今村正因为年轻，朴素的毛衣反而更衬托出她的美。

**接続（せつぞく）** N／普通形（ふつうけい）（ナAは「〜な／〜である」、Nは「〜である」）＋ だけに
▶ 基本（きほん）の仕組（しく）みはAと同（おな）じだが、期待（きたい）が強（つよ）かったため失望（しつぼう）も大（おお）きい、または前項（ぜんこう）の性質（せいしつ）が普通（ふつう）とは反対（はんたい）の結果（けっか）を際立（きわだ）たせる。「かえって」とよく使（つか）う。（机制与 A 相同，但后项可表现“期待越强，失望越大”，或让前项性质反而突显出与通常预期相反的结果，常与「かえって」连用。）

**【扩展说明】**
A、B 并非两个完全不同的语法。共同核心都是“前项越突出，后项越显著”。A 的后项符合通常预期；B 的后项与表面预期形成落差。例①没有「かえって」，但“本以为会赢”与“实际输了”的落差已经足够明确。

### 19Ⅱ・9 〜あまり（に）・あまりの〜に ★2

**【意味（いみ）】程度（ていど）が極端（きょくたん）なので (过于……以至于……)**

①質問（しつもん）は簡単（かんたん）だったのに、緊張（きんちょう）した（ **あまり** ）答（こた）えられなかった。

### 19Ⅱ・13 〜手前（てまえ） ★1

**【意味（いみ）】自分（じぶん）の発言（はつげん）・立場（たちば）・面目（めんぼく）があるので (碍于情面；顾及立场)**

- **中文理解**：既然已经当众说了“我来做”，碍于面子，不能再退缩。

②T社（ティーしゃ）にはいつも世話（せわ）になっている（ **手前（てまえ）** ）、今回（こんかい）もまた無理（むり）をお願（ねが）いすることはできない。
- **中文理解**：一直承蒙 T 公司关照，碍于这层情面，这次不能再提出过分的请求。

③田中（たなか）さんは子（こ）どもにディズニーランドへ連（つ）れていくと約束（やくそく）した（ **手前（てまえ）** ）、今年（ことし）はどうしても行（い）かなければならないそうだ。
- **中文理解**：田中已经答应孩子带他们去迪士尼乐园，为了不失信，听说今年无论如何都得去。

**接続（せつぞく）** Vる・Vた・Vている／Nの ＋ 手前（てまえ）
▶ 自分（じぶん）が言（い）ったこと・したこと、受（う）けている恩（おん）、または人（ひと）との関係（かんけい）のため、他人（たにん）からどう見（み）られるかを考（かんが）えると、自由（じゆう）に行動（こうどう）できないことを表（あらわ）す。（由于自己的言行、所受恩惠或与他人的关系，顾及别人如何看待自己，因而不能随意行动。）

**【扩展说明】**
它不等于单纯的“因为”。后项多为「〜できない・〜しかない・〜なければならない」等受约束的选择。「子どもの手前、弱音を吐けない」中的「Nの手前」还可表示“当着某人的面／顾及某人的眼光”。

#### 原因表达的主观评价对比

| 句型 | 说话人的评价 | 常见结果 |
| :--- | :--- | :--- |
| 〜によって／〜ことから | 尽量客观 | 中性事实、判断依据 |
| 〜おかげで | 归功、感谢 | 有利结果（反讽除外） |
| 〜せいで | 归咎、不满 | 不利结果 |
| 〜ばかりに | 后悔“偏偏只因这一点” | 意外且不理想的结果 |
| 〜あまり（に） | 强调程度失控 | 非常态或不由自主的结果 |
