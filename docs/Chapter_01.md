# 第1章 行為（こうい）の対象（たいしょう） (动作行为的对象)

**核心提示**：行為（こうい）が向（む）かう相手（あいて）やものごとを示（しめ）したいときは、どんな言（い）い方（かた）がありますか。（当想表达行为所指向的对手或事物时，有哪些表达方式呢？）

---

## 0. 導入（どうにゅう） (引入)

### 知（し）っていますか (你知道吗？)
**[ ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。**
（使用方框中的词语，完成句子。1个词语只能使用1次。）
【选项：a. について b. に対（たい）して c. 向（む）きに d. にこたえて e. をめぐって】

1. わたしは日本（にほん）の民謡（みんよう）[ a. について ] 調（しら）べている。
   - **中文理解**：我正在调查关于日本民谣的事情。

2. 大会（たいかい）ではみんなの期待（きたい）[ d. にこたえて ] 、精一杯（せいいっぱい）がんばろうと思（おも）う。
   - **中文理解**：在大会上，为了回应大家的期待，我打算拼尽全力努力。

3. この本（ほん）は、専門家（せんもんか）ではなく一般（いっぱん）の人（ひと）[ c. 向（む）きに ] 書（か）かれている。
   - **中文理解**：这本书不是面向专家，而是按适合一般读者的方式写的。

4. いつもまじめな田中（たなか）さん[ b. に対（たい）して ] 、山田（やまだ）さんはいつも不真面目（ふまじめ）だ。
   - **中文理解**：与总是很认真的田中相比，山田总是不太正经。（这里表示对比）

5. その事件（じけん）[ e. をめぐって ] 、様々（さまざま）なうわさが流（なが）れている。
   - **中文理解**：围绕那个事件，流传着各种各样的传闻。

### 使（つか）えますか (你会用吗？)
**どちらが正（ただ）しいですか。正（ただ）しい方（ほう）を選（えら）びなさい。**
（哪一个是正确的？请选择正确的一方。）

1. この本（ほん）は小学生（しょうがくせい）｛ **a. 向（む）けに** b. 向（む）きに｝書（か）かれた本（ほん）です。
   - **中文理解**：这本书是面向小学生写的书。

2. 彼（かれ）の発言（はつげん）｛ **a. に対（たい）して** b. について｝、何（なに）か意見（いけん）のある方（かた）は手（て）を挙（あ）げてください。
   - **中文理解**：对于他的发言，有意见的人请举手。

3. わたしはあの人（ひと）に関（かん）して、｛ **a. 何（なに）も知（し）らないのです。** b. あまり好（す）きではありません。｝
   - **中文理解**：关于那个人，我什么都不知道。

4. ｛ **a. 社員（しゃいん）たちの要望（ようぼう）にこたえて、** b. 社長（しゃちょう）の反対（はんたい）にこたえて、｝社員旅行（しゃいんりょこう）は2泊（にはく）3日（みっか）と決定（けってい）した。
   - **中文理解**：回应员工们的要求，员工旅行决定为三天两夜。

5. 土地（とち）の問題（もんだい）をめぐって、｛a. あなたにお話（はな）ししておきたいことがあります。 **b. 兄弟（きょうだい）の争（あらそ）いが続（つづ）いている。** ｝
   - **中文理解**：围绕土地问题，兄弟间的争斗仍在持续。

## 1-1 ～について
【接続（せつぞく）】N ＋ について
【意味（いみ）】〜のことに関（かん）して（关于～）
▶ 話（はな）す・聞（き）く・考（かんが）える・書（か）く・調（しら）べるなどの行為（こうい）の対象（たいしょう）を言（い）うときに使（つか）う。（用于说明说、听、想、写、调查等行为所涉及的主题或对象。）

### 例文（れいぶん） (例句)

1. この町（まち）の歴史（れきし） **について** 調（しら）べています。
   - **中文理解**：我正在调查关于这个城市的历史。

2. 田中（たなか）さん、この番組（ばんぐみ） **について** どう思（おも）われますか。
   - **中文理解**：田中先生，关于这个节目您怎么看？

3. この本にはトマトの育（そだ）て方（かた） **について** 詳（くわ）しく書（か）いてある。
   - **中文理解**：这本书里详细地写了关于番茄的种植方法。

4. 兄（あに）は文学（ぶんがく） **について** はまったく無関心（むかんしん）なんです。
   - **中文理解**：哥哥对文学完全不感兴趣。

**【拡張説明】(扩展说明)**
「について」和「に関して」都可以表示“关于”，但「について」多用于日常、具体的事务，而「に関して」更偏向正式场合或较正式的主题说明。后接名词时，变为「〜についてのN」。

- 「〜については」可以把某个话题单独提出来说明，常有“至于～”的语感。
- 「好き・嫌い・親切・失礼」这类直接表达态度或感情的词，通常不用「について」标对象，而多用「に対して」或其他格助词。

## 1-2 ～に対（たい）して・～に対（たい）する
【接続（せつぞく）】N ＋ に対（たい）して
【意味（いみ）】〜に／〜を相手（あいて）として（对～ / 以～为对象）
▶ 「何（なに）に向（む）かってそうするか・そう感（かん）じるか」を言（い）うとき、その相手（あいて）や対象（たいしょう）を示（しめ）す。（在说明“行为、态度、感情、评价朝向谁/什么”时，表示其对象。）

### 例文（れいぶん） (例句)

1. この老人（ろうじん）ホームのスタッフたちは、お年寄（としよ）り **に対して** ほんとうにやさしいです。
   - **中文理解**：这家养老院的工作人员们，对老人们真的非常温柔。

2. 今（いま）のランさんの発言（はつげん） **に対して** 、何（なに）か意見（いけん）のある方（かた）は手（て）を上（あ）げてください。
   - **中文理解**：对于刚才阿兰的发言，有意见的人请举手。

3. ご迷惑（めいわく）をおかけした方々（かたがた） **に対しまして** 、心（こころ）からおわびいたします。
   - **中文理解**：向被我们添了麻烦的各位，由衷地表示歉意。（「に対しまして」是更郑重的表达）

4. 鈴木（すずき）先生 **に対する** わたしの気持（きも）ちは昔（むかし）も今（いま）も変（か）わりません。
   - **中文理解**：我对铃木老师的感情过去和现在都没有改变。

**【拡張説明】(扩展说明)**
除了表示“对象、针对”，「に対して」还可以表示“对比”，例如「Aに対してB」可译为“与 A 相比，B 则……”。但在本节中，重点考察其表示“行为对象”的用法。修饰名词时通常用「〜に対するN」。

- 「発言に対して意見を言う」强调“针对那段发言作出反应”。
- 「発言について話す」则偏向“以那段发言为话题来谈”。

## 1-3 ～向（む）け
【接続（せつぞく）】N ＋ 向（む）け
【意味（いみ）】〜のために／〜を対象（たいしょう）として（面向～ / 为～而制作）
▶ 商品（しょうひん）・本（ほん）・サービスなどが「〜を対象（たいしょう）として作（つく）られた／用意（ようい）された」と言（い）いたいときに使（つか）う。（用于表达商品、书籍、服务等是以某类人为对象而制作或准备的。）

### 例文（れいぶん） (例句)

1. これは幼児（ようじ） **向け** に書（か）かれた本（ほん）です。
   - **中文理解**：这是面向幼儿写的书。

2. 1人暮らし（ひとりぐらし）の女性（じょせい） **向け** のマンションはありませんか。
   - **中文理解**：有面向独居女性的公寓吗？

3. この『東京案内（とうきょうあんない）』は外国人（がいこくじん） **向け** だが、日本人（にほんじん）が読（よ）んでもとてもおもしろくて、ためになる。
   - **中文理解**：这本《东京指南》虽然是面向外国人的，但日本人读起来也非常有趣且有用。

**【拡張説明】(扩展说明)**
常见形式有「N向けだ」「N向けに作る」「N向けの本」。重点在“设计者、制作者、提供者原本设定的对象”。

---

## 1-4 ～向（む）き
【接続（せつぞく）】N ＋ 向（む）き
【意味（いみ）】〜にちょうど合（あ）うように（适合～ / 正好符合～）
▶ 「その対象（たいしょう）に適（てき）している・性質（せいしつ）が合（あ）っている」と言（い）いたいときに使（つか）う。（用于表达“性质上适合某类对象”。）

### 例文（れいぶん） (例句)

1. 当店（とうてん）では10代（じゅうだい）の女性（じょせい） **向き** に作（つく）ったかわいいアクセサリーを扱（あつか）っております。
   - **中文理解**：本店出售适合10多岁女性的可爱饰品。

2. お年寄（としよ）り **向き** の料理（りょうり）にはどんなものがありますか。
   - **中文理解**：适合老年人的料理有哪些呢？

3. この家（いえ）の台所（だいどころ）は広（ひろ）いし、明（あか）るいし、使（つか）いやすそうで、大家族（だいかぞく） **向き** ですね。
   - **中文理解**：这个家的厨房又宽敞又明亮，看起来很好用，很适合大家庭呢。

**【拡張説明】(扩展说明)**
**「向（む）け」与「向（む）き」的区别**：

- 「向け」(面向)：带有明确的 **设计/提供对象** ，即“最初就是为了这个对象而设计、制作或准备的”。
- 「向き」(适合)：强调客观上 **性质相符** ，即“无论最初是为谁设计的，其性质或现状适合这个群体”。

例：

「子（こ）ども向（む）けの本（ほん）」＝专门给孩子写的书。
「子（こ）ども向（む）きの本（ほん）」＝内容、难度等适合孩子读的书。

## 1-5 ～に関（かん）して・～に関（かん）する
【接続（せつぞく）】N ＋ に関（かん）して
【意味（いみ）】〜に関係（かんけい）することを（关于～ / 与～有关的）
▶ 話（はな）す・聞（き）く・考（かんが）える・書（か）く・調（しら）べるなどの行為（こうい）の対象（たいしょう）を言（い）うときに使（つか）う。「〜について」と意味（いみ）・用法（ようほう）は大体（だいたい）同（おな）じだが、「〜について」より硬（かた）い表現（ひょうげん）。（与「〜について」意思、用法基本相同，但语气更正式。）

### 例文（れいぶん） (例句)

1. この町（まち）の騒音（そうおん）問題（もんだい） **に関して** もう少し考（かんが）える必要（ひつよう）がある。
   - **中文理解**：关于这个城市的噪音问题，有必要再稍微考虑一下。

2. この件（けん） **に関しては** 現在（げんざい）調査（ちょうさ）しております。結論（けつろん）が出（で）るまでもうしばらくお待（ま）ちください。
   - **中文理解**：关于这件事目前正在调查中。在得出结论之前请再稍等片刻。

3. 今、わたしたちは自然災害（しぜんさいがい） **に関しての** 資料（しりょう）を集（あつ）めています。
   - **中文理解**：现在，我们正在收集关于自然灾害的资料。

4. この論文（ろんぶん）は日本（にほん）の政治史（せいじし） **に関する** 部分（ぶぶん）の調（しら）べ方が少し足（た）りない。
   - **中文理解**：这篇论文关于日本政治史部分的调查有些不足。

**【拡張説明】(扩展说明)**
修饰名词时，书面语中更常用「〜に関するN」。例句③的「〜に関してのN」也可以使用，但比「〜に関するN」略显绕。

## 1-6 ～にこたえて・～にこたえる
【接続（せつぞく）】N ＋ にこたえて
【意味（いみ）】〜に応（おう）じて／〜に沿（そ）うように（回应～ / 满足～）
▶ 質問（しつもん）・期待（きたい）・要望（ようぼう）・要求（ようきゅう）などを表（あらわ）す名詞（めいし）につき、「それに応（おう）じる行為（こうい）をする」と言（い）いたいときに使（つか）われる。（接在表示提问、期待、要求等名词后，用于表达“采取回应、满足其内容的行为”。）

### 例文（れいぶん） (例句)

1. 住民（じゅうみん）の要望（ようぼう） **にこたえて** 、この町（まち）にスポーツ施設（しせつ）が建設（けんせつ）されることになった。
   - **中文理解**：顺应居民的要求，决定在这个城市建设体育设施。

2. 聴衆（ちょうしゅう）のアンコール **にこたえて** 、指揮者（しきしゃ）はふたたび舞台（ぶたい）に姿（すがた）を見（み）せた。
   - **中文理解**：回应听众的安可，指挥家再次出现在舞台上。

3. 政府（せいふ）には、国民（こくみん）の期待（きたい） **にこたえる** ような有効（ゆうこう）な解決策（かいけつさく）を出（だ）してもらいたい。
   - **中文理解**：希望政府能提出回应国民期待的有效解决方案。

**【拡張説明】(扩展说明)**
汉字常写作「応えて」。常搭配「期待（きたい）・要望（ようぼう）・要求（ようきゅう）・希望（きぼう）・声（こえ）・アンコール」等词。
注意：「反対（はんたい）にこたえて」は通常不自然；如果要说“迫于反对而改变”，常用「反対（はんたい）を受（う）けて」「反対（はんたい）があって」等。

## 1-7 ～をめぐって・～をめぐる
【接続（せつぞく）】N ＋ をめぐって
【意味（いみ）】〜を議論（ぎろん）や争（あらそ）いの中心点（ちゅうしんてん）として（围绕着～）
▶ 「そのことを中心（ちゅうしん）に、議論（ぎろん）・対立（たいりつ）・争（あらそ）い・競争（きょうそう）・うわさなどが起（お）こっている」と言（い）うときに使（つか）う。やや硬（かた）い表現（ひょうげん）。（表示“以某事为中心发生争论、对立、竞争、传闻等”。语气偏正式、书面。）

### 例文（れいぶん） (例句)

1. マンション建設（けんせつ） **をめぐって** 、住民（じゅうみん）たちと建設会社（けんせつがいしゃ）との対立（たいりつ）が続（つづ）いている。
   - **中文理解**：围绕公寓建设问题，居民与建筑公司之间的对立仍在持续。

2. 彼（かれ）の急死（きゅうし） **をめぐって** 、みんながいろいろなうわさをしている。
   - **中文理解**：围绕他的突然死亡，大家都在议论纷纷。

3. 町（まち）の再開発（さいかいはつ） **をめぐり** 、討論（とうろん）が3日（みっか）続（つづ）いた。
   - **中文理解**：围绕城市的重新开发，讨论持续了三天。（「めぐり」是中止形，更书面化）

4. 宇宙開発（うちゅうかいはつ） **をめぐる** 各国（かっこく）の競争（きょうそう）はさらに激（はげ）しくなってきた。
   - **中文理解**：围绕太空开发的各国竞争变得更加激烈了。

**【拡張説明】(扩展说明)**
「〜をめぐるN」用于修饰名词，如「事件（じけん）をめぐる報道（ほうどう）」「土地（とち）をめぐる争（あらそ）い」。单纯表示“关于某个话题说话、调查”时，一般不用「をめぐって」，而用「について／に関して」。

## 1-8 ～にかかわる
【接続（せつぞく）】N ＋ にかかわる
【意味（いみ）】〜のような重大（じゅうだい）なことに影響（えいきょう）を及（およ）ぼす（关系到～ / 影响到～）
▶ 「〜にかかわるN」の形（かたち）で「ただ〜に関係（かんけい）があるだけでなく、〜に重大（じゅうだい）な影響（えいきょう）を及（およ）ぼすN」と言（い）いたいときの表現（ひょうげん）。（以「〜にかかわるN」的形式，表达“不仅仅是与～有关系，而是对～产生重大影响的N”。）

### 例文（れいぶん） (例句)

1. 父（ちち）はこれまで3度（さんど）も命（いのち） **にかかわる** 病気（びょうき）をした。
   - **中文理解**：父亲至今已经生了三次关系到性命的重病。

2. プライバシーを守（まも）るということは人権（じんけん） **にかかわる** 大切（たいせつ）な問題（もんだい）です。
   - **中文理解**：保护隐私是关系到人权的重要问题。

3. 教育（きょういく）は国（くに）の将来（しょうらい） **にかかわる** 大事業（だいじぎょう）ではないでしょうか。
   - **中文理解**：教育难道不是关系到国家未来的大事业吗？

**【拡張説明】(扩展说明)**
「にかかわる」强调事情重大，常和「命（いのち）・人権（じんけん）・将来（しょうらい）・名誉（めいよ）・存亡（そんぼう）」等词搭配。普通的“有关系”一般说「関係（かんけい）がある」「関（かん）する」。

## 1 練習 (练习题)

### A. どちらが正（ただ）しいですか。正（ただ）しい方（ほう）を選（えら）びなさい。（哪一个是正确的？请选择正确的一方。）

1. あなたの林（はやし）さんに（ a. 対（たい）して / **b. 対（たい）する** ）尊敬心（そんけいしん）はいつごろからのものですか。
   - **中文理解**：你对林先生的尊敬之心是从什么时候开始的？

2. これは若（わか）い人（ **a. 向（む）けに** / b. 向（む）けの ）デザインされた服（ふく）だけれど、母（はは）にもとてもよく似合（にあ）う。
   - **中文理解**：这虽然是面向年轻人设计的衣服，但也很适合母亲。

3. 地元（じもと）の人（ひと）たちの期待（きたい）に（ a. こたえて / **b. こたえる** ）ような活躍（かつやく）をしたいと思（おも）います。
   - **中文理解**：我想有一番能够回应当地人期待的表现。

4. 事故（じこ）の原因（げんいん）に（ **a. 関（かん）して** / b. 関（かん）する ）ただ今（いま）調査中（ちょうさちゅう）です。
   - **中文理解**：关于事故的原因，目前正在调查中。

5. この空き地（あきち）の利用法（りようほう）を（ **a. めぐって** / b. めぐる ）まだ両者（りょうしゃ）の対立（たいりつ）が続（つづ）いている。
   - **中文理解**：围绕这块空地的使用方法，双方的对立仍在持续。

### B. [ ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。1つの言葉（ことば）は1回（かい）しか使（つか）いません。
（使用方框中的词语，完成句子。1个词语只能使用1次。）
