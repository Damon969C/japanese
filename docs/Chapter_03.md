# 第3章 起点（きてん）・終点（しゅうてん）・限界（げんかい）・範囲（はんい）

**核心提示**：ものごとの始（はじ）まりと終（お）わり、上（うえ）と下（した）の限界（げんかい）、その間（あいだ）や範囲（はんい）を言（い）いたいときは、どんな言（い）い方（かた）がありますか。（当想表达事物的起点、终点、上下界限以及范围时，有哪些表达方式？）

---

## 0. 導入（どうにゅう） (引入)

### 知（し）っていますか (你知道吗？)
**[ ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。**
（使用方框中的词语，完成句子。1个词语只能使用1次。）
【选项：a. にかけて b. を通（つう）じて c. だけ d. にわたって e. をはじめ】

1. 京都（きょうと）には清水寺（きよみずでら）[ **e. をはじめ** ]、観光名所（かんこうめいしょ）がたくさんある。
   - **中文理解**：京都有以清水寺为代表的众多观光胜地。

2. テーブルの上（うえ）のものは食（た）べたい[ **c. だけ** ]食（た）べていいんですよ。
   - **中文理解**：桌子上的东西，你想吃多少就可以吃多少。

3. 9月（くがつ）から10月（じゅうがつ）[ **a. にかけて** ]、日本各地（にほんかくち）で祭（まつ）りが行（おこな）われます。
   - **中文理解**：从9月到10月期间，日本各地会举行祭典。

4. 今（いま）、世界（せかい）ではすべての分野（ぶんや）[ **d. にわたって** ]女性（じょせい）たちの活躍（かつやく）が目立（めだ）つ。
   - **中文理解**：如今，在世界各个领域，女性们的活跃都非常引人注目。

5. 在学期間（ざいがくきかん）[ **b. を通（つう）じて** ]、彼（かれ）はいつもクラスのリーダーだった。
   - **中文理解**：在校期间，他一直都是班级的领导者。

### 使（つか）えますか (你会用吗？)
**どちらが正（ただ）しいですか。正（ただ）しい方（ほう）を選（えら）びなさい。**
（哪一个是正确的？请选择正确的一方。）

1. ｛a. 夜中（よなか）から明（あ）け方（がた）まで、 **b. 夜中（よなか）から明（あ）け方（がた）にかけて、**｝弱（よわ）い地震（じしん）が数回（すうかい）あった。
   - **中文理解**：半夜到黎明时分，发生了几次弱地震。（不是一直持续不断地震，而是在这个范围内断续发生，所以用「にかけて」更合适。）

2. ここにある本（ほん）を｛ **a. できるだけたくさん** b. できるばかりたくさん｝持（も）って帰（かえ）ってください。
   - **中文理解**：请尽可能多地把这里的书带回去。

## 3 Ⅰ 起点（きてん）・終点（しゅうてん）・範囲（はんい）

### 3 Ⅰ・1 〜から〜にかけて
【接続（せつぞく）】N ＋ から ＋ N ＋ にかけて
【意味（いみ）】〜から〜までの間（あいだ）／範囲（はんい）で（从……到……期间/范围内）
▶ 時間（じかん）や場所（ばしょ）の「だいたいこのあたりからこのあたりまで」という範囲（はんい）を表（あらわ）す。始（はじ）まりと終（お）わりは「〜から〜まで」ほどはっきりしない。（表示时间或地点的大致范围，起点和终点不像「〜から〜まで」那么明确。）

#### 例文（れいぶん） (例句)

1. 朝（あさ）、7時半（しちじはん） **から** 8時（はちじ） **にかけて**、バスがとても込（こ）む。
   - **中文理解**：早上7点半到8点前后，公交车非常拥挤。

2. 昨年（さくねん）の夏（なつ） **から** 今年（ことし）の春（はる） **にかけて**、わたしのうちではいろいろなことが起（お）こった。
   - **中文理解**：从去年夏天到今年春天期间，我家发生了很多事情。

3. あすは関東地方（かんとうちほう） **から** 東北地方（とうほくちほう） **にかけて**、小雨（こさめ）が降（ふ）るでしょう。（天気予報（てんきよほう））
   - **中文理解**：明天从关东地区到东北地区一带会下小雨吧。（天气预报）

4. 首都高速道路（しゅとこうそくどうろ）は銀座（ぎんざ） **から** 羽田（はねだ） **にかけて** 渋滞（じゅうたい）しています。（交通情報（こうつうじょうほう））
   - **中文理解**：首都高速公路从银座到羽田一带正在堵车。（交通信息）

**【拡張説明】(扩展说明)**
「〜から〜にかけて」后面常接在该范围内持续或断续发生的事情，不适合接只发生一次、位置单一的事情。

- (✖) A駅（えき）からB駅（えき）にかけて、わたしのアパートがあります。（只有一栋公寓，位置单一）
- (〇) A駅（えき）からB駅（えき）にかけて、アパートがたくさん並（なら）んでいる。（公寓在这一带连续分布）
- (△) 夜中（よなか）から明（あ）け方（がた）にかけて、チンさんが訪（たず）ねてきました。（单次拜访通常不自然）
- (〇) 夜中（よなか）から明（あ）け方（がた）にかけて、雨（あめ）が降（ふ）りました。（持续或断续下雨）

### 3 Ⅰ・2 〜を通（つう）じて・〜を通（とお）して
【接続（せつぞく）】N ＋ を通（つう）じて / を通（とお）して
【意味（いみ）】〜の間（あいだ）ずっと（在……整个期间内一直）
▶ ある期間（きかん）の初（はじ）めから終（お）わりまで、同（おな）じ状態（じょうたい）や傾向（けいこう）が続（つづ）くことを表（あらわ）す。（表示在某段期间从头到尾都持续同一种状态或倾向。）

#### 例文（れいぶん） (例句)

1. この地方（ちほう）は年間（ねんかん） **を通（つう）じて** ほとんど同（おな）じような天候（てんこう）です。
   - **中文理解**：这个地区全年气候几乎都一样。

2. 人類（じんるい）の歴史（れきし） **を通（つう）じて**、地球（ちきゅう）のどこかでつねに戦争（せんそう）が行（おこな）われていた。
   - **中文理解**：纵观人类历史，地球上的某些地方总是在发生战争。

3. この画家（がか）は一生（いっしょう） **を通（とお）して** 小（ちい）さい動物（どうぶつ）たちの絵（え）をかき続（つづ）けた。
   - **中文理解**：这位画家一生都在画小动物。

4. 母（はは）は3か月（さんかげつ）の入院期間（にゅういんきかん） **を通（とお）して** 1度（いちど）も不満（ふまん）を言（い）わなかった。
   - **中文理解**：母亲在住院的3个月里，一次也没有抱怨过。

**【拡張説明】(扩展说明)**
第2章的「〜を通じて／〜を通して」表示“以……为媒介”；本节表示“贯穿整个期间”。判断时看前面的名词是否是时间段，如「年間・一生・入院期間・歴史」等。

---

### 3 Ⅰ・3 〜だけ・〜だけの
【接続（せつぞく）】普通形（ふつうけい）・ナAな ＋ だけ / だけのN
【意味（いみ）】〜の限度（げんど）まで（到……限度为止 / 尽……所能 / 想……多少就……多少）
▶ 「できる範囲（はんい）・望（のぞ）む量（りょう）・必要（ひつよう）な量（りょう）の限界（げんかい）まで」と言（い）いたいときに使（つか）う。（用于表示达到能力、愿望或必要量的上限。）

#### 例文（れいぶん） (例句)

1. わたしはごみの袋（ふくろ）を持（も）てる **だけ** 持（も）ってごみ置（お）き場（ば）まで運（はこ）んだ。
   - **中文理解**：我把能拿得动的垃圾袋都拿上，搬到了垃圾存放处。

2. どうぞお菓子（おかし）を好（す）きな **だけ** お取り（おとり）ください。
   - **中文理解**：点心请随便拿，想拿多少拿多少。

3. あしたはできる **だけ** 早（はや）く来（き）てください。
   - **中文理解**：明天请尽可能早点来。

4. わたしは彼（かれ）に言（い）いたい **だけの** ことを全部（ぜんぶ）言（い）うつもりだ。
   - **中文理解**：我打算把想对他说的话全部说出来。

**【拡張説明】(扩展说明)**
「できるだけ」是惯用表达，意思是“尽可能”。「〜だけのN」用于修饰名词，如「言いたいだけのこと」「必要なだけのお金」。

---

### 3 Ⅰ・4 〜にわたって・〜にわたる
【接続（せつぞく）】N ＋ にわたって / にわたる / にわたり
【意味（いみ）】〜の全体（ぜんたい）に／長（なが）い期間（きかん）・広（ひろ）い範囲（はんい）で（在……整个范围内 / 长达 / 多达）
▶ 期間（きかん）・場所（ばしょ）・分野（ぶんや）などの範囲（はんい）が広（ひろ）いことを強調（きょうちょう）する。（强调时间、地点、领域等范围很长或很广。）

#### 例文（れいぶん） (例句)

1. 山田（やまだ）先生（せんせい）は長（なが）い年月（ねんげつ） **にわたって**、子（こ）どもの音楽教育（おんがくきょういく）に力（ちから）を注（そそ）いだ。
   - **中文理解**：山田老师长期致力于儿童音乐教育。

2. この店（みせ）は親（おや）、子（こ）、孫（まご）の3代（さんだい） **にわたり**、伝統的（でんとうてき）な和風（わふう）の味（あじ）を守（まも）っている。
   - **中文理解**：这家店历经祖孙三代，一直守护着传统的日式风味。

3. 1年間（いちねんかん） **にわたる** 橋（はし）の工事（こうじ）がやっと終（お）わった。
   - **中文理解**：长达一年的建桥工程终于结束了。

4. 15日間（じゅうごにちかん） **にわたった** 夏季（かき）オリンピック大会（たいかい）も今日（きょう）で幕（まく）を閉（と）じます。
   - **中文理解**：历时15天的夏季奥运会今天也将落下帷幕。

**【拡張説明】(扩展说明)**
「〜にわたって」强调范围“长、广、大”。如果只是普通地说“从 A 到 B”，不一定要用它。修饰名词时用「〜にわたるN」。

---

### 3 Ⅰ・5 〜をはじめ（として）・〜をはじめとする
【接続（せつぞく）】N ＋ をはじめ（として） / をはじめとするN
【意味（いみ）】〜を第1（だいいち）の例（れい）として（以……为首 / 以……为代表）
▶ 代表的（だいひょうてき）なものを一（ひと）つ挙（あ）げて、「そのほかにも同（おな）じグループのものがたくさんある」と言（い）いたいときに使（つか）う。（举出一个代表，表示同类还有很多。）

#### 例文（れいぶん） (例句)

1. ご両親（ごりょうしん） **をはじめ**、家族（かぞく）のみなさんによろしくお伝え（おつたえ）ください。
   - **中文理解**：请代我向您的父母以及各位家人问好。

2. わたしは日本（にほん）に来（き）てから先輩（せんぱい）のリンさん **をはじめ** 多（おお）くの方（かた）のお世話（おせわ）になっています。
   - **中文理解**：我来到日本后，得到了以林前辈为代表的许多人的照顾。

3. 東京（とうきょう）の永田町（ながたちょう）には国会議事堂（こっかいぎじどう） **をはじめとして**、国（くに）のいろいろな機関（きかん）が集（あつ）まっている。
   - **中文理解**：东京的永田町聚集了以国会议事堂为代表的各种国家机关。

4. 今回（こんかい）のサミットでは、アメリカ **をはじめとする** 主要（しゅよう）8か国（はちかこく）の首脳（しゅのう）が参加（さんか）して話（はな）し合（あ）いが行（おこな）われる。
   - **中文理解**：在这次峰会上，以美国为首的8个主要国家的首脑将参加并进行会谈。

**【拡張説明】(扩展说明)**
后半句常出现「みなさん・いろいろ・たくさん・多く・大勢」等表示多数的词。修饰名词时用「〜をはじめとするN」。

## 3 Ⅱ 限界（げんかい）・上限（じょうげん）

### 3 Ⅱ・1 〜からして
【接続（せつぞく）】N ＋ からして
【意味（いみ）】〜を第1（だいいち）の例（れい）として／〜だけを見（み）ても（单从……来看 / 就连……都）
▶ 基本的（きほんてき）なこと、または普通（ふつう）はあまり問題（もんだい）にならないことを例（れい）に出（だ）して、「そこからもう評価（ひょうか）できる」と言（い）いたいときに使（つか）う。（举出最基本或最小的例子，表示仅从这一点就能判断整体。）

#### 例文（れいぶん） (例句)

1. この職場（しょくば）には時間（じかん）を守（まも）らない人（ひと）が多（おお）い。所長（しょちょう） **からして** よく遅刻（ちこく）する。
   - **中文理解**：这个职场里很多人都不守时。就连所长都经常迟到。

2. 新（あたら）しく買（か）い替（か）えた携帯電話（けいたいでんわ）は前（まえ）のとはずいぶん違（ちが）う。だいいち、色（いろ） **からして** 違（ちが）う。
   - **中文理解**：新换的手机和以前的差别很大。首先，单从颜色来看就不一样。

3. この店（みせ）の雰囲気（ふんいき）は好（す）きになれない。まず、流（なが）れている音楽（おんがく） **からして** わたしの好（この）みではない。
   - **中文理解**：我喜欢不上这家店的氛围。首先，单是播放的音乐就不合我的喜好。

**【拡張説明】(扩展说明)**
「〜からして」常带有“连最基本的部分都这样，其他方面更不用说”的语感。不要和表示理由的「〜から」混淆。

---

### 3 Ⅱ・2 〜かぎり・〜かぎりの
【接続（せつぞく）】Vる / Vている / Nの ＋ かぎり / かぎりのN
【意味（いみ）】〜の限界（げんかい）ぎりぎりまで（直到……的极限 / 尽最大……）
▶ 能力（のうりょく）・視野（しや）・知識（ちしき）・条件（じょうけん）などの限界（げんかい）まで、という意味（いみ）を表（あらわ）す。（表示达到能力、视野、知识、条件等的极限。）

#### 例文（れいぶん） (例句)

1. できる **かぎり** お手伝い（おてつだい）いたします。遠慮（えんりょ）なく言（い）ってください。
   - **中文理解**：我会尽我所能帮忙。请不要客气。

2. さあ、いよいよあしたは入学試験（にゅうがくしけん）だ。力（ちから）の **かぎり** がんばろう。
   - **中文理解**：好，明天终于要入学考试了。让我们尽全力拼搏吧。

3. この事件（じけん）について知（し）っている **かぎりの** ことを話（はな）してください。
   - **中文理解**：请把你知道的关于这个事件的所有情况都说出来。

4. わたしたちのチームが負（ま）けそうになったので、みんなあらん **かぎりの** 声（こえ）を出（だ）して応援（おうえん）した。
   - **中文理解**：因为我们的队伍快要输了，所以大家都竭尽全力地大声应援。

**【拡張説明】(扩展说明)**
「できるかぎり」是常用惯用表达，意思是“尽可能”。「あらんかぎり」也是惯用表达，表示“全部、所有、竭尽”。本章的「かぎり」不是条件用法「〜かぎりは（只要……就……）」。

---

### 3 Ⅱ・3 〜に至（いた）るまで
【接続（せつぞく）】N ＋ に至（いた）るまで
【意味（いみ）】〜までも／〜にまで及（およ）んで（甚至到…… / 一直到……）
▶ 範囲（はんい）が普通（ふつう）なら考（かんが）えにくい細（こま）かい部分（ぶぶん）や極端（きょくたん）なところまで及（およ）ぶことを強調（きょうちょう）する。（强调范围甚至达到细微或极端的部分。）

#### 例文（れいぶん） (例句)

1. フィギュアスケートの指導（しどう）は厳（きび）しかった。指（ゆび）の先（さき） **に至（いた）るまで** 細（こま）かく注意（ちゅうい）された。
   - **中文理解**：花样滑冰的指导非常严格。甚至连指尖的动作都被细致地提醒。

2. 身近（みぢか）なごみ問題（もんだい）から国際経済（こくさいけいざい）の問題（もんだい） **に至（いた）るまで**、面接試験（めんせつしけん）の質問内容（しつもんないよう）は実（じつ）にいろいろだった。
   - **中文理解**：从身边的垃圾问题一直到国际经济问题，面试问题的内容真是五花八门。

3. 何年（なんねん）か前（まえ）に、0歳（ぜろさい）の赤（あか）ん坊（ぼう）から100歳（ひゃくさい）を越（こ）える高齢者（こうれいしゃ） **に至（いた）るまで**、すべての住民（じゅうみん）に国（くに）から一定額（いっていがく）のお金（おかね）が支給（しきゅう）された。
   - **中文理解**：几年前，从0岁的婴儿一直到超过100岁的高龄者，所有居民都收到了国家发放的一定金额。

**【拡張説明】(扩展说明)**
常用于「AからBに至るまで」的形式，表示范围从 A 一直延伸到 B。B 往往是“甚至连那里也包括”的极端例子。

## 3 Ⅲ 終点（しゅうてん）・最後（さいご）・程度（ていど）

### 3 Ⅲ・1 〜を皮切り（かわきり）に（して）・〜を皮切り（かわきり）として
【接続（せつぞく）】N ＋ を皮切り（かわきり）に（して） / を皮切り（かわきり）として
【意味（いみ）】〜から始（はじ）まって（以……为开端 / 从……开始）
▶ ある出来事（できごと）を最初（さいしょ）のきっかけとして、その後（ご）同（おな）じようなことが次々（つぎつぎ）に続（つづ）くことを表（あらわ）す。（表示以某事为开端，之后同类事情接连发生。）

#### 例文（れいぶん） (例句)

1. あのスーパーは大阪（おおさか）での出店（しゅってん） **を皮切り（かわきり）に**、日本各地（にほんかくち）に次々（つぎつぎ）に支店（してん）を出（だ）している。
   - **中文理解**：那家超市以在大阪开店为开端，陆续在日本各地开设分店。

2. 彼（かれ）の発言（はつげん） **を皮切り（かわきり）にして**、大勢（おおぜい）の人（ひと）が次々（つぎつぎ）に意見（いけん）を言（い）った。
   - **中文理解**：以他的发言为开端，很多人接连发表了意见。

3. この作品（さくひん） **を皮切り（かわきり）として**、彼女（かのじょ）はその後（ご）、多（おお）くの小説（しょうせつ）を発表（はっぴょう）した。
   - **中文理解**：以这部作品为开端，她之后发表了许多小说。

**【拡張説明】(扩展说明)**
后半句常有「次々に」「続々と」「相次いで」等表示接连发生的词。只发生一次的后续行为不适合用「を皮切りに」。

---

### 3 Ⅲ・2 〜を限（かぎ）りに
【接続（せつぞく）】N ＋ を限（かぎ）りに
【意味（いみ）】〜を最後（さいご）として（以……为最后 / 到……为止）
▶ それまで続（つづ）いていたことを、その時点（じてん）で終（お）わりにすることを表（あらわ）す。（表示把一直持续到现在的事情到某个时间点为止结束。）

#### 例文（れいぶん） (例句)

1. 今日（きょう） **を限（かぎ）りに** 禁煙（きんえん）することにしました。
   - **中文理解**：我决定从今天起戒烟。（今天作为最后界限）

2. 20年（にじゅうねん）続（つづ）いたこのマラソン大会（たいかい）も、今回（こんかい） **を限（かぎ）りに** 打（う）ち切（き）られるそうだ。
   - **中文理解**：听说持续了20年的这场马拉松大会，到这次为止也将停办。

3. 今年度（こんねんど） **を限（かぎ）りに** 土曜日（どようび）の業務（ぎょうむ）は行（おこな）わないことになりました。
   - **中文理解**：从本年度结束起，星期六将不再办公。

**【拡張説明】(扩展说明)**
「を限りに」强调“以此为最后一次/最后期限”。常和「やめる・打ち切る・終了する・行わない」等表示结束的表达搭配。

---

### 3 Ⅲ・3 〜をもって
【接続（せつぞく）】N ＋ をもって
【意味（いみ）】〜で／〜を終了時点（しゅうりょうじてん）として（在…… / 以……为结束点）
▶ 公式（こうしき）な場面（ばめん）で、物事（ものごと）が終（お）わる時点（じてん）を告（つ）げるときに使（つか）う、硬（かた）い表現（ひょうげん）。（正式场合宣布事情结束时间点时使用的书面表达。）

#### 例文（れいぶん） (例句)

1. 本日（ほんじつ） **をもって** 職場（しょくば）の皆様（みなさま）とお別れ（おわかれ）することになりました。
   - **中文理解**：我将于今天和职场的各位告别。

2. 展示会（てんじかい）の最終日（さいしゅうび）は午後（ごご）5時（ごじ） **をもって** 終（お）わりにさせていただきます。
   - **中文理解**：展览会最后一天将于下午5点结束。

3. これ **をもちまして** 第10回（だいじゅっかい）卒業式（そつぎょうしき）を終了（しゅうりょう）いたします。
   - **中文理解**：第10届毕业典礼到此结束。

**【拡張説明】(扩展说明)**
第2章的「をもって」表示“以……为手段/凭借”；本节表示“以某时间点为结束点”。「をもちまして」是更郑重的形式。

---

### 3 Ⅲ・4 〜というところだ・〜といったところだ
【接続（せつぞく）】数量（すうりょう）・程度（ていど）を表（あらわ）す語（ご） ＋ というところだ / といったところだ
【意味（いみ）】最高（さいこう）でも〜だ／せいぜい〜だ（最多也就是…… / 充其量也就是……）
▶ 数量（すうりょう）や程度（ていど）がそれほど高（たか）くない、または限界（げんかい）がそのくらいだと言（い）いたいときに使（つか）う。（表示数量或程度并不高，最多也就是那个程度。）

#### 例文（れいぶん） (例句)

1. 来年度（らいねんど）わたしがもらえそうな奨学金（しょうがくきん）はせいぜい5万円（ごまんえん） **というところだ**。
   - **中文理解**：明年我可能拿到的奖学金，充其量也就是5万日元。

2. わたしが作（つく）れる料理（りょうり）ですか。そうですねえ。卵焼（たまごや）き、みそ汁（しる） **といったところです**。
   - **中文理解**：我会做的菜吗？这个嘛，也就煎鸡蛋、味噌汤这类吧。

3. 彼女（かのじょ）、ダンスがうまくなったね。仕上（しあ）がりまでもう1歩（いっぽ） **といったところだ** ね。
   - **中文理解**：她跳舞进步了呢。离完成大概也就是一步之遥吧。

**【拡張説明】(扩展说明)**
常和「せいぜい」「まあ」「多くても」等搭配，有“估计上限也就如此”的语感。「といったところだ」比「というところだ」更带有列举、概括的感觉。

## 3 練習（れんしゅう） (练习题)

### A. 下線部（かせんぶ）を、[ ] の中（なか）の言葉（ことば）を使（つか）って言（い）い換（か）えなさい。1つ（ひとつ）の言葉（ことば）は1回（いっかい）しか使（つか）いません。
（使用方框中的词语替换下划线部分。1个词语只能使用1次。）
【 a. から〜にかけて / b. を通（つう）じて / c. にわたって / d. にわたる / e. だけ 】

1. バイキングでは、食（た）べたいものを全部（ぜんぶ）（→ **e. 食（た）べたいだけ**）食（た）べられるんですよ。
   - **中文理解**：在自助餐，想吃多少就能吃多少。

2. 3時間（さんじかん）続（つづ）いた（→ **d. 3時間（さんじかん）にわたる**）試合（しあい）がやっと終（お）わった。会場（かいじょう）から大（おお）きな拍手（はくしゅ）が起（お）こった。
   - **中文理解**：长达3小时的比赛终于结束了。会场响起了热烈的掌声。

3. 明日（あす）は夕方（ゆうがた）から夜（よる）までの間（あいだ）（→ **a. 夕方（ゆうがた）から夜（よる）にかけて**）、小雨（こさめ）が降（ふ）るでしょう。
   - **中文理解**：明天傍晚到晚上期间会下小雨吧。

4. 4年間（よねんかん）ずっと（→ **c. 4年間（よねんかん）にわたって**）研究（けんきゅう）されてきた新（あたら）しいロボットが、明日（あす）いよいよ働（はたら）き始（はじ）める。
   - **中文理解**：历时4年研发的新型机器人，明天终于要开始工作了。

5. うちの畑（はたけ）では1年（いちねん）の間（あいだ）（→ **b. 1年（いちねん）を通（つう）じて**）次々（つぎつぎ）にいろいろな草花（くさばな）が育（そだ）つんです。
   - **中文理解**：我家的田地一年到头都会接连不断地生长出各种花草。

### B. どちらが正（ただ）しいですか。正（ただ）しい方（ほう）を選（えら）びなさい。（哪一个是正确的？请选择正确的一方。）

1. この店（みせ）の商品（しょうひん）は高級品（こうきゅうひん）ばかりだ。（**a. ハンカチ** b. ダイヤの指輪（ゆびわ））からして、わたしには手（て）が出（で）ない。
   - **中文理解**：这家店的商品全都是高级货。单单是手帕，我就买不起。（「からして」举出最小、最基本的例子来暗示其他更不用说。）

2. 年末（ねんまつ）から年始（ねんし）にかけて、わたしは（a. 新（あたら）しい服（ふく）を買（か）った **b. 母（はは）のところに行（い）っていた**）。
   - **中文理解**：从年末到年初期间，我一直待在母亲那里。（「にかけて」后适合接持续性的动作或状态，而不是买衣服这种一次性动作。）

3. この学校（がっこう）の屋上（おくじょう）から見（み）ると、見渡（みわた）すかぎり（a. 富士山（ふじさん）が見（み）える **b. ビルばかりだ**）。
   - **中文理解**：从这所学校的楼顶望去，目光所及之处全是大楼。

4. （a. 週末（しゅうまつ） **b. 1週間（いっしゅうかん）**）にわたる講習会（こうしゅうかい）は、とても評判（ひょうばん）がよく、次回（じかい）もぜひ参加（さんか）したいという人（ひと）が大勢（おおぜい）いた。
   - **中文理解**：为期一周的讲习班评价非常好，很多人表示下次也一定要参加。（「にわたる」用于强调期间之长、范围之广。）

5. 今年（ことし）は1年（いちねん）を通（つう）じて（**a. 忙（いそが）しかった** b. 日本語学校（にほんごがっこう）に入学（にゅうがく）した）。
   - **中文理解**：今年一整年都很忙。（「を通じて」后接贯穿整个期间的状态。）

### C. [ ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。1つ（ひとつ）の言葉（ことば）は1回（いっかい）しか使（つか）いません。
【 a. にかけて / b. にわたる / c. を通（つう）じて / d. だけ / e. をはじめ / f. からして / g. かぎり 】

わたしは2004年（にせんよねん）から2005年（にせんごねん）（ **1. a. にかけて** ）、世界（せかい）のあちこちに行（い）った。そして、2006年（にせんろくねん）から2010年（にせんじゅうねん）まで日本（にほん）の大学（だいがく）で勉強（べんきょう）した。4年間（よねんかん）（ **2. b. にわたる** ）留学生活（りゅうがくせいかつ）の間（あいだ）、田中（たなか）先生（せんせい）（ **3. e. をはじめ** ）いろいろな方（かた）のお世話（おせわ）になった。日本（にほん）では食（た）べ物（もの）（ **4. f. からして** ）わたしには合（あ）わなくて、はじめのうちはとても困（こま）った。しかし、日本（にほん）には年間（ねんかん）（ **5. c. を通（つう）じて** ）いろいろな野菜（やさい）があるし、田中（たなか）先生（せんせい）も「うちの畑（はたけ）のものは好（す）きな（ **6. d. だけ** ）持（も）っていっていいですよ」と言（い）ってくれたのでありがたかった。わたしもお金（おかね）が続（つづ）く（ **7. g. かぎり** ）がんばって日本（にほん）で勉強（べんきょう）を続（つづ）けようと思（おも）った。

**【段落中文理解】**
我从2004年到2005年期间去了世界各地。之后，从2006年到2010年在日本的大学学习。在长达4年的留学生活中，我得到了以田中老师为代表的许多人的照顾。在日本，单从食物来说就不合我的胃口，一开始非常苦恼。但是，日本一年到头都有各种各样的蔬菜，田中老师也对我说“我家田里的东西，你喜欢多少就拿多少”，让我非常感激。我也决定只要钱还支撑得住，就努力在日本继续学习下去。

### D. どちらが正（ただ）しいですか。正（ただ）しい方（ほう）を選（えら）びなさい。（哪一个是正确的？请选择正确的一方。）

1. 彼（かれ）は5年前（ごねんまえ）初（はじ）めて本（ほん）を出版（しゅっぱん）したのを皮切り（かわきり）に、以後（いご）（**a. 次々（つぎつぎ）にいい本（ほん）を出版（しゅっぱん）している** b. 1冊（いっさつ）も出版（しゅっぱん）していない）。
   - **中文理解**：他以5年前首次出版书籍为开端，之后接连出版了许多好书。（「を皮切りに」表示作为契机，后续接连发生同类事情。）

2. うちの親（おや）は（a. 自分（じぶん）の友（とも）だちの電話番号（でんわばんごう） **b. わたしの友（とも）だちの電話番号（でんわばんごう）**）に至（いた）るまで関心（かんしん）があるようだ。
   - **中文理解**：我父母似乎连我朋友的电话号码都关心。（「に至るまで」强调范围达到了令人吃惊的细微或极端程度。）

3. 今日（きょう）を限（かぎ）りに（a. 別（べつ）の薬（くすり）を飲（の）み始（はじ）める **b. この薬（くすり）を飲（の）むのをやめる**）。
   - **中文理解**：今天是我最后一次吃这个药了。（「を限りに」表示一直持续的事情到此为止不再继续。）

4. 今年度（こんねんど）をもって（**a. この研究会（けんきゅうかい）は終（お）わります** b. 新（あたら）しい研究会（けんきゅうかい）が発足（ほっそく）します）。
   - **中文理解**：本研究会将于本年度结束。（「をもって」常用于正式宣布事情的结束点。）

5. わたしの睡眠時間（すいみんじかん）は（**a. 5時間（ごじかん）** b. 10時間（じゅうじかん））といったところです。
   - **中文理解**：我的睡眠时间充其量也就是5个小时左右。（「といったところだ」表示最多也就如此，常用于评价数量少或程度不高。）

### E. [ ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。1つ（ひとつ）の言葉（ことば）は1回（いっかい）しか使（つか）いません。
【 a. を皮切り（かわきり）に / b. に至（いた）るまで / c. を限（かぎ）りに / d. をもって / e. といったところ 】

1. 今日（きょう）（ **c. を限（かぎ）りに** ）、A社（エーしゃ）との交渉（こうしょう）を打（う）ち切（き）ることにした。
   - **中文理解**：以今天为最后期限，我们决定中止与 A 公司的谈判。

2. A社（エーしゃ）の初任給（しょにんきゅう）はそんなに高（たか）くないです。せいぜい18万円（じゅうはちまんえん）（ **e. といったところ** ）でしょうか。
   - **中文理解**：A 公司的起薪没那么高。充其量也就18万日元吧。

3. この映画（えいが）（ **a. を皮切り（かわきり）に** ）、以後（いご）次々（つぎつぎ）にアジアの映画（えいが）が日本（にほん）で上映（じょうえい）されるようになった。
   - **中文理解**：以这部电影为开端，之后亚洲电影开始接连不断地在日本上映。

4. 彼（かれ）は神経（しんけい）の細（こま）かい人（ひと）で、その日（ひ）に食（た）べた食事（しょくじ）の内容（ないよう）やその値段（ねだん）、買（か）った店（みせ）の名前（なまえ）（ **b. に至（いた）るまで** ）ノートに書（か）いている。
   - **中文理解**：他是个心思细腻的人，那一天吃了什么、价格多少，甚至连买东西的店名都写在笔记本上。

5. 本年度（ほんねんど）（ **d. をもって** ）、当協会（とうきょうかい）は解散（かいさん）いたします。
   - **中文理解**：本协会将于本年度解散。
