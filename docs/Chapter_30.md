# 30 感嘆（かんたん）・願望（がんぼう）

驚（おどろ）きや感動（かんどう）を込（こ）めて述（の）べたり、実現（じつげん）してほしい願（ねが）いを強（つよ）く表（あらわ）したりするとき、どのような表現（ひょうげん）を使（つか）えばよいでしょうか。（表达惊叹、感慨或强烈愿望时，可以使用哪些说法？）

| 核心功能 | 句型 | 语感重点 |
| :--- | :--- | :--- |
| 直接发出感叹 | なんと／なんて〜だろう | “多么……啊”，不是普通推测 |
| 希望别人或事态改变 | 〜てほしい | 可用于请求，也可表达单纯愿望 |
| 怀念过去 | 〜たものだ | 回想过去反复发生的事或状态 |
| 惊叹、感慨 | 〜ものだ | 对能力、变化或一般情状深有感触 |
| 强调程度之深 | 〜ことだろう／〜ことか | 常与「どんなに・何度」呼应 |
| 对事实作感情评价 | 〜ことだ | 多接感情、评价形容词 |
| 先说感受，再说事实 | 〜ことに（は） | “令人……的是”，偏书面 |
| 感到某种突出特质 | 〜ものがある | “确有一种……之处” |
| 对意外事实感到惊讶 | 〜なんて／〜とは | 前者随意，后者较正式 |
| 表达由衷而非轻易的愿望 | 〜たいものだ／〜てほしいものだ | 愿望强、常非立即可实现 |
| 寻求实现愿望的可能 | 〜ないものか | “难道没有办法……吗” |

## 30 感嘆（かんたん）・願望（がんぼう）

### 30・1 〜だろう（感嘆（かんたん）） ★3

**【意味（いみ）】非常（ひじょう）に〜だ／なんと〜なのだ (多么……啊／真……啊)**

①（月（つき）を見（み）て）ああ、なんときれいな月（つき） **だろう** 。
- **中文理解**：（望着月亮）啊，多么美丽的月亮。

②（みかんを食（た）べながら）なんておいしいん **だろう** 。
- **中文理解**：（吃着橘子）真是太好吃了。

**接続（せつぞく）** なんと／なんて／どんなに／どれほど ＋ 普通形（ふつうけい）＋（の）だろう（ナA・Nの現在肯定形（げんざいこうていけい）＋ のだろう → なのだろう）

▶ 心（こころ）に強（つよ）く感（かん）じた性質（せいしつ）や程度（ていど）を、疑問語（ぎもんご）と「だろう」の形（かたち）で感嘆（かんたん）として表（あらわ）します。実際（じっさい）の答（こた）えを求（もと）める疑問文（ぎもんぶん）ではありません。（用疑问词与「だろう」构成感叹，强调程度之深，并非真的提问。）

▶ 名詞句（めいしく）では①の「なんときれいな月（つき）だろう」のような形（かたち）が自然（しぜん）です。述語（じゅつご）を強調（きょうちょう）するときは「なんておいしいんだろう」「どんなに大変（たいへん）だったんだろう」のように「ん／の」を伴（ともな）うことが多（おお）いです。

> **普通（ふつう）の推量（すいりょう）との違（ちが）い**：「明日（あした）は雨（あめ）だろう」は“明天大概会下雨”；「なんて激（はげ）しい雨（あめ）だろう」は“雨下得多大啊”。疑问词与语境决定这里是感叹。

### 30・2 〜てほしい ★3

**【意味（いみ）】〜てもらいたい／その状態（じょうたい）になってもらいたい (希望……／希望能……)**

①毎日（まいにち）、暑（あつ）い日（ひ）が続（つづ）いています。早（はや）く涼（すず）しくなって **ほしい** ですね。（手紙（てがみ））
- **中文理解**：炎热的日子天天持续，真希望天气早点凉快下来。（书信）

②子（こ）どもには、他人（たにん）の気持（きも）ちを考（かんが）えないような人（ひと）になって **ほしくない** 。
- **中文理解**：我不希望孩子成为不顾别人感受的人。

③「また、酒（さけ）を飲（の）んだな」
　「兄（にい）さんだって飲（の）んでるのに。そんなこと言（い）わないで **ほしい** 」
- **中文理解**：“你又喝酒了吧。”“哥哥你明明也在喝，别那样说我。”

④親（おや）は、生（う）まれた子（こ）に元気（げんき）に育（そだ）って **ほしい** と願（ねが）う。
- **中文理解**：父母希望刚出生的孩子健康成长。

**接続（せつぞく）** （Nに）Vて形（けい）・Vないで ＋ ほしい

▶ 話（はな）し手（て）が、相手（あいて）や第三者（だいさんしゃ）にある行動（こうどう）をしてもらいたい、または事態（じたい）がある状態（じょうたい）になってほしいと願（ねが）う表現（ひょうげん）です。行動（こうどう）の主体（しゅたい）は普通（ふつう）「Nに」で示（しめ）します。（表示希望对方、第三者采取某行动，或希望某种状态出现。）

▶ 直接（ちょくせつ）相手（あいて）に言（い）えば要望（ようぼう）・依頼（いらい）になります。目上（めうえ）の人（ひと）には「〜ていただきたい」「〜ていただけるとありがたい」などの方（ほう）が丁寧（ていねい）です。

**【二（ふた）つの否定形（ひていけい）】**

- 「Vないでほしい」：その行動（こうどう）をしないよう直接（ちょくせつ）求（もと）める。例（れい）：ここでは写真（しゃしん）を撮（と）らないでほしい。
- 「Vてほしくない」：その行動（こうどう）が起（お）こることを自分（じぶん）は望（のぞ）まない。例（れい）：子（こ）どもには危険（きけん）な場所（ばしょ）へ行（い）ってほしくない。

两者在很多场景中接近，但「ないでほしい」更像直接请求“不做”，「てほしくない」更突出说话人的不愿与担忧。

### 30・3 〜ものだ（回想（かいそう）） ★2

**【意味（いみ）】昔（むかし）はよく〜した／〜だったなあ (以前常常……／那时候真是……)**

①子（こ）どもの頃（ころ）、寝（ね）る前（まえ）に母（はは）がよく絵本（えほん）を読（よ）んでくれた **ものだ** 。
- **中文理解**：小时候，睡前母亲常给我读绘本。

②小学校（しょうがっこう）の頃（ころ）、兄（あに）とけんかをして、よく父（ちち）に叱（しか）られた **ものだ** 。
- **中文理解**：小学时，我常因和哥哥打架而被父亲训斥。

③学生（がくせい）の頃（ころ）、クラブ活動（かつどう）で夜遅（よるおそ）くまで歌（うた）を歌（うた）い、語（かた）り合（あ）った **ものだ** 。
- **中文理解**：学生时代参加社团活动时，我们常唱歌、谈心到深夜。

④昔（むかし）、この辺（あた）りは本当（ほんとう）に静（しず）かだった **ものだ** 。
- **中文理解**：从前这一带可真安静啊。

**接続（せつぞく）** Vた形（けい）（中心（ちゅうしん））／イAかった／ナAだった ＋ ものだ

▶ 過去（かこ）に繰（く）り返（かえ）した行動（こうどう）や、長（なが）く続（つづ）いた状態（じょうたい）を思（おも）い出（だ）し、懐（なつ）かしさや感慨（かんがい）を込（こ）めて述（の）べます。「昔（むかし）は」「子（こ）どもの頃（ころ）」「よく」などとよく共起（きょうき）します。（带着怀念回想过去反复发生的行为或持续的状态。）

▶ ただ過去（かこ）の事実（じじつ）を報告（ほうこく）する表現（ひょうげん）ではありません。「去年（きょねん）京都（きょうと）へ行（い）ったものだ」は、一度（いちど）の旅行（りょこう）を単（たん）に報告（ほうこく）するだけなら不自然（ふしぜん）で、「行（い）った」と言（い）えば十分（じゅうぶん）です。一度（いちど）の出来事（できごと）でも、それに驚（おどろ）きや感心（かんしん）を込（こ）める場合（ばあい）は、次節（じせつ）の感嘆用法（かんたんようほう）になることがあります。

→ 28課（か）4「〜ものだ（常識（じょうしき））」／30課（か）4「〜ものだ（感嘆（かんたん））」

### 30・4 〜ものだ（感嘆（かんたん）） ★2

**【意味（いみ）】本当（ほんとう）に〜だなあ／よく〜できるなあ (真是……啊／居然能……)**

①小（ちい）さな子（こ）どもが、よくこんな難（むずか）しい体操（たいそう）をする **ものだ** 。大（たい）した **もんだ** 。
- **中文理解**：这么小的孩子居然能做这样困难的体操，真了不起。这里的「よく」是“竟能、亏能”，不是“经常”。

②タンさんは10歳（じゅっさい）のときに両親（りょうしん）を亡（な）くしたそうだ。今日（きょう）まで1人（ひとり）でよく生（い）きてきた **ものだ** 。
- **中文理解**：听说小谭 10 岁时失去了双亲，竟能独自生活到今天，真不容易。

③月日（つきひ）のたつのは早（はや）い **もんで** 、日本（にほん）に来（き）たのはもう10年（じゅうねん）も前（まえ）のことだ。
- **中文理解**：岁月过得真快，来日本已经是十年前的事了。

④外国（がいこく）に住（す）んで、その国（くに）のことを知（し）るのは楽（たの）しい **ものだ** 。
- **中文理解**：住在国外并逐渐了解那个国家，确实是一件有趣的事。

**接続（せつぞく）** 普通形（ふつうけい）（主（おも）に非過去形（ひかこけい）；ナAは「な」）＋ ものだ

▶ ある能力（のうりょく）・行動（こうどう）・変化（へんか）に驚（おどろ）いたり、感心（かんしん）したり、ある様子（ようす）や性質（せいしつ）をしみじみ感（かん）じたりするときに使（つか）います。「よく〜ものだ」は文脈（ぶんみゃく）によって「よく〜した（经常做）」にも「よく〜できる（竟能做）」にもなります。時制（じせい）と文脈（ぶんみゃく）を見（み）て判断（はんだん）します。

▶ ④のように、経験（けいけん）から得（え）た一般的（いっぱんてき）な感想（かんそう）を述（の）べることもあります。第（だい）28課（か）の「約束（やくそく）は守（まも）るものだ」は規範（きはん）や常識（じょうしき）を示（しめ）しますが、本節（ほんせつ）の用法（ようほう）は感情（かんじょう）を込（こ）めた評価（ひょうか）です。会話（かいわ）では「もんだ」と言（い）います。

▶ この感嘆用法（かんたんようほう）では、Nに「ものだ」が直接（ちょくせつ）続（つづ）くことは普通（ふつう）ありません。「それが人生（じんせい）というものだ」の「N＋というものだ」は、第（だい）29課（か）6の別（べつ）の文型（ぶんけい）です。

### 30・5 〜ことだろう・〜ことか ★2 [W]

**【意味（いみ）】どんなに／どれほど〜だろう (多么……啊／不知有多……)**

①あの子（こ）が生（い）きていると分（わ）かっただけでも、どんなにうれしい **ことだろう** 。
- **中文理解**：哪怕只是得知那个孩子还活着，也不知有多高兴。

②今（いま）ではインターネットで本（ほん）が注文（ちゅうもん）できる。なんと便利（べんり）な **ことだろう** 。
- **中文理解**：如今可以在网上订书，多么方便啊。

③朝（あさ）起（お）きるのが遅（おそ）いイチローに、試験（しけん）のときには遅（おく）れないように何度（なんど）注意（ちゅうい）した **ことか** 。
- **中文理解**：为了不让总是晚起的一郎在考试时迟到，我不知提醒过他多少次。

④小鳥（ことり）が死（し）んだとき、ケンがどんなに悲（かな）しんだ **ことか** 。
- **中文理解**：小鸟死去时，肯不知有多伤心。

**接続（せつぞく）** どんなに／どれほど／何度（なんど）など ＋ 普通形（ふつうけい）＋ ことだろう・ことか

▶ 感情（かんじょう）・程度（ていど）・回数（かいすう）が非常（ひじょう）に大（おお）きいことを、疑問（ぎもん）の形（かたち）で強調（きょうちょう）します。「ことか」は強（つよ）い実感（じっかん）を言（い）い切（き）る響（ひび）きがあります。「ことだろう」は自分（じぶん）の感嘆（かんたん）のほか、他人（たにん）の気持（きも）ちを想像（そうぞう）し、「どれほど〜だろう」と思（おも）いやるときにもよく使（つか）います。（用疑问形式强调感情、程度或次数之大。）

▶ 「何度（なんど）〜たことか」「どれだけ〜たことか」は、回数（かいすう）や程度（ていど）が非常（ひじょう）に大（おお）きかったことを感嘆的（かんたんてき）に表（あらわ）し、正確（せいかく）な数（かず）を尋（たず）ねているのではありません。ナAの現在肯定形（げんざいこうていけい）は「便利（べんり）なことだろう」、過去（かこ）の事態（じたい）は「どんなに大変（たいへん）だったことか」のように言（い）います。

### 30・6 〜ことだ（感嘆（かんたん）） ★2

**【意味（いみ）】本当（ほんとう）に〜だ／非常（ひじょう）に〜だ (真是……啊／非常……)**

①弟（おとうと）の就職（しゅうしょく）が決（き）まった。本当（ほんとう）にうれしい **ことだ** 。
- **中文理解**：弟弟的工作定下来了，真是令人高兴。

②10年前（じゅうねんまえ）、この図書館（としょかん）でよく本（ほん）を借（か）りて読（よ）んだ。懐（なつ）かしい **ことだ** 。
- **中文理解**：十年前常在这座图书馆借书读，真令人怀念。

③昨夜（さくや）のテニスの試合（しあい）では、A選手（せんしゅ）は最後（さいご）に負（ま）けてしまった。残念（ざんねん）な **ことだ** 。
- **中文理解**：昨晚的网球比赛中，A 选手最后输了，真遗憾。

**接続（せつぞく）** イAい／ナAな ＋ ことだ

▶ 既（すで）に分（わ）かっている事実（じじつ）について、話（はな）し手（て）が抱（いだ）いた喜（よろこ）び・懐（なつ）かしさ・残念（ざんねん）さなどを、やや硬（かた）く感情（かんじょう）を込（こ）めて述（の）べます。感情（かんじょう）・評価（ひょうか）を表（あらわ）す形容詞（けいようし）に付（つ）くことが多（おお）いです。（对已知事实作出带感情色彩的评价，语气略显书面、感叹。）

> **第（だい）28課（か）との違（ちが）い**：「上手（じょうず）になりたければ練習（れんしゅう）することだ」は忠告（ちゅうこく）です。「弟（おとうと）の就職（しゅうしょく）が決（き）まった。本当（ほんとう）にうれしいことだ」は感嘆（かんたん）です。V辞書形（じしょけい）・Vない形（けい）に続（つづ）く場合（ばあい）は普通（ふつう）忠告（ちゅうこく）、感情形容詞（かんじょうけいようし）に続（つづ）く場合（ばあい）は本節（ほんせつ）の用法（ようほう）です。

### 30・7 〜ことに（は） ★2

**【意味（いみ）】〜と感（かん）じることだが／〜なのは (令人……的是／……的是)**

①うれしい **ことに** 、彼女（かのじょ）が「イエス」という返事（へんじ）をくれた。
- **中文理解**：令人高兴的是，她给了我肯定的答复。

②不思議（ふしぎ）な **ことに** 、空（そら）から魚（さかな）が降（ふ）ってきたそうだ。
- **中文理解**：令人不可思议的是，听说鱼从天上掉了下来。

③悔（くや）しい **ことに** 、1点差（いってんさ）でA校（こう）との野球（やきゅう）の試合（しあい）に負（ま）けてしまった。
- **中文理解**：令人懊恼的是，我们在与 A 校的棒球赛中以一分之差落败。

④驚（おどろ）いた **ことには** 、彼（かれ）は一晩（ひとばん）でその仕事（しごと）を終（お）わらせた。
- **中文理解**：令人吃惊的是，他一夜之间就完成了那项工作。

**接続（せつぞく）** 感情（かんじょう）・評価（ひょうか）を表（あらわ）す Vた形（けい）／イAい／ナAな ＋ ことに（は）

▶ 文頭（ぶんとう）で話（はな）し手（て）の感情（かんじょう）・評価（ひょうか）を先（さき）に示（しめ）し、その後（あと）に感情（かんじょう）の原因（げんいん）となる具体的（ぐたいてき）な事実（じじつ）を述（の）べます。やや書（か）き言葉的（ことばてき）な表現（ひょうげん）です。「ことには」は感情（かんじょう）をさらに取（と）り立（た）てます。（先给出说话人的感受，再说明引起该感受的具体事实。）

▶ 後（うし）ろには、普通（ふつう）、すでに成立（せいりつ）した事実（じじつ）や判明（はんめい）した結果（けっか）が来（き）ます。単純（たんじゅん）な意志（いし）・命令（めいれい）・誘（さそ）いを表（あらわ）す文（ぶん）は続（つづ）きにくいです。

- △ うれしいことに、来年（らいねん）カナダに留学（りゅうがく）するつもりだ。（只是陈述自己的打算，感情的依据尚未成为事实。）
- ○ うれしいことに、来年（らいねん）カナダに留学（りゅうがく）できることになった。（留学一事已经确定。）

### 30・8 〜ものがある ★2

**【意味（いみ）】確（たし）かに〜と感（かん）じさせる性質（せいしつ）がある (确有一种……之处／有种令人……的感觉)**

①半年前（はんとしまえ）にいなくなった猫（ねこ）が帰（かえ）ってきた。私（わたし）にとって、特別（とくべつ）うれしい **ものがある** 。
- **中文理解**：半年前走失的猫回来了，对我而言，确有一种格外的喜悦。

②長年（ながねん）通学（つうがく）に使（つか）っていた電車（でんしゃ）が廃止（はいし）されることになった。何（なん）となく寂（さび）しい **ものがある** 。
- **中文理解**：多年来上学乘坐的电车要停运了，总有一种难言的寂寞。

③20年（にじゅうねん）続（つづ）けてきた日本語教室（にほんごきょうしつ）が、建物（たてもの）の都合（つごう）で閉（と）じられることになった。私（わたし）には残念（ざんねん）な **ものがある** 。
- **中文理解**：办了二十年的日语教室因场地原因要关闭，我确实深感遗憾。

④彼（かれ）の演説（えんぜつ）には、人（ひと）の心（こころ）を動（うご）かす **ものがある** 。
- **中文理解**：他的演说有一种打动人心的力量。

**接続（せつぞく）** V辞書形（じしょけい）・Vない形（けい）／イAい／ナAな ＋ ものがある

▶ 予想（よそう）していなかった事実（じじつ）を見（み）たり聞（き）いたりして、驚（おどろ）き・感心（かんしん）・失望（しつぼう）などを表（あらわ）します。後（あと）の「驚（おどろ）いた」「信（しん）じられない」などが省略（しょうりゃく）され、①のように感嘆部分（かんたんぶぶん）が文末（ぶんまつ）に倒置（とうち）されることも多（おお）いです。（把意外事实作为惊讶、感慨等情绪的对象；后项常省略。）

## まとめ：「もの」と「こと」の見分（みわ）け方（かた）

| 形式 | 主要作用 | 例 |
| :--- | :--- | :--- |
| Vた＋ものだ | 怀念过去 | 昔（むかし）はよく遊（あそ）んだものだ。 |
| 普通形＋ものだ | 感叹、一般感慨 | よく一人（ひとり）でできたものだ。 |
| 〜ものがある | 感到某种突出特质 | 心（こころ）を動（うご）かすものがある。 |
| 〜たいものだ | 由衷愿望 | 一度（いちど）は行（い）きたいものだ。 |
| 〜ないものか | 寻求实现可能 | 何（なん）とか直（なお）せないものか。 |
| 〜ことだろう／ことか | 感叹程度、次数 | どんなに喜（よろこ）んだことか。 |
| 感情形容词＋ことだ | 对事实作感情评价 | 本当（ほんとう）に残念（ざんねん）なことだ。 |
| 感情表达＋ことに | 先评价，后说明事实 | 幸（さいわ）いなことに、全員（ぜんいん）無事（ぶじ）だった。 |

「もの」往往把经历、性质或愿望当作一种有分量的感受来表达；「こと」则更常把事实、程度或评价作为内容来突出。最终仍需按各句型的固定接续判断，不能只凭中文的“事／东西”来选择。
