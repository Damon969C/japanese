- 本集新增文法从 `G0272` 到 `G0303`，重点覆盖服务说明、条件判断、让步责备、即时处理、口语副词、险些发生和话题限定。
- 值得复习的口语缩约包括 `っつう/っつー`、`ちゃう`、`てる/てん`、`こっから`、`すんの`、`じゃん`。
- 下一集 `E05` 从 `0001` 开始继续按约 200 字幕块推进。
