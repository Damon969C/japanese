# 18 逆接（ぎゃくせつ）・譲歩（じょうほ） (转折・让步)

前（まえ）の事柄（ことがら）から普通（ふつう）に予想（よそう）されることと違（ちが）う結果（けっか）を述（の）べたり、前提（ぜんてい）を認（みと）めた上（うえ）で別（べつ）の判断（はんだん）を示（しめ）したりするときは、どんな言（い）い方（かた）がありますか。 (想表达与前项通常预期不同的结果，或先承认前提再提出另一判断时，可以使用哪些表达方式呢？)

| 功能 | 句型 | 核心语感 |
| :--- | :--- | :--- |
| 修正名称带来的过度想象 | 〜といっても | 虽说是……，实际不过…… |
| 同一主体的矛盾状态 | 〜ながら（も）、〜つつ（も） | 虽然处于前项状态，却…… |
| 带责备的反常行为 | 〜くせに・〜くせして | 明明……却…… |
| 承认事实后补充相反情况 | 〜ものの・〜とはいうものの、〜とはいえ | 虽承认……，但实际…… |
| 不受既成事实影响 | 〜にもかかわらず | 尽管……仍…… |
| 否定由理由直接推出结论 | 〜からといって | 不能仅仅因为……就…… |
| 假定让步 | 〜にしても・〜にしろ・〜にせよ | 即便承认……也…… |
| 后悔、不满与体谅 | 〜ものを、〜ところを | 本来……却；在……情况下还…… |
| 连特殊对象也不例外 | 〜といえども | 即使是……也…… |
| 结果出乎预料 | 〜と思いきや | 原以为……，不料…… |

## 学習前（がくしゅうまえ）の小（しょう）テスト (课前小测验)

### 知（し）っていますか

①入院（にゅういん）（ **といっても** ）、検査（けんさ）のために1日（いちにち）入院（にゅういん）するだけです。
- **中文理解**：虽说要住院，其实只是为了检查住一天。

②この辺（あた）りは都心（としん）の近（ちか）くにあり（ **ながら** ）、緑（みどり）も多（おお）く、静（しず）かな住宅地（じゅうたくち）です。
- **中文理解**：这一带虽然靠近市中心，却绿地很多，是片安静的住宅区。

③太郎（たろう）は自分（じぶん）では歌（うた）えない（ **くせに** ）、ほかの人（ひと）の歌（うた）を「下手（へた）だ、下手（へた）だ」と言（い）う。
- **中文理解**：太郎自己明明不会唱，却总说别人唱得差。

④昼間（ひるま）は晴（は）れる（ **ものの** ）、北風（きたかぜ）が強（つよ）く、気温（きおん）は上（あ）がらないでしょう。（天気（てんき）予報（よほう））
- **中文理解**：白天虽会放晴，但北风强劲，气温预计不会上升。（天气预报）

⑤日本人（にほんじん）だ（ **からといって** ）、日本（にほん）のことをよく知（し）っているとは限（かぎ）らない。
- **中文理解**：不能仅仅因为是日本人，就认定他一定很了解日本。

### 使（つか）えますか

①経験（けいけん）がある（ **といっても** ）、まだこの仕事（しごと）を始（はじ）めて3年（さんねん）です。
- **中文理解**：虽说有经验，但这份工作也才做了三年。

②彼（かれ）は通勤（つうきん）に15分（じゅうごふん）しかかからない所（ところ）に住（す）んでいる（ **くせに** ）、遅刻（ちこく）が多（おお）い。
- **中文理解**：他明明住在通勤只需十五分钟的地方，却经常迟到。

③雨（あめ）（ **にもかかわらず** ）、大勢（おおぜい）の人（ひと）が集（あつ）まった。
- **中文理解**：尽管下着雨，仍有很多人到场。

④新入（しんにゅう）社員（しゃいん）である（ **にしても** ）、彼（かれ）は仕事（しごと）が遅（おそ）すぎる。
- **中文理解**：就算他是新员工，做事也未免太慢了。

⑤自分（じぶん）でも悪（わる）いと知（し）り（ **つつ** ）、試験（しけん）のときに友（とも）だちの答（こた）えを見（み）てしまった。
- **中文理解**：明知这样不对，考试时还是看了朋友的答案。

### 18・1 〜といっても ★3

**【意味（いみ）】〜というけれども、実際（じっさい）は (虽说……，但实际……)**

①わたしの住（す）んでいるマンションの隣（となり）に公園（こうえん）があります。公園（こうえん）（ **といっても** ）、普通（ふつう）の家（いえ）の庭（にわ）のように小（ちい）さなものです。
- **中文理解**：我住的公寓旁有个公园。虽说是公园，其实小得像普通人家的院子。

②授業料（じゅぎょうりょう）は高（たか）い（ **といっても** ）、わたしに払（はら）えないほど高（たか）くはなかった。
- **中文理解**：学费虽贵，却没有贵到我付不起的程度。

③家（いえ）では家族（かぞく）みんながよく集（あつ）まって一緒（いっしょ）に過（す）ごします。一緒（いっしょ）に（ **といっても** ）、テレビを見（み）るだけなんですが。
- **中文理解**：在家时全家人常聚在一起。说是“一起相处”，其实也只是看看电视。

④わたしはフランス語（ご）が分（わ）かる（ **といっても** ）、料理（りょうり）関係（かんけい）の言葉（ことば）だけなんです。
- **中文理解**：虽说我懂法语，其实只懂烹饪方面的词汇。

**接続（せつぞく）** N／普通形（ふつうけい）＋ といっても
▶ 前（まえ）の言葉（ことば）から相手（あいて）が想像（そうぞう）しそうな程度（ていど）・内容（ないよう）を修正（しゅうせい）し、「実際（じっさい）はそれほどではない／少（すこ）し違（ちが）う」と説明（せつめい）する。（修正对方可能由前项产生的程度或内容上的想象，说明实际没到那种程度，或情况略有不同。）

**【扩展说明】**
它并非单纯把两个相反事实连接起来，而是先沿用某个名称或评价，再缩小、限定其实际内容。典型结构为「Nといっても、実は……」「普通形といっても、……だけだ」。口语中也说「っていっても」。

### 18・2 〜ながら・〜ながらも ★2

**【意味（いみ）】〜のに／〜だが (虽然……却……)**

①田中（たなか）さん一家（いっか）はお金（かね）があり（ **ながら** ）、とても地味（じみ）に暮（く）らしている。
- **中文理解**：田中一家虽然有钱，生活却十分朴素。

②わたしは40歳（よんじゅっさい）のときに、小（ちい）さい（ **ながら** ）自分（じぶん）の家（いえ）を持（も）つことができた。
- **中文理解**：我四十岁时拥有了自己的房子，虽然房子不大。

③残念（ざんねん）（ **ながら** ）、日本（にほん）の代表（だいひょう）チームは負（ま）けてしまった。
- **中文理解**：很遗憾，日本代表队输了。

④太郎（たろう）は子（こ）ども（ **ながらも** ）、しっかりした考（かんが）えを持（も）っている。
- **中文理解**：太郎虽然还是个孩子，却有成熟稳重的想法。

⑤1歳（いっさい）のケンは、ゆっくり（ **ながらも** ）、自分（じぶん）で歩（ある）けるようになった。
- **中文理解**：一岁的小健虽然走得慢，却已经能自己走路了。

⑥彼（かれ）らは貧（まず）しい（ **ながらも** ）、互（たが）いに助（たす）け合（あ）って心（こころ）豊（ゆた）かな生活（せいかつ）をしていた。
- **中文理解**：他们虽然贫穷，却互相帮助，过着精神富足的生活。

**接続（せつぞく）** Vます形（けい）の語幹（ごかん）／イA普通形（ふつうけい）／ナA語幹（ごかん）／N ＋ ながら（も）　　ナA・N ＋ でありながら（も）
▶ 同（おな）じ主体（しゅたい）にある二（ふた）つの状態（じょうたい）・性質（せいしつ）を取（と）り上（あ）げ、前（まえ）の状態（じょうたい）から予想（よそう）されることに反（はん）して、後（あと）の状態（じょうたい）も成（な）り立（た）つと述（の）べる。（提出同一主体具有的两种状态或性质，表示后项与由前项产生的预期相反，却仍然成立。）

**【扩展说明】**
动词多为「ある→ありながら」「知っている→知っていながら」等状态性表达；「食べながら話す」表示两个动作同时进行，是另一个基础用法。例③「残念ながら」是固定的评注表达，用来委婉引出不理想的消息。例⑤接副词「ゆっくり」属于有限的扩展用法。

「ながらも」比「ながら」更明确地突出转折，常见于书面语。逆接用法原则上让前后项围绕同一主体或主题；若主语完全不同，使用「のに／にもかかわらず」通常更清楚。

### 18・3 〜つつ・〜つつも ★2

**【意味（いみ）】〜ているのに／〜と思（おも）いながら (虽然……；明知……却……)**

①マリはダイエット中（ちゅう）だと言（い）い（ **つつ** ）、甘（あま）いものを見（み）ると買（か）ってくる。
- **中文理解**：玛丽嘴上说在减肥，一看到甜食却还是会买回来。

②早（はや）くお金（かね）を払（はら）い込（こ）まなければと思（おも）い（ **つつ** ）、遅（おそ）くなってしまいました。
- **中文理解**：一直想着必须赶快把钱汇过去，结果还是拖晚了。

③悪（わる）いと知（し）り（ **つつも** ）、拾（ひろ）った5,000円（ごせんえん）を警察（けいさつ）に届（とど）けず、使（つか）ってしまった。
- **中文理解**：明知道不对，却没把捡到的五千日元交给警察，反而花掉了。

④春子（はるこ）が元気（げんき）でないことが気（き）になり（ **つつも** ）、忙（いそが）しかったので、何（なに）も聞（き）かずに帰（かえ）ってきてしまった。
- **中文理解**：虽然很在意春子没精神的样子，但因为忙，什么也没问就回来了。

**接続（せつぞく）** Vます形（けい）の語幹（ごかん）＋ つつ・つつも
▶ 心（こころ）では前（まえ）のことを意識（いしき）している、または言葉（ことば）では前（まえ）のように言（い）っているのに、実際（じっさい）の行動（こうどう）がそれと矛盾（むじゅん）することを表（あらわ）す。（表示心里明知或嘴上虽那么说，实际行动却与之矛盾。）

**【扩展说明】**
常用于反省、后悔或坦白，典型搭配有「知りつつ」「思いつつ」「気になりつつ」。语体比「ながら」正式，书面语较多；「つつも」会让转折更明确。「働きつつ学ぶ」也可表示两个动作并行，相当于「働きながら学ぶ」，需与本节逆接用法区分。

### 18・4 〜くせに・〜くせして ★2

**【意味（いみ）】〜のに、実際（じっさい）は (明明……却……)**

①彼（かれ）は本当（ほんとう）のことを知（し）っている（ **くせに** ）、わたしに教（おし）えてくれない。
- **中文理解**：他明明知道真相，却不告诉我。

②今度（こんど）この会（かい）に入（はい）った人（ひと）は、新人（しんじん）の（ **くせに** ）、先輩（せんぱい）に挨拶（あいさつ）もしない。
- **中文理解**：这次新加入的人明明是新人，却连招呼也不向前辈打。

③あの人（ひと）はお金（かね）もない（ **くせに** ）、ブランド品（ひん）を買（か）う話（はなし）ばかりする。
- **中文理解**：那个人明明没钱，却净谈买名牌商品的事。

④ほかの人（ひと）のことを馬鹿（ばか）にするもんじゃないよ。自分（じぶん）は何（なに）もできない（ **くせして** ）。
- **中文理解**：别瞧不起别人。明明你自己什么也不会。

**接続（せつぞく）** 普通形（ふつうけい）（ナAな／Nの）＋ くせに　　普通形（ふつうけい）＋ くせして
▶ 同（おな）じ人（ひと）の立場（たちば）・能力（のうりょく）・発言（はつげん）と実際（じっさい）の行動（こうどう）の矛盾（むじゅん）を取（と）り上（あ）げ、非難（ひなん）・軽蔑（けいべつ）・不満（ふまん）を表（あらわ）す。（指出同一个人的身份、能力或说法与实际行为之间的矛盾，表达责备、轻蔑或不满。）

**【扩展说明】**
比中性的「のに」攻击性更强，不能用于需要保持礼貌的客观说明。前后项通常以同一人物为中心，因为说话人是在责怪此人的“条件与行为不相称”。「くせして」更口语、更粗鲁；也常省略后项，以「知っているくせに！」结束。

### 18・5 〜ものの・〜とはいうものの ★2

**【意味（いみ）】〜ことは認（みと）めるが、しかし (虽然……，但……)**

①祖父（そふ）は元気（げんき）ではある（ **ものの** ）、居眠（いねむ）りをしている時間（じかん）が多（おお）くなってきた。
- **中文理解**：祖父虽然还算硬朗，但打瞌睡的时间渐渐多了。

②襟（えり）に毛皮（けがわ）の付（つ）いたコートを買（か）った（ **ものの** ）、暖冬（だんとう）なので着（き）ていく機会（きかい）がほとんどない。
- **中文理解**：虽然买了件毛皮领大衣，但因为是暖冬，几乎没有机会穿出去。

③彼（かれ）は「やります」とは言（い）った（ **ものの** ）、実際（じっさい）にはできないのではないか。
- **中文理解**：他虽然说了“我来做”，实际上恐怕做不到吧。

④暦（こよみ）の上（うえ）では春（はる）だ（ **とはいうものの** ）、まだまだ寒（さむ）い日（ひ）が続（つづ）く。
- **中文理解**：虽说按节气已是春天，寒冷的日子仍会持续。

⑤20歳（はたち）を超（こ）えている（ **とはいうものの** ）、彼女（かのじょ）は考（かんが）え方（かた）もすることもまだ幼（おさな）い。
- **中文理解**：虽说她已经超过二十岁，想法和行为却仍很幼稚。

**接続（せつぞく）** 普通形（ふつうけい）（ナAは「〜な／〜である」、Nは「〜である」）＋ ものの ／ N・普通形（ふつうけい）＋ とはいうものの
▶ 前（まえ）の事実（じじつ）を一応（いちおう）認（みと）めた上（うえ）で、その事実（じじつ）から普通（ふつう）に期待（きたい）される結果（けっか）にはならないと述（の）べる。（先承认前项事实，再说明事情并未发展成由该事实通常可预期的结果。）

**【扩展说明】**
「ものの」偏书面，常连接已经成立的事实与不理想、未完成或相反的现实。「とはいうものの」有“话虽如此”的回头修正感，可承接刚说过的话，也可独立放在句首写成「とはいうものの、……」。两者都比「けれども」正式。

### 18・6 〜にもかかわらず ★2

**【意味（いみ）】〜のに、それに影響（えいきょう）されず (尽管……却……)**

①家族（かぞく）が反対（はんたい）した（ **にもかかわらず** ）、彼（かれ）は家族（かぞく）を置（お）いてフランスへ料理（りょうり）の修業（しゅぎょう）に行（い）ってしまった。
- **中文理解**：尽管家人反对，他还是抛下家人去法国学习厨艺了。

②本日（ほんじつ）は悪天候（あくてんこう）（ **にもかかわらず** ）、このように大勢（おおぜい）の方々（かたがた）がお集（あつ）まりくださいまして、ありがとうございます。
- **中文理解**：今天天气恶劣，各位仍这样踊跃到场，谨致谢意。

③忙（いそが）しい日程（にってい）である（ **にもかかわらず** ）、大臣（だいじん）は人々（ひとびと）との直接（ちょくせつ）対話（たいわ）を強（つよ）く望（のぞ）んだ。
- **中文理解**：尽管日程繁忙，大臣仍强烈希望与民众直接对话。

**接続（せつぞく）** N／普通形（ふつうけい）（ナA・Nは「〜である」）＋ にもかかわらず
▶ 前（まえ）の事実（じじつ）なら後（あと）の結果（けっか）を妨（さまた）げるはずなのに、その影響（えいきょう）を受（う）けず、予想外（よそうがい）の結果（けっか）になったと述（の）べる。（前项事实本应阻碍后项，结果却未受其影响，出现了出乎预料的情况。）

**【扩展说明】**
语气正式，常见于书面说明、致辞和新闻。根据语境可带惊讶、赞赏或责备。注意不要与第14章的「Nにかかわらず（不论N如何）」混淆：「雨にもかかわらず」是“尽管下雨”，「天候にかかわらず」是“不论天气如何”。

### 18・7 〜からといって ★2

**【意味（いみ）】〜という理由（りゆう）だけで、当然（とうぜん）…とは言（い）えない (不能仅因为……就……)**

①大学（だいがく）を出（で）た（ **からといって** ）、教養（きょうよう）があるとは限（かぎ）らない。
- **中文理解**：不能因为读过大学，就认定一定有教养。

②田中（たなか）さんがフランスに3年（さんねん）いた（ **からといって** ）、フランスのことに詳（くわ）しいわけではない。
- **中文理解**：不能因为田中在法国待了三年，就认为他一定熟悉法国。

③おいしい（ **からといって** ）、際限（さいげん）なく食（た）べたら、おなかを壊（こわ）しますよ。
- **中文理解**：不能因为好吃就没有节制地吃，否则会吃坏肚子。

④好（す）きだ（ **からって** ）、肉（にく）ばかり食（た）べちゃだめだよ。野菜（やさい）も食（た）べなきゃ。
- **中文理解**：不能因为喜欢就只吃肉。蔬菜也得吃。

⑤「先生（せんせい）に聞（き）いてみたら」
「先生（せんせい）だ（ **からって** ）、分（わ）かるとは限（かぎ）らないよ」
- **中文理解**：“问问老师怎么样？”“就算是老师，也未必知道啊。”

**接続（せつぞく）** 普通形（ふつうけい）＋ からといって
▶ 前（まえ）の理由（りゆう）から後（あと）の結論（けつろん）を単純（たんじゅん）に導（みちび）くことを否定（ひてい）し、話者（わしゃ）の判断（はんだん）・注意（ちゅうい）・批判（ひはん）を述（の）べる。（否定从前项理由直接推出后项结论，并表达说话人的判断、提醒或批评。）

**【扩展说明】**
中文不宜一律只译成“虽说……但是……”，其核心是“仅凭这个理由，并不能……”。后项常用「とは限らない・わけではない・てはいけない」等部分否定、禁止或否定判断。口语形式为「からって」。

### 18・8 〜にしても・〜にしろ・〜にせよ ★2

**【意味（いみ）】仮（かり）に〜を認（みと）めても (即使……也……；就算……也……)**

①いくら忙（いそが）しかった（ **にしても** ）、携帯（けいたい）でメールを送（おく）るくらいはできただろう。どうして彼（かれ）は外国（がいこく）へ行（い）くことをわたしに知（し）らせてくれなかったのだろうか。
- **中文理解**：就算再忙，发一条手机邮件总做得到吧。他为什么没告诉我要去国外呢？

②電車（でんしゃ）の事故（じこ）があった（ **にしろ** ）、約束（やくそく）の時間（じかん）に遅（おく）れたのだから、一言（ひとこと）謝（あやま）った方（ほう）がいい。
- **中文理解**：即使电车出了事故，既然迟到了，也最好先道一声歉。

③今度（こんど）の爆発（ばくはつ）事件（じけん）とは関係（かんけい）がなかった（ **にしろ** ）、あの人（ひと）たちが危（あぶ）ないことをしているのは確（たし）かだ。
- **中文理解**：即使与这次爆炸事件无关，那些人在从事危险活动也是事实。

④田中（たなか）さんほどではない（ **にせよ** ）、山本（やまもと）さんだってよく遅（おく）れてくる。
- **中文理解**：即使没田中那么严重，山本也经常迟到。

⑤いくら無料（むりょう）（ **にしたって** ）、あんなつまらないものを見（み）せるとはひどい。見（み）るだけ時間（じかん）の無駄（むだ）だ。
- **中文理解**：就算免费，让人看那么无聊的东西也太过分了；看它只是浪费时间。

**接続（せつぞく）** N／普通形（ふつうけい）（ナA・Nは「〜である」も可（か））＋ にしても・にしろ・にせよ
▶ 前（まえ）の事情（じじょう）を仮（かり）に事実（じじつ）として認（みと）めても、後（あと）の意見（いけん）・批判（ひはん）・評価（ひょうか）は変（か）わらないと述（の）べる。（即便暂且承认前项情况为事实，后项意见、批评或评价仍不改变。）

**【扩展说明】**
后项常带“仍不能接受”“也应该……”等说话人的立场。「にしろ／にせよ」比「にしても」正式，「にせよ」书面色彩尤其明显；口语中可说「にしたって」。常与「いくら・どんなに」呼应。

第15章的「AにしてもBにしても」用于列举并表示“A、B都……”；本节只有一个让步条件，表示“即便A……”。形式相同，结构和功能不同。

### 18・10 〜ものを ★1

**【意味（いみ）】〜すればよかったのに／〜のに (本来……就好了，可是……)**

①電車（でんしゃ）に乗（の）れば早（はや）く着（つ）いた（ **ものを** ）、タクシーに乗（の）ったから渋滞（じゅうたい）に巻（ま）き込（こ）まれ、かえって遅（おそ）くなってしまった。
- **中文理解**：本来坐电车能早到，却坐出租车遇上堵车，反而迟到了。

②寒（さむ）い日（ひ）にジョギングなんかしなければいい（ **ものを** ）、無理（むり）をするから風邪（かぜ）を引（ひ）いたんです。
- **中文理解**：大冷天本来不去跑步就好了，偏要勉强自己，所以才感冒。

③夏休（なつやす）みの初（はじ）めに宿題（しゅくだい）をやっておけばよかった（ **ものを** ）。今（いま）になって後悔（こうかい）しても遅（おそ）い。
- **中文理解**：本来暑假一开始就把作业做完就好了。事到如今再后悔也晚了。

④今（いま）ならいい薬（くすり）もある。兄（あに）が病気（びょうき）になったのがあと10年（じゅうねん）遅（おそ）ければ、命（いのち）を落（お）とすこともなかった（ **ものを** ）。
- **中文理解**：如今已经有了好药。哥哥若晚十年患上那种病，本来就不会丧命。

**接続（せつぞく）** 普通形（ふつうけい）（ナAな。Nは「Nであるものを」がまれにある）＋ ものを
▶ 実際（じっさい）とは違（ちが）う望（のぞ）ましい可能性（かのうせい）を示（しめ）し、そうならなかった現実（げんじつ）への不満（ふまん）・非難（ひなん）・後悔（こうかい）・残念（ざんねん）な気持（きも）ちを表（あらわ）す。（指出一个与现实不同、原本更理想的可能性，表达对现实的不满、责备、后悔或遗憾。）

**【扩展说明】**
常与反事实条件搭配，如「〜ばよかったものを」「〜ていれば……ものを」。后项经常省略，以句末「ものを」留下遗憾或责怪的余韵。例②要表达“不去跑步就好了”，应说「しなければいいものを」；「ジョギングなんかしかければ」既不合句形，也不能表达这一意思。

### 18・11 〜ところを ★1

**【意味（いみ）】〜という状況（じょうきょう）なのに (正值……之际还……；本来可以……却……)**

①お忙（いそが）しい（ **ところを** ）、わざわざお出（で）かけくださり、ありがとうございました。
- **中文理解**：您百忙之中还特意前来，非常感谢。

②知（し）らん顔（かお）をしていてもいい（ **ところを** ）、田中（たなか）さんは「わたしがやりました」と自分（じぶん）から正直（しょうじき）に言（い）った。
- **中文理解**：本来装作不知道也可以，田中却主动坦白说“是我做的”。

③お休（やす）みの（ **ところを** ）、お邪魔（じゃま）いたしました。
- **中文理解**：在您休息的时候前来打扰，实在抱歉。

**接続（せつぞく）** 普通形（ふつうけい）（ナAな／Nの）＋ ところを
▶ 相手（あいて）が忙（いそが）しい、休（やす）んでいるなどの状況（じょうきょう）にあるのに、何（なに）かをしてもらったり妨（さまた）げたりしたことに配慮（はいりょ）を示（しめ）す。また、本来（ほんらい）なら別（べつ）の行動（こうどう）も可能（かのう）だったのに、実際（じっさい）はそうしなかったと述（の）べる。（体谅对方正处于忙碌、休息等状态却仍为自己做事或受到打扰；也可表示本可采取别的行动，实际却没有那样做。）

**【扩展说明】**
「お忙しいところを」「お休みのところを」「ご多忙のところを」是寒暄中的固定表达，后面常接感谢、道歉或请求。不要与「出かけるところを呼び止められた（正要出门时被叫住）」这种表示动作阶段的「ところを」混淆。

### 18・12 〜とはいえ ★1

**【意味（いみ）】〜ことは認（みと）めるが、それでも (虽说……，但仍……)**

①景気（けいき）が悪（わる）い（ **とはいえ** ）、歳末（さいまつ）だからか、人（ひと）の集（あつ）まる所（ところ）はきれいに飾（かざ）られている。
- **中文理解**：虽说经济不景气，也许因为到了年末，人多的地方仍装饰得很漂亮。

②親（した）しい友（とも）（ **とはいえ** ）、ある程度（ていど）の礼儀（れいぎ）と遠慮（えんりょ）が必要（ひつよう）だ。
- **中文理解**：虽说是亲近的朋友，也需要一定的礼貌和分寸。

③教授（きょうじゅ）のおっしゃること（ **とはいえ** ）、わたしには本当（ほんとう）のこととは思（おも）えない。
- **中文理解**：即使这是教授所说的话，我仍无法相信它是真的。

④秋（あき）になった（ **とはいえ** ）、日中（にっちゅう）はまだ暑（あつ）い。
- **中文理解**：虽说已经入秋，白天仍然很热。

**接続（せつぞく）** N／普通形（ふつうけい）＋ とはいえ
▶ 前（まえ）の事実（じじつ）や評価（ひょうか）を認（みと）めながら、それだけでは説明（せつめい）できない例外（れいがい）・制限（せいげん）・話者（わしゃ）の判断（はんだん）を後（あと）に加（くわ）える。（承认前项事实或评价，同时补充仅靠它无法说明的例外、限制或说话人的判断。）

**【扩展说明】**
意义接近「といっても／ものの」，但「とはいえ」较正式，重点是“即便承认这一点，后项判断仍成立”。它也可独立作接续语：「計画は順調だ。とはいえ、問題がないわけではない」。

### 18・13 〜といえども ★1

**【意味（いみ）】〜であっても例外（れいがい）ではない (即使是……也……)**

①面会（めんかい）謝絶（しゃぜつ）であるから、親友（しんゆう）（ **といえども** ）会（あ）うことはできない。
- **中文理解**：因为谢绝探视，即使是挚友也不能见面。

②副（ふく）主任（しゅにん）（ **といえども** ）、監督者（かんとくしゃ）なら事故（じこ）の責任（せきにん）は逃（のが）れられない。
- **中文理解**：即使只是副主任，只要是监督者就无法逃避事故责任。

③大臣（だいじん）（ **といえども** ）、法（ほう）を犯（おか）した場合（ばあい）は裁（さば）きを受（う）けなければならない。
- **中文理解**：即使是大臣，违法后也必须接受制裁。

**接続（せつぞく）** N／普通形（ふつうけい）＋ といえども（ナA・Nの文（ぶん）では「〜であるといえども」も使（つか）う）
▶ 普通（ふつう）なら例外（れいがい）になりそうな高（たか）い地位（ちい）の人（ひと）、特別（とくべつ）な場合（ばあい）、極端（きょくたん）な例（れい）を挙（あ）げ、それでも後（あと）の原則（げんそく）が当（あ）てはまると述（の）べる。（举出通常可能被视为例外的高地位者、特殊情况或极端例子，说明即便如此，后项原则仍然适用。）

**【扩展说明】**
非常正式且带文言色彩，常见于演说、规则、评论和书面论述。现代日常会话通常改用「でも／であっても」。常见搭配有「何人（なんぴと）といえども」「いかなる場合（ばあい）といえども」。

### 18・14 〜と思（おも）いきや ★1

**【意味（いみ）】〜と思（おも）ったが、予想（よそう）に反（はん）して (原以为……，不料……)**

①実力（じつりょく）から言（い）って、日本（にほん）チームは負（ま）ける（ **と思（おも）いきや** ）、なんと勝（か）ってしまった。
- **中文理解**：从实力看，本以为日本队会输，没想到竟然赢了。

②成績（せいせき）から見（み）て、弟（おとうと）はA大学（だいがく）に合格（ごうかく）できる（ **と思（おも）いきや** ）、落（お）ちてしまった。
- **中文理解**：从成绩看，本以为弟弟能考上A大学，结果却落榜了。

③彼（かれ）は医者（いしゃ）の息子（むすこ）だから医者（いしゃ）になる（ **と思（おも）いきや** ）、漫画家（まんがか）になった。
- **中文理解**：他是医生的儿子，本以为也会当医生，没想到成了漫画家。

**接続（せつぞく）** 引用（いんよう）の「と」の前（まえ）に来（く）る形（かたち）＋ と思（おも）いきや
▶ 常識（じょうしき）・外見（がいけん）・前（まえ）の情報（じょうほう）から当然（とうぜん）そうなると予想（よそう）したが、実際（じっさい）は反対（はんたい）または意外（いがい）な結果（けっか）だったと述（の）べる。（根据常识、外表或已有信息本以为会出现某种结果，实际却相反或出乎意料。）

**【扩展说明】**
前项是说话人或一般人的预想，后项必须带意外性。形式略带旧式修辞感，但现代文章、报道标题和轻松叙述中仍会使用，能制造戏剧性的反转；严肃公文和学术论文通常不用。
