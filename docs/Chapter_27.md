# 27 心情（しんじょう）の強調（きょうちょう）・避（さ）けられない心情（しんじょう）や行動（こうどう）

感情（かんじょう）や身体感覚（しんたいかんかく）が非常（ひじょう）に強（つよ）いこと、自然（しぜん）にある思（おも）いが湧（わ）くこと、または内外（ないがい）の力（ちから）によってある行動（こうどう）が避（さ）けられないことを、どのように表（あらわ）せばよいでしょうか。（如何表达强烈的感情、自然涌现的感受，或在内外因素作用下无法避免的行为？）

| 核心功能 | 句型 | 语感重点 |
| :--- | :--- | :--- |
| 感受强到无法控制 | 〜て仕方（しかた）がない | 最通用；「しょうがない」较口语 |
| 感受强到难以忍受 | 〜てたまらない | 身心刺激、欲望的强度很突出 |
| 因责任或情理必须做 | 〜ないわけにはいかない | 不做在心理、社会上说不过去 |
| 某种想法自然涌现 | 〜てならない | 常与「思える・気がする」等搭配 |
| 忍不住采取某行动 | 〜ずにはいられない | 内在冲动无法压住 |
| 客观上不得不做 | 〜ざるを得（え）ない | 没有别的选择，无奈感强 |
| 某种感情持续不止 | 〜てやまない | 正式，搭配词有限 |
| 极其……／……之至 | 〜限（かぎ）りだ | 对当前状态作强烈感情评价 |
| 程度无法形容 | 〜といったらない | 好坏评价均可，感情色彩强 |
| 不做便无法了结 | 〜ずには済（す）まない | 社会责任或后果要求补救 |
| 必然导致／一定要做 | 〜ずにはおかない | 外力必然作用，或主体的强烈意志 |
| 被迫处于某状态 | 〜を余儀（よぎ）なくされる | 正式书面，强调外部强制力 |

## 学習前（がくしゅうまえ）の小（しょう）テスト (课前小测验)

### 知（し）っていますか

[ a. たまらない　b. ないわけにはいかない　c. ならない　d. ずにはいられない　e. ざるを得（え）ない ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。

1. 会（かい）には出席（しゅっせき）できないが、出席（しゅっせき）の返事（へんじ）をしてしまったので会費（かいひ）を払（はら）わ（ **b. ないわけにはいかない** ）。
   - **中文理解**：虽然不能出席，但已经回复说会参加，所以从情理上不能不交会费。
2. 電車（でんしゃ）の中（なか）で荷物（にもつ）を持（も）ったお年寄（としよ）りを見（み）ると、祖母（そぼ）のことを思（おも）い出（だ）して席（せき）を立（た）た（ **d. ずにはいられない** ）。
   - **中文理解**：在电车里一看到提着行李的老人，便想起祖母，忍不住起身让座。
3. この歌（うた）を聞（き）くと、この歌（うた）をよく歌（うた）っていた友（とも）のことが思（おも）い出（だ）されて（ **c. ならない** ）。
   - **中文理解**：一听到这首歌，便不由得不断想起那位常唱此歌的朋友。
4. 今日（きょう）は朝（あさ）から歯（は）が痛（いた）くて（ **a. たまらない** ）。全然（ぜんぜん）勉強（べんきょう）ができない。
   - **中文理解**：今天从早上起牙就痛得受不了，完全无法学习。
5. 保証人（ほしょうにん）の海外転勤（かいがいてんきん）が決（き）まったので、これからはほかの方（かた）にお願（ねが）いせ（ **e. ざるを得（え）ない** ）。
   - **中文理解**：担保人已确定调往海外，今后不得不请另一位帮忙。

### 使（つか）えますか

文脈（ぶんみゃく）に合（あ）う方（ほう）を選（えら）びなさい。

1. このゲームは { **a. 楽（たの）しくてたまらない。** ／ b. 高（たか）くてたまらない。 }
   - **中文理解**：这个游戏好玩得不得了。无上下文时，纯客观属性「高い」不如直接感受「楽しい」自然。不过「物価（ぶっか）が上（あ）がり、何（なに）もかも高（たか）くてたまらない」等有切身负担的语境中，b 并非绝对错误。
2. タノムさんの冗談（じょうだん）には、田中（たなか）さんも { a. 笑（わら）わないではいられない。／ **b. 笑（わら）わないではいられないようだ。** }
   - **中文理解**：面对塔农的玩笑，田中似乎也忍不住笑。描述第三者内心冲动时，要用「ようだ」等表明这是观察推断。
3. 大切（たいせつ）な会議（かいぎ）だから { **a. 出席（しゅっせき）しないわけにはいかない。** ／ b. 出席（しゅっせき）するわけにはいかない。 }
   - **中文理解**：因为是重要会议，不能不出席。b 表示“碍于情理不能出席”，意思相反。
4. 田中（たなか）さんの表情（ひょうじょう）を見（み）ていると、{ **a. うそをついているように思（おも）えてならない。** ／ b. うそをついているように思（おも）えてたまらない。 }
   - **中文理解**：看着田中的表情，我总觉得他像是在撒谎。「思えて／気がして」这类自然涌现且挥之不去的判断，典型搭配是「てならない」。
5. { a. ハナ子（こ）は朝（あさ）から寒気（さむけ）がしてならない。／ **b. 朝（あさ）から寒気（さむけ）がしてならない。** } 風邪（かぜ）をひきそうだ。
   - **中文理解**：从早上起我一直觉得发冷，好像要感冒了。无标记时是说话人的直接感受；a 直接断言第三者的身体感觉，不自然。

## 27 心情（しんじょう）の強調（きょうちょう）・避（さ）けられない行動（こうどう）

### 27・1 〜て仕方（しかた）がない・〜てしょうがない ★3

**【意味（いみ）】感情（かんじょう）・感覚（かんかく）が強（つよ）くて、自分（じぶん）では抑（おさ）えられない (……得不得了／怎么也控制不住……)**

①結婚（けっこん）10年目（じゅうねんめ）でやっと子供（こども）が生（う）まれたので、うれしく **て仕方（しかた）がありません** 。
- **中文理解**：结婚第十年终于有了孩子，高兴得不得了。

②眼鏡（めがね）を変（か）えたからか、この頃（ごろ）目（め）が疲（つか）れ **て仕方（しかた）がない** 。
- **中文理解**：不知道是不是因为换了眼镜，最近眼睛累得不行。

③どうして大川（おおかわ）さんが突然（とつぜん）テニス部（ぶ）を辞（や）めたのか、私（わたし）は気（き）になっ **て仕方（しかた）がない** 。
- **中文理解**：我非常在意大川为何突然退出网球部，怎么也放不下。

④姉（あね）はいつも「かわいそうな小説（しょうせつ）を読（よ）むと泣（な）け **てしょうがない** 」と言（い）っている。
- **中文理解**：姐姐总说：“一读悲惨的小说，就忍不住流泪。”

⑤あき子（こ）は「数学（すうがく）の勉強（べんきょう）が嫌（いや） **でしょうがない** 」と言（い）っている。
- **中文理解**：秋子说：“我讨厌学数学，讨厌得不得了。”

**接続（せつぞく）** Vて／イAくて／ナAで ＋ 仕方（しかた）がない・しょうがない

▶ 自然（しぜん）に生（しょう）じる感情（かんじょう）、身体感覚（しんたいかんかく）、欲求（よっきゅう）が強（つよ）く、意志（いし）では制御（せいぎょ）できないことを表（あらわ）します。「気（き）になる・思（おも）える・泣（な）ける」などともよく使（つか）われます。「しょうがない」は「仕方（しかた）がない」の口語的（こうごてき）な形（かたち）です。（表示感情、感觉或欲望强烈到无法凭意志控制；「しょうがない」更口语。）

▶ 原则上直接表达说话人自己的内在感受。第三者作主语时，通常需要「〜ようだ・〜らしい・〜と言（い）っている」等依据；小说的全知叙述或直接引语不受此限制。

### 27・2 〜てたまらない ★3

**【意味（いみ）】我慢（がまん）できないほど非常（ひじょう）に〜だ (……得受不了／非常想……)**

①この頃（ごろ）よく寝（ね）ていないので、昼間（ひるま）でも眠（ねむ）く **てたまらない** 。
- **中文理解**：最近总睡不好，即使白天也困得受不了。

②今（いま）、妹（いもうと）はクラブ活動（かつどう）が楽（たの）しく **てたまらないようだ** 。
- **中文理解**：妹妹现在似乎觉得社团活动有趣极了。

③高等学校（こうとうがっこう）を卒業（そつぎょう）したときには、大（おお）きな都会（とかい）の大学（だいがく）に行（い）きたく **てたまらなかった** 。
- **中文理解**：高中毕业时，我非常想到大城市上大学。

④昼（ひる）ご飯（はん）に辛（から）い物（もの）を食（た）べたので、喉（のど）が渇（かわ）い **てたまらず** 、水（みず）ばかり飲（の）んでいる。
- **中文理解**：午饭吃了辣的东西，渴得受不了，一直在喝水。

**接続（せつぞく）** Vて／イAくて／ナAで ＋ たまらない

▶ 身体的（しんたいてき）・心理的（しんりてき）な刺激（しげき）による感覚（かんかく）、感情（かんじょう）、欲求（よっきゅう）が「耐（た）えられないほど強（つよ）い」ことを強調（きょうちょう）します。「〜たくてたまらない」表示强烈愿望。第三者时也要用「ようだ」等观察标记。

**【「てならない」との使い分け】**
「眠（ねむ）い・暑（あつ）い・寂（さび）しい・〜たい」等直接刺激的身心感受，典型用「てたまらない」；「思（おも）えて・気（き）がして・思（おも）い出（だ）されて」等自然浮现并萦绕心头的认知，典型用「てならない」。传统教材常把「泣（な）けてたまらない」判为不宜搭配；现实语料中并非完全不存在，但考试和规范表达宜选「泣（な）けてならない／しょうがない」。

- △ 病気（びょうき）の母（はは）のことを思（おも）うと、泣（な）け **てたまらない** 。（现实中可见，但不属于本句型最典型的搭配。）
- ○ 病気（びょうき）の母（はは）のことを思（おも）うと、泣（な）け **てならない** 。
- ○ 病気（びょうき）の母（はは）のことを思（おも）うと、泣（な）け **てしょうがない** 。
- **中文理解**：一想到生病的母亲，便不由得落泪。

### 27・3 〜ないわけにはいかない ★3

**【意味（いみ）】心理的（しんりてき）・社会的（しゃかいてき）な事情（じじょう）から、どうしても〜する必要（ひつよう）がある (不能不……／从情理上必须……)**

①田中（たなか）さんに昨年（さくねん）から何度（なんど）も頼（たの）まれているから、留学生会（りゅうがくせいかい）の役員（やくいん）を引（ひ）き受（う）け **ないわけにはいかない** 。
- **中文理解**：田中从去年起多次拜托我，所以留学生会干部一职不能不接。

②明日（あした）は私（わたし）が発表（はっぴょう）をする。今夜（こんや）は友達（ともだち）に誘（さそ）われたが、断（ことわ）って明日（あした）の準備（じゅんび）をし **ないわけにはいかない** 。
- **中文理解**：明天轮到我发表。朋友虽约我今晚出去，但我不得不拒绝并准备明天的发表。

③父（ちち）には私（わたし）が会社（かいしゃ）を首（くび）になったことを話（はな）さ **ないわけにはいかなかった** 。
- **中文理解**：我被公司解雇的事，不能不告诉父亲。

**接続（せつぞく）** Vない形（けい） ＋ わけにはいかない

▶ 法律（ほうりつ）や客観的（きゃっかんてき）な必要（ひつよう）を単（たん）に述（の）べる「〜なければならない」と違（ちが）い、个人责任、人际关系、常识或心理压力使“不做”成为不合适的选择。常用于说明自己为何只得去做。

> **正反两式**：「行（い）かないわけにはいかない」＝不能不去；「行（い）くわけにはいかない」＝碍于某种理由不能去。肯定形与否定形意思相反，务必先看接续。

### 27・4 〜てならない ★2

**【意味（いみ）】ある感情（かんじょう）・考（かんが）えが自然（しぜん）に湧（わ）き、頭（あたま）から離（はな）れない (不由得……／总觉得……)**

①夏休（なつやす）みの間（あいだ）一生懸命（いっしょうけんめい）に練習（れんしゅう）したのに、県大会（けんたいかい）の試合（しあい）でA高等学校（こうとうがっこう）に負（ま）けてしまい、悔（くや）しく **てなりません** 。
- **中文理解**：暑假期间明明拼命练习，却在县级比赛中输给 A 高中，实在懊悔不已。

②役所（やくしょ）が税金（ぜいきん）の無駄遣（むだづか）いをしている話（はなし）を聞（き）くと、腹（はら）が立（た）っ **てならない** 。
- **中文理解**：一听说政府机关浪费税款，我便气愤不已。

③長男（ちょうなん）が勉強（べんきょう）もしないでぶらぶらしているので、心配（しんぱい） **でならない** 。
- **中文理解**：长子不学习，整日无所事事，实在令人担心得不得了。

④学校（がっこう）でいじめられて自殺（じさつ）した子供（こども）のことをテレビで聞（き）くと、かわいそうで泣（な）け **てならない** 。
- **中文理解**：从电视上听到孩子因在学校受欺凌而自杀的事，便觉得太可怜，不由得落泪。

**接続（せつぞく）** Vて／イAくて／ナAで ＋ ならない

▶ 自然（しぜん）に生（しょう）じた感情（かんじょう）や認知（にんち）が強（つよ）く続（つづ）き、意志（いし）で消（け）せないことを表（あらわ）します。尤其常与自发、认知表达「思える・思い出される・気がする・泣ける」搭配，较「てしかたがない」稍正式。第三者内心仍需「ようだ」等依据。

### 27・5 〜ないではいられない・〜ずにはいられない ★2

**【意味（いみ）】内（うち）から起（お）こる衝動（しょうどう）を抑（おさ）えられず、どうしても〜してしまう (忍不住……／不由得……)**

①この店（みせ）のカレーはとても辛（から）い。少（すこ）し食（た）べたら、水（みず）を飲（の）ま **ないではいられない** 。
- **中文理解**：这家店的咖喱很辣，吃一点便忍不住喝水。

②虫（むし）に刺（さ）された所（ところ）がかゆくて、かか **ないではいられない** 。
- **中文理解**：被虫咬的地方很痒，忍不住要挠。

③中学生（ちゅうがくせい）がだまされている所（ところ）を見（み）たので、何（なに）か言（い）わ **ないではいられなかった** 。
- **中文理解**：看到一名初中生正在受骗，我忍不住说了几句。

④津波（つなみ）の被災者（ひさいしゃ）のニュースを見（み）ると、早（はや）く復興（ふっこう）が進（すす）むようにと願（ねが）わ **ずにはいられません** 。
- **中文理解**：一看到海啸灾民的新闻，就不由得祈愿灾区早日复兴。

⑤家（うち）の子（こ）は保育園（ほいくえん）に行（い）くと、家（いえ）であったことを何（なん）でも話（はな）さ **ずにはいられないようだ** 。
- **中文理解**：我家孩子一到幼儿园，好像就忍不住把家里的事全说出来。

**接続（せつぞく）**

- Vない形（けい） ＋ ではいられない
- Vない形（けい）から「ない」を除（のぞ）いた形（かたち） ＋ ずにはいられない
- する → せずにはいられない

▶ 身体反应、感情或价值判断催生出行动，而主体无法靠意志压住这一冲动。「〜ないわけにはいかない」是外部情理让人必须做；「〜ずにはいられない」是内心或身体让人忍不住做。前者不一定想做，后者则强调冲动。

### 27・6 〜ざるを得（え）ない ★2 [W]

**【意味（いみ）】ほかに選択肢（せんたくし）がなく、仕方（しかた）なく〜する (不得不……／只好……)**

①物理（ぶつり）は好（す）きではないが、必修（ひっしゅう）だから取（と）ら **ざるを得（え）ない** 。
- **中文理解**：虽然不喜欢物理，但它是必修课，所以不得不选。

②仕事（しごと）を途中（とちゅう）で辞（や）めるのは無責任（むせきにん）だと言（い）わ **ざるを得（え）ない** 。
- **中文理解**：不得不说，工作做到一半便退出是不负责任的。

③京都（きょうと）でとてもいい茶碗（ちゃわん）を見（み）つけたが、値段（ねだん）が高（たか）かったので諦（あきら）め **ざるを得（え）なかった** 。
- **中文理解**：在京都发现了一只很好的茶碗，但价格太高，只得放弃。

④富士山（ふじさん）の途中（とちゅう）まで登（のぼ）った。しかし、強（つよ）い風雨（ふうう）のために引（ひ）き返（かえ）さ **ざるを得（え）なかった** 。
- **中文理解**：登到富士山半途，却因强风暴雨不得不折返。

**接続（せつぞく）** Vない形（けい）から「ない」を除（のぞ）いた形（かたち） ＋ ざるを得（え）ない（する → せざるを得（え）ない）

▶ 外部情况排除了其他选择，主体虽不愿意或原本另有打算，也只好那样做。比「〜ないわけにはいかない」更强调“客观上没有替代方案”和无奈，且更正式、书面。「得ない」在本句型中读作「えない」。

### 27・7 〜てやまない ★1 [W]

**【意味（いみ）】ある感情（かんじょう）を強（つよ）く持（も）ち続（つづ）けている (始终由衷地……／……不已)**

①お大事（だいじ）に。一日（いちにち）も早（はや）く元気（げんき）になることを祈（いの）っ **てやみません** 。（手紙（てがみ））
- **中文理解**：请多保重。衷心祈愿您早日康复。（书信）

②世界（せかい）から核兵器（かくへいき）がなくなることを願（ねが）っ **てやみません** 。
- **中文理解**：我始终由衷希望核武器从世界上消失。

③私（わたし）が尊敬（そんけい）し **てやまない** 山川先生（やまかわせんせい）が賞（しょう）を受（う）けられた。
- **中文理解**：我一直无比尊敬的山川老师获奖了。

**接続（せつぞく）** Vて ＋ やまない

▶ 「祈（いの）る・願（ねが）う・愛（あい）する・尊敬（そんけい）する」等持续性情感动词的范围有限，表示该感情强烈而从未停止。是郑重书面表达，常见于致辞、贺信、悼词；并非任意动作都能接。也可用于负面情感，如「憎（にく）んでやまない」，只是祝愿、敬爱类搭配更常见。

### 27・9 〜といったらない・〜といったらありはしない ★1

**【意味（いみ）】言葉（ことば）では表現（ひょうげん）できないほど程度（ていど）が極端（きょくたん）だ (……得无法形容／别提多……了)**

- **中文理解**：工厂作业每天都重复同样的事，那种无聊简直难以形容。

②外国（がいこく）の町（まち）を初（はじ）めて歩（ある）いたときの興奮（こうふん） **といったらなかった** 。自分（じぶん）が映画（えいが）の中（なか）の一人（ひとり）になったような気（き）がした。
- **中文理解**：第一次走在外国街头时，别提有多兴奋了，感觉自己仿佛成了电影中的人物。

③ドリアンという果物（くだもの）の匂（にお）い **といったらない** 。好（す）きな人（ひと）にも嫌（きら）いな人（ひと）にもたまらない。
- **中文理解**：榴莲的气味强烈得难以形容；爱它的人觉得香得无法抗拒，讨厌它的人则觉得难以忍受。「たまらない」在这里同时利用了正、负两种语感。

- **中文理解**：这家食堂的拉面别提有多难吃了。

**接続（せつぞく）** イAい／程度（ていど）を表（あらわ）すN ＋ といったらない

▶ 好坏两方面的评价都可使用，如「うれしいといったらない」「寂（さび）しさといったらない」。「〜ったらない」是随意的缩略说法；「〜といったらありはしない／ありゃしない」带更强烈的感叹，常用于抱怨，但并非在语法上绝对只能评价坏事。原文例⑤的强调范围应为完整的「**ったらない**」，不能拆成「ったらな＋い」。

### 27・10 〜ないでは済（す）まない・〜ずには済（す）まない ★1 [W]

**【意味（いみ）】責任（せきにん）・規則（きそく）・結果（けっか）を考（かんが）えると、必（かなら）ず〜しなければならない (不……便无法了结／非……不可)**

- **中文理解**：弄坏了别人家的贵重物品，不赔偿便无法了事。

## まとめ：何（なに）が人（ひと）を動（うご）かすか

| 驱动力 | 最自然的句型 | 例 |
| :--- | :--- | :--- |
