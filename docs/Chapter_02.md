# 第2章 目的（もくてき）・手段（しゅだん）・媒介（ばいかい）

**核心提示**：ものごとが行（おこな）われる目的（もくてき）や手段（しゅだん）や方法（ほうほう）、その間（あいだ）で役目（やくめ）を果（は）たす人（ひと）やものを言（い）いたいときは、どんな言（い）い方（かた）がありますか。（当想表达事情进行的 **目的**、**手段** 或 **方法**，以及在其中起作用的人或物（**媒介**）时，有哪些表达方式呢？）

---

## 0. 導入（どうにゅう） (引入)

### 知（し）っていますか (你知道吗？)
**[ ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。**
（使用方框中的词语，完成句子。1个词语只能使用1次。）
【选项：a. によると b. ように c. を通（つう）じて d. によって e. 上（うえ）で】

1. 約束（やくそく）の時間（じかん）に遅（おく）れない[ **b. ように** ] 、早（はや）く家（いえ）を出（で）た。
   - **中文理解**：为了不迟到约定的时间，我早早地出门了。

2. 小林（こばやし）さんの話（はなし）[ **a. によると** ] 、駅前（えきまえ）にスポーツセンターができるそうだ。
   - **中文理解**：根据小林的话，车站前好像要建一个体育中心。

3. 木村（きむら）さんとは共通（きょうつう）の友人（ゆうじん）[ **c. を通（つう）じて** ] 知（し）り合（あ）ったんです。
   - **中文理解**：我和木村是通过共同的朋友认识的。

4. 調査（ちょうさ）を進（すす）めていく[ **e. 上（うえ）で** ] 、関係者全員（かんけいしゃぜんいん）から意見（いけん）を聞（き）くことが必要（ひつよう）だ。
   - **中文理解**：在推进调查的过程中，有必要听取所有相关人员的意见。

5. アンケート調査（ちょうさ）[ **d. によって** ] 消費者（しょうひしゃ）の希望（きぼう）が明（あき）らかになった。
   - **中文理解**：通过问卷调查，消费者的需求变得明确了。（这里是手段；「農家（のうか）の努力（どりょく）によって増（ふ）えた」则属于原因用法。）

### 使（つか）えますか (你会用吗？)
**どちらが正（ただ）しいですか。正（ただ）しい方（ほう）を選（えら）びなさい。**
（哪一个是正确的？请选择正确的一方。）

1. 上野（うえの）には｛**a. 地下鉄（ちかてつ）よりJR線（ジェイアールせん）で** / b. 地下鉄（ちかてつ）よりJR線（ジェイアールせん）によって｝行（い）く方（ほう）が便利（べんり）でしょう。
   - **中文理解**：去上野，坐JR线比坐地铁更方便吧。（日常交通工具通常用「で」而不是「によって」）

2. 広告（こうこく）の内容（ないよう）を伝聞（でんぶん）として伝（つた）えるなら、この広告（こうこく）によれば、｛a. 新（あたら）しいゲームソフトが発売（はつばい）されると書（か）いてある。 / **b. 新（あたら）しいゲームソフトが発売（はつばい）されるそうだ。**｝
   - **中文理解**：若把广告内容作为传闻转述，应选“据说要发售新的游戏软件”。（「によれば」常与「そうだ・ということだ」呼应；若强调文字记载，直接说「この広告（こうこく）には～と書（か）いてある」更简洁。）

3. 「旅行会社（りょこうがいしゃ）を経由（けいゆ）する」が名詞（めいし）「予約（よやく）」を直接（ちょくせつ）修飾（しゅうしょく）する形（かたち）はどちらですか。｛**a. 旅行会社（りょこうがいしゃ）を通（とお）しての** / b. 旅行会社（りょこうがいしゃ）を通（とお）して｝予約（よやく）は簡単（かんたん）で便利（べんり）です。
   - **中文理解**：若让“通过旅行社”直接修饰名词“预约”，用「を通（とお）しての」。（「旅行会社（りょこうがいしゃ）を通（とお）して、予約（よやく）する」中的「を通（とお）して」可作状语；这里专门考查名词修饰形式。）

4. ｛**a. 小学生（しょうがくせい）とテレビの関係（かんけい）について調査（ちょうさ）するために** / b. 小学生（しょうがくせい）とテレビの関係（かんけい）について調査（ちょうさ）するように｝アンケートを行（おこな）うことにした。
   - **中文理解**：为了调查小学生与电视的关系，决定进行问卷调查。（「ために」接意志动词，表示为了某个目的；「ように」通常接无意志动词或可能态）

5. 外国語学習（がいこくごがくしゅう）におけるテレビの有用性（ゆうようせい）を評価（ひょうか）するなら、外国語（がいこくご）を勉強（べんきょう）する上（うえ）で｛a. テレビをさっそく買（か）った。 / **b. テレビはかなり役（やく）に立（た）つ。**｝
   - **中文理解**：若要评价电视在外语学习方面的用途，应选“电视相当有用”。（「V辞書形（じしょけい）＋上（うえ）で」后典型地接必要性、重要性、用途、困难等；若只叙述先后动作，应按语境用「ために」「てから」等。）

## 本章（ほんしょう）の見取（みと）り図（ず）

| 表現（ひょうげん） | 核心（かくしん） | 使用（しよう）条件（じょうけん） |
|---|---|---|
| ～ように | 为使某种状态实现 | 常接可能形（かのうけい）、无意志动词或否定形 |
| ～上（うえ）で | 在做某事的过程、场合或方面 | 后项多为必要性、重要性、困难、注意点等 |
| ～べく | 为了某目的而采取行动 | 正式书面语；前后行动者原则上相同 |
| ～によって | 通过某方法、制度、过程 | 比助词「で」正式；另有原因、施事等用法 |
| ～によると／～によれば | 标示消息来源 | 后项常见「そうだ・という・らしい」 |
| ～を通（つう）じて／～を通（とお）して | 经由人、组织、活动等媒介 | 也可表示“贯穿整个期间”，见第3章 |
| ～をもって | 以正式手段、资格、能力等 | 语气郑重；通常不用普通日常工具 |

## 2 Ⅰ 目的（もくてき）

### 2 Ⅰ・1 ～ように
【接続（せつぞく）】V辞書形（じしょけい）・Vない形（けい） ＋ ように
【意味（いみ）】〜という目的（もくてき）が実現（じつげん）することを期待（きたい）して（为了实现～这样的目的）

#### 例文（れいぶん） (例句)

1. 子（こ）どもでも読（よ）める **ように** 、漢字（かんじ）の上（うえ）にふりがなが書（か）いてあります。
   - **中文理解**：为了让孩子也能读懂，汉字的上面标注了假名。

2. 飛行機（ひこうき）の中（なか）から富士山（ふじさん）がよく見（み）える **ように** 、窓側（まどがわ）の席（せき）にすわった。
   - **中文理解**：为了能从飞机里清楚地看到富士山，我坐了靠窗的位子。

3. 外国（がいこく）からの客（きゃく）が困（こま）らない **ように** 、店（みせ）には英語（えいご）や中国語（ちゅうごくご）が分（わ）かる店員（てんいん）がいる。
   - **中文理解**：为了不让外国客人感到困扰，店里有懂英语和中文的店员。

4. 工事中（こうじちゅう）、歩行者（ほこうしゃ）が安全（あんぜん）なところを通（とお）る **ように** 、係（かかり）の人（ひと）が案内（あんない）している。
   - **中文理解**：施工期间，为了让行人通过安全的地方，工作人员正在进行引导。

**【拡張説明】(扩展说明)**

1) 「〜ように」前面常接 **非意志动词**、**可能形** 或 **Vない**，表示希望某种状态实现或避免某种情况发生。
2) 当前后主语不同，且前项表示“让别人/其他事物达到某种状态”时，也可接含有意志性的动词，如例句④「歩行者（ほこうしゃ）が安全（あんぜん）なところを通（とお）るように」。
3) 如果前后主语相同，且前项是说话人主动要做的动作，通常用「〜ために」。例如：「留学（りゅうがく）するために貯金（ちょきん）する」比「留学（りゅうがく）するように貯金（ちょきん）する」自然。
4) 不要把目的用法和指示、请求用法混淆：「静（しず）かにするように言（い）う」是“叫某人保持安静”，不是“为了保持安静而说”。

### 2 Ⅰ・2 ～上（うえ）で
【接続（せつぞく）】V辞書形（じしょけい）／Nの ＋ 上（うえ）で
【意味（いみ）】〜する場合（ばあい）・過程（かてい）・観点（かんてん）で（在～方面 / 在～过程中）

#### 例文（れいぶん） (例句)

1. 今度（こんど）の企画（きかく）を成功（せいこう）させる **上（うえ）で** 、みんなの協力（きょうりょく）が必要（ひつよう）なのだ。
   - **中文理解**：为了让这次企划取得成功（在使企划成功的过程中），大家的合作是必不可少的。

2. 人々（ひとびと）の社会的（しゃかいてき）な行動（こうどう）や目標（もくひょう）などについての傾向（けいこう）を知（し）る **上（うえ）で** 、アンケート調査（ちょうさ）は欠（か）かせない。
   - **中文理解**：在了解人们社会行为和目标等倾向方面，问卷调查是不可或缺的。

3. これは食品（しょくひん）を保存（ほぞん）する **上（うえ）での** 注意点（ちゅういてん）です。よくお読（よ）みください。
   - **中文理解**：这是保存食品方面的注意事项。请仔细阅读。（修饰名词时用「〜上（うえ）でのN」）

4. 理科（りか）の学習（がくしゅう）の **上（うえ）で** 大切（たいせつ）なことは、身（み）の回（まわ）りのことに疑問（ぎもん）を持（も）つことだという。
   - **中文理解**：据说在理科学习方面最重要的是，对身边的事物保持疑问。

**【拡張説明】(扩展说明)**
▶ 以「〜上（うえ）で...」的形式，表示把「〜」作为场面、目的或判断范围，在后半句叙述实现该目的时**必要的事物、重要的事情、应注意的点**等。后半句通常不是单纯叙述“做了某个具体动作”。

- 本节是 `V辞書形（じしょけい）＋上（うえ）で`。`Vた形（けい）＋上（うえ）で` 表示“做完 A 之后再做 B”，例如「内容（ないよう）を確認（かくにん）した上（うえ）で署名（しょめい）する」，接续和意思都不同。

- (△) 生け花（いけばな）教室（きょうしつ）に入会（にゅうかい）する **上（うえ）で** 、申込書（もうしこみしょ）に名前（なまえ）を書（か）いた。（若只是叙述一次具体行为，用「入会（にゅうかい）するために／入会（にゅうかい）の際（さい）に」更自然；若把填写申请表说成入会手续中必要的一环，则可以使用「上（うえ）で」）
- (〇) 生け花（いけばな）教室（きょうしつ）に入会（にゅうかい）する **上（うえ）で** 、なにか用意（ようい）するものがありますか。（询问必要准备，正确）

### 2 Ⅰ・3 ～べく
【接続（せつぞく）】V辞書形（じしょけい） ＋ べく（「する」は「するべく／すべく」）
【意味（いみ）】〜するために（为了～）

#### 例文（れいぶん） (例句)

1. 会議（かいぎ）での決定事項（けっていじこう）を知（し）らせる **べく** 、メーリングリスト上の20名（にじゅうめい）にメールを送（おく）った。
   - **中文理解**：为了通知会议的决定事项，给邮件列表上的20人发送了邮件。

2. 田中（たなか）氏（し）は記者会見場（きしゃかいけんじょう）に向（む）かう **べく** 、上着（うわぎ）を着（き）て部屋（へや）を出（で）た。
   - **中文理解**：田中先生为了前往记者招待会现场，穿上外套走出了房间。

3. 父（ちち）は海外出張（かいがいしゅっちょう）の前（まえ）に投票（とうひょう）を済（す）ませる **べく** 、区役所（くやくしょ）の「期日前投票所（きじつぜんとうひょうじょ）」へ行（い）った。
   - **中文理解**：父亲为了在海外出差前完成投票，去了区役所的“提前投票所”。

4. 彼女（かのじょ）は新（あたら）しい気持（きも）ちで再出発（さいしゅっぱつ）する **べく** 、海外支援活動（かいがいしえんかつどう）の募集（ぼしゅう）に応募（おうぼ）した。
   - **中文理解**：她为了带着全新的心情重新出发，应征了海外支援活动的招募。

**【拡張説明】(扩展说明)**

▶ 1) 用于表达“**带着某种目的而采取行动**”。是比较正式、书面的表达。
▶ 2) 后半句通常接已经采取或正在采取的行动，不直接接委托、命令、劝诱等句子。
▶ 3) 「する」接「べく」时，传统上常说「すべく」，现代日语中「するべく」也可见。
▶ 4) 前项的目的和后项的行动原则上属于同一行动者。这里只表示目的，不等于表示义务的「～べきだ」。

- (✖) この書類（しょるい）を会議（かいぎ）に提出（ていしゅつ）する **べく** 、コピーをお願（ねが）いします。（后接请求，不正确）
- (〇) 課長（かちょう）はその書類（しょるい）を会議（かいぎ）に提出（ていしゅつ）する **べく** 、徹夜（てつや）で完成（かんせい）させた。（描述为达成某目的而采取的行动，正确）

## 2 Ⅱ 手段（しゅだん）・媒介（ばいかい）

### 2 Ⅱ・1 ～によって・～による
【接続（せつぞく）】N ＋ によって
【意味（いみ）】〜の方法（ほうほう）で／〜を手段（しゅだん）として（通过～的方法 / 以～为手段）

#### 例文（れいぶん） (例句)

1. その問題（もんだい）は話（はな）し合（あ）い **によって** 解決（かいけつ）できると思（おも）います。
   - **中文理解**：我认为那个问题可以通过协商解决。

2. アンケート調査（ちょうさ） **によって** 学生（がくせい）たちの希望（きぼう）や不満（ふまん）を知（し）る。
   - **中文理解**：通过问卷调查了解学生们的希望和不满。

3. ボランティア活動（かつどう）に参加（さんか）すること **により** 、自分自身（じぶんじしん）も多（おお）くのことを学（まな）んだ。
   - **中文理解**：通过参加志愿者活动，我自己也学到了很多东西。（「により」更为书面化）

4. 小学生（しょうがくせい）の間（あいだ）でも携帯電話（けいたいでんわ） **による** コミュニケーションが盛（さか）んだ。
   - **中文理解**：在小学生之间，通过手机进行的交流也很盛行。（修饰名词用「〜によるN」）

**【拡張説明】(扩展说明)**
▶ 1) 以「Nによって...」的形式，用于表达“用 N 这种手段、方法或方式来做……”。
▶ 2) 当「N」是**具体的日常工具、交通工具**时，更常用「Nで」而不是「Nによって」。修饰名词时则常用「NによるN」。

「によって」还有几种常见用法，不能看到它就一律译成“通过”：

- 原因（げんいん）：「大雨（おおあめ）によって試合（しあい）が中止（ちゅうし）になった」（由于大雨）。
- 被动句的施事（せじ）：「この寺（てら）は名高（なだか）い僧（そう）によって建（た）てられた」（由某人建造）。
- 因对象而异：「人（ひと）によって考（かんが）え方（かた）が違（ちが）う」（因人而异）。

本节重点是“手段、方法”，需结合后项语义判断。

- (✖) わたしは自転車（じてんしゃ） **によって** 通勤（つうきん）している。（具体交通工具不适用，不正确）
- (〇) わたしは自転車（じてんしゃ） **で** 通勤（つうきん）している。（正确）
- (〇) 自転車（じてんしゃ） **による** 通勤（つうきん）は禁止（きんし）されている。（修饰名词，正确）
- (△) その件（けん）をメール **によって** 通知（つうち）してください。（意思可懂，但日常指具体工具时不自然）
- (〇) メール **による** 一斉通知（いっせいつうち）は便利（べんり）だ。（修饰名词，正确）

### 2 Ⅱ・2 ～によると・～によれば
【接続（せつぞく）】N ＋ によると / によれば
【意味（いみ）】〜では／〜を情報源（じょうほうげん）にすると（根据～）

#### 例文（れいぶん） (例句)

1. テレビの長期予報（ちょうきよほう） **によると** 、10月（じゅうがつ）、11月（じゅういちがつ）はいつもより暖（あたた）かい日（ひ）が多（おお）いそうです。
   - **中文理解**：根据电视的长期天气预报，10月、11月似乎比往常温暖的日子要多。

2. 専門家（せんもんか）の予想（よそう） **によれば** 、円高（えんだか）は今後（こんご）も続（つづ）くということだ。
   - **中文理解**：根据专家的预测，日元升值的趋势今后也将持续。

3. 母（はは）からのメール **によれば** 、今年（ことし）は父（ちち）が初（はじ）めての海外旅行（かいがいりょこう）をするそうだ。
   - **中文理解**：根据母亲发来的邮件，今年父亲好像要进行第一次海外旅行。

4. 新聞（しんぶん） **によると** 、たばこ税（たばこぜい）が上（あ）がるらしい。
   - **中文理解**：根据报纸（的消息），烟草税好像要上涨了。

**【拡張説明】(扩展说明)**
▶ 当讲述从别处听来的事情或推测的事情时，表示**信息来源**。句尾常搭配「〜そうだ」「〜ということだ」「〜らしい」等传闻或推测表达。
▶ 「によれば」比「によると」略显正式，新闻、报告、书面说明中较常见。

### 2 Ⅱ・3 ～を通（つう）じて・～を通（とお）して
【接続（せつぞく）】N ＋ を通（つう）じて / を通（とお）して
【意味（いみ）】〜を手段（しゅだん）として／〜を媒介（ばいかい）として（以～为手段 / 以～为媒介）

#### 例文（れいぶん） (例句)

1. この会（かい）での活動（かつどう） **を通（つう）じて** 、わたしは伊藤（いとう）さんという女性（じょせい）と知（し）り合（あ）いました。
   - **中文理解**：通过这个会的活动，我认识了一位名叫伊藤的女性。

2. このような民間（みんかん）レベルの国際交流（こくさいこうりゅう） **を通（つう）じて** 、両国間（りょうこくかん）の理解（りかい）が少（すこ）しずつ進（すす）んでいくことを願（ねが）っています。
   - **中文理解**：我希望通过这种民间级别的国际交流，两国之间的理解能逐步加深。

3. 仕事（しごと）の内容（ないよう）についてのお問（と）い合（あ）わせは、事務所（じむしょ） **を通（とお）して** 行（おこな）ってください。
   - **中文理解**：关于工作内容的咨询，请通过事务所进行。

4. 田中（たなか）さん **を通（とお）して** のビジネスの話（はなし）は残念（ざんねん）ながらうまくいかなかった。
   - **中文理解**：很遗憾，经由田中先生牵线的生意没能顺利进行。（修饰名词用「〜を通（とお）してのN」）

**【拡張説明】(扩展说明)**
▶ 两种说法很多时候可以互换使用，但「〜を通（つう）じて」的侧重点在于**借由某种媒介、经历或活动而成立**；「〜を通（とお）して」则更容易强调**有意识地利用某个媒介或渠道来进行**。
▶ 修饰名词时常用「〜を通（つう）じてのN」「〜を通（とお）してのN」。
▶ 上述差别只是倾向，并非任何句子中都能严格二分。人或组织作中介时，两者通常都可用；固定搭配应按实际语境判断。

### 2 Ⅱ・4 ～をもって
【接続（せつぞく）】N ＋ をもって
【意味（いみ）】〜を用（もち）いて／〜を手段（しゅだん）として（用～ / 以～ / 凭借～）

#### 例文（れいぶん） (例句)

1. 田中（たなか）さんは並々（なみなみ）ならぬ努力（どりょく） **をもって** 問題（もんだい）の解決（かいけつ）に当（あ）たった。
   - **中文理解**：田中以非同寻常的努力着手解决问题。

2. 面接（めんせつ）の結果（けっか）は、1週間後（いっしゅうかんご）に書面（しょめん） **をもって** お知（し）らせします。
   - **中文理解**：面试的结果将在1周后以书面形式通知您。

3. 今回（こんかい）のアルバイトでわたしは働（はたら）くことの厳（きび）しさを身（み） **をもって** 経験（けいけん）した。
   - **中文理解**：在这次的兼职中，我亲身（以自己的身体）体会到了工作的艰辛。

4. 彼（かれ）の実力（じつりょく） **をもって** すれば、金（きん）メダルは間違（まちが）いないだろう。
   - **中文理解**：以他的实力，拿金牌是毫无悬念的吧。

5. 彼（かれ）の能力（のうりょく） **をもって** しても、この危機（きき）を切（き）り抜（ぬ）けるのは難（むずか）しいだろう。
   - **中文理解**：即使凭他的能力，要度过这次危机也很困难吧。

**【拡張説明】(扩展说明)**
▶ 1) 用于表达“以某种手段、材料、资格、能力或凭据来做某事”，是较为正式、生硬的表达。
▶ 2) 例句③的「身（み）をもって」是惯用语，意思是“亲身、切身体会”。
▶ 3) 像例句④、⑤那样，「〜をもってすれば」（如果凭～）、「〜をもってしても」（即使凭～）的形式也很常用。
▶ 4) **不太用于**身边的日常道具或普通手段；这类情况通常用「で」。
▶ 5) 「〜をもって」还可郑重地标示某个时间点或界限，可用于开始、变更或结束，如「4月1日（しがつついたち）をもって新制度（しんせいど）へ移行（いこう）します」「本日（ほんじつ）をもって終了（しゅうりょう）します」。本章重点是“手段、凭借”的用法。

- (✖) この紙（かみ）を10枚（じゅうまい）ずつクリップ **をもって** 留（と）めておいてください。（日常用品，不适用）
- (〇) この紙（かみ）を10枚（じゅうまい）ずつクリップ **で** 留（と）めておいてください。（正确）
