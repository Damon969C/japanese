# 23 傾向（けいこう）・状態（じょうたい）・様子（ようす） (倾向・状态・样态)

物事（ものごと）にどのような傾向（けいこう）・状態（じょうたい）があるか、また人（ひと）や動作（どうさ）がどのように見（み）えるかを述（の）べる時（とき）、どの表現（ひょうげん）を使（つか）えばよいでしょうか。（说明事物具有何种倾向或状态，以及人或动作呈现何种样态时，应使用哪些表达？）

| 核心功能 | 句型 | 语感重点 |
| :--- | :--- | :--- |
| 经常出现某种不良倾向 | 〜がち | 频率高、容易如此 |
| 大量存在或附着 | 〜だらけ | 多带负面评价 |
| 像……、容易…… | 〜っぽい | 外观近似、性格或反复倾向 |
| 稍微出现某种状态 | 〜気味（ぎみ） | 程度轻、常为暂时状态 |
| 本质上有不良倾向 | 〜きらいがある | 正式、带批评 |
| 表面沾满某物 | 〜まみれ | 液体、粉尘等附着全身／表面 |
| 清一色、尽是 | 〜ずくめ | 同类事物连续或占满 |
| 仿佛……一样 | 〜かのように | 与事实不同的比喻或外观 |
| 以……般的动作方式 | 〜ようにして | 描写动作的姿态、方式 |
| 显出……的样子 | 〜げ | 根据外观判断情绪 |
| 漫无目的／不知何时何地 | 〜ともなく | 无明确意图或对象不定 |
| 保持原有状态 | 〜ながら（に） | 多为固定搭配 |
| 几乎就要……似的 | 〜んばかり | 强烈样态、书面色彩 |

## 学習前（がくしゅうまえ）の小（しょう）テスト (课前小测验)

### 知（し）っていますか

[ a. がち　b. だらけ　c. ようにして　d. っぽい　e. かのように ] の中（なか）の言葉（ことば）を使（つか）って、文（ぶん）を完成（かんせい）させなさい。

1. 忙（いそが）しくて何日（なんにち）も掃除（そうじ）しなかったから、部屋（へや）がほこり（ **b. だらけ** ）だ。
   - **中文理解**：太忙，好几天没打扫，房间里满是灰尘。
2. 山（やま）の上（うえ）で見（み）る星（ほし）は、今（いま）にも降（ふ）ってくる（ **e. かのように** ）近（ちか）く感（かん）じられる。
   - **中文理解**：在山顶看星星，会觉得它们近得仿佛马上要落下来。
3. 外食（がいしょく）ばかりしていると、カルシウムが不足（ふそく）し（ **a. がち** ）になる。
   - **中文理解**：如果总在外面吃饭，就容易缺钙。
4. こんな子（こ）ども（ **d. っぽい** ）服（ふく）はもう着（き）られないよ。
   - **中文理解**：这么孩子气的衣服，我已经不能穿了。
5. かばんの中（なか）に押（お）し込（こ）む（ **c. ようにして** ）、たくさんの書類（しょるい）を入（い）れた。
   - **中文理解**：我把许多文件像硬塞似的装进了包里。

### 使（つか）えますか

文脈（ぶんみゃく）に最（もっと）も自然（しぜん）な方（ほう）を選（えら）びなさい。

1. 週末（しゅうまつ）は { **a. 曇（くも）りがちの天気（てんき）になるそうだ。** ／ b. 晴（は）れがちの天気（てんき）になるそうだ。 }
   - **中文理解**：听说周末天气容易阴沉。
2. { a. 花（はな）だらけの庭（にわ）ですね。きれいですね。／ **b. ごみだらけの庭（にわ）だなあ。掃除（そうじ）した方（ほう）がいいよ。** }
   - **中文理解**：院子里满是垃圾，最好打扫一下。
3. 最近（さいきん）、山田（やまだ）さんは { a. 会社（かいしゃ）を休（やす）みっぽい。疲（つか）れているのだろうか。／ **b. 忘（わす）れっぽくなって困（こま）ったと言（い）っている。** }
   - **中文理解**：最近山田说自己变得很健忘，十分苦恼。
4. { **a. このごろ成績（せいせき）が下（さ）がり気味（ぎみ）で、** ／ b. このごろあの夫婦（ふうふ）は離婚（りこん）気味（ぎみ）で、 } 心配（しんぱい）している。
   - **中文理解**：最近成绩略有下降，我很担心。
5. あの子（こ）はけがをしたのか、 { a. 歩（ある）くようにして足（あし）を引（ひ）きずっています。／ **b. 足（あし）を引（ひ）きずるようにして歩（ある）いています。** }
   - **中文理解**：那个孩子是不是受伤了？他拖着一条腿走路。

> **判断要点**：「だらけ」通常含“太多、杂乱、不理想”的评价，赞美鲜花满园宜说「花（はな）いっぱいの庭（にわ）」。「休（やす）みっぽい」不能表示频繁请假，应说「休（やす）みがち」。「離婚（りこん）気味（ぎみ）」也不自然，因为离婚不是可以略微呈现的连续状态。

## 23 Ⅰ 傾向（けいこう）・状態（じょうたい）

### 23 Ⅰ・1 〜がち ★3

**【意味（いみ）】よく〜する／〜の状態（じょうたい）になることが多（おお）い (常常……；容易处于……状态)**

①わたしは田中（たなか）さんに「手伝（てつだ）ってもらえませんか」と、遠慮（えんりょ） **がちに** 頼（たの）んでみた。
- **中文理解**：我有些拘谨地问田中：“能请你帮个忙吗？”

②昨年（さくねん）は病気（びょうき） **がちの** 一年間（いちねんかん）でしたが、今年（ことし）はとても元気（げんき）に過（す）ごしています。
- **中文理解**：去年一整年经常生病，但今年过得很健康。

③彼（かれ）は物事（ものごと）を甘（あま）く考（かんが）え **がちだ** 。もっと現実（げんじつ）をしっかり見（み）た方（ほう）がいいと思（おも）う。
- **中文理解**：他往往把事情想得太简单。我觉得他应该更认真地面对现实。

**接続（せつぞく）** Vます形（けい）の語幹（ごかん）／N ＋ がち

▶ ある行為（こうい）の回数（かいすう）が多（おお）い、またはある状態（じょうたい）になりやすい傾向（けいこう）を表（あらわ）します。多（おお）くは好（この）ましくない傾向（けいこう）ですが、「遠慮（えんりょ）がち」のように必（かなら）ずしも強（つよ）い非難（ひなん）を含（ふく）まない例（れい）もあります。（表示某行为频繁发生或容易进入某状态，多用于不理想的倾向，但不一定都含强烈批评。）

**【扩展说明】**
常见搭配有「留守（るす）がち・忘（わす）れがち・休（やす）みがち・遅（おく）れがち」。它着重频率和反复性；「疲（つか）れ気味（ぎみ）」只是眼下稍显疲劳，「怒（おこ）りっぽい」则更像容易发怒的性格。

### 23 Ⅰ・2 〜だらけ ★3

**【意味（いみ）】好（この）ましくないものがたくさんある／付（つ）いている (满是……；到处都是……)**

①子（こ）どもたちは泥（どろ） **だらけ** になって遊（あそ）んでいる。
- **中文理解**：孩子们玩得浑身是泥。

②わたしが英語（えいご）で書（か）いた間違（まちが）い **だらけの** 手紙（てがみ）を、ジムに直（なお）してもらった。
- **中文理解**：吉姆帮我修改了那封由我用英语写、错误百出的信。

③この古（ふる）い机（つくえ）はもう傷（きず） **だらけだ** 。でも、大切（たいせつ）な思（おも）い出（で）の品（しな）だから捨（す）てたくない。
- **中文理解**：这张旧桌子已经满是划痕，但它承载着珍贵回忆，所以我不想扔掉。

**接続（せつぞく）** N ＋ だらけ

▶ 目（め）に見（み）える物（もの）だけでなく、「間違（まちが）い・欠点（けってん）」などが大量（たいりょう）にある場合（ばあい）にも使（つか）えます。話（はな）し手（て）が“多（おお）すぎる、乱雑（らんざつ）だ、好（この）ましくない”と評価（ひょうか）することが多（おお）い表現（ひょうげん）です。（既可用于大量可见物，也可用于错误、缺点等抽象事物，常带“过多、杂乱、不理想”的评价。）

**【扩展说明】**
常见搭配有「ほこりだらけ・ごみだらけ・血（ち）だらけ・しわだらけ・穴（あな）だらけ」。美好事物单纯“很多”时通常不用「だらけ」；「花（はな）でいっぱい」「花（はな）に囲（かこ）まれた」更自然。但若说话人嫌花过多，「花（はな）だらけ」也可能成立，因此这不是机械的语法禁令，而是评价语感的差异。

### 23 Ⅰ・3 〜っぽい ★2

**【意味（いみ）】〜の感（かん）じがする／すぐ〜する傾向（けいこう）がある (有……的感觉；容易……)**

①あの黒（くろ） **っぽい** セーターを着（き）ている人（ひと）が田中（たなか）さんです。
- **中文理解**：穿那件偏黑色毛衣的人就是田中。

②花子（はなこ）は飽（あ）き **っぽい** 。何（なに）をやってもすぐ辞（や）めてしまう。
- **中文理解**：花子容易厌倦，无论做什么都很快放弃。

③父（ちち）は怒（おこ）り **っぽくて** 、小（ちい）さいことでもすぐ怒（おこ）る。
- **中文理解**：父亲很容易发火，哪怕一点小事也会马上生气。

④あの子（こ）はこのごろ大人（おとな） **っぽく** なったね。
- **中文理解**：那个孩子最近变得很像大人了。

**接続（せつぞく）** Vます形（けい）の語幹（ごかん）／N／イ形容詞（けいようし）の語幹（ごかん）＋ っぽい

▶ 色（いろ）や外見（がいけん）が完全（かんぜん）には同（おな）じでないものの近（ちか）いこと、人（ひと）や物（もの）がある性質（せいしつ）を帯（お）びていること、または同（おな）じ行動（こうどう）を起（お）こしやすいことを表（あらわ）します。（表示颜色或外观近似、带有某种性质，或容易反复做某事。）

**【扩展说明】**
「っぽい」本身按イ形容词活用：子（こ）どもっぽい／子（こ）どもっぽくない／子（こ）どもっぽかった。常见词有「白（しろ）っぽい・水（みず）っぽい・忘（わす）れっぽい・飽（あ）きっぽい」。表示颜色接近时不带负面意义；表示性格或行为倾向时则常有负面评价。

### 23 Ⅰ・4 〜気味（ぎみ） ★2

**【意味（いみ）】少（すこ）し〜の状態（じょうたい）・傾向（けいこう）がある (稍微有些……；略呈……趋势)**

①今日（きょう）はちょっと風邪（かぜ） **気味（ぎみ）なので** 、早（はや）めに帰（かえ）らせてください。
- **中文理解**：今天有点像感冒，请让我早点回去。

②最近（さいきん）、忙（いそが）しい仕事（しごと）が続（つづ）いたので、少（すこ）し疲（つか）れ **気味（ぎみ）です** 。
- **中文理解**：最近工作一直很忙，稍微有些疲劳。

③長雨（ながあめ）のため、このところ工事（こうじ）はかなり遅（おく）れ **気味（ぎみ）だ** 。
- **中文理解**：由于连日下雨，最近工程进度明显有些滞后。

④昨日（きのう）のサッカーの試合（しあい）で、うちのチームは終始（しゅうし）相手（あいて）チームに押（お）され **気味（ぎみ）だった** が、最後（さいご）にゴールを決（き）めた。
- **中文理解**：昨天的足球比赛中，我队始终略显被动，但最后还是进了球。

**接続（せつぞく）** Vます形（けい）の語幹（ごかん）／N ＋ 気味（ぎみ）

▶ 程度（ていど）は強（つよ）くないものの、ある状態（じょうたい）や変化（へんか）の兆（きざ）しが少（すこ）し見（み）えることを表（あらわ）します。多（おお）くは好（この）ましくない状態（じょうたい）に使（つか）います。（表示程度不强，但已略显某种状态或变化迹象，多用于不理想的状态。）

**【扩展说明】**
「気味（ぎみ）」按名词性成分使用：疲（つか）れ気味（ぎみ）だ、疲（つか）れ気味（ぎみ）の人（ひと）、疲（つか）れ気味（ぎみ）なので。常见搭配有「太（ふと）り気味（ぎみ）・不足（ふそく）気味（ぎみ）・緊張（きんちょう）気味（ぎみ）・上（あ）がり気味（ぎみ）」。它常描述目前可观察到的轻微状态，不适合「結婚（けっこん）・離婚（りこん）」这类不能只实现“一点点”的一次性事件。

### 23 Ⅰ・5 〜きらいがある ★1

**【意味（いみ）】好（この）ましくない本質的（ほんしつてき）傾向（けいこう）がある (有某种不良倾向)**

①あの人（ひと）の話（はなし）は、いつも大（おお）げさになる **きらいがある** 。
- **中文理解**：那个人说话总有夸大的倾向。

②田中課長（たなかかちょう）は、大切（たいせつ）な文書（ぶんしょ）を注意深（ちゅういぶか）く読（よ）まない **きらいがある** 。
- **中文理解**：田中科长有不认真阅读重要文件的倾向。

③我々（われわれ）は厳（きび）しい現実（げんじつ）から目（め）をそらすという **きらいがある** のではないか。
- **中文理解**：我们是否有逃避严酷现实的倾向呢？

④メールが普及（ふきゅう）した今（いま）、現代人（げんだいじん）は対面（たいめん）のコミュニケーションを軽視（けいし）する **きらいがある** と思（おも）う。
- **中文理解**：在电子邮件普及的今天，我认为现代人有轻视面对面沟通的倾向。

**接続（せつぞく）** V普通形（ふつうけい）／Nの ＋ きらいがある

▶ 一時的（いちじてき）な様子（ようす）ではなく、人（ひと）・集団（しゅうだん）・社会（しゃかい）などが本質的（ほんしつてき）に持（も）つ好（この）ましくない傾向（けいこう）を、分析的（ぶんせきてき）・批判的（ひはんてき）に述（の）べる硬（かた）い表現（ひょうげん）です。（不是描述一时外观，而是正式、分析性地批评人、群体或社会的固有倾向。）

**【扩展说明】**
常与「どうも・やや・ともすると」搭配。汉字可写作「嫌（きら）い」，但这一语法通常写平假名。「彼（かれ）は今日（きょう）疲（つか）れているきらいがある」不自然，因为这只是临时状态，应说「疲（つか）れ気味（ぎみ）だ」。

### 23 Ⅰ・6 〜まみれ ★1

**【意味（いみ）】液体（えきたい）・粉（こな）などが表面（ひょうめん）全体（ぜんたい）に付（つ）いている (表面沾满……)**

①吉田（よしだ）さんは工事現場（こうじげんば）で、毎日（まいにち）ほこり **まみれ** になって働（はたら）いている。
- **中文理解**：吉田每天在建筑工地工作，弄得满身灰尘。

②足跡（あしあと）から、犯人（はんにん）は泥（どろ） **まみれの** 靴（くつ）を履（は）いていたと思（おも）われる。
- **中文理解**：从脚印推测，犯人当时穿着沾满泥的鞋。

③今日（きょう）は朝（あさ）から農作業（のうさぎょう）で、全身（ぜんしん）汗（あせ） **まみれです** 。
- **中文理解**：今天从早上起一直干农活，现在浑身是汗。

**接続（せつぞく）** N ＋ まみれ

▶ 泥（どろ）・血（ち）・汗（あせ）・油（あぶら）・ほこりなどが、人（ひと）や物（もの）の表面（ひょうめん）に広（ひろ）く付着（ふちゃく）して汚（よご）れている様子（ようす）を表（あらわ）します。（表示泥、血、汗、油、灰尘等广泛附着于人或物体表面，使其显得肮脏。）

**【扩展说明】**
「傷（きず）まみれ」「しわまみれ」通常不自然，因为伤和皱纹不是附着物，应说「傷（きず）だらけ」「しわだらけ」；「間違（まちが）い」也通常说「間違（まちが）いだらけ」。不过「借金（しゃっきん）まみれ・欲（よく）まみれ」のような比喩的（ひゆてき）用法（ようほう）も定着（ていちゃく）しているため，“只能接液体或粉末”也并非绝对。

### 23 Ⅰ・7 〜ずくめ ★1

**【意味（いみ）】同（おな）じ種類（しゅるい）のものばかりで満（み）たされる／続（つづ）く (清一色；尽是……)**

①山田（やまだ）さんの家（うち）は、長男（ちょうなん）の結婚（けっこん）や長女（ちょうじょ）の出産（しゅっさん）など、最近（さいきん）、おめでたいこと **ずくめだ** 。
- **中文理解**：山田家最近尽是喜事，例如长子结婚、长女生产。

②昨日（きのう）のパーティーは和食（わしょく）・洋食（ようしょく）・中華料理（ちゅうかりょうり）など、ごちそう **ずくめだった** 。
- **中文理解**：昨天的聚会上有日餐、西餐和中餐等，尽是美味佳肴。

③就職（しゅうしょく）が内定（ないてい）したり、彼（かれ）からプレゼントが届（とど）いたり、今日（きょう）は朝（あさ）からいいこと **ずくめだ** 。
- **中文理解**：工作定下来了，又收到了他寄来的礼物，今天从早上起尽是好事。

④黒（くろ） **ずくめの** 男（おとこ）が玄関（げんかん）の前（まえ）に立（た）っていた。
- **中文理解**：一个从头到脚一身黑的男人站在门前。

**接続（せつぞく）** N ＋ ずくめ

▶ 同（おな）じ性質（せいしつ）・種類（しゅるい）の物（もの）や出来事（できごと）が続（つづ）いたり、全体（ぜんたい）を占（し）めたりすることを表（あらわ）します。よいことにも悪（わる）いことにも使（つか）えますが、「いいことずくめ・おめでたいことずくめ」など、よい例（れい）が多（おお）く見（み）られます。（表示同一性质或种类的事物连续出现或占据整体，可用于好事或坏事。）

**【扩展说明】**
「黒（くろ）ずくめ」表示衣帽鞋等整体清一色为黑色；「規則（きそく）ずくめ」可表示处处都是规章。它强调“同类统一占满”，「だらけ」则强调大量散布并常带脏乱、缺陷等负面评价。

## 23 Ⅱ 様子（ようす）

### 23 Ⅱ・1 〜かのように・〜かのような・〜かのようだ ★2

**【意味（いみ）】実際（じっさい）はそうでないが、まるで〜ように見（み）える (仿佛……一样)**

①彼女（かのじょ）は事故（じこ）の後（あと）も、何事（なにごと）もなかった **かのように** 明（あか）るく振（ふ）る舞（ま）っていた。
